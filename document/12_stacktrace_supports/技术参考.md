## 1. x86_64 调用约定

### 1.1 System V AMD64 ABI

x86_64 上的 UNIX 系统遵循 System V AMD64 ABI 调用约定。

#### 寄存器用途

| 寄存器 | 用途 | 调用后 |
|--------|------|--------|
| `RAX` | 返回值 | 修改 |
| `RBX` | 被调用者保存 | 保留 |
| `RCX` | 第 4 个参数 | 修改 |
| `RDX` | 第 3 个参数 | 修改 |
| `RSP` | 栈指针 | 保留 |
| `RBP` | 帧指针 (可选) | 保留 |
| `RSI` | 第 2 个参数 | 修改 |
| `RDI` | 第 1 个参数 | 修改 |
| `R8` | 第 5 个参数 | 修改 |
| `R9` | 第 6 个参数 | 修改 |
| `R10-R15` | 被调用者保存 | 保留 |

#### 参数传递顺序

```
参数 1 → RDI
参数 2 → RSI
参数 3 → RDX
参数 4 → RCX
参数 5 → R8
参数 6 → R9
参数 7+ → 栈上
```

#### 栈帧结构

```
高地址
    +------------------+  <- 上一个栈帧
    |  保存的 RBP      |  [RBP]
    +------------------+  <- 当前 RBP 指向这里
    |  返回地址        |  [RBP + 8]
    +------------------+
    |  参数 7 (如果有) |  [RBP + 16]
    +------------------+
    |  参数 8 (如果有) |  [RBP + 24]
    +------------------+
    |  局部变量 1      |  [RBP - 8]
    +------------------+
    |  局部变量 2      |  [RBP - 16]
    +------------------+
    |  Red Zone        |  [RBP - 128 ~ RBP]
    +------------------+  <- 当前 RSP
低地址
```

#### Red Zone

- **大小**: 128 字节
- **用途**: 允许函数在栈指针下方使用临时空间
- **限制**: 信号/中断处理时不可用

### 1.2 函数序言 (Prologue) 和尾声 (Epilogue)

#### 标准序言

```asm
push rbp              ; 保存调用者的 RBP
mov rbp, rsp          ; 设置新的帧指针
; 可选: sub rsp, N     ; 为局部变量分配空间
```

#### 标准尾声

```asm
mov rsp, rbp          ; 恢复栈指针
pop rbp               ; 恢复调用者的 RBP
ret                   ; 返回 (弹出返回地址)
```

## 2. 栈回溯系统

### 2.1 配置常量

**文件**: [`kernel/stacktrace/stacktrace.h`](../../kernel/stacktrace/stacktrace.h)

```c
// 默认最大栈帧数
#define DUMP_STACK_DEFAULT_FRAMES 16

// 最大允许栈帧数 (防止无限循环)
#define DUMP_STACK_MAX_FRAMES 64
```

### 2.2 核心接口

#### dump_stack

打印当前栈回溯。

```c
void dump_stack(int max_frames);
```

**参数**:
- `max_frames`: 最大栈帧数量 (0 表示使用默认值)

**行为**:
1. 读取当前 RSP 和 RBP
2. 遍历栈帧链
3. 对每个返回地址查找符号
4. 打印格式化的栈回溯

#### dump_stack_full

使用默认参数打印栈回溯。

```c
void dump_stack_full(void);
```

**等价于**:
```c
dump_stack(DUMP_STACK_DEFAULT_FRAMES);
```

### 2.3 内部函数

#### get_rsp

获取当前栈指针。

```c
static inline uintptr_t get_rsp(void);
```

**返回值**: 当前 RSP 寄存器值

#### get_rbp

获取当前帧指针。

```c
static inline uintptr_t get_rbp(void);
```

**返回值**: 当前 RBP 寄存器值

#### is_valid_frame

验证帧指针是否有效。

```c
static bool is_valid_frame(uintptr_t ptr);
```

**验证规则**:
1. 8 字节对齐检查
2. 栈边界检查 (STACK_BASE ± STACK_SIZE)

## 3. 符号解析系统

### 3.1 数据结构

**文件**: [`kernel/stacktrace/symbol.h`](../../kernel/stacktrace/symbol.h)

#### symbol_entry_t

符号表条目。

```c
typedef struct {
    uintptr_t address;     /**< 符号地址 */
    const char* name;      /**< 指向字符串表的指针 */
} symbol_entry_t;
```

#### symbol_table_t

符号表。

```c
typedef struct {
    const symbol_entry_t* entries;  /**< 符号条目数组 */
    int count;                      /**< 符号数量 */
    uintptr_t text_start;           /**< .text 段起始地址 */
    uintptr_t text_end;             /**< .text 段结束地址 */
} symbol_table_t;
```

### 3.2 符号查找

#### get_symbol_table

获取符号表。

```c
const symbol_table_t* get_symbol_table(void);
```

**返回值**: 指向全局符号表的指针

#### find_symbol

查找地址对应的符号。

```c
bool find_symbol(uintptr_t addr,
                const char** out_name,
                uintptr_t* out_offset);
```

**参数**:
- `addr`: 要查找的地址
- `out_name`: 输出符号名称
- `out_offset`: 输出相对于符号起始的偏移量

**返回值**:
- `true`: 找到符号
- `false`: 未找到符号

**算法**: 二分查找 (O(log n))

#### format_symbol

格式化地址为符号字符串。

```c
void format_symbol(char* buffer, size_t size, uintptr_t addr);
```

**输出格式**:
- 有符号: `function_name`
- 有偏移: `function_name + 0x12`
- 未找到: `0x7c00`

### 5.2 使用示例

#### 基本使用

```c
#include "stacktrace/stacktrace.h"

void debug_function() {
    klog_info("Current stack trace:\n");
    dump_stack_full();
}
```

#### 错误处理中使用

```c
void panic(const char* message) {
    klog_error("KERNEL PANIC: %s\n", message);
    klog_error("Stack trace:\n");
    dump_stack_full();
    while (1) {
        __asm__ volatile("hlt");
    }
}
```

#### 条件转储

```c
void assert_impl(bool condition, const char* expr) {
    if (!condition) {
        klog_error("Assertion failed: %s\n", expr);
        dump_stack(32);  // 打印更多栈帧
        halt();
    }
}
```

## 6. 符号提取脚本

### 6.1 脚本位置

**文件**: [`scripts/extract_symbols.py`](../../scripts/extract_symbols.py)

### 6.2 使用方法

```bash
# 基本用法
python scripts/extract_symbols.py build/kernel/kernel.elf

# 指定输出文件
python scripts/extract_symbols.py build/kernel/kernel.elf -o kernel/stacktrace/symbols.c

# 显示详细信息
python scripts/extract_symbols.py build/kernel/kernel.elf --verbose
```

### 6.3 脚本功能

1. **解析 ELF 文件**
   - 读取 `.symtab` 段
   - 提取函数符号
   - 过滤零地址符号

2. **生成代码**
   - 符号字符串表
   - 符号条目数组
   - 段边界标记

3. **优化**
   - 按地址排序
   - 去重符号
   - 紧凑字符串表

```bash
# 安装 PyELF 工具
pip install pyelftools
```

## 7. 编译配置

### 7.1 CMake 配置

**文件**: [`kernel/stacktrace/CMakeLists.txt`](../../kernel/stacktrace/CMakeLists.txt)

```cmake
# 定义栈回溯库
add_library(stacktrace STATIC
    stacktrace.c
    symbol.c
    symbols.c
)

target_include_directories(stacktrace PUBLIC
    ${CMAKE_CURRENT_SOURCE_DIR}
)

# 链接依赖
target_link_libraries(stacktrace PUBLIC klogs)

# 确保保留帧指针
target_compile_options(stacktrace PUBLIC
    -fno-omit-frame-pointer
    -fno-optimize-sibling-calls
)
```

### 7.2 符号表生成规则

```cmake
# 添加自定义命令生成符号表
add_custom_command(
    OUTPUT ${CMAKE_CURRENT_SOURCE_DIR}/symbols.c
    COMMAND python3 ${PROJECT_SOURCE_DIR}/scripts/extract_symbols.py
        $<TARGET_FILE:kernel>
        -o ${CMAKE_CURRENT_SOURCE_DIR}/symbols.c
    DEPENDS kernel
    COMMENT "Generating symbol table..."
)

# 符号表源文件依赖于生成的文件
set_source_files_properties(
    ${CMAKE_CURRENT_SOURCE_DIR}/symbols.c
    PROPERTIES GENERATED TRUE
    OBJECT_DEPENDS ${CMAKE_CURRENT_SOURCE_DIR}/symbols.c
)
```

### 7.3 全局编译选项

确保所有目标保留帧指针：

```cmake
# 顶层 CMakeLists.txt
target_compile_options(kernel PUBLIC
    -fno-omit-frame-pointer    # 保留帧指针
    -fno-optimize-sibling-calls # 禁用尾调用优化
)
```

## 8. 内存布局

### 8.1 符号表内存

```
地址          大小      用途
─────────────────────────────────
0x...        可变      符号字符串表
0x...        N * 16    符号条目数组
0x...        8         text_start
0x...        8         text_end
```

### 8.2 栈内存

```
地址          内容
─────────────────────────────────
0x80000      栈顶 (STACK_BASE)
             ...
0x7f000      当前 RBP
0x7ef08      返回地址
             ...
0x70000      栈底 (STACK_BASE - STACK_SIZE)
```

## 9. 性能特征

### 9.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `dump_stack` | O(n) | n 为栈帧数量 |
| `find_symbol` | O(log m) | m 为符号数量 |
| `format_symbol` | O(log m) | 包含二分查找 |

### 9.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 符号表 | O(m) | m 为符号数量 |
| 字符串表 | O(s) | s 为所有符号名长度 |
| 栈遍历 | O(1) | 只使用局部变量 |
