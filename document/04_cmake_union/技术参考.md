# CCOS CMake 构建系统与 C 内核 - 技术参考

本文档提供 CMake 构建系统、链接脚本、Freestanding C 环境等技术细节的完整参考。

---

## 1. CMake 技术参考

### 1.1 基础语法

#### project()
声明项目名称和使用的语言：

```cmake
project(CCOS_x64 ASM C)
```

- `CCOS_x64` - 项目名称
- `ASM` - 支持汇编语言（NASM）
- `C` - 支持 C 语言

#### cmake_minimum_required()
指定最低 CMake 版本：

```cmake
cmake_minimum_required(VERSION 3.20)
```

### 1.2 工具链检测

#### find_program()
查找可执行文件：

```cmake
find_program(NASM nasm REQUIRED)
find_program(QEMU qemu-system-x86_64 REQUIRED)
```

- `NASM` - 存储结果的变量名
- `nasm` - 要查找的程序名
- `REQUIRED` - 如果找不到则报错

使用结果：
```cmake
if(NOT NASM)
    message(FATAL_ERROR "NASM not found")
endif()
message(STATUS "Found NASM: ${NASM}")
```

#### find_package()
查找第三方包（未来可能使用）：

```cmake
find_package(GCC REQUIRED)
find_package(Binutils REQUIRED)
```

### 1.3 编译选项

#### add_compile_options()
添加编译选项：

```cmake
add_compile_options(
    $<$<COMPILE_LANGUAGE:C>:-Wall>
    $<$<COMPILE_LANGUAGE:C>:-Wextra>
)
```

#### 生成器表达式
- `$<COMPILE_LANGUAGE:C>` - 仅对 C 文件应用
- `$<CONFIG:Debug>` - 仅在 Debug 配置时应用
- `$<BOOL:condition>` - 条件为真时应用

示例：
```cmake
$<$<COMPILE_LANGUAGE:C>:-Wall>           # C 文件添加 -Wall
$<$<CONFIG:Debug>:-g>                    # Debug 配置添加 -g
$<$<CXX_COMPILER_ID:Clang>:-Wno-everything>  # Clang 编译器时
```

#### set(CMAKE_C_FLAGS_...)
设置特定配置的编译标志：

```cmake
set(CMAKE_C_FLAGS_DEBUG "-g -O0")
set(CMAKE_C_FLAGS_RELEASE "-O2 -DNDEBUG")
```

### 1.4 目录和输出

#### CMAKE_BINARY_DIR
构建目录路径：
```cmake
message(STATUS "Build directory: ${CMAKE_BINARY_DIR}")
# 输出: /path/to/project/build
```

#### CMAKE_SOURCE_DIR
源码目录路径：
```cmake
message(STATUS "Source directory: ${CMAKE_SOURCE_DIR}")
# 输出: /path/to/project
```

#### set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ...)
设置输出目录：
```cmake
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR})
set(CMAKE_LIBRARY_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)
set(CMAKE_ARCHIVE_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)
```

### 1.5 自定义命令和目标

#### add_custom_command()
添加自定义构建命令：

```cmake
add_custom_command(
    OUTPUT ${CMAKE_BINARY_DIR}/bootloader.bin
    COMMAND ${NASM} -f bin
        ${CMAKE_CURRENT_SOURCE_DIR}/bootloader.asm
        -o ${CMAKE_BINARY_DIR}/bootloader.bin
    DEPENDS ${CMAKE_CURRENT_SOURCE_DIR}/bootloader.asm
    COMMENT "Building bootloader"
    VERBATIM
)
```

参数说明：
- `OUTPUT` - 输出文件
- `COMMAND` - 要执行的命令
- `DEPENDS` - 依赖文件
- `COMMENT` - 构建时显示的注释
- `VERBATIM` - 正确处理参数中的空格

#### add_custom_target()
添加自定义目标：

```cmake
add_custom_target(bootloader DEPENDS ${CMAKE_BINARY_DIR}/bootloader.bin)
```

```cmake
add_custom_target(run
    COMMAND ${QEMU} -drive format=raw,file=${CMAKE_BINARY_DIR}/boot.img
    DEPENDS boot_img
    COMMENT "Running CCOS"
    VERBATIM
)
```

### 1.6 子目录

#### add_subdirectory()
添加子目录：

```cmake
add_subdirectory(boot)
add_subdirectory(kernel)
```

子目录中需要有自己的 `CMakeLists.txt`。

#### CMAKE_CURRENT_SOURCE_DIR
当前 CMakeLists.txt 所在目录：

```cmake
# 在 boot/CMakeLists.txt 中
message(STATUS "Boot source: ${CMAKE_CURRENT_SOURCE_DIR}")
# 输出: /path/to/project/boot
```

### 1.7 库和目标

#### add_library()
添加库目标：

```cmake
# OBJECT 库 - 只编译，不归档
add_library(kernel_main OBJECT
    kernel_main.c
)

# 静态库
add_library(kernel STATIC
    kernel_main.c
)
```

#### target_include_directories()
设置目标的包含目录：

```cmake
target_include_directories(kernel_main PUBLIC
    ${CMAKE_CURRENT_SOURCE_DIR}/include
    ${CMAKE_BINARY_DIR}/include
)
```

- `PUBLIC` - 对此目标和使用此目标的目标可见
- `PRIVATE` - 仅对此目标可见
- `INTERFACE` - 仅对使用此目标的目标可见

#### target_sources()
向目标添加源文件：

```cmake
target_sources(kernel_main PRIVATE
    more_code.c
    another.c
)
```

### 1.8 配置文件

#### configure_file()
生成配置文件：

```cmake
configure_file(
    ${CMAKE_SOURCE_DIR}/cmake/ccos_config.h.in
    ${CMAKE_BINARY_DIR}/include/ccos_config.h
)
```

模板文件 (`ccos_config.h.in`)：
```c
#ifndef CCOS_CONFIG_H
#define CCOS_CONFIG_H

#cmakedefine CCOS_ENABLE_SERIAL 1
#cmakedefine CCOS_ENABLE_QEMU_DEBUG 1

#define CCOS_BUILD_TYPE "@CMAKE_BUILD_TYPE@"
#define CCOS_VERSION "0.1.0"

#endif
```

生成的文件 (`ccos_config.h`)：
```c
#ifndef CCOS_CONFIG_H
#define CCOS_CONFIG_H

/* #define CCOS_ENABLE_SERIAL 1 */  // 未定义时注释掉
#define CCOS_ENABLE_QEMU_DEBUG 1     // 定义时保留

#define CCOS_BUILD_TYPE "Debug"
#define CCOS_VERSION "0.1.0"

#endif
```

### 1.9 选项

#### option()
定义构建选项：

```cmake
option(CCOS_ENABLE_SERIAL "Enable serial port debug output" OFF)
option(CCOS_ENABLE_QEMU_DEBUG "Enable QEMU debug target" OFF)
```

使用选项：
```cmake
if(CCOS_ENABLE_SERIAL)
    add_compile_options(-DCCOS_SERIAL=1)
endif()
```

命令行使用：
```bash
cmake -DCCOS_ENABLE_SERIAL=ON -B build
```

## 2. 链接脚本技术参考

### 2.1 基本结构

```ld
ENTRY(kernel_start)

SECTIONS
{
    . = 0x10000;

    .text : { *(.text) }
    .rodata : { *(.rodata) }
    .data : { *(.data) }
    .bss : { __bss_start = .; *(.bss) __bss_end = .; }
}
```

### 2.2 关键指令

#### ENTRY()
指定入口点：

```ld
ENTRY(kernel_start)
```

等效于：
```bash
ld -e kernel_start ...
```

#### SECTIONS
定义段布局：

```ld
SECTIONS
{
    . = 0x10000;  /* 设置位置计数器 */
    .text : { ... }  /* 定义 .text 段 */
}
```

#### 位置计数器 `.`
表示当前位置：

```ld
. = 0x10000;    /* 设置为 0x10000 */
. = ALIGN(16);  /* 对齐到 16 字节边界 */
```

### 2.3 段定义语法

```ld
.段名 : {
    输入段模式
    输入段模式
    ...
} > 区域 = 填充值
```

示例：
```ld
.text : {
    *(.text)           /* 所有文件的 .text 段 */
    *(.text.*)         /* 所有文件的 .text.* 段 */
    KEEP(*(.init))     /* 保留特定段，不被优化掉 */
} > RAM = 0xff
```

### 2.4 符号定义

在段内定义符号：

```ld
.bss : {
    __bss_start = .;   /* 定义符号，指向当前地址 */
    *(.bss)
    *(COMMON)
    __bss_end = .;     /* 定义结束符号 */
}
```

在 C 代码中使用：
```c
extern uint8_t __bss_start;
extern uint8_t __bss_end;
```

### 2.5 通配符模式

| 模式 | 匹配 | 示例 |
|------|------|------|
| `*(.text)` | 所有文件的 .text | 所有 .text 段 |
| `*(.text.*)` | 所有 .text.* | .text.hot, .text.unlikely |
| `kernel/*.o(.text)` | kernel 目录下 | kernel/main.o 的 .text |
| `*(EXCLUDE_FILE(*test.o).text)` | 排除 test.o | 除 test.o 外的 .text |

### 2.6 常用段

```ld
SECTIONS
{
    /* 代码段 */
    .text : {
        *(.text)
        *(.text.*)
    }

    /* 只读数据 */
    .rodata : {
        *(.rodata)
        *(.rodata.*)
    }

    /* 已初始化数据 */
    .data : {
        *(.data)
        *(.data.*)
    }

    /* 未初始化数据 */
    .bss : {
        __bss_start = .;
        *(.bss)
        *(.bss.*)
        *(COMMON)
        __bss_end = .;
    }
}
```

### 2.7 丢弃段

```ld
/DISCARD/ : {
    *(.comment)
    *(.eh_frame)
    *(.note.gnu.build-id)
}
```

### 2.8 对齐

```ld
. = ALIGN(16);     /* 对齐到 16 字节 */
. = ALIGN(4K);     /* 对齐到 4KB */
```

## 3. Freestanding C 技术参考

### 3.1 编译选项

| 选项 | 含义 | 原因 |
|------|------|------|
| `-ffreestanding` | 声明为 freestanding 环境 | 不假设标准库存在 |
| `-fno-builtin` | 禁用内置函数 | 避免依赖 libc 实现 |
| `-fno-stack-protector` | 禁用栈保护 | 需要 __stack_chk_fail |
| `-nostdlib` | 不链接标准库 | 我们没有标准库 |
| `-nostdinc` | 不包含标准头文件 | 系统没有标准头文件 |
| `-nostartfiles` | 不使用标准启动文件 | 我们有自己的入口 |
| `-nodefaultlibs` | 不链接默认库 | 完全自包含 |
| `-mcmodel=large` | 大代码模型 | 支持大内核 |

### 3.2 类型大小

| 类型 | 大小 | 说明 |
|------|------|------|
| `char` | 1 字节 | |
| `short` | 2 字节 | |
| `int` | 4 字节 | |
| `long` | 8 字节 | LP64 模型 |
| `long long` | 8 字节 | |
| `void *` | 8 字节 | 64 位指针 |
| `size_t` | 8 字节 | 等同于 `unsigned long` |

### 3.3 调用约定

#### System V AMD64 ABI

**整数/指针参数**（顺序）：
1. RDI, RSI, RDX, RCX, R8, R9
2. 栈（从右向左）

**返回值**：
- 整数/指针: RAX
- 浮点: XMM0

**被调用者保存**：RBX, RBP, R12, R13, R14, R15
**调用者保存**：RAX, RCX, RDX, RSI, RDI, R8, R9, R10, R11

示例：
```c
// 函数: long add(long a, long b, long c);
// 调用时: a=RDI, b=RSI, c=RDX
// 返回值: RAX
```

### 3.4 内联汇编

#### 基本语法

```c
__asm__ volatile(
    "assembly code"
    : output operands    /* 可选 */
    : input operands     /* 可选 */
    : clobbers           /* 可选 */
);
```

#### 示例

HLT 指令：
```c
__asm__ volatile("hlt");
```

带输入输出：
```c
uint64_t cr3;
__asm__ volatile(
    "mov %%cr3, %0"
    : "=r"(cr3)    /* 输出到 cr3 变量 */
);
```

端口 I/O：
```c
// outb(val, port)
__asm__ volatile(
    "outb %0, %1"
    :
    : "a"(val), "Nd"(port)
);
```

#### 约束代码

| 代码 | 含义 | 示例 |
|------|------|------|
| `r` | 任何通用寄存器 | `"r"(var)` |
| `a` | RAX | `"a"(var)` |
| `b` | RBX | `"b"(var)` |
| `c` | RCX | `"c"(var)` |
| `d` | RDX | `"d"(var)` |
| `S` | RSI | `"S"(var)` |
| `D` | RDI | `"D"(var)` |
| `N` | 立即数 (0-255) | `"N"(port)` |
| `m` | 内存操作数 | `"m"(var)` |

## 4. 汇编与 C 接口

### 4.1 声明外部符号

#### C 调用汇编

汇编导出：
```assembly
global my_asm_function
my_asm_function:
    mov rax, 42
    ret
```

C 声明：
```c
extern long my_asm_function(void);
```

#### 汇编调用 C

C 定义：
```c
void c_function(int param);
```

汇编声明：
```assembly
extern c_function

call_c_func:
    mov rdi, 42      ; 第一个参数
    call c_function
    ret
```

### 4.2 符号可见性

| 指令 | 含义 |
|------|------|
| `global symbol` | 导出符号，可被其他文件访问 |
| `extern symbol` | 导入符号，定义在其他文件 |
| (无修饰) | 局部符号，仅当前文件可见 |

### 4.3 多文件链接

```ld
/* 链接多个目标文件 */
ld -m elf_x86_64 -T linker.ld \
   kernel_entry.o \
   kernel_main.o \
   -o kernel.elf
```

## 5. QEMU 参数参考

### 5.1 磁盘参数

```bash
-drive format=raw,file=boot.img,if=ide
```

| 参数 | 值 | 含义 |
|------|---|------|
| `format` | raw | 磁盘格式（原始镜像） |
| `file` | boot.img | 镜像文件路径 |
| `if` | ide | 接口类型（ide, scsi, sd, virtio...） |

### 5.2 显示参数

```bash
-nographic              # 纯文本模式
-display gtk           # GTK 窗口
-display sdl           # SDL 窗口
-display vnc=:0        # VNC 服务器（端口 5900）
-vga std               # 标准 VGA
-vga virtio            # Virtio VGA
```

### 5.3 调试参数

```bash
-s          # 启用 GDB 服务器（端口 1234）
-S          # 启动时暂停 CPU
```

### 5.4 串口参数

```bash
-serial stdio          # 串口重定向到 stdin/stdout
-serial file:log.txt   # 串口输出到文件
-serial pty            # 伪终端
```

## 6. 常用工具参考

### 6.1 objdump

查看 ELF 信息：
```bash
objdump -f build/kernel.elf          # 文件头
objdump -h build/kernel.elf          # 段表
objdump -d build/kernel.elf          # 反汇编
objdump -t build/kernel.elf          # 符号表
objdump -s build/kernel.elf          # 内容
```

### 6.2 objcopy

提取二进制：
```bash
objcopy -O binary kernel.elf kernel.bin
```

只提取特定段：
```bash
objcopy -O binary --only-section=.text kernel.elf text.bin
```

### 6.3 readelf

查看 ELF 详细信息：
```bash
readelf -h kernel.elf    # ELF 头
readelf -S kernel.elf    # 段表
readelf -s kernel.elf    # 符号表
readelf -l kernel.elf    # 程序头
```

### 6.4 nm

列出符号：
```bash
nm kernel.elf            # 所有符号
nm -u kernel.elf         # 未定义符号
nm -g kernel.elf         # 外部符号
nm --size-sort kernel.elf # 按大小排序
```

### 6.5 size

查看段大小：
```bash
size kernel.elf
# 输出: text    data     bss     dec     hex filename
#       120       0       4     124      7c kernel.elf
```

## 7. 内存布局参考

### 7.1 x86_64 内存映射

| 地址范围 | 用途 |
|---------|------|
| 0x00000000 - 0x00000FFF | Null 指针检测区 |
| 0x00001000 - 0x00007FFF | 低内存保留区 |
| 0x00007C00 - 0x00007DFF | Bootloader (MBR) |
| 0x00007E00 - 0x00007FFF | Bootloader (Stage 2) |
| 0x00008000 - 0x0009FFFF | 可用低内存 |
| 0x000A0000 - 0x000BFFFF | VGA 显存 |
| 0x000C0000 - 0x000FFFFF | BIOS ROM 区域 |
| 0x00100000 - 0x00FFFFFF | 可用扩展内存 |
| 0x00800000 - 0x00FFFFFF | 内核可用区域 |
| 0x100000 - 0x1FFFFF | 内核加载区域 |

### 7.2 CCOS 内存布局

```
┌─────────────────────────────────────────────────────┐
│ 0x00000000                                           │
│   └─ Null 指针检测区 (4KB)                          │
├─────────────────────────────────────────────────────┤
│ 0x00007C00                                           │
│   └─ Bootloader - Stage 1 (512B)                    │
├─────────────────────────────────────────────────────┤
│ 0x00007E00                                           │
│   └─ Bootloader - Stage 2 (~1KB)                    │
├─────────────────────────────────────────────────────┤
│ 0x00010000 (= 64KB)                                  │
│   └─ 内核代码 (text)                                │
│   └─ 内核只读数据 (rodata)                          │
│   └─ 内核数据 (data)                                │
│   └─ 内核 BSS (bss)                                 │
├─────────────────────────────────────────────────────┤
│ 0x00080000 (= 512KB)                                 │
│   └─ 栈顶 (向下增长 ~8KB)                           │
├─────────────────────────────────────────────────────┤
│ 0x000B8000 (= 744KB)                                 │
│   └─ VGA 文本缓冲区 (80x25x2 = 4000B)              │
└─────────────────────────────────────────────────────┘
```

## 8. VGA 缓冲区参考

### 8.1 文本模式 VGA

| 属性 | 值 |
|------|---|
| 分辨率 | 80 字符 × 25 行 |
| 内存地址 | 0xB8000 |
| 总大小 | 80 × 25 × 2 = 4000 字节 |
| 每字符大小 | 2 字节 (1 字符 + 1 属性) |

### 8.2 字符格式

```
偏移 0: 字符 ASCII 码
偏移 1: 颜色属性
```

### 8.3 颜色属性

| 位 | 含义 |
|----|------|
| 0-2 | 前景色 (0-7) |
| 3 | 前景亮度 |
| 4-6 | 背景色 (0-7) |
| 7 | 背景闪烁/亮度 |

颜色值：
```
0 = 黑    1 = 蓝    2 = 绿    3 = 青
4 = 红    5 = 品红  6 = 棕    7 = 白
```

示例：
```c
// 白色(15) 背景，蓝色(1) 前景 = 0x1F
uint16_t attr = 0x1F;
uint16_t entry = ('C' & 0xFF) | (attr << 8);
vga[offset] = entry;
```

### 8.4 行偏移计算

```c
// 计算第 n 行的第 m 列的偏移
size_t offset = n * 80 + m;  // 字符单位
size_t byte_offset = offset * 2;  // 字节单位
```

简写（当前项目使用）：
```c
vga[160 * line + col * 2] = character;
vga[160 * line + col * 2 + 1] = attribute;
// 或合并写入
vga[80 * line + col] = (attr << 8) | char;
```
