# CCOS CMake 构建系统与 C 内核 - 调试工具指南

本文档介绍在使用 CMake 构建系统和 C 内核时的调试工具和方法。

---

## 1. CMake 调试构建

### 1.1 Debug 配置

```bash
# 配置为 Debug 模式
cmake -B build -DCMAKE_BUILD_TYPE=Debug

# 查看当前配置
cmake -B build -LA
```

Debug 模式特点：
- 包含调试符号 (`-g`)
- 无优化 (`-O0`)
- 便于单步调试
- 代码执行效率低

### 1.2 Release 配置

```bash
# 配置为 Release 模式
cmake -B build -DCMAKE_BUILD_TYPE=Release
```

Release 模式特点：
- 包含少量调试信息
- 优化 (`-O2`)
- 定义 `NDEBUG` 宏
- 代码执行效率高

### 1.3 查看编译命令

```bash
# 显示详细编译命令
cmake --build build --verbose

# 或使用环境变量
VERBOSE=1 cmake --build build
```

## 2. GDB 调试 C 内核

### 2.1 准备工作

确保使用 Debug 构建：
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

### 2.2 启动调试会话

**终端 1** - 启动 QEMU：
```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -s -S
```

参数说明：
- `-s` - 启用 GDB 服务器（端口 1234）
- `-S` - 启动时暂停 CPU

**终端 2** - 连接 GDB：
```bash
gdb build/kernel.elf
```

### 2.3 GDB 基本命令

#### 连接和运行
```gdb
(gdb) target remote :1234      # 连接到 QEMU
(gdb) break kernel_start       # 设置断点
(gdb) continue                 # 继续执行
(gdb) step                     # 单步执行（进入函数）
(gdb) next                     # 单步执行（跳过函数）
(gdb) finish                   # 跳出当前函数
```

#### 断点管理
```gdb
(gdb) break kernel_main        # 在函数入口设置断点
(gdb) break *0x10000           # 在地址设置断点
(gdb) break kernel_main.c:12   # 在源文件行设置断点
(gdb) info breakpoints         # 查看所有断点
(gdb) delete 1                 # 删除断点 1
(gdb) disable 1                # 禁用断点 1
(gdb) enable 1                 # 启用断点 1
```

#### 查看代码
```gdb
(gdb) list                     # 列出当前代码
(gdb) list kernel_main         # 列出函数代码
(gdb) list 1,20                # 列出行范围
(gdb) disas                    # 反汇编当前函数
```

#### 查看变量
```gdb
(gdb) print vga                # 打印变量值
(gdb) print *vga@10            # 打印数组
(gdb) whatis vga               # 查看变量类型
(gdb) info locals              # 查看所有局部变量
```

#### 查看内存
```gdb
(gdb) x/10x 0xB8000            # 以十六进制查看内存
(gdb) x/10i 0x10000            # 反汇编并查看指令
(gdb) x/10s 0xB8000            # 查看字符串
```

#### 查看寄存器
```gdb
(gdb) info registers           # 所有寄存器
(gdb) print $rsp               # 打印特定寄存器
(gdb) print $rip
```

#### 查看栈
```gdb
(gdb) backtrace                # 查看调用栈
(gdb) frame 0                  # 切换栈帧
(gdb) info frame               # 查看当前栈帧信息
```

### 2.4 汇编与 C 混合调试

```gdb
(gdb) disas kernel_start       # 反汇编汇编函数
(gdb) break *kernel_start+10   # 在汇编代码中设置断点
(gdb) stepi                    # 单步执行指令
(gdb) nexti                    # 单步执行指令（跳过调用）
```

### 2.5 自动化调试

创建 `.gdbinit` 文件：
```
target remote :1234
break kernel_main
break kernel_start
continue
```

然后直接运行 `gdb build/kernel.elf`，自动执行这些命令。

## 3. CMake 调试技巧

### 3.1 查看生成的内容

```bash
# 查看所有缓存变量
cmake -B build -LA

# 查看特定变量
cmake -B build -D CMAKE_BUILD_TYPE=Debug -LA | grep CMAKE
```

### 3.2 添加调试输出

在 CMakeLists.txt 中添加：
```cmake
message(STATUS "NASM: ${NASM}")
message(STATUS "Build type: ${CMAKE_BUILD_TYPE}")
message(STATUS "Compiler: ${CMAKE_C_COMPILER}")
message(STATUS "Flags: ${CMAKE_C_FLAGS}")
```

### 3.3 条件编译调试

在 CMake 中：
```cmake
option(CCOS_DEBUG_VERBOSE "Enable verbose debug output" OFF)

if(CCOS_DEBUG_VERBOSE)
    add_compile_options(-DDEBUG_VERBOSE)
endif()
```

在 C 代码中：
```c
#ifdef DEBUG_VERBOSE
    kprintf("Debug: vga = %p\n", vga);
#endif
```

### 3.4 追踪依赖

```bash
# 重新扫描依赖
cmake --build build --remove-first

# 查看依赖关系
cmake --graphviz=build/graph.dot build
```

## 4. 常见调试场景

### 4.1 链接错误调试

**症状**：链接时出现未定义引用

```bash
# 查看目标文件内容
nm build/kernel_entry.o
nm build/kernel_main.o

# 查看未定义符号
nm -u build/kernel_main.o

# 查看符号是否定义
nm -A build/kernel_entry.o | grep kernel_main
```

### 4.2 内存布局调试

**查看 ELF 布局**：
```bash
objdump -h build/kernel.elf
readelf -S build/kernel.elf
```

**检查符号地址**：
```bash
nm build/kernel.elf | grep kernel_main
```

**检查 BSS 符号**：
```bash
nm build/kernel.elf | grep __bss
```

### 4.3 编译器标志验证

**查看实际使用的编译命令**：
```bash
cmake --build build --verbose 2>&1 | grep gcc
```

**手动编译测试**：
```bash
# 提取编译命令并手动运行
gcc -c -ffreestanding -fno-builtin -nostdlib \
    -mcmodel=large -m64 -O0 -g \
    -Ikernel/include \
    kernel/kernel_main.c -o test.o
```

### 4.4 运行时调试

**QEMU 监控器**：
```bash
# 在 QEMU 中按 Ctrl+A, C 进入监控器
(qemu) info registers     # 查看寄存器
(qemu) xp /10x 0xB8000    # 查看物理内存
(qemu) x /10i $rip        # 查看当前指令
(qemu) quit               # 退出
```

## 5. VSCode 调试集成

### 5.1 配置文件

创建 `.vscode/launch.json`：

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Debug CCOS Kernel",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/build/kernel.elf",
            "miDebuggerServerAddress": "localhost:1234",
            "miDebuggerPath": "/usr/bin/gdb",
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "description": "Enable pretty printing",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "Set breakpoint",
                    "text": "-break-insert kernel_main",
                    "ignoreFailures": false
                },
                {
                    "description": "Continue",
                    "text": "-exec continue",
                    "ignoreFailures": false
                }
            ],
            "preLaunchTask": "start-qemu-debug"
        }
    ]
}
```

### 5.2 任务配置

创建 `.vscode/tasks.json`：

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "start-qemu-debug",
            "type": "shell",
            "command": "qemu-system-x86_64",
            "args": [
                "-drive", "format=raw,file=${workspaceFolder}/build/boot.img",
                "-nographic",
                "-s",
                "-S"
            ],
            "isBackground": true,
            "problemMatcher": []
        },
        {
            "label": "build-debug",
            "type": "shell",
            "command": "cmake",
            "args": ["--build", "build", "--config", "Debug"],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}
```

## 6. 性能分析

### 6.1 QEMU 性能分析

```bash
# 启用性能计数器（需要特殊配置）
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -d in_asm,cpu,exec
```

### 6.2 代码大小分析

```bash
# 查看各段大小
size build/kernel.elf

# 详细段信息
readelf -S build/kernel.elf | grep -E "\.text|\.data|\.bss"

# 符号大小
nm --size-sort build/kernel.elf
```

## 7. 日志和输出

### 7.1 串口输出

修改 CMake 配置启用串口：
```bash
cmake -B build -DCCOS_ENABLE_SERIAL=ON
```

运行时重定向串口：
```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -serial stdio
```

### 7.2 VGA 输出调试

由于 VGA 输出需要图形界面，可以：
1. 使用 VNC 后端
2. 截取 VGA 内容

```bash
# 使用 VNC
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -display vnc=:0

# 连接
vncviewer localhost:5900
```

## 8. 常用调试命令速查

### CMake
| 命令 | 功能 |
|------|------|
| `cmake -B build -DCMAKE_BUILD_TYPE=Debug` | 配置 Debug 构建 |
| `cmake --build build --verbose` | 显示详细编译命令 |
| `cmake -B build -LA` | 列出所有缓存变量 |
| `cmake --build build --target clean` | 清理构建 |

### GDB
| 命令 | 功能 |
|------|------|
| `target remote :1234` | 连接到远程调试 |
| `break kernel_main` | 设置断点 |
| `continue` | 继续执行 |
| `step` / `next` | 单步执行 |
| `print var` | 打印变量 |
| `backtrace` | 查看调用栈 |
| `disas` | 反汇编 |

### 二进制工具
| 命令 | 功能 |
|------|------|
| `objdump -d kernel.elf` | 反汇编 |
| `objdump -h kernel.elf` | 显示段信息 |
| `nm kernel.elf` | 显示符号表 |
| `readelf -S kernel.elf` | 显示段表 |
| `size kernel.elf` | 显示段大小 |
| `strings kernel.elf` | 显示可打印字符串 |
