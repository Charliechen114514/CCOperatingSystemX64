## 初始化问题

### 问题 1：用户态子系统初始化失败

**症状**：
```
[USER] Failed to initialize user mode subsystem
```

**可能原因**：
1. VMM 未初始化
2. 页帧分配器不可用
3. 内核栈配置错误

**诊断步骤**：
```c
// 检查初始化顺序
void kernel_init(void) {
    pframe_init();    // 1. 物理帧
    vmm_init();       // 2. 虚拟内存
    proc_init();      // 3. 进程管理
    // 确保上面都成功后再调用
    if (user_init() != 0) {
        klog_error("user_init failed\n");
        while(1) halt();
    }
}
```

**解决方案**：
1. 确保 `vmm_init()` 在 `user_init()` 之前调用
2. 检查 `USER_BASE` 和 `USER_END` 常量定义
3. 验证页帧分配器正常工作

## 用户进程创建问题

### 问题 2：用户进程创建失败

**症状**：
```
[USER] Failed to create user process
[USER] Failed to allocate user stack page
```

**可能原因**：
1. 物理内存不足
2. 用户空间创建失败
3. 页映射权限错误

**诊断步骤**：
```c
// 添加详细错误日志
int user_create_process(virtual_addr_t entry, pcb_t* pcb) {
    klog_trace("[USER] Allocating user stack...\n");

    for (size_t i = 0; i < stack_pages; i++) {
        physical_addr_t paddr;
        if (pframe_alloc(&paddr) != PFRAME_OK) {
            klog_error("[USER] Page allocation failed at page %zu\n", i);
            // 回滚...
            return -1;
        }

        vmm_result_t result = vmm_map_to_user(pcb->mm.pml4_phys, vaddr, paddr, 1,
                                               VMAP_FLAG_WRITE | VMAP_FLAG_USER);
        if (result != VMM_OK) {
            klog_error("[USER] Page mapping failed at 0x%llX\n", vaddr);
            // 回滚...
            return -1;
        }
    }
}
```

**解决方案**：
1. 增加物理内存
2. 检查 `vmm_map_to_user` 权限标志
3. 验证 PML4 页表有效

---

### 问题 3：用户栈地址未对齐

**症状**：
```
[PAGE FAULT] at 0x...
[USER] Stack misalignment detected
```

**可能原因**：
1. 栈地址未页对齐
2. `USER_END` 未对齐

**解决方案**：
```c
// 确保页对齐
pcb->user_stack = (USER_END - USER_STACK_SIZE) & ~(PAGE_SIZE - 1);

// 或者使用更明确的宏
pcb->user_stack = ALIGN_DOWN(USER_END - USER_STACK_SIZE, PAGE_SIZE);
```

## 系统调用问题

### 问题 4：系统调用参数验证失败

**症状**：
```
[SYSCALL] Invalid user pointer
uname() failed!
```

**可能原因**：
1. 用户指针指向内核空间
2. 指针范围计算溢出
3. 验证函数逻辑错误

**诊断步骤**：
```c
// 在系统调用处理中添加验证
static int64_t sys_uname(syscall_frame_t* frame) {
    struct utsname* buf = (struct utsname*)frame->arg0;

    klog_debug("[SYSCALL] uname called with buf=0x%llX\n", buf);

    if (!user_validate_pointer(buf, sizeof(struct utsname), true)) {
        klog_warn("[SYSCALL] Invalid user pointer: 0x%llX\n", buf);
        return SYS_ERR_INVAL;
    }

    // ...
}
```

**解决方案**：
```c
// 确保 user_validate_pointer 正确
bool user_validate_pointer(const void* ptr, size_t size, bool write) {
    virtual_addr_t addr = (virtual_addr_t)ptr;

    if (!vmm_is_user_addr(addr)) {
        klog_debug("[USER] Not user addr: 0x%llX\n", addr);
        return false;
    }

    if (addr + size < addr) {  // 溢出检查
        klog_debug("[USER] Overflow detected\n");
        return false;
    }

    if (addr + size > USER_END) {
        klog_debug("[USER] Exceeds USER_END\n");
        return false;
    }

    return true;
}
```

### 问题 5：系统调用返回值错误

**症状**：
```
uname() returned -1 instead of 0
```

**可能原因**：
1. 复制到用户空间失败
2. 返回值未正确设置
3. 用户地址映射错误

**解决方案**：
```c
static int64_t sys_uname(syscall_frame_t* frame) {
    struct utsname* buf = (struct utsname*)frame->arg0;

    if (!user_validate_pointer(buf, sizeof(struct utsname), true)) {
        return SYS_ERR_INVAL;
    }

    struct utsname kernel_info = { /* ... */ };

    // 检查复制结果
    int64_t copied = user_copy_to_user(buf, &kernel_info,
                                       sizeof(struct utsname));
    if (copied < 0) {
        klog_error("[SYSCALL] Copy to user failed\n");
        return SYS_ERR_IO;
    }

    return SYS_OK;  // 确保返回成功
}
```

## 内存管理问题

### 问题 6：brk 系统调用失败

**症状**：
```
malloc() failed
brk() returned -1
```

**可能原因**：
1. 新断点超出用户空间
2. 页分配失败
3. 断点未正确初始化

**诊断步骤**：
```c
// 添加调试信息
virtual_addr_t user_brk(pcb_t* pcb, virtual_addr_t new_brk) {
    klog_debug("[BRK] old_brk=0x%llX, new_brk=0x%llX\n",
              pcb->mm.brk, new_brk);

    if (new_brk == 0) {
        klog_debug("[BRK] Query current brk: 0x%llX\n", pcb->mm.brk);
        return pcb->mm.brk;
    }

    // 检查范围
    if (new_brk < USER_BASE || new_brk >= (USER_END - USER_STACK_SIZE)) {
        klog_warn("[BRK] Invalid brk address\n");
        return pcb->mm.brk;
    }

    // ...
}
```

**解决方案**：
1. 确保初始 brk 正确设置
2. 检查用户空间范围常量
3. 验证页分配器可用

### 问题 7：mmap 映射失败

**症状**：
```
mmap() returned NULL
```

**可能原因**：
1. 标志不支持 (如 MAP_SHARED)
2. 地址未对齐
3. 页分配失败

**解决方案**：
```c
// 检查标志支持
static int64_t sys_mmap(syscall_frame_t* frame) {
    int flags = (int)frame->arg3;

    // 只支持匿名映射
    if (!(flags & MAP_ANONYMOUS)) {
        klog_warn("[MMAP] Only anonymous mappings supported\n");
        return SYS_ERR_NOTIMPL;
    }

    // ...
}
```

### 问题 8：符号重定义错误

**症状**：
```
multiple definition of '_start'
undefined reference to 'write'
```

**可能原因**：
1. 用户程序和内核符号冲突
2. 用户库未正确链接
3. 符号可见性问题

**解决方案**：
```cmake

    -nostdlib
    -static

# 自定义入口点
target_link_options(uname_test PRIVATE
    -Wl,-e_start
)
```

### 问题 9：段选择器错误

**症状**：
```
[GENERAL PROTECTION FAULT]
```

**可能原因**：
1. 用户 CS/SS 选择器错误
2. RPL 未设置为 3
3. GDT 条目未配置

**解决方案**：
```c
// 确保正确设置 RPL
#define USER_CS    (0x18 | 3)   // 11000 | 11 = 11011 = 0x1B
#define USER_SS    (0x20 | 3)   // 11100 | 11 = 11111 = 0x23

// 验证 GDT 配置
// GDT[3] = 用户代码段 (base=0, limit=0xFFFFF, type=Code, DPL=3)
// GDT[4] = 用户数据段 (base=0, limit=0xFFFFF, type=Data, DPL=3)
```

## Ring 3 切换问题

### 问题 10：iretq 切换失败

**症状**：
```
[DOUBLE FAULT] after iretq
```

**可能原因**：
1. iretq 栈帧顺序错误
2. 用户栈指针无效
3. RFLAGS 值错误

**解决方案**：
```assembly
; 正确的 iretq 栈帧顺序
; (从低地址到高地址)
user_ss      ; 必须是 0x23
user_rsp     ; 必须是有效的用户栈地址
user_rflags  ; IF=1 (0x202)
user_cs      ; 必须是 0x1B
user_rip     ; 用户代码入口

; 压栈顺序 (注意：栈向下增长)
push user_ss      ; 第1个压入
push user_rsp     ; 第2个压入
push user_rflags  ; 第3个压入
push user_cs      ; 第4个压入
push user_rip     ; 第5个压入
iretq
```

---

### 问题 11：段寄存器未设置

**症状**：
```
用户程序访问数据时崩溃
```

**可能原因**：
1. DS/ES/FS/GS 未设置
2. 指向了内核数据段

**解决方案**：
```assembly
; 在 iretq 前设置所有数据段
mov ax, 0x23    ; USER_SS
mov ds, ax
mov es, ax
mov fs, ax
mov gs, ax

iretq
```

## 常见错误码

| 错误码 | 含义 | 常见原因 |
|--------|------|----------|
| SYS_OK (0) | 成功 | - |
| SYS_ERR_INVAL (-22) | 无效参数 | 用户指针无效 |
| SYS_ERR_NFILE (-9) | 坏文件描述符 | fd 超出范围 |
| SYS_ERR_NOENT (-2) | 文件不存在 | 路径无效 |
| SYS_ERR_NOTIMPL (-38) | 未实现 | 功能不支持 |
| SYS_ERR_IO (-5) | I/O 错误 | 复制到用户失败 |

    // 测试 1: 用户指针验证
    char* user_ptr = (char*)0x400000;
