## 1. 数据结构定义

### 1.1 进程控制块 (PCB)

进程控制块是进程管理的核心数据结构，定义在 [`kernel/process/process.h`](../../kernel/process/process.h)：

```c
typedef struct pcb {
    /* ===== 进程标识 ===== */
    int32_t            pid;            /* 进程 ID */
    int32_t            ppid;           /* 父进程 ID */

    /* ===== 进程状态 ===== */
    process_state_t    state;          /* 当前状态 */
    int32_t            exit_code;      /* 退出码 (如果为僵尸) */

    /* ===== 调度相关 ===== */
    list_head          run_list;       /* 运行队列链表 */
    list_head          siblings;       /* 兄弟链表 (父进程的子进程列表) */
    list_head          children;       /* 子进程链表 */
    list_head          zombie_children;/* 可回收的僵尸子进程 */

    /* ===== 内存上下文 ===== */
    memory_context_t   mm;             /* 地址空间信息 */

    /* ===== CPU 上下文 ===== */
    cpu_context_t*     cpu_ctx;        /* 保存的内核上下文 */
    trap_frame_t*      trap_frame;     /* 用户陷阱帧 */
    virtual_addr_t     kernel_stack;   /* 内核栈顶 (用于 TSS.rsp0) */
    virtual_addr_t     kernel_stack_base; /* 内核栈基址 */

    /* ===== 父子关系 ===== */
    struct pcb*        parent;         /* 父进程指针 */

    /* ===== 统计信息 ===== */
    uint64_t           start_time;     /* 进程创建时间 */
    char               comm[16];       /* 命令名称 */
} pcb_t;
```

**内存布局**：
- PCB 结构本身：约 200 字节
- CPU 上下文：56 字节（动态分配）
- 内核栈：16 KB（动态分配）
- **总计**：约 16.3 KB/进程

### 1.2 CPU 上下文

```c
typedef struct PACKED cpu_context {
    uint64_t rbx;        /* callee-saved */
    uint64_t rbp;        /* callee-saved */
    uint64_t r12;        /* callee-saved */
    uint64_t r13;        /* callee-saved */
    uint64_t r14;        /* callee-saved */
    uint64_t r15;        /* callee-saved */
    uint64_t rsp;        /* 栈指针 */
    uint64_t rip;        /* 返回地址 */
} cpu_context_t;
```

**保存位置**：[`kernel/process/switch.s`](../../kernel/process/switch.s) 中 `switch_context()` 函数

**设计说明**：
- 只保存 callee-saved 寄存器（System V AMD64 ABI）
- RAX、RCX、RDX、RSI、RDI、R8-R11 由调用者保护
- RIP 保存返回地址，用于恢复执行

### 1.3 陷阱帧

```c
typedef struct PACKED trap_frame {
    /* 通用寄存器 */
    uint64_t rax;
    uint64_t rbx;
    uint64_t rcx;
    uint64_t rdx;
    uint64_t rsi;
    uint64_t rdi;
    uint64_t rbp;
    uint64_t r8;
    uint64_t r9;
    uint64_t r10;
    uint64_t r11;
    uint64_t r12;
    uint64_t r13;
    uint64_t r14;
    uint64_t r15;

    /* 中断/系统调用信息 */
    uint64_t vector;      /* 中断向量 */
    uint64_t error_code;  /* 错误码 */

    /* 返回信息 */
    uint64_t rip;
    uint64_t cs;
    uint64_t rflags;
    uint64_t rsp;
    uint64_t ss;
} trap_frame_t;
```

**用途**：从用户态进入内核时保存完整上下文

### 1.4 内存上下文

```c
typedef struct memory_context {
    physical_addr_t pml4_phys;    /* PML4 物理地址 */
    virtual_addr_t  brk;          /* 程序断点 (堆结束) */

```

### 1.5 调度器结构

```c
typedef struct scheduler {
    list_head          run_queue;      /* 运行队列 */
```

## 2. 常量定义

### 2.1 进程常量

| 常量 | 值 | 说明 |
|:-----|:---|:-----|
| `PID_MAX` | 32768 | 最大进程数 |
| `KERNEL_STACK_SIZE` | 16384 (16KB) | 内核栈大小 |
| `USER_STACK` | `USER_END - PAGE_SIZE` | 用户栈地址 |

### 2.2 进程状态

```c
typedef enum process_state {
    PROC_READY    = 0,    /* 就绪：可运行 */
    PROC_RUNNING  = 1,    /* 运行中：当前执行 */
    PROC_BLOCKED  = 2,    /* 阻塞：等待事件 */
    PROC_ZOMBIE   = 3,    /* 僵尸：已退出，等待回收 */
} process_state_t;
```

**状态转换规则**：
- `READY → RUNNING`: 被 `schedule()` 选中
- `RUNNING → READY`: 时间片用完（未实现）
- `RUNNING → BLOCKED`: 调用 `wait4()` 等
- `RUNNING → ZOMBIE`: 调用 `exit()`
- `BLOCKED → READY`: 等待的事件发生

### 2.3 内存区域常量

```c
/* 堆区域 - 堆分配器专用 */
#define KERNEL_HEAP_BASE     0xFFFFFFFF81000000ULL
#define KERNEL_HEAP_SIZE     (128 * 1024 * 1024)   /* 128MB */
#define KERNEL_HEAP_MAX      (KERNEL_HEAP_BASE + KERNEL_HEAP_SIZE)

/* 通用分配区域 - VMM demo 等使用 */
#define KERNEL_GENERAL_BASE  0xFFFFFFFF88000000ULL
#define KERNEL_GENERAL_SIZE  (128 * 1024 * 1024)   /* 128MB */
#define KERNEL_GENERAL_MAX   (KERNEL_GENERAL_BASE + KERNEL_GENERAL_SIZE)
```

## 3. API 参考

### 3.1 进程管理 API

定义于 [`kernel/process/process.h`](../../kernel/process/process.h)：

#### proc_init()

```c
int proc_init(void);
```

**功能**：初始化进程子系统

**返回**：
- `0`: 成功
- `<0`: 失败

**副作用**：
- 初始化调度器
- 初始化 PID 分配器

---

#### proc_fork()

```c
int32_t proc_fork(void);
```

**功能**：创建新进程（fork 系统调用的内核实现）

**返回**：
- `>0`: 父进程，返回子进程 PID
- `0`: 子进程
- `<0`: 失败

**实现步骤**：
1. 分配子进程 PCB
2. 分配 PID
3. 设置父进程关系
4. 复制地址空间（当前为空实现）
5. 添加到运行队列

---

#### proc_exit()

```c
void proc_exit(int exit_code) __attribute__((noreturn));
```

**功能**：退出当前进程

**参数**：
- `exit_code`: 退出码

**副作用**：
- 设置进程为 ZOMBIE 状态
- 从运行队列移除
- 触发调度器
- **永不返回**

---

#### proc_wait4()

```c
int32_t proc_wait4(int32_t pid, int* wstatus, int options);
```

**功能**：等待子进程退出

**参数**：
- `pid`: 等待的进程 ID（-1 表示任意子进程）
- `wstatus`: 输出参数，存储退出状态
- `options`: 选项（当前未实现）

**返回**：
- `>0`: 退出的子进程 PID
- `<0`: 失败

---

#### proc_current()

```c
static inline pcb_t* proc_current(void);
```

**功能**：获取当前进程指针

**返回**：当前进程的 PCB 指针，或 NULL

---

#### proc_find()

```c
pcb_t* proc_find(int32_t pid);
```

**功能**：根据 PID 查找进程

**参数**：
- `pid`: 要查找的进程 ID

**返回**：进程的 PCB 指针，或 NULL

**复杂度**：O(n)，遍历运行队列

---

#### schedule()

```c
void schedule(void);
```

**功能**：调度下一个进程运行

**副作用**：
- 保存当前进程状态
- 切换到下一个进程
- 可能永不返回到当前调用点

---

### 3.2 PID 分配器 API

#### pid_alloc_init()

```c
void pid_alloc_init(void);
```

**功能**：初始化 PID 分配器

**副作用**：
- 初始化 bitmap
- 保留 PID 0

---

#### pid_alloc()

```c
int32_t pid_alloc(void);
```

**功能**：分配一个新的 PID

**返回**：
- `>=0`: 分配的 PID
- `-1`: 失败（PID 耗尽）

---

#### pid_free()

```c
void pid_free(int32_t pid);
```

**功能**：释放 PID

**参数**：
- `pid`: 要释放的 PID（必须 > 0）

---

### 3.3 TSS 扩展 API

新增于 [`kernel/interrupt/tss.h`](../../kernel/interrupt/tss.h)：

#### tss_set_kernel_stack_ctx()

```c
void tss_set_kernel_stack_ctx(virtual_addr_t stack_top);
```

**功能**：设置内核栈（用于进程上下文切换）

**参数**：
- `stack_top`: 内核栈顶地址（栈 grows down）

**用途**：
- 从汇编 `switch_context()` 调用
- 更新 TSS.RSP0 字段

---

### 3.4 VMM 扩展 API

新增于 [`kernel/mm/vmm/vmm.h`](../../kernel/mm/vmm/vmm.h)：

#### vmm_load_pml4()

```c
void vmm_load_pml4(physical_addr_t pml4_phys);
```

**功能**：加载 PML4（切换地址空间）

**参数**：
- `pml4_phys`: PML4 物理地址

**副作用**：
- 修改 CR3 寄存器
- 刷新 TLB
- 切换到新的地址空间

## 4. 上下文切换详解

### 4.1 switch_context 流程

定义于 [`kernel/process/switch.s`](../../kernel/process/switch.s)：

```asm
global switch_context
switch_context:
    ; 参数: RDI = &prev (指针的指针), RSI = next

    ; === 保存当前进程状态 ===
    push rbx
    push rbp
    push r12
    push r13
    push r14
    push r15

    ; 获取 prev PCB 指针
    mov rax, [rdi]           ; rax = *prev

    ; 保存 RSP 和 RIP
    mov [rax + pcb.cpu_ctx + cpu_ctx.rsp], rsp
    mov r15, [rsp + 48]      ; 返回地址在栈上的偏移
    mov [rax + pcb.cpu_ctx + cpu_ctx.rip], r15

    ; === 切换到下一个进程 ===

    ; 更新 TSS.RSP0
    mov rdi, [rsi + pcb.kernel_stack]
    call tss_set_kernel_stack_ctx

    ; 切换 CR3
    mov rdi, [rsi + pcb.mm_pml4]
    call vmm_load_pml4

    ; 恢复寄存器
    mov rax, [rsi + pcb.cpu_ctx]
    mov rbx, [rax + cpu_ctx.rbx]
    mov rbp, [rax + cpu_ctx.rbp]
    mov r12, [rax + cpu_ctx.r12]
    mov r13, [rax + cpu_ctx.r13]
    mov r14, [rax + cpu_ctx.r14]
    mov r15, [rax + cpu_ctx.r15]
    mov rsp, [rax + cpu_ctx.rsp]

    ; 恢复并返回
    pop r15
    pop r14
    pop r13
    pop r12
    pop rbp
    pop rbx
    ret
```

### 4.2 switch_to_first 流程

```asm
global switch_to_first
switch_to_first:
    ; 参数: RDI = first (首个进程)

    ; 更新 TSS.RSP0
    mov rsi, rdi
    mov rdi, [rsi + pcb.kernel_stack]
    push rsi
    call tss_set_kernel_stack_ctx
    pop rsi

    ; 切换 CR3
    mov rdi, [rsi + pcb.mm_pml4]
    push rsi
    call vmm_load_pml4
    pop rsi

    ; 恢复寄存器
    mov rax, [rsi + pcb.cpu_ctx]
    mov rbx, [rax + cpu_ctx.rbx]
    mov rbp, [rax + cpu_ctx.rbp]
    mov r12, [rax + cpu_ctx.r12]
    mov r13, [rax + cpu_ctx.r13]
    mov r14, [rax + cpu_ctx.r14]
    mov r15, [rax + cpu_ctx.r15]
    mov rsp, [rax + cpu_ctx.rsp]

    ; 跳转到进程入口
    mov rax, [rax + cpu_ctx.rip]
    jmp rax
```

### 4.3 PCB 结构偏移

汇编代码中使用的偏移量（与 C 结构体对应）：

```asm
; pcb_t 偏移
struc pcb
    .pid                resd 1    ; +0
    .ppid               resd 1    ; +4
    .state              resd 1    ; +8
    .exit_code          resd 1    ; +12
    .run_list           resq 2    ; +16, +24
    .siblings           resq 2    ; +32, +40
    .children           resq 2    ; +48, +56
    .zombie_children    resq 2    ; +64, +72
    .mm_pml4            resd 1    ; +80
    .mm_brk             resq 1    ; +88
    .mm_stack_start     resq 1    ; +96
    .cpu_ctx            resq 1    ; +104
    .trap_frame         resq 1    ; +112
    .kernel_stack       resq 1    ; +120
    .kernel_stack_base  resq 1    ; +128
    .parent             resq 1    ; +136
    .start_time         resq 1    ; +144
    .comm               resb 16   ; +152
endstruc

; cpu_context_t 偏移
struc cpu_ctx
    .rbx    resq 1    ; +0
    .rbp    resq 1    ; +8
    .r12    resq 1    ; +16
    .r13    resq 1    ; +24
    .r14    resq 1    ; +32
    .r15    resq 1    ; +40
    .rsp    resq 1    ; +48
    .rip    resq 1    ; +56
endstruc
```

## 5. 系统调用实现

定义于 [`kernel/syscall/syscall_table.c`](../../kernel/syscall/syscall_table.c)：

### 5.1 sys_fork

```c
static int64_t sys_fork(syscall_frame_t* frame) {
    (void)frame;
    int32_t result = proc_fork();
    return (int64_t)result;
}
```

**系统调用号**：`SYS_FORK` (57)

**返回值**：
- 父进程：子进程 PID
- 子进程：0
- 失败：负数

---

### 5.2 sys_exit

```c
static int64_t sys_exit(syscall_frame_t* frame) {
    int exit_code = (int)frame->arg0;
    proc_exit(exit_code);
    __builtin_unreachable();  /* proc_exit 永不返回 */
}
```

**系统调用号**：`SYS_EXIT` (60)

**参数**：`arg0` = 退出码

---

### 5.3 sys_wait4

```c
static int64_t sys_wait4(syscall_frame_t* frame) {
    int32_t pid = (int32_t)frame->arg0;
    int* wstatus = (int*)frame->arg1;
    int options = (int)frame->arg2;
    int32_t result = proc_wait4(pid, wstatus, options);
    return (int64_t)result;
}
```

**系统调用号**：`SYS_WAIT4` (61)

**参数**：
- `arg0`: PID
- `arg1`: wstatus 指针
- `arg2`: options

---

### 5.4 sys_getpid

```c
static int64_t sys_getpid(syscall_frame_t* frame) {
    (void)frame;
    pcb_t* current = proc_current();
    return current ? (int64_t)current->pid : -1;
}
```

**系统调用号**：`SYS_GETPID` (39)

---

### 5.5 sys_getppid

```c
static int64_t sys_getppid(syscall_frame_t* frame) {
    (void)frame;
    pcb_t* current = proc_current();
    if (current && current->parent) {
        return (int64_t)current->parent->pid;
    }
    return 0;
}
```

**系统调用号**：`SYS_GETPPID` (110)
