# 技术参考 - Stage 18 写时复制与异常处理

本文档提供 CCOS Stage 18 写时复制与异常处理机制的技术细节和 API 参考。

---

## 1. 写时复制 (COW) 详解

### 1.1 COW 数据结构

#### cow_block_t

```c
typedef struct cow_block {
    physical_addr_t    orig_phys;     /* 原始物理页地址 (作为键) */
    uint16_t           refcount;      /* 引用计数 (1-COW_MAX_REFCOUNT) */
} cow_block_t;
```

**字段说明**：
- `orig_phys`: 被共享的物理页地址
- `refcount`: 共享该页的虚拟映射数量

#### cow_region_t

```c
typedef struct cow_region {
    virtual_addr_t     start;         /* 区域起始地址 (页对齐) */
    uint64_t           page_count;    /* 页数 */
    physical_addr_t    pml4;          /* 所属地址空间 PML4 */
    struct cow_region* next;          /* 链表下一项 */
} cow_region_t;
```

**用途**：跟踪大型 COW 区域（如 fork 后的整个地址空间）

#### cow_stats_t

```c
typedef struct {
    uint64_t    cow_faults_handled;   /* 处理的 COW 故障数 */
    uint64_t    cow_pages_allocated;  /* 分配的 COW 页总数 */
    uint64_t    cow_pages_freed;      /* 释放的 COW 页总数 */
    uint64_t    cow_current_blocks;   /* 当前 COW 块数 */
    uint64_t    cow_write_faults;     /* COW 页写入故障数 */
    uint64_t    cow_coalesced;        /* 无需复制的页数 (refcount=1) */
} cow_stats_t;
```

### 1.2 COW 常量

```c
/* COW 标志位 (使用页表保留位) */
#define COW_FLAG_MASK          (1ULL << 9)

/* 最大引用计数 */
#define COW_MAX_REFCOUNT       255

/* COW 哈希表大小 */
#define COW_HASH_SIZE          64
```

### 1.3 COW API 参考

#### 初始化函数

```c
cow_result_t cow_init(void);
```
- **返回**: `COW_OK` 成功, `COW_ERR_OOM` 内存不足
- **说明**: 初始化 COW 子系统，创建内部哈希表

```c
bool cow_is_initialized(void);
```
- **返回**: `true` 已初始化, `false` 未初始化

#### 页管理函数

```c
cow_result_t cow_add_page(physical_addr_t phys);
```
- **参数**: `phys` - 物理页地址
- **返回**: `COW_OK` 成功, `COW_ERR_OOM` 内存不足
- **说明**: 将物理页添加到 COW 跟踪，初始引用计数为 1

```c
cow_result_t cow_inc_refcount(physical_addr_t phys);
```
- **参数**: `phys` - 物理页地址
- **返回**: `COW_OK` 成功, `COW_ERR_NOT_COW` 未跟踪
- **说明**: 增加引用计数

```c
cow_result_t cow_dec_refcount(physical_addr_t phys);
```
- **参数**: `phys` - 物理页地址
- **返回**: `COW_OK` 成功, `COW_ERR_NOT_COW` 未跟踪
- **说明**: 减少引用计数，refcount=0 时自动移除

```c
cow_result_t cow_get_refcount(physical_addr_t phys, uint16_t* out_refcount);
```
- **参数**: `phys` - 物理页地址, `out_refcount` - 输出引用计数
- **返回**: `COW_OK` 成功, `COW_ERR_NOT_COW` 未跟踪

#### 区域管理函数

```c
cow_result_t cow_register_region(physical_addr_t pml4,
                                 virtual_addr_t base,
                                 size_t size);
```
- **参数**: `pml4` - 地址空间, `base` - 基地址 (页对齐), `size` - 大小 (页倍数)
- **返回**: `COW_OK` 成功, `COW_ERR_INVALID` 参数无效, `COW_ERR_OOM` 内存不足
- **说明**: 注册区域为 COW，自动处理页对齐和映射

```c
cow_result_t cow_unregister_region(physical_addr_t pml4,
                                   virtual_addr_t base);
```
- **参数**: `pml4` - 地址空间, `base` - 基地址
- **返回**: `COW_OK` 成功
- **说明**: 注销 COW 区域，减少所有页的引用计数

#### 故障处理函数

```c
cow_result_t cow_handle_fault(physical_addr_t pml4, virtual_addr_t fault_addr);
```
- **参数**: `pml4` - 地址空间, `fault_addr` - 故障地址
- **返回**: `COW_OK` 已处理, `COW_ERR_NOT_COW` 非 COW 页
- **说明**: 处理 COW 页写入故障

```c
cow_result_t cow_mark_page_readonly(physical_addr_t pml4, virtual_addr_t vaddr);
```
- **参数**: `pml4` - 地址空间, `vaddr` - 虚拟地址
- **返回**: `COW_OK` 成功
- **说明**: 标记页为只读 + COW 标志

#### 工具函数

```c
static inline bool cow_is_cow_page(uint64_t pte_flags);
```
- **参数**: `pte_flags` - 页表项标志
- **返回**: `true` 是 COW 页, `false` 不是

```c
static inline uint64_t cow_set_cow_flag(uint64_t pte_flags);
```
- **参数**: `pte_flags` - 当前标志
- **返回**: 带有 COW 标志的新标志

```c
static inline uint64_t cow_clear_cow_flag(uint64_t pte_flags);
```
- **参数**: `pte_flags` - 当前标志
- **返回**: 清除 COW 标志的新标志

## 2. 哈希表 API 参考

### 2.1 哈希表类型

```c
typedef size_t (*hash_fn_t)(const void* key);
typedef bool (*hash_eq_fn_t)(const void* a, const void* b);
typedef bool (*hashmap_iterator_fn)(const void* key, void* value, void* context);
```

### 2.2 哈希表函数

```c
hashmap_t* hashmap_create(size_t num_buckets, hash_fn_t hash_fn, hash_eq_fn_t eq_fn);
```
- **参数**: `num_buckets` - 桶数量, `hash_fn` - 哈希函数, `eq_fn` - 比较函数
- **返回**: 哈希表指针, 或 `NULL` 失败

```c
void hashmap_destroy(hashmap_t* map);
```
- **说明**: 销毁哈希表 (不释放键和值)

```c
int hashmap_put(hashmap_t* map, const void* key, void* value);
```
- **返回**: `0` 成功, `-1` 参数无效, `-2` 内存不足

```c
void* hashmap_get(hashmap_t* map, const void* key);
```
- **返回**: 值指针, 或 `NULL` 未找到

```c
void* hashmap_remove(hashmap_t* map, const void* key);
```
- **返回**: 被移除的值, 或 `NULL` 未找到

```c
size_t hashmap_size(hashmap_t* map);
```
- **返回**: 条目数量

```c
bool hashmap_contains(hashmap_t* map, const void* key);
```
- **返回**: `true` 包含, `false` 不包含

```c
void hashmap_clear(hashmap_t* map);
```
- **说明**: 清空所有条目

```c
size_t hashmap_foreach(hashmap_t* map, hashmap_iterator_fn iter_fn, void* context);
```
- **返回**: 迭代的条目数

### 2.3 内置哈希函数

```c
size_t hash_uint64(const void* key);
```
- **说明**: 64位整数哈希 (FNV-1a 风格)

```c
size_t hash_ptr(const void* key);
```
- **说明**: 指针哈希

```c
bool eq_uint64(const void* a, const void* b);
```
- **说明**: 64位整数比较

```c
bool eq_ptr(const void* a, const void* b);
```
- **说明**: 指针比较

## 3. 异常处理详解

### 3.1 异常向量

| 向量 | 异常 | 缩写 | 错误码 | 优先级 |
|------|------|------|--------|--------|
| 8 | Double Fault | #DF | 有 | 最高 |
| 12 | Stack Fault | #SS | 有 | 高 |
| 13 | General Protection Fault | #GP | 有 | 正常 |
| 14 | Page Fault | #PF | 有 | 正常 |

### 3.2 异常错误码

#### GPF 错误码

```
位 0: External event (1=外部, 0=内部)
位 1: IDT descriptor violation (1=IDT, 0=表)
位 2: GDT/LDT violation (1=表, 0=非)
位 3-15: Selector index
```

```c
typedef struct {
    bool external;           /* 外部事件 */
    bool idt_descriptor;     /* IDT 描述符违规 */
    bool gdt_table;          /* GDT/LDT 表违规 */
    bool ti;                 /* 表指示符 (0=GDT, 1=LDT) */
    uint16_t selector_index; /* 选择子索引 */
} gpf_error_info_t;
```

#### Stack Fault 错误码

```
0: 不在栈上访问
1: 栈操作导致异常
```

### 3.3 异常结果码

```c
typedef enum {
    EXC_SUCCESS,           /* 处理成功，可继续 */
    EXC_TERMINATE_PROCESS, /* 应终止当前进程 */
    EXC_KERNEL_PANIC,      /* 不可恢复，必须停机 */
} exception_result_t;
```

### 3.4 异常 API 参考

```c
void exception_init(void);
```
- **说明**: 初始化异常处理器

```c
void double_fault_handler(interrupt_frame_t* frame, uint64_t error_code);
```
- **说明**: Double Fault 处理器 (向量 8)

```c
void stack_fault_handler(interrupt_frame_t* frame, uint64_t error_code);
```
- **说明**: Stack Fault 处理器 (向量 12)

```c
void gp_fault_handler(interrupt_frame_t* frame, uint64_t error_code);
```
- **说明**: GPF 处理器 (向量 13)

```c
void gp_parse_error_code(uint64_t error_code, gpf_error_info_t* info);
```
- **说明**: 解析 GPF 错误码

```c
const char* ss_parse_error_code(uint64_t error_code);
```
- **说明**: 解析 Stack Fault 错误码，返回描述字符串

```c
void exception_get_stats(exception_stats_t* stats);
```

## 4. GDT/TSS 详解

### 4.1 GDT 选择子

```c
#define GDT_NULL        0x00  /* 空描述符 */
#define GDT_KERNEL_CODE 0x08  /* 内核 64位代码 */
#define GDT_KERNEL_DATA 0x10  /* 内核数据 */
#define GDT_USER_CODE   0x18  /* 用户 64位代码 */
#define GDT_USER_DATA   0x20  /* 用户数据 */
#define GDT_TSS         0x28  /* TSS */
```

### 4.2 GDT 访问字节

```c
#define GDT_ACCESS_PRESENT    (1 << 7)   /* 存在位 */
#define GDT_ACCESS_DPL0       (0 << 5)   /* DPL 0 */
#define GDT_ACCESS_DPL3       (3 << 5)   /* DPL 3 */
#define GDT_ACCESS_SYSTEM     (1 << 4)   /* 系统段标志 */
#define GDT_ACCESS_TYPE_CODE  (0xA)      /* 代码段 */
#define GDT_ACCESS_TYPE_DATA  (0x2)      /* 数据段 */
#define GDT_ACCESS_TYPE_TSS   (0x9)      /* 64位 TSS */
```

### 4.3 IST 索引

```c
#define IST_NONE     0    /* 无 IST 切换 */
#define IST_DF       1    /* Double Fault 使用 IST1 */
#define IST_NMI      2    /* NMI 使用 IST2 */
#define IST_DEBUG    3    /* Debug 使用 IST3 */
#define IST_SS       4    /* Stack Fault 使用 IST4 */
```

### 4.4 TSS 结构

```c
typedef struct PACKED tss {
    uint32_t reserved0;    /* 保留 */
    uint64_t rsp0;         /* Ring 0 栈指针 */
    uint64_t rsp1;         /* Ring 1 栈指针 */
    uint64_t rsp2;         /* Ring 2 栈指针 */
    uint64_t reserved1;    /* 保留 */
    uint64_t ist1;         /* IST1: Double Fault 栈 */
    uint64_t ist2;         /* IST2: NMI 栈 */
    uint64_t ist3;         /* IST3: Debug 栈 */
    uint64_t ist4;         /* IST4: Stack Fault 栈 */
    uint64_t ist5;         /* IST5: 保留 */
    uint64_t ist6;         /* IST6: 保留 */
    uint64_t ist7;         /* IST7: 保留 */
    uint64_t reserved2;    /* 保留 */
    uint16_t reserved3;    /* 保留 */
    uint16_t iomap_base;   /* I/O 权限位图基址 */
} __attribute__((aligned(16))) tss_t;
```

### 4.5 GDT/TSS API

- **说明**: 初始化内核 GDT

```c

```
- **说明**: 加载 GDT 和 TSS (汇编实现)

- **返回**: GDT 指针

```c

```
- **说明**: 打印 GDT 条目


## 6. 数据结构布局

### 6.1 页表 COW 标志

```
|63................................10|9|8.....0|
|                               PML4|C|   索引  |
|                               PDPT|O|        |
|                                 PD|W|        |
|                                 PT| |        |
```

第 9 位用作 COW 标志：
- `1`: 页是 COW 页
- `0`: 页不是 COW 页

### 6.2 COW 处理流程

```
写入 COW 页
    │
    ▼
触发 #PF (error_code.P=1, W=1)
    │
    ▼
pf_handler() → 读取 CR2
    │
    ▼
检查 COW 标志 (pte_flags & COW_FLAG_MASK)
    │
    ├─→ 无 COW 标志 → 正常处理
    │
    ▼ 有 COW 标志
cow_handle_fault()
    │
    ▼
查找 COW 块 (hashmap)
    │
    ▼
检查引用计数
    │
    ├─→ refcount = 1 → cow_make_writable()
    │                      ▼
    │                  设置写权限，清除 COW 标志
    │
    └─→ refcount > 1 → cow_copy_on_write()
                           ▼
                       分配新物理页
                           ▼
                       复制内容
                           ▼
                       更新页表
                           ▼
                       减少原页引用计数
```

## 7. 寄存器和内存布局

### 7.1 CR2 寄存器

```
CR2: 页错误地址
当 #PF 发生时，CPU 自动将故障虚拟地址存入 CR2
```

### 7.2 IST 栈布局

```
高地址
    │
    ├─► IST_DF 栈 (16KB)         - Double Fault 使用
    │
    ├─► IST_NMI 栈 (16KB)        - NMI 使用
    │
    ├─► IST_DEBUG 栈 (16KB)      - Debug 使用
    │
    └─► IST_SS 栈 (16KB)         - Stack Fault 使用
    │
低地址
```
