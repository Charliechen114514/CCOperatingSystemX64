## 1. BIOS 内存检测协议

### 1.1 INT 15h/E820 - BIOS 内存地图

#### 功能描述

获取系统内存地图的详细信息，包括每个内存区域的基地址、长度和类型。

#### 调用约定

**输入寄存器：**
```
AX    = 0xE820
BX    = 连续值 (Continuation Value)
         - 首次调用: 0
         - 后续调用: 上一次返回的 BX 值
ES:DI = 缓冲区地址 (指向 E820_ENTRY 结构)
CX    = 缓冲区大小 (建议 24 字节)
EDX   = 'SMAP' 签名 (0x534D4150)
```

**输出寄存器：**
```
CF    = 0 成功, 1 失败
AX    = 'SMAP' 签名 (验证用)
CX    = 实际写入的字节数
ES:DI = 填充后的缓冲区
BX    = 下一次调用的连续值 (0 表示最后一条)
```

#### E820 条目结构

```c
typedef struct PACKED {
    uint64_t base;       // 基地址
    uint64_t length;     // 区域长度 (字节)
    uint32_t type;       // 内存类型
    uint32_t acpi_attrs; // ACPI 扩展属性 (通常为 0)
} e820_entry_t;          // 总大小: 24 字节
```

#### 内存类型定义

| 类型值 | 名称 | 说明 |
|--------|------|------|
| 1 | Usable | 可用 RAM，可自由使用 |
| 2 | Reserved | 保留区域，包含 BIOS、内存映射 I/O |
| 3 | ACPI Reclaimable | ACPI 数据，可被内核回收使用 |
| 4 | ACPI NVS | ACPI NVS 内存，必须保留 |
| 5 | Unusable | 内存区域存在但不可用 |
| 其他 | 保留 | 未来使用 |

#### 调用示例 (汇编)

```asm
detect_memory_e820:
    xor ebx, ebx                    ; BX = 0 (首次调用)
    mov di, E820_STORAGE_ADDR       ; ES:DI = 缓冲区
    mov edx, 'SMAP'                 ; EDX = 'SMAP'
    mov eax, 0xE820                 ; AX = E820

.e820_loop:
    mov ecx, 24                     ; 缓冲区大小
    int 0x15                        ; 调用 BIOS
    jc .e820_failed                 ; CF=1 表示失败
    cmp eax, 'SMAP'                 ; 验证签名
    jne .e820_failed

    ; 条目已存储在 ES:DI
    add di, 24                      ; 移动到下一个条目
    inc byte [e820_entry_count]     ; 增加计数

    test ebx, ebx                   ; BX=0 表示完成
    jnz .e820_loop                  ; 继续获取下一条

    clc                              ; 成功完成
    ret

.e820_failed:
    stc                              ; 设置失败标志
    ret
```

### 1.2 INT 15h/E801 - 简化内存检测

#### 功能描述

获取两个内存区域的内存大小：1MB 以下和 1MB 以上。

#### 调用约定

**输入寄存器：**
```
AX    = 0xE801
```

**输出寄存器：**
```
CF    = 0 成功, 1 失败
AX    = 1MB 以下的内存大小 (KB), 最大 640KB
BX    = 1MB 以下的内存大小 (KB), 最大 640KB (重复)
CX    = 1MB 以上的内存大小 (KB), 最大 16MB-1MB
DX    = 1MB 以上的内存大小 (64KB 单位), 用于超过 16MB 的情况
```

#### 转换为 E820 格式

```c
// Entry 0: 0 ~ 1MB
e820_entry_t entry0 = {
    .base = 0,
    .length = ax * 1024,      // 转换为字节
    .type = E820_TYPE_USABLE
};

// Entry 1: 1MB ~ (1MB + 上限)
uint64_t above_1mb;
if (dx != 0) {
    above_1mb = dx * 64 * 1024;  // 使用 DX (64KB 单位)
} else {
    above_1mb = cx * 1024;       // 使用 CX (KB 单位)
}

e820_entry_t entry1 = {
    .base = 0x100000,           // 1MB
    .length = above_1mb,
    .type = E820_TYPE_USABLE
};
```

### 1.3 INT 15h/AH=88h - 传统内存检测

#### 功能描述

获取系统中最大连续内存的大小（从 0 开始），最大支持 64MB。

#### 调用约定

**输入寄存器：**
```
AH    = 0x88
```

**输出寄存器：**
```
CF    = 0 成功, 1 失败
AX    = 连续内存大小 (KB), 最大 65536 = 64MB
```

#### 转换为 E820 格式

```c
e820_entry_t entry = {
    .base = 0,
    .length = (uint64_t)ax * 1024,
    .type = E820_TYPE_USABLE
};
```

**注意：** 此方法不提供区域信息，假设从 0 到返回值都是可用内存。实际使用时需要手动排除低 1MB 的保留区域。

## 2. 数据结构定义

### 2.1 E820 相关结构

#### e820_mem_type_t

```c
typedef enum {
    E820_TYPE_USABLE = 1,       /* 可用 RAM */
    E820_TYPE_RESERVED = 2,     /* 保留区域 */
    E820_TYPE_ACPI_RECLAIM = 3, /* ACPI 可回收 */
    E820_TYPE_NVS = 4,          /* ACPI NVS */
    E820_TYPE_UNUSABLE = 5,     /* 不可用 */
} e820_mem_type_t;
```

#### mem_detect_method_t

```c
typedef enum {
    MEM_DETECT_E820 = 0,    /* E820 详细地图 */
    MEM_DETECT_E801 = 1,    /* E801 两区域 */
    MEM_DETECT_88H = 2,     /* INT 15h/88h */
    MEM_DETECT_UNKNOWN = 3, /* 无可用方法 */
} mem_detect_method_t;
```

#### e820_entry_t

```c
typedef struct PACKED {
    uint64_t base;       /* 基地址 */
    uint64_t length;     /* 长度 (字节) */
    uint32_t type;       /* 类型 */
    uint32_t acpi_attrs; /* ACPI 属性 */
} e820_entry_t;
```

#### mem_stats_t

```c
typedef struct {
    uint64_t total_bytes;    /* 总内存 (字节) */
    uint64_t usable_bytes;   /* 可用内存 (字节) */
    uint64_t reserved_bytes; /* 保留内存 (字节) */
    uint32_t total_mb;       /* 总内存 (MB) */
    uint32_t usable_mb;      /* 可用内存 (MB) */
    uint32_t entry_count;    /* 条目数量 */
} mem_stats_t;
```

## 3. E820 API 参考

### 3.1 初始化函数

#### void e820_init(void)

**描述：** 初始化 E820 内存地图解析器。

**参数：** 无

**返回值：** 无

**注意：** 必须在任何其他 E820 函数之前调用。

---

### 3.2 查询函数

#### mem_detect_method_t e820_get_detect_method(void)

**描述：** 获取实际使用的内存检测方法。

**返回值：** `mem_detect_method_t` 枚举值

#### const char* e820_get_detect_method_name(mem_detect_method_t method)

**描述：** 获取检测方法的名称字符串。

**参数：**
- `method` - 检测方法

**返回值：** 方法名称字符串（如 "E820"、"E801"、"88h"）

#### uint32_t e820_get_entry_count(void)

**描述：** 获取 E820 条目数量。

**返回值：** 条目数 (0-128)

#### bool e820_get_entry(uint32_t index, e820_entry_t* entry)

**描述：** 获取指定索引的 E820 条目。

**参数：**
- `index` - 条目索引 (0-based)
- `entry` - 指向存储条目的指针

**返回值：**
- `true` - 条目存在
- `false` - 索引超出范围

### 3.3 统计函数

#### void e820_get_stats(mem_stats_t* stats)

- `stats` - 指向存储统计结构的指针

#### uint64_t e820_get_usable_memory_above(uint64_t min_base)

**描述：** 查找指定地址以上最大的可用内存区域大小。

**参数：**
- `min_base` - 最小基地址

**返回值：** 最大可用区域的大小，如果没有则返回 0

#### uint32_t e820_count_usable_regions(void)

**描述：** 统计可用内存区域数量。

**返回值：** 可用区域数量

---

### 3.4 可用性检查

#### bool e820_is_range_usable(uint64_t base, uint64_t length)

**描述：** 检查指定内存范围是否完全可用。

**参数：**
- `base` - 基地址
- `length` - 长度

**返回值：**
- `true` - 范围完全可用
- `false` - 范围包含不可用区域或部分不可用

#### bool e820_find_usable_range(uint64_t min_base, uint64_t min_length, uint64_t* out_base, uint64_t* out_length)

**描述：** 查找满足条件的可用内存区域。

**参数：**
- `min_base` - 最小基地址
- `min_length` - 最小长度要求
- `out_base` - 输出找到的基地址
- `out_length` - 输出找到的长度

**返回值：**
- `true` - 找到满足条件的区域
- `false` - 未找到

## 4. 物理帧分配器 API 参考

### 4.1 初始化

#### pframe_result_t pframe_init(void)

**描述：** 初始化物理帧分配器。

**返回值：**
- `PFRAME_OK` - 初始化成功
- 错误码 - 初始化失败

**执行流程：**
1. 解析 E820 内存地图
2. 计算位图大小
3. 初始化位图（全部设为 1 = 保留）
4. 标记可用内存区域为 0
5. 标记内核和保留区域为 1

---

### 4.2 分配函数

#### pframe_result_t pframe_alloc(physical_addr_t* out_addr)

**描述：** 分配单个物理帧（4KB）。

**参数：**
- `out_addr` - 输出分配的物理地址

**返回值：**
- `PFRAME_OK` - 分配成功
- `PFRAME_ERR_OOM` - 内存不足
- `PFRAME_ERR_NOT_INIT` - 未初始化
- `PFRAME_ERR_INVALID` - 无效参数

**示例：**
```c
physical_addr_t frame;
if (pframe_alloc(&frame) == PFRAME_OK) {
    klog_info("Allocated frame at 0x%llx\n", frame);
}
```

#### pframe_result_t pframe_alloc_n(physical_addr_t* out_addr, uint64_t frame_count)

**描述：** 分配多个连续物理帧。

**参数：**
- `out_addr` - 输出分配的基地址
- `frame_count` - 帧数量

**返回值：**
- `PFRAME_OK` - 分配成功
- `PFRAME_ERR_OOM` - 内存不足或无足够连续空间
- 其他错误码

**示例：**
```c
physical_addr_t frames;
if (pframe_alloc_n(&frames, 16) == PFRAME_OK) {
    klog_info("Allocated 16 frames at 0x%llx\n", frames);
}
```

## 6. 位图操作宏

```c
// 计算位图索引
#define PFRAME_BITMAP_INDEX(frame)  ((frame) / BITS_PER_QWORD)
#define PFRAME_BITMAP_BIT(frame)    ((frame) % BITS_PER_QWORD)

// 帧地址转换
#define PFRAME_ADDR_TO_FRAME(addr)  ((addr) >> PAGE_SHIFT)
#define PFRAME_FRAME_TO_ADDR(frame) ((frame) << PAGE_SHIFT)

// 位操作
#define BITMAP_SET(bitmap, frame) \
    (bitmap)[PFRAME_BITMAP_INDEX(frame)] |= (1ULL << PFRAME_BITMAP_BIT(frame))
#define BITMAP_CLEAR(bitmap, frame) \
    (bitmap)[PFRAME_BITMAP_INDEX(frame)] &= ~(1ULL << PFRAME_BITMAP_BIT(frame))
#define BITMAP_TEST(bitmap, frame) \
    ((bitmap)[PFRAME_BITMAP_INDEX(frame)] & (1ULL << PFRAME_BITMAP_BIT(frame)))
```
