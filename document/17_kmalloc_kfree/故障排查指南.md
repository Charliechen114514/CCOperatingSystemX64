## 初始化问题

### 问题 1.1: heap_init() 返回 HEAP_ERR_OOM

**症状**:
```
[HEAP] Failed to initialize heap!
[VMM] vmm_alloc_pages_at failed
```

**原因**:
- VMM 未初始化
- 物理内存不足
- 堆区域与已映射内存冲突

**解决方案**:

1. 确保正确的初始化顺序：
```c
void kernel_init(void) {
    pframe_init();    // 1. 物理帧管理
    page_init();      // 2. 页表管理
    vmm_init();       // 3. 虚拟内存管理
    heap_init();      // 4. 堆分配器
}
```

2. 检查 VMM 状态：
```c
vmm_stats_t vmm_stats;
vmm_get_stats(&vmm_stats);
klog_trace("VMM free pages: %llu\n", vmm_stats.total_pages - vmm_stats.mapped_pages);
```

3. 检查物理内存：
```c
pframe_stats_t pframe_stats;
pframe_get_stats(&pframe_stats);
klog_trace("Physical free: %llu frames\n", pframe_stats.free_frames);
```

### 问题 1.2: 堆初始化后立即崩溃

**症状**:
```
[HEAP] Heap initialized
[HEAP] Invalid magic at 0x...
```

**原因**:
- 堆区域被其他代码覆盖
- VMM 映射失败但未检测到
- 链接脚本问题

**解决方案**:

1. 验证堆区域未与内核代码/数据重叠：
```bash
# 查看内核内存映射
objdump -h build/kernel.elf
```

2. 检查 VMM 映射：
```c
// 验证堆区域确实已映射
page_query_result_t result;
page_query(page_get_pml4(), KERNEL_HEAP_BASE, &result);
if (!result.present) {
    klog_error("Heap base not mapped!\n");
}
```

## 分配问题

### 问题 2.1: kmalloc 返回 NULL

**症状**:
```c
void* ptr = kmalloc(1024);
if (ptr == NULL) {
    // 内存不足
}
```

**原因**:
- 堆已满
- 堆扩展失败
- 碎片化严重
- size 参数为 0

**解决方案**:

1. 检查堆统计：
```c
heap_stats_t stats;
heap_get_stats(&stats);

klog_trace("Heap: %llu / %llu bytes used\n",
          stats.used_bytes, stats.total_bytes);
klog_trace("Free blocks: %llu\n", stats.free_blocks);

if (stats.free_bytes >= size && stats.free_blocks > 0) {
    // 可能是碎片化问题
} else if (stats.total_bytes >= KERNEL_HEAP_MAX - KERNEL_HEAP_BASE) {
    // 堆已满
}
```

2. 转储堆状态：
```c
heap_dump();  // 查看所有块
```

3. 尝试分配较小的块：
```c
// 分配多个小块代替一个大块
void* part1 = kmalloc(512);
void* part2 = kmalloc(512);
```

### 问题 2.2: 小分配导致大内存消耗

**症状**:
```
分配 1000 个 16 字节对象后，堆扩展了很多次
```

**原因**:
- 每个块有 32 字节头部开销
- 实际使用率低

**分析**:
```
请求: 16 字节
实际: 32 字节 (16 头 + 16 数据)
开销: 50%
```

**解决方案**:

1. 使用内存池：
```c
// 预分配大块，手动管理小对象
void* pool = kmalloc(4096);
// 从 pool 中手动分配 16 字节对象
```

2. 批量分配：
```c
// 一次分配多个对象
struct object* array = kmalloc(1000 * sizeof(struct object));
```

### 问题 2.3: kmalloc_aligned 返回 NULL

**症状**:
```c
void* ptr = kmalloc_aligned(256, 4096);  // 返回 NULL
```

**原因**:
- alignment 不是 2 的幂
- 内存不足
- 对齐要求太高

**解决方案**:

1. 验证对齐值：
```c
bool is_power_of_two(size_t x) {
    return x != 0 && (x & (x - 1)) == 0;
}

if (!is_power_of_two(alignment)) {
    klog_error("Alignment must be power of 2\n");
}
```

2. 使用较小的对齐：
```c
// 4KB 对齐可能失败，尝试 512 字节
void* ptr = kmalloc_aligned(256, 512);
```

## 释放问题

### 问题 3.1: 双重释放

**症状**:
```
[HEAP] Double free at 0x...
```

**原因**:
- 同一指针被释放两次
- 释放后未置 NULL

**示例**:
```c
void* ptr = kmalloc(100);
kfree(ptr);
// ... 其他代码 ...
kfree(ptr);  // 双重释放！
```

**解决方案**:

1. 释放后置 NULL：
```c
void* ptr = kmalloc(100);
kfree(ptr);
ptr = NULL;  // 防止重复释放

// 后续释放是安全的
kfree(ptr);  // NULL 是安全的
```

2. 使用包装函数：
```c
void safe_free(void** ptr) {
    if (ptr != NULL && *ptr != NULL) {
        kfree(*ptr);
        *ptr = NULL;
    }
}

// 使用
safe_free(&ptr);
```

### 问题 3.2: 野指针访问

**症状**:
系统崩溃或行为异常，可能是堆损坏

**原因**:
- 使用已释放的内存
- 释放后继续使用指针

**示例**:
```c
int* ptr = kmalloc(sizeof(int));
kfree(ptr);
*ptr = 42;  // 野指针！
```

**解决方案**:

1. 释放后立即置 NULL：
```c
int* ptr = kmalloc(sizeof(int));
kfree(ptr);
ptr = NULL;  // 必须置 NULL
*ptr = 42;   // 会立即崩溃（更容易发现）
```

2. 使用调试工具：
```c
// 在 kfree 中填充模式
void kfree(void* ptr) {
    // ...
    memset(ptr, 0xCD, block->size - sizeof(heap_block_t));
    // ...
}
```

3. 使用静态分析工具检测

### 问题 3.3: 内存泄漏

**症状**:
```
长期运行后可用内存逐渐减少
```

**原因**:
- 分配的内存未释放
- 引用丢失

**检测**:

1. 定期检查统计：
```c
heap_stats_t stats_before, stats_after;

heap_get_stats(&stats_before);
// ... 执行操作 ...
heap_get_stats(&stats_after);

if (stats_after.used_bytes > stats_before.used_bytes) {
    klog_warn("Possible memory leak: %llu bytes\n",
             stats_after.used_bytes - stats_before.used_bytes);
}
```

2. 使用 heap_dump 查找已用块：
```c
heap_dump();  // 查看所有已使用块
```

3. 实现泄漏检测器：
```c
typedef struct {

    int line;
} alloc_info_t;
```

## 堆损坏问题

### 问题 4.1: 魔数错误

**症状**:
```
[HEAP] Invalid magic at 0x... (expected 0x00114514, got 0x12345678)
```

**原因**:
- 缓冲区溢出覆盖了块头
- 野指针写入
- 多线程竞争

**诊断**:

1. 转储堆状态：
```c
heap_dump();  // 查看所有块的状态
```

2. 检查最近的分配：
```c
// 在分配/释放时打印地址
void* ptr = kmalloc(size);
klog_trace("[DEBUG] Allocated: %p (size=%zu)\n", ptr, size);
```

**解决方案**:

1. 检查缓冲区边界：
```c
char* buf = kmalloc(100);
// 错误：写入超过 100 字节
memset(buf, 0, 200);  // 会覆盖下一个块！

// 正确：只写入分配的大小
memset(buf, 0, 100);
```

2. 添加边界检查：
```c
#ifdef DEBUG
#define SAFE_MEMCPY(dst, src, n) do { \
    if (n > ALLOC_SIZE(dst)) { \
        klog_error("Buffer overflow!\n"); \
    } \
    memcpy(dst, src, n); \
} while(0)
#else
#define SAFE_MEMCPY(dst, src, n) memcpy(dst, src, n)
#endif
```

### 问题 4.2: 块链表损坏

**症状**:
```
[HEAP] Corrupted free list!
遍历 free_list 时崩溃
```

**原因**:
- 块头被覆盖
- next/prev 指针损坏
- 块大小不一致

**诊断**:

1. 验证块一致性：
```c
static bool verify_block(heap_block_t* block) {
    if (block->magic != HEAP_MAGIC) {
        klog_error("Bad magic at %p\n", block);
        return false;
    }

    if (block->size < sizeof(heap_block_t)) {
        klog_error("Invalid size: %llu\n", block->size);
        return false;
    }

    if (block->prev != NULL && block->prev->next != block) {
        klog_error("Broken prev link\n");
        return false;
    }

    if (block->next != NULL && block->next->prev != block) {
        klog_error("Broken next link\n");
        return false;
    }

    return true;
}
```

**解决方案**:

1. 添加完整检查：
```c
void heap_verify(void) {
    heap_block_t* current = (heap_block_t*)s_heap.heap_start;

    while ((virtual_addr_t)current < s_heap.heap_brk) {
        if (!verify_block(current)) {
            klog_error("Heap corruption detected!\n");
            heap_dump();
            return;
        }
        current = (heap_block_t*)((uint8_t*)current + current->size);
    }

    klog_trace("Heap verified OK\n");
}
```

### 问题 5.1: 外部碎片

**症状**:

- 小块无法合并

### 问题 5.2: 内部碎片

**症状**:
```
请求 100 字节，实际使用 200+ 字节
```

**原因**:
- 对齐开销
- 头部开销
- 块分割最小限制

**示例**:
```
请求: kmalloc(100)
实际: 头部(32) + 数据(112，16字节对齐) = 144 字节
浪费: 44 字节 (30%)
```

**解决方案**:

1. 批量分配：
```c
// 一次分配多个对象
struct object* array = kmalloc(100 * sizeof(struct object));
// 手动管理
```

2. 使用内存池：
```c
// 为特定类型创建池
struct object_pool {
    void* memory;
    struct object* free_list;
};

struct object* pool_alloc(struct object_pool* pool) {
    if (pool->free_list != NULL) {
        struct object* obj = pool->free_list;
        pool->free_list = obj->next;
        return obj;
    }
    return NULL;
}
```

## 调试技巧

### 技巧 1: 详细日志

```c
// 在 heap.c 中启用详细日志
#define HEAP_DEBUG 1

void* kmalloc(size_t size) {
#ifdef HEAP_DEBUG
    klog_trace("[HEAP] kmalloc(%zu) called from %p\n",
              size, __builtin_return_address(0));
#endif

    // ... 分配逻辑 ...

#ifdef HEAP_DEBUG
    klog_trace("[HEAP] -> %p\n", ptr);
#endif

    return ptr;
}
```

### 技巧 2: 分配跟踪

```c
typedef struct {
    void* ptr;
    size_t size;
    const char* file;
    int line;
} alloc_record_t;

static alloc_record_t alloc_records[1024];
static int record_index = 0;

void* tracked_malloc(size_t size, const char* file, int line) {
    void* ptr = kmalloc(size);
    if (ptr != NULL && record_index < 1024) {
        alloc_records[record_index].ptr = ptr;
        alloc_records[record_index].size = size;
        alloc_records[record_index].file = file;
        alloc_records[record_index].line = line;
        record_index++;
    }
    return ptr;
}

void tracked_free(void* ptr) {
    kfree(ptr);
    // 从记录中移除
}

#define kmalloc(size) tracked_malloc(size, __FILE__, __LINE__)
#define kfree(ptr) tracked_free(ptr)
```

### 技巧 3: 崩溃后分析

```c
// 在关键点保存堆状态
static heap_stats_t last_good_stats;

void save_heap_state(void) {
    heap_get_stats(&last_good_stats);
}

void compare_heap_state(void) {
    heap_stats_t current;
    heap_get_stats(&current);

    klog_trace("Used bytes: %llu -> %llu\n",
              last_good_stats.used_bytes, current.used_bytes);
    klog_trace("Blocks: %llu -> %llu\n",
              last_good_stats.used_blocks, current.used_blocks);
}
```

### 技巧 4: 边界检测

```c
// 在块头和用户数据之间添加 canary
struct heap_block {
    uint64_t size;
    bool used;
    uint32_t magic;
    uint32_t canary;  // 新增：随机值
    // ...
};

#define CANARY_VALUE  0xDEADBEEF

// 分配时设置
block->canary = CANARY_VALUE;

// 释放时检查
if (block->canary != CANARY_VALUE) {
    klog_error("Buffer overflow detected!\n");
}
```
