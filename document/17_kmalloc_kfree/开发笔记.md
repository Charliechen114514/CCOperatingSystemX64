## 为什么需要堆分配器

### 1. 从虚拟内存管理到堆分配器

Stage 16 实现了虚拟内存管理系统（VMM），能够以 4KB 页为单位分配内存。但这存在以下限制：

- **粒度过大**：4KB 页对于小对象（如链表节点、字符串）太大
- **内存浪费**：分配 16 字节结构体需要一整页（4KB），浪费 99.6%
- **管理复杂**：页级管理不适合频繁的小对象分配/释放
- **缺乏灵活性**：无法按需分配任意大小的内存

### 2. 堆分配器的优势

堆分配器解决了上述问题：

- **字节级粒度**：可以精确分配所需的字节数
- **内存高效**：多个小对象可以共享一个页
- **使用简便**：类似标准 malloc/free 的接口
- **统计精确**：精确跟踪已用/空闲字节数

### 3. 为什么现在实现

在 Stage 16 VMM 完成后，我们已经具备了：

- 可靠的虚拟内存分配器
- 页错误处理机制
- 直接物理映射
- 足够的基础设施

这些是堆分配器实现的必要前置条件。

### 4. 与标准 malloc/free 的区别

```c
// 标准 malloc (用户态)
void* malloc(size_t size);
void free(void* ptr);

// 内核 kmalloc (内核态)
void* kmalloc(size_t size);
void kfree(void* ptr);
```

**主要区别**：
- 运行环境：kmalloc 运行在内核态
- 后备存储：kmalloc 使用 VMM，malloc 使用 sbrk/mmap
- 线程安全：当前实现未考虑多线程
- 错误处理：内核环境无法返回 errno

## 堆分配器设计基础

### 1. 堆与栈的区别

| 特性 | 栈 (Stack) | 堆 (Heap) |
|------|-----------|----------|
| 分配方式 | 自动（函数调用） | 手动（kmalloc/kfree） |
| 生命周期 | 函数作用域 | 显式释放 |
| 分配速度 | 极快（仅移动指针） | 较慢（搜索空闲块） |
| 大小限制 | 较小（通常 MB 级） | 较大（GB 级） |
| 内存布局 | 连续增长 | 分散分配 |

### 2. 堆内存布局

```
内核虚拟地址空间:
┌────────────────────────────────────┐
│ 0xFFFFFFFF80200000  内核数据       │
├────────────────────────────────────┤
│ 0xFFFFFFFF81000000  堆起始         │  KERNEL_HEAP_BASE
│                                    │
│         ┌──────────┐               │
│         │  Block 1 │ 已使用        │
│         ├──────────┤               │
│         │  Block 2 │ 空闲          │
│         ├──────────┤               │
│         │  Block 3 │ 已使用        │
│         ├──────────┤               │
│         │    ...   │               │
│                                    │
│ 0xFFFFFFFF89000000  堆结束         │  KERNEL_HEAP_MAX
└────────────────────────────────────┘
```

### 3. 分配算法选择

常见的堆分配算法：

#### First-Fit (首次适应)
- 找到第一个足够大的空闲块
- 优点：速度快
- 缺点：外部碎片严重

#### Best-Fit (最佳适应) ✅
- 找到最小的足够大的空闲块
- 优点：减少外部碎片
- 缺点：分配速度较慢

#### Worst-Fit (最差适应)
- 找到最大的空闲块
- 优点：剩余块较大
- 缺点：容易产生小碎片

#### Buddy System (伙伴系统)
- 按固定大小（2 的幂）分配
- 优点：合并简单，碎片少
- 缺点：内部碎片多

**我们的选择**：Best-Fit
- 适合内核场景（分配大小相对固定）
- 实现简单
- 块合并可以减轻碎片问题

## 设计决策

### 1. 使用 VMM 作为后备存储

#### 决策：堆内存来自 VMM 分配

```c
#define KERNEL_HEAP_BASE   0xFFFFFFFF81000000ULL
#define KERNEL_HEAP_MAX    0xFFFFFFFF89000000ULL  // 128MB
#define HEAP_INITIAL_SIZE  (64 * 1024)            // 64KB
```

**理由**：
- VMM 已经提供了虚拟内存管理
- 堆可以按需扩展（不是一次性分配 128MB）
- 与其他内核模块一致的内存管理方式

**实现**：
```c
// 初始化时分配初始堆
vmm_alloc_pages_at(KERNEL_HEAP_BASE, initial_pages, VMAP_FLAG_WRITE);

// 需要时扩展堆
vmm_alloc_pages_at(s_heap.heap_brk, more_pages, VMAP_FLAG_WRITE);
```

### 2. 块头设计

#### 决策：每个块都有 16 字节头部

```c
typedef struct heap_block {
    uint64_t size;           // 总大小（包含头部），16字节对齐
    bool used;               // 使用状态
    struct heap_block* prev; // 前一个块（内存中相邻）
    struct heap_block* next; // 下一个块（空闲链表）
    uint32_t magic;          // 魔数 0x00114514
    uint32_t _padding;       // 填充到 16 字节
} __attribute__((aligned(16))) heap_block_t;
```

**理由**：
- 16 字节对齐满足大多数需求（SSE/AVX）
- 魔数检测内存损坏
- prev/next 指针支持块合并
- 空闲链表独立于内存布局

### 3. 最小分配大小

#### 决策：最小分配 16 字节

```c
#define HEAP_MIN_ALLOC_SIZE  16
```

**理由**：
- 块头已是 16 字节
- 更小的分配不划算
- 减少碎片

```c
// 分配 0-15 字节都会得到 16 字节
kmalloc(1)   // 实际分配 32 字节（16 头 + 16 数据）
kmalloc(16)  // 实际分配 32 字节
kmalloc(17)  // 实际分配 48 字节（16 头 + 32 数据，16字节对齐）
```

### 4. 块合并策略

#### 决策：释放时自动合并相邻空闲块

```c
void kfree(void* ptr) {
    // 标记为空闲
    block->used = false;

    // 合并下一个
    if (block->next && !block->next->used) {
        block->size += block->next->size;
        // ...
    }

    // 合并前一个
    if (block->prev && !block->prev->used) {
        block->prev->size += block->size;
        // ...
    }
}
```

**理由**：
- 减少外部碎片
- 自动维护较大的空闲块
- 释放时代价相对较小

### 5. 堆扩展策略

#### 决策：按需扩展，最小扩展 4 页

```c
#define HEAP_MIN_EXPANSION_PAGES  4
```

**理由**：
- 避免频繁扩展（每次扩展都有开销）
- 4 页 (16KB) 是合理的增长单位
- 大块分配可以一次性扩展更多

## 实现细节

### 1. 初始化流程

```c
heap_result_t heap_init(void) {
    if (s_heap.initialized) {
        return HEAP_OK;
    }

    // 1. 设置堆区域
    s_heap.heap_start = KERNEL_HEAP_BASE;
    s_heap.heap_end = KERNEL_HEAP_MAX;

    // 2. 分配初始页（64KB = 16 页）
    size_t initial_pages = HEAP_INITIAL_SIZE / PAGE_SIZE;
    virtual_addr_t init_vaddr = s_heap.heap_start;

    if (vmm_alloc_pages_at(init_vaddr, initial_pages, VMAP_FLAG_WRITE) != VMM_OK) {
        return HEAP_ERR_OOM;
    }

    // 3. 清零内存
    memzero((void*)init_vaddr, HEAP_INITIAL_SIZE);

    // 4. 创建初始块
    heap_block_t* initial_block = (heap_block_t*)init_vaddr;
    initial_block->size = HEAP_INITIAL_SIZE;
    initial_block->used = false;
    initial_block->prev = NULL;
    initial_block->next = NULL;
    initial_block->magic = HEAP_MAGIC;

    // 5. 设置空闲链表
    s_heap.free_list = initial_block;
    s_heap.heap_brk = init_vaddr + HEAP_INITIAL_SIZE;

    // 6. 更新统计
    s_heap.stats.total_bytes = HEAP_INITIAL_SIZE;
    s_heap.stats.free_bytes = HEAP_INITIAL_SIZE - sizeof(heap_block_t);
    s_heap.stats.free_blocks = 1;

    s_heap.initialized = true;
    return HEAP_OK;
}
```

### 2. 分配流程

```c
void* kmalloc(size_t size) {
    // 1. 参数检查
    if (size == 0 || !s_heap.initialized) {
        return NULL;
    }

    // 2. 计算需要的大小（头部 + 用户数据，16字节对齐）
    size_t total_size = total_block_size(size);

    // 3. 搜索最佳空闲块
    heap_block_t* block = find_best_fit(total_size);
    if (block == NULL) {
        // 没有合适的块，尝试扩展堆
        if (expand_heap(total_size) != HEAP_OK) {
            return NULL;  // 内存不足
        }
        block = find_best_fit(total_size);
        if (block == NULL) {
            return NULL;
        }
    }

    // 4. 如果块太大，分割它
    if (block->size >= total_size + sizeof(heap_block_t) + HEAP_MIN_ALLOC_SIZE) {
        split_block(block, total_size);
    }

    // 5. 标记为已使用
    block->used = true;
    remove_from_free_list(block);

    // 6. 更新统计
    s_heap.stats.used_blocks++;
    s_heap.stats.alloc_count++;

    // 7. 返回用户数据指针
    return (void*)((uint8_t*)block + sizeof(heap_block_t));
}
```

### 3. Best-Fit 搜索

```c
static heap_block_t* find_best_fit(size_t size) {
    heap_block_t* best = NULL;
    heap_block_t* current = s_heap.free_list;

    while (current != NULL) {
        if (!current->used && current->size >= size) {
            if (best == NULL || current->size < best->size) {
                best = current;
                // 如果完全匹配，立即返回
                if (current->size == size) {
                    break;
                }
            }
        }
        current = current->next;
    }

    return best;
}
```

### 4. 块分割

```c
static void split_block(heap_block_t* block, size_t new_size) {
    // 新块的位置
    heap_block_t* new_block = (heap_block_t*)((uint8_t*)block + new_size);

    // 设置新块的头部
    new_block->size = block->size - new_size;
    new_block->used = false;
    new_block->prev = block;
    new_block->next = block->next;
    new_block->magic = HEAP_MAGIC;

    // 更新旧块
    block->size = new_size;
    if (block->next != NULL) {
        block->next->prev = new_block;
    }
    block->next = new_block;

    // 将新块加入空闲链表
    add_to_free_list(new_block);
}
```

### 5. 堆扩展

```c
static heap_result_t expand_heap(size_t min_expansion) {
    // 1. 计算需要扩展的页数
    uint64_t page_count = (min_expansion + PAGE_SIZE - 1) / PAGE_SIZE;
    if (page_count < HEAP_MIN_EXPANSION_PAGES) {
        page_count = HEAP_MIN_EXPANSION_PAGES;
    }

    // 2. 检查是否超过堆最大值
    virtual_addr_t new_brk = s_heap.heap_brk + page_count * PAGE_SIZE;
    if (new_brk > s_heap.heap_end) {
        return HEAP_ERR_OOM;
    }

    // 3. 使用 VMM 分配虚拟页
    if (vmm_alloc_pages_at(s_heap.heap_brk, page_count, VMAP_FLAG_WRITE) != VMM_OK) {
        return HEAP_ERR_OOM;
    }

    // 4. 清零新内存
    memzero((void*)s_heap.heap_brk, page_count * PAGE_SIZE);

    // 5. 创建新块并合并到空闲链表
    heap_block_t* new_block = (heap_block_t*)s_heap.heap_brk;
    new_block->size = page_count * PAGE_SIZE;
    new_block->used = false;
    new_block->prev = get_last_block();
    new_block->next = NULL;
    new_block->magic = HEAP_MAGIC;

    add_to_free_list(new_block);

    // 6. 更新堆顶和统计
    s_heap.heap_brk = new_brk;
    s_heap.stats.total_bytes += page_count * PAGE_SIZE;
    s_heap.stats.free_bytes += page_count * PAGE_SIZE - sizeof(heap_block_t);
    s_heap.stats.expand_count++;

    return HEAP_OK;
}
```

### 6. 释放流程

```c
void kfree(void* ptr) {
    // 1. 参数检查
    if (ptr == NULL) {
        return;
    }

    // 2. 获取块头
    heap_block_t* block = (heap_block_t*)((uint8_t*)ptr - sizeof(heap_block_t));

    // 3. 验证魔数
    if (block->magic != HEAP_MAGIC) {
        klog_error("[HEAP] Invalid magic at 0x%p\n", block);
        return;
    }

    // 4. 检查双重释放
    if (!block->used) {
        klog_error("[HEAP] Double free at 0x%p\n", ptr);
        return;
    }

    // 5. 标记为空闲
    block->used = false;

    // 6. 添加到空闲链表
    add_to_free_list(block);

    // 7. 合并相邻空闲块
    coalesce_blocks(block);

    // 8. 更新统计
    s_heap.stats.used_blocks--;
    s_heap.stats.free_count++;
}
```

### 7. 块合并

```c
static void coalesce_blocks(heap_block_t* block) {
    // 向后合并
    if (block->next != NULL && !block->next->used) {
        // 从空闲链表中移除下一个块
        remove_from_free_list(block->next);

        // 合并大小
        block->size += block->next->size;

        // 更新链接
        block->next = block->next->next;
        if (block->next != NULL) {
            block->next->prev = block;
        }
    }

    // 向前合并
    if (block->prev != NULL && !block->prev->used) {
        // 从空闲链表中移除当前块
        remove_from_free_list(block);

        // 合并到前一个块
        block->prev->size += block->size;
        block->prev->next = block->next;
        if (block->next != NULL) {
            block->next->prev = block->prev;
        }

        // 不需要再次添加，前一个块已经在空闲链表中
    }
}
```

### 8. 对齐分配

```c
void* kmalloc_aligned(size_t size, size_t alignment) {
    // 1. 验证对齐值（必须是 2 的幂）
    if (alignment == 0 || (alignment & (alignment - 1)) != 0) {
        return NULL;
    }

    // 2. 最小对齐是 HEAP_ALIGN (16)
    if (alignment < HEAP_ALIGN) {
        alignment = HEAP_ALIGN;
    }

    // 3. 分配额外空间：alignment + sizeof(virtual_addr_t*)
    size_t total_size = total_block_size(size) + alignment + sizeof(virtual_addr_t*);

    void* raw_ptr = kmalloc(total_size);
    if (raw_ptr == NULL) {
        return NULL;
    }

    // 4. 计算对齐地址
    virtual_addr_t raw_start = (virtual_addr_t)raw_ptr;
    virtual_addr_t aligned_addr = align_up(raw_start + sizeof(virtual_addr_t*), alignment);

    // 5. 在对齐地址前存储原始指针
    virtual_addr_t* orig_ptr_loc = (virtual_addr_t*)(aligned_addr - sizeof(virtual_addr_t*));
    *orig_ptr_loc = raw_start;

    // 6. 返回对齐地址
    return (void*)aligned_addr;
}

// 释放时需要恢复原始指针
void kfree(void* ptr) {
    // 检查是否是对齐分配的指针
    virtual_addr_t vaddr = (virtual_addr_t)ptr;

    // 获取可能的原始指针
    virtual_addr_t* orig_ptr_loc = (virtual_addr_t*)(vaddr - sizeof(virtual_addr_t*));
    virtual_addr_t possible_orig = *orig_ptr_loc;

    // 简单检查：如果指向的位置有有效的魔数，就是对齐分配
    heap_block_t* possible_block = (heap_block_t*)possible_orig;
    if (possible_block >= s_heap.heap_start &&
        possible_block < s_heap.heap_brk &&
        possible_block->magic == HEAP_MAGIC) {
        // 是对齐分配，使用原始指针
        kfree_internal((void*)possible_orig);
    } else {
        // 普通分配
        kfree_internal(ptr);
    }
}
```

## 常见陷阱与注意事项

### 1. 内存碎片

**问题**：频繁分配/释放不同大小的块会导致碎片

**现象**：
```
空闲块: [16B][16B][32B][16B][16B][128B]
需要 64B，但没有足够大的连续块
```

**解决方案**：
- 尽量分配固定大小的对象
- 使用内存池
- 实现更复杂的分配算法

### 2. 双重释放

**问题**：同一指针被释放两次

**检测**：
```c
if (!block->used) {
    klog_error("[HEAP] Double free detected!\n");
    return;
}
```

**预防**：
- 释放后置 NULL：`ptr = NULL;`
- 使用工具检测

### 3. 野指针

**问题**：使用已释放的内存

```c
int* ptr = kmalloc(sizeof(int));
kfree(ptr);
*ptr = 42;  // 野指针！
```

**预防**：
- 释放后立即置 NULL
- 使用静态分析工具
- 启用内存填充检测

### 4. 内存泄漏

**问题**：分配的内存从未释放

```c
void leaky_function(void) {
    void* ptr = kmalloc(1024);
    // 忘记 kfree(ptr)
}
```

**检测**：
```c
// 定期检查统计
heap_stats_t stats;
heap_get_stats(&stats);

if (stats.used_bytes > threshold) {
    klog_warn("Possible memory leak!\n");
}
```

### 5. 对齐问题

**问题**：某些硬件需要特定对齐

```c
// DMA 需要 4KB 对齐
void* dma_buffer = kmalloc_aligned(4096, 4096);

// SSE/AVX 需要 16/32 字节对齐
void* simd_data = kmalloc_aligned(64, 32);
```

### 6. 堆耗尽

**问题**：堆扩展到最大值后无法再分配

**现象**：
```
[HEAP] Out of memory!
```

**解决方案**：
- 增加 KERNEL_HEAP_MAX
- 使用内存池
- 优化内存使用

### 7. 初始化顺序

**问题**：在 VMM 初始化前使用 heap

**正确顺序**：
```c
void kernel_init(void) {
    pframe_init();    // 1. 物理帧
    page_init();      // 2. 页表
    vmm_init();       // 3. 虚拟内存
    heap_init();      // 4. 堆分配器
    // ...
}
```
