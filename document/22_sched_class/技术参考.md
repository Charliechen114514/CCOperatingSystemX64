## 调度策略枚举

### sched_policy_t

```c
typedef enum sched_policy {
    SCHED_NORMAL   = 0,    /* 普通 Round-Robin 调度 */
    SCHED_PRIORITY = 1,    /* 优先级调度 */
    SCHED_MAX      = 2,    /* 调度策略数量 */
} sched_policy_t;
```

| 策略 | 值 | 说明 | 调度类 |
|------|-----|------|--------|
| `SCHED_NORMAL` | 0 | 普通 Round-Robin 调度 | rr_sched_class |
| `SCHED_PRIORITY` | 1 | 优先级调度 | prio_sched_class |

## 调度类框架 API

### sched_class_init

初始化调度类框架。

```c
int sched_class_init(void);
```

**返回值**:
- `0` - 成功
- `负值` - 失败

**说明**:
- 初始化 per-policy 运行队列数组
- 清空调度类注册表
- 注册定时器回调函数

**示例**:
```c
int proc_init(void) {
    int ret = sched_class_init();
    if (ret != 0) {
        klog_error("Failed to init scheduler classes\n");
        return ret;
    }
    // ...
}
```

---

### sched_class_register

注册一个调度类。

```c
int sched_class_register(sched_class_t* class, sched_policy_t policy);
```

**参数**:
- `class` - 指向调度类结构的指针
- `policy` - 调度策略标识

**返回值**:
- `0` - 成功
- `-1` - 失败（class 为 NULL 或 policy 无效或已注册）

**示例**:
```c
int sched_rr_init(void) {
    return sched_class_register(&rr_sched_class, SCHED_NORMAL);
}
```

---

### sched_enqueue_task

将任务加入其调度类的运行队列。

```c
void sched_enqueue_task(struct pcb* pcb, bool head);
```

**参数**:
- `pcb` - 要加入的进程控制块
- `head` - `true` 加入队首，`false` 加入队尾

**说明**:
- 自动根据 `pcb->sched_entity.policy` 选择运行队列
- 调用对应调度类的 `enqueue_task` 方法
- 更新全局 `nr_running` 计数

**示例**:
```c
// 创建新进程后加入队列
sched_set_policy(child, SCHED_NORMAL, 0);
sched_enqueue_task(child, false);  // 加入队尾
```

---

### sched_dequeue_task

将任务从其调度类的运行队列移除。

```c
void sched_dequeue_task(struct pcb* pcb);
```

**参数**:
- `pcb` - 要移除的进程控制块

**说明**:
- 自动根据 `pcb->sched_entity.policy` 选择运行队列
- 调用对应调度类的 `dequeue_task` 方法
- 更新全局 `nr_running` 计数

---

### sched_pick_next_task

选择下一个要运行的任务。

```c
struct pcb* sched_pick_next_task(void);
```

**返回值**:
- 指向下一个运行任务的 PCB 指针
- `NULL` - 没有可运行任务

**选择顺序**:
1. 如果当前进程仍有时间片且没有更高优先级任务，保持当前
2. 检查 Priority 队列，选择最高优先级任务
3. 检查 RR 队列，选择队首任务
4. 返回 `NULL`（运行 idle）

---

### sched_set_policy

设置进程的调度策略。

```c
int sched_set_policy(struct pcb* pcb, sched_policy_t policy, int priority);
```

**参数**:
- `pcb` - 进程控制块
- `policy` - 调度策略
- `priority` - 优先级（仅用于 SCHED_PRIORITY）

**返回值**:
- `0` - 成功
- `-1` - 失败（pcb 为 NULL 或 policy 无效或类未注册）

**示例**:
```c
// 设置为普通 RR 调度
sched_set_policy(process, SCHED_NORMAL, 0);

// 设置为高优先级调度
sched_set_policy(process, SCHED_PRIORITY, 10);
```

---

## 数据结构定义

### sched_class_t

调度类虚函数表。

```c
typedef struct sched_class {
    const char* name;              /* 类名称 */
    sched_policy_t policy;         /* 策略标识 */

    /* 队列管理 */
    void (*enqueue_task)(struct sched_rq* rq, struct pcb* pcb, bool head);
    void (*dequeue_task)(struct sched_rq* rq, struct pcb* pcb);

    /* 任务选择 */
    struct pcb* (*pick_next_task)(struct sched_rq* rq, struct pcb* prev);
    bool (*should_preempt)(struct pcb* p, struct pcb* curr);

    /* 时间管理 */
    void (*task_tick)(struct sched_rq* rq, struct pcb* pcb);
    uint32_t (*get_time_slice)(const struct pcb* pcb);

    /* 生命周期 */
    void (*task_fork)(struct pcb* pcb, int nice);
} sched_class_t;
```

---

### sched_rq_t

Per-policy 运行队列。

```c
typedef struct sched_rq {
    sched_class_t* sched_class;    /* 关联的调度类 */
    list_head        queue;         /* 通用运行队列 */
    uint32_t         nr_running;    /* 运行任务数 */
    void*            class_data;    /* 类特定数据 */
} sched_rq_t;
```

---

### sched_entity_t

进程调度实体。

```c
typedef struct sched_entity {
    sched_policy_t    policy;         /* 调度策略 */
    sched_class_t*    sched_class;    /* 调度类指针 */
    uint32_t          time_slice;     /* 剩余时间片 (ms) */
    uint32_t          time_slice_total; /* 完整时间片 (ms) */
    int               priority;       /* 优先级 (0-127) */
    int               nice;           /* Nice 值 */
    uint64_t          last_ran;       /* 上次运行时间 */
    list_head         run_list;       /* 队列节点 */
} sched_entity_t;
```

---

### prio_rq_data_t

Priority 调度类的私有数据。

```c
typedef struct prio_rq_data {
    list_head    active[PRIO_LEVELS];   /* 活跃队列 */
    list_head    expired[PRIO_LEVELS];  /* 过期队列 */
    uint32_t     nr_active;             /* 活跃任务数 */
    uint32_t     nr_expired;            /* 过期任务数 */
    int          highest_prio;          /* 当前最高优先级 */
    bool         active_expired;        /* 是否需要交换 */
} prio_rq_data_t;
```

---

### scheduler_t (扩展)

调度器结构（已扩展）。

```c
typedef struct scheduler {
```

## 算法说明

### 1. 时间片管理算法

**初始化**:
```c
void sched_init_time_slice(struct pcb* pcb) {
    uint32_t slice = pcb->sched_entity.sched_class->get_time_slice(pcb);
    pcb->sched_entity.time_slice = slice;
    pcb->sched_entity.time_slice_total = slice;
}
```

**递减**（每个时钟 tick）:
```c
if (pcb->sched_entity.time_slice > 0) {
    pcb->sched_entity.time_slice--;
}
```

**重置**（任务被选中运行时）:
```c
pcb->sched_entity.time_slice = pcb->sched_entity.time_slice_total;
```

---

### 2. RR 调度算法

**入队**: FIFO 加入队尾
```c
static void rr_enqueue_task(struct sched_rq* rq, struct pcb* pcb, bool head) {
    if (head) {
        list_add(&pcb->sched_entity.run_list, &rq->queue);
    } else {
        list_add_tail(&pcb->sched_entity.run_list, &rq->queue);
    }
    rq->nr_running++;
}
```

**选择任务**: 返回队首
```c
static struct pcb* rr_pick_next_task(struct sched_rq* rq, struct pcb* prev) {
    if (list_is_empty(&rq->queue)) {
        return NULL;
    }
    return list_first_entry(&rq->queue, struct pcb, sched_entity.run_list);
}
```

**时间复杂度**: O(1)

---

### 3. Priority 调度算法

**入队**: 加入对应优先级的 active 队列
```c
static void prio_enqueue_task(struct sched_rq* rq, struct pcb* pcb, bool head) {
    prio_rq_data_t* data = prio_rq_data(rq);
    int prio = pcb->sched_entity.priority;

    if (head) {
        list_add(&pcb->sched_entity.run_list, &data->active[prio]);
    } else {
        list_add_tail(&pcb->sched_entity.run_list, &data->active[prio]);
    }
    data->nr_active++;

    // 更新最高优先级
    if (prio < data->highest_prio) {
        data->highest_prio = prio;
    }
}
```

**选择任务**: 从最高优先级队列选择
```c
static struct pcb* prio_pick_next_task(struct sched_rq* rq, struct pcb* prev) {
    prio_rq_data_t* data = prio_rq_data(rq);

    // active 空，交换 active/expired
    if (data->nr_active == 0) {
        if (data->nr_expired > 0) {
            prio_swap_active_expired(data);
        } else {
            return NULL;
        }
    }

    // 获取最高优先级队列
    int highest = find_highest_prio(data);
    return list_first_entry(&data->active[highest], struct pcb, sched_entity.run_list);
}
```

**时间复杂度**:
- `enqueue_task`: O(1)
- `pick_next_task`: O(128) = O(1)（优先级数量固定）

---

### 4. Active/Expired 交换算法

```c
static void prio_swap_active_expired(prio_rq_data_t* data) {
    for (int i = 0; i < PRIO_LEVELS; i++) {
        list_head temp;
        INIT_LIST_HEAD(&temp);

        // 交换 active[i] 和 expired[i]
        list_splice_init(&data->active[i], &temp);
        list_splice_init(&data->expired[i], &data->active[i]);
        list_splice_init(&temp, &data->expired[i]);
    }

    // 交换计数器
    uint32_t temp_count = data->nr_active;
    data->nr_active = data->nr_expired;
    data->nr_expired = temp_count;

    data->highest_prio = find_highest_prio(data);
}
```

### 5. 抢占判断算法

**Priority 抢占**:
```c
static bool prio_should_preempt(struct pcb* p, struct pcb* curr) {
    // 高优先级抢占低优先级
    if (p->sched_entity.priority < curr->sched_entity.priority) {
        return true;
    }

    // 同优先级：仅当当前时间片用完
    if (p->sched_entity.priority == curr->sched_entity.priority) {
        return (curr->sched_entity.time_slice == 0);
    }

    return false;
}
```

**RR 抢占**:
```c
static bool rr_should_preempt(struct pcb* p, struct pcb* curr) {
    // RR 不基于优先级抢占
    // 仅在当前时间片用完时允许切换
    return (curr->sched_entity.time_slice == 0);
}
```

### 6. 调度类选择流程

```
sched_pick_next_task()
    │
    ├─→ 当前进程仍有时间片？
    │   └─ 是 → 检查是否有更高优先级任务
    │            └─ 有 → 返回高优先级任务
    │            └─ 无 → 返回当前进程
    │
    ├─→ Priority 队列有任务？
    │   └─ 是 → 返回最高优先级任务
    │
    ├─→ RR 队列有任务？
    │   └─ 是 → 返回队首任务
    │
    └─→ 返回 NULL (idle)
```

## 系统调用集成

### 相关系统调用

虽然本阶段主要实现内核调度框架，但以下系统调用会触发调度：

| 系统调用 | 触发的调度操作 |
|----------|----------------|
| `sys_fork` | 创建新进程，调用 `sched_set_policy()` 和 `sched_enqueue_task()` |
| `sys_exit` | 进程退出，调用 `schedule()` |
| `sys_yield` | 主动让出 CPU，调用 `schedule()` |
| `sys_wait4` | 等待子进程，可能阻塞，调用 `schedule()` |
