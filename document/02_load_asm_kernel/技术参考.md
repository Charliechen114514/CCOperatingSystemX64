## 1. 内存布局

### 1.1 完整内存映射

```
┌─────────────────────────────────────────────────────────────┐
│                      物理内存地址空间                        │
├─────────────────────────────────────────────────────────────┤
│ 0x00000000 - 0x000003FF │ IVT (中断向量表, 1KB)            │
│ 0x00000400 - 0x000004FF │ BDA (BIOS 数据区, 256B)          │
│ 0x00000500 - 0x00007BFF │ 常规内存可用区 (~29KB)           │
│ 0x00007C00 - 0x00007DFF │ Stage 1 Bootloader (512B)        │
│ 0x00007E00 - 0x000083FF │ Stage 2 Bootloader (~1KB)        │
│ 0x00008400 - 0x00008FFF │ 可用空间 (~3KB)                 │
│ 0x00009000 - 0x00009FFF │ PML4 页表 (4KB)                  │
│ 0x0000A000 - 0x0000AFFF │ PDPT 页表 (4KB)                  │
│ 0x0000B000 - 0x0000BFFF │ PD 页表 (4KB)                    │
│ 0x0000C000 - 0x0009FFFF │ 常规内存可用区 (~604KB)          │
│ 0x000A0000 - 0x000BFFFF │ VGA 显存 (128KB)                 │
│ 0x000C0000 - 0x000FFFFF │ BIOS ROM 区域 (256KB)            │
│ 0x00100000 - 0x001FFFFF │ 1MB - 2MB 低内存扩展区           │
├─────────────────────────────────────────────────────────────┤
│ 0x00010000 - ...        │ 内核加载地址                     │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 内核地址空间

```
Identity Mapping (启动时):
  虚拟地址 = 物理地址

  0x10000 虚拟  →  0x10000 物理  (内核代码)
  0x7E00  虚拟  →  0x7E00  物理  (boot2 代码)

Higher-Half Mapping (未来):
  内核代码:  0xFFFF800000100000+
  用户空间:  0x0000000000400000+
```

### 1.3 VGA 显存

```
地址: 0xB8000 - 0xBFFFF (128KB)

文本模式 (80x25):
  - 每字符 2 字节 (字符 + 属性)
  - 每行 80 字符 = 160 字节
  - 25 行 = 4000 字节

属性字节:
  7 6 5 4 3 2 1 0
  │ │ │ │ │ │ │ └─ 前景色 (0-15)
  │ │ │ │ │ │ └─── 前景亮度
  │ │ │ │ └───── 背景色 (0-15)
  │ │ │ └────── 背景亮度
  │ └┴────────── 保留 (00)
  └───────────── 闪烁

常用颜色:
  0x0F = 白字黑底
  0x1F = 白字蓝底
  0x1E = 黄字蓝底
```

## 2. 磁盘布局

### 2.1 扇区分配

```
CCOS Boot Image (boot.img):

┌────────────────────────────────────────────────────────────┐
│ 扇区 │ 大小    │ 内容                      │ 源文件        │
├──────┼─────────┼──────────────────────────┼──────────────┤
│ 0    │ 512B    │ Stage 1 Bootloader      │ boot.bin      │
│ 1-2  │ 1024B   │ Stage 2 Bootloader      │ boot2.bin     │
│ 3    │ 512B    │ 内核                    │ kernel.bin    │
│ 4+   │ -       │ (保留)                  │ -             │
└──────┴─────────┴──────────────────────────┴──────────────┘

CHS 地址 ( Cylinder, Head, Sector ):
  Boot1:  (0, 0, 1)
  Boot2:  (0, 0, 2-3)
  Kernel: (0, 0, 4)

LBA 地址 (0-based):
  Boot1:  0
  Boot2:  1-2
  Kernel: 3
```

### 2.2 dd 命令详解

```bash
# 构建 boot.img 的命令

# Step 1: 写入 boot1.bin (sector 0)
dd if=build/boot.bin of=build/boot.img \
   bs=512 count=1 conv=notrunc

# Step 2: 写入 boot2.bin (sectors 1-2)
dd if=build/boot2.bin of=build/boot.img \
   bs=512 seek=1 conv=notrunc

# Step 3: 写入 kernel.bin (sector 3)
dd if=build/kernel.bin of=build/boot.img \
   bs=512 seek=3 conv=notrunc
```

**参数说明**：
- `bs=512` - 块大小 = 1 扇区
- `count=N` - 复制 N 块
- `seek=N` - 跳过输出文件的前 N 块
- `conv=notrunc` - 不截断输出文件

### 2.3 验证磁盘布局

```bash
# 查看 boot.img 的十六进制内容
xxd build/boot.img | less

# 提取特定扇区
dd if=build/boot.img bs=512 skip=3 count=1 | xxd
# 应该看到 kernel.bin 的内容

# 检查 MBR 签名 (最后 2 字节)
xxd -s 510 -l 2 build/boot.img
# 应该显示: 00001fe: 55aa
```

## 3. BIOS 中断

### 3.1 INT 10h - 视频服务

#### 功能 0Eh:写字符到光标位置

```asm
输入:
  AH = 0Eh    (写字符功能)
  AL = 字符代码
  BH = 页号 (通常 0)
  BL = 前景色 (图形模式)

输出:
  无

示例:
  mov ah, 0x0e
  mov al, 'X'
  int 0x10    ; 屏幕显示 'X'
```

### 3.2 INT 13h - 磁盘服务

#### 功能 02h: 读取扇区 (CHS)

```asm
输入:
  AH = 02h        (读取功能)
  AL = 扇区数 (1-128)
  CH = 柱面号 (0-1023)
  CL = 扇区号 (1-17, bit 7-6 = 柱面号高2位)
  DH = 磁头号 (0-15)
  DL = 驱动器号 (80h = 第一硬盘)
  ES:BX = 缓冲区地址

输出:
  AH = 错误码 (CF=1 时)
  AL = 实际读取扇区数
  CF = 0 (成功) / 1 (失败)

示例:
  mov ax, 0x1000
  mov es, ax          ; ES = 0x1000
  xor bx, bx          ; BX = 0x0000 (地址 = 0x10000)

  mov ah, 0x02        ; 读取功能
  mov al, 0x01        ; 1 个扇区
  mov ch, 0x00        ; 柱面 0
  mov cl, 0x04        ; 扇区 4
  mov dh, 0x00        ; 磁头 0
  mov dl, 0x80        ; 第一硬盘

  int 0x13

  jc read_error      ; CF=1 表示错误
  cmp al, 0x01        ; 确认读取了 1 个扇区
  jne read_error
```

#### 错误码 (AH)

```
00h  - 无错误
01h  - 无效命令
02h  - 找不到地址标记
03h  - 写保护 (磁盘)
04h  - 扇区未找到
05h  - 复位失败
06h  - 磁盘已换
07h  - 驱动器参数活动失败
08h  - DMA 过溢出
09h  - DMA 边界错误 (64K)
0Ah  - 检测到坏扇区
0Bh  - 检测到坏磁道
0Ch  - 不支持的磁道/无效介质
0Dh  - 格式化时扇区数无效
0Eh  - 控制数据地址检测到错误
0Fh  - DMA 确定 arbitration level 异常
10h  - ECC/CRC 错误
11h  - ECC 更正数据
20h  - 控制器失败
40h  - 查找失败
80h  - 超时
AAh  - 驱动器未就绪
B0h  - 卷未锁定
B1h  - 卷锁定
B2h  - 卷未弹出
B3h  - 卷已在使用中
B4h  - 卷无效
B5h  - 锁定队列满
B6h  - 早期弹出
BBh  - 未定义错误
CCh  - 写故障
E0h  - 状态错 / 寄存器错
FFh  - 检测到设备故障
```

### 3.3 INT 15h - 系统服务

#### 功能 E820h: 查询内存映射

```asm
输入:
  AX = E820h
  CX = 缓冲区大小 (字节)
  ES:DI = 缓冲区地址
  EBX = 延续值 (首次调用=0)

输出:
  CF = 0 (成功)
  EAX = 'SMAP' (签名)
  ES:DI = 填充的内存条目
  EBX = 下一次延续值
  ECX = 条目大小

内存条目格式 (20 字节):
struct e820_entry {
    uint64_t base;    // 基地址
    uint64_t length;  // 长度
    uint32_t type;    // 类型
    uint32_t acpi;    // ACPI 扩展属性
};

类型:
  1  - 可用内存
  2  - 保留
  3  - ACPI 可 reclaimable
  4  - ACPI NVS
  5  - 包含坏块
```

## 4. 数据结构

### 4.1 GDT 描述符

```
结构 (8 字节 / 64 位):
┌─────────────────────────────────────────────────────────────┐
│ 63 56 55 52 51 48 47 40 39 32 31 24 23 16 15 8 7 0    │
│  │    │    │    │    │    │    │    │    │  │  │  │    │
│  │    │    │    │    │    │    │    │    │  │  │  └─ Limit 0-15
│  │    │    │    │    │    │    │    │    └──┴──┴─── Base 0-23
│  │    │    │    │    │    │    │    └─────────────── Base 24-31
│  │    │    │    │    │    │    └───────────────────── Access Byte
│  │    │    │    │    │    └───────────────────────── Limit 16-19
│  │    │    │    │    └────────────────────────────── Granularity
│  │    │    │    └─────────────────────────────────── Base 32-63
└─────────────────────────────────────────────────────────────┘

Access Byte:
  7 6 5 4 3 2 1 0
  │ │ │ │ │ │ │ └─ Accessed (CPU 自动设置)
  │ │ │ │ │ │ └─── Readable/Writable (1=是)
  │ │ │ │ │ └──── Direction/Conforming (0=向上增长)
  │ │ │ │ └───── Executable (1=代码段)
  │ │ │ └────── Descriptor Type (1=系统段)
  │ └┴───────── DPL (Descriptor Privilege Level)
  └──────────── Present (必须为1)

常用值:
  Null:      0x0000000000000000
  Code32:    0x00CF9A000000FFFF  (G=1, D=1, Type=代码段)
  Data32:    0x00CF92000000FFFF  (G=1, D=1, Type=数据段)
  Code64:    0x00AF9A000000FFFF  (G=1, L=1, Type=代码段)
```

### 4.2 GDT 指针

```asm
; lgdt 指令使用的结构
struc gdt_ptr
    .limit: resw 1    ; GDT 大小 - 1 (16 位)
    .base:  resd 1    ; GDT 基地址 (32 位)
endstruc

; 示例
gdt_ptr:
    dw 5 * 8 - 1      ; 5 个描述符, 每个 8 字节
    dd 0x00007E03     ; GDT 从 0x7E03 开始
```

### 4.3 页表结构

```
x86_64 4 级页表:

┌─────────────┐
│   CR3      │ ──→ PML4 (512 项, 4KB)
├─────────────┤      │
│             │      ├─→ PDPT (512 项, 4KB)
│             │      │   ├─→ PD (512 项, 4KB)
│             │      │   │   ├─→ PT (512 项, 4KB)
│             │      │   │   │   ├─→ 物理页 (4KB)
│             │      │   │   │   └─→ ...
│             │      │   │   └─→ 2MB 页 (可选)
│             │      │   └─→ ...
│             │      └─→ ...
└─────────────┘

页表项格式 (8 字节):
  63                   12 11 9 8 7 6 5 4 3 2 1 0
  │                     │  │  │ │ │ │ │ │ └─ Present
  │                     │  │  │ │ │ │ │ └─── Writable
  │                     │  │  │ │ │ │ └──── User/Supervisor
  │                     │  │  │ │ │ └───── Write-Through
  │                     │  │  │ │ └────── Cache Disabled
  │                     │  │  │ └─────── Accessed
  │                     │  │  └──────── Dirty
  │                     │  └────────── Page Size (0=4KB, 1=2MB)
  │                     └───────────── Available
  └───────────────────────────────── Physical Page Number
```

## 5. 处理器模式

### 5.1 模式对比

```
┌──────────┬─────────┬──────────┬──────────┬─────────┐
│   特性   │ 实模式  │ 保护模式 │ 长模式   │ 备注   │
├──────────┼─────────┼──────────┼──────────┼─────────┤
│ 地址宽度 │ 16 位   │ 32 位    │ 64 位    │         │
│ 地址空间 │ 1 MB    │ 4 GB     │ 256 TB   │        │
│ 段机制   │ 段:偏移 │ GDT/LDT  │ 忽略     │ LM 无段│
│ 内存保护 │ 无      │ 有       │ 有       │        │
│ 分页     │ 无      │ 可选     │ 必须     │        │
│ 指令集   │ x86     │ x86      │ x86-64   │        │
│ 寄存器   │ AX,BX.. │ EAX..    │ RAX..    │        │
│ BIOS中断 │ 可用    │ 不可用   │ 不可用   │        │
│ 系统调用 │ INT XX  │ INT 0x80 │ SYSCALL  │        │
└──────────┴─────────┴──────────┴──────────┴─────────┘
```

### 5.2 模式切换流程

```
┌──────────┐        ┌──────────┐        ┌──────────┐
│ 实模式    │   →    │ 保护模式  │   →    │ 长模式    │
└──────────┘        └──────────┘        └──────────┘
│                       │                   │
│ 启动状态              │ CR0.PE=1         │ CR0.PG=1
│ BIOS 可用             │ GDT 加载         │ EFER.LME=1
│                       │ Far jump         │ Paging on
│                       │                   │
└───────────────────────┴───────────────────┘
         │                       │
         ▼                       ▼
    load_kernel()          lgdt [gdt_ptr]
    必须在这里调用！       setup_page_tables()
                           enable_pae()
                           set_lme()
```

### 5.3 寄存器扩展

```
实模式 (16 位):
  AX, BX, CX, DX, SI, DI, BP, SP
  CS, DS, ES, SS

保护模式 (32 位):
  EAX, EBX, ECX, EDX, ESI, EDI, EBP, ESP
  (增加 E 前缀，低 16 位兼容)

长模式 (64 位):
  RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP
  (增加 R 前缀，低 32 位兼容)
  + R8-R15 (新 64 位寄存器)
  + R8D-R15D (32 位视图)
  + R8W-R15W (16 位视图)
  + R8B-R15B (8 位视图)
```

## 6. 汇编指令

### 6.1 控制流指令

#### JMP - 无条件跳转

```asm
; Near jump (段内跳转)
jmp label

; Far jump (段间跳转)
jmp selector:offset

; Indirect jump (间接跳转)
jmp rax           ; 64 位
jmp eax           ; 32 位
jmp ax            ; 16 位

; 手动编码 far jump (从 16 位跳到 32 位)
db 0x66           ; operand-size prefix
db 0xEA           ; jmp far opcode
dd offset         ; 32 位 offset
dw selector       ; 16 位 segment selector
```

#### CALL - 调用子程序

```asm
; Near call
call function     ; push return address, then jump

; Far call
call 0x18:func    ; push CS, push return address, then jump

; Indirect call
call rdi         ; call to address in RDI
call [rax]       ; call to address in memory
```

### 6.2 数据传送指令

#### MOV - 传送数据

```asm
; 立即数到寄存器
mov eax, 0x12345678
mov rdi, 0xB8000

; 寄存器到寄存器
mov ebx, eax

; 内存到寄存器
mov ax, [rdi]
mov eax, [0x9000]

; 寄存器到内存
mov [rdi], ax
mov dword [0x9000], eax

; 特殊寄存器
mov eax, cr0
mov cr3, eax
```

#### MOV 控制寄存器

```
CR0 (Control Register 0):
  bit 31 - PG (Paging)          - 启用分页
  bit 30  - CD (Cache Disable)  - 禁用缓存
  bit 29  - NW (Not Write-through)
  bit 18  - AM (Alignment Mask)
  bit 16  - WP (Write Protect)
  bit 5   - NE (Numeric Error)
  bit 4   - ET (Extension Type)
  bit 3   - TS (Task Switched)
  bit 2   - EM (Emulation)
  bit 1   - MP (Monitor Coprocessor)
  bit 0   - PE (Protection Enable) - 启用保护模式

CR3 (Control Register 3):
  bit 63-52 - 保留 (必须为 0)
  bit 51-40 - 保留
  bit 39    - 保留
  bit 38-12 - PML4 基地址 (必须 4KB 对齐)
  bit 11-0  - 保留 (必须为 0)

CR4 (Control Register 4):
  bit 5 - PAE (Physical Address Extension) - 启用 PAE
  ...
```

### 6.3 标志控制指令

```asm
cli   ; Clear Interrupts (禁用中断)
```


### 6.4 算术指令


## 7. GDT 和段

### 7.1 CCOS GDT 定义

```asm
; boot2.asm:13-23
gdt_start:
    dq 0x0000000000000000                    ; null descriptor
gdt_code:
    dq 0x00CF9A000000FFFF                   ; 32-bit code segment
gdt_data:
    dq 0x00CF92000000FFFF                   ; 32-bit data segment
gdt_code64:
    dq 0x00AF9A000000FFFF                   ; 64-bit code segment
gdt_data64:
    dq 0x00CF92000000FFFF                   ; 64-bit data segment
gdt_end:
```

### 7.2 段选择子

```
段选择子格式 (16 位):
┌─15───3┬──2┬─1─0┐
│ Index │ TI│ RPL│
└───────┴────┴────┘

Index: GDT 中的索引 (0-8191)
TI:    0 = GDT, 1 = LDT
RPL:   Requested Privilege Level (0-3)

计算公式:
Selector = (Index × 8) | (TI << 2) | RPL

CCOS 选择子:
0x00 = (0 × 8) | 0 | 0 → Null
0x08 = (1 × 8) | 0 | 0 → gdt_code
0x10 = (2 × 8) | 0 | 0 → gdt_data
0x18 = (3 × 8) | 0 | 0 → gdt_code64
0x20 = (4 × 8) | 0 | 0 → gdt_data64
```

### 7.3 段寄存器加载

```asm
; 数据段
mov ax, 0x10
mov ds, ax
mov es, ax
mov fs, ax
mov gs, ax
mov ss, ax

; 代码段 (通过 far jump)
jmp 0x08:protected_mode
jmp 0x18:long_mode
```

## 8. 页表详解

### 8.1 CCOS 页表布局

```asm
; boot2.asm:257-294
setup_page_tables:
    ; PML4 at 0x9000 (4KB)
    mov edi, 0x9000
    mov ecx, 4096 / 4
    xor eax, eax
    rep stosd              ; 清零

    ; PDPT at 0xA000 (4KB)
    mov edi, 0xA000
    mov ecx, 4096 / 4
    xor eax, eax
    rep stosd              ; 清零

    ; PD at 0xB000 (4KB)
    mov edi, 0xB000
    mov ecx, 4096 / 4
    xor eax, eax
    rep stosd              ; 清零

    ; PML4[0] → PDPT (identity mapping)
    mov dword [0x9000], 0x0000A003
    ; base=0xA000, P=1, RW=1

    ; PML4[511] → PDPT (higher-half)
    mov dword [0x9FF8], 0x0000A003
    ; base=0xA000, P=1, RW=1

    ; PDPT[0] → PD
    mov dword [0xA000], 0x0000B003
    ; base=0xB000, P=1, RW=1

    ; PD[0] → 2MB 页
    mov dword [0xB000], 0x00000083
    mov dword [0xB004], 0x00000000
    ; base=0x0, PS=1 (2MB), P=1, RW=1

    ; PD[511] → 2MB 页 (higher-half)
    mov dword [0xBFF0], 0x00000083
    mov dword [0xBFF4], 0x00000000
```

### 8.2 地址翻译

