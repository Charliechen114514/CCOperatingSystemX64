## 🔍 本文档涵盖的功能

### 内核加载功能 (v2.0)

**主要特性**:
- ✅ Boot2 在实模式加载内核
- ✅ 内核加载到 0x10000
- ✅ 长模式跳转到内核
- ✅ 内核成功执行并输出

**代码变更**:
- [boot/boot.asm](../../boot/boot.asm) - Stage 1 支持 2 扇区
- [boot/boot2.asm](../../boot/boot2.asm) - Stage 2 内核加载
- [kernel/kernel.asm](../../kernel/kernel.asm) - 64 位内核
- [Makefile](../../Makefile) - 构建系统更新

**磁盘布局**:
```
Sector 0:   boot1.bin (512B)
Sector 1-2: boot2.bin (1024B)
Sector 3:   kernel.bin (512B)
```

**验证方法**:
- VGA 行 0: Boot2 调试字符 (S...K)
- VGA 行 5: 内核字符 (X)
