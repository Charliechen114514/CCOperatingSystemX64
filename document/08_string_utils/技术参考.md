# 字符串工具库与断言系统 - 技术参考

本文档提供字符串函数库和断言系统的完整技术参考。

---

## 1. 字符串函数 API 参考

### 1.1 基础操作

#### `strlen`

计算字符串长度。

```c
size_t strlen(const char* s);
```

**参数**:
- `s`: 输入字符串（必须非空）

**返回值**:
- 字符串长度（不包括终止空字符）

**行为**:
- 计算到第一个 `'\0'` 的字符数
- 使用断言验证 `s` 非空

**示例**:
```c
size_t len = strlen("hello");  // 返回 5
```

---

#### `strnlen`

计算字符串长度，有上限。

```c
size_t strnlen(const char* s, size_t maxlen);
```

**参数**:
- `s`: 输入字符串（必须非空）
- `maxlen`: 最大检查长度

**返回值**:
- 字符串长度，最多 `maxlen`

**用途**:
- 处理可能非空终止的字符串
- 防止缓冲区溢出

**示例**:
```c
// 安全检查
size_t len = strnlen(unsafe_str, 100);
if (len >= 100) {
    // 字符串可能没有终止符
}
```

---

#### `strcpy`

复制字符串。

```c
char* strcpy(char* dest, const char* src);
```

**参数**:
- `dest`: 目标缓冲区（必须足够大）
- `src`: 源字符串（必须非空）

**返回值**:
- `dest` 指针

**行为**:
- 复制包括终止空字符在内的所有字符
- 不检查目标缓冲区大小

**警告**: 缓冲区溢出风险

**安全替代**:
```c
// 如果知道大小
strncpy(dest, src, dest_size - 1);
dest[dest_size - 1] = '\0';
```

---

#### `strncpy`

复制字符串，有长度限制。

```c
char* strncpy(char* dest, const char* src, size_t n);
```

**参数**:
- `dest`: 目标缓冲区
- `src`: 源字符串
- `n`: 最多复制字符数

**返回值**:
- `dest` 指针

**行为**:
- 如果 `src` 长度 < `n`，剩余部分用 `'\0'` 填充
- 如果 `src` 长度 ≥ `n`，结果不会空终止

**注意**: 可能不添加终止符

---

### 1.2 字符串比较

#### `strcmp`

比较两个字符串。

```c
int strcmp(const char* s1, const char* s2);
```

**返回值**:
- `< 0`: `s1` < `s2`
- `= 0`: `s1` == `s2`
- `> 0`: `s1` > `s2`

**示例**:
```c
if (strcmp(user_input, "quit") == 0) {
    // 用户输入了 "quit"
}
```

---

#### `strncmp`

比较两个字符串，有长度限制。

```c
int strncmp(const char* s1, const char* s2, size_t n);
```

**用途**:
- 比较字符串前缀

**示例**:
```c
if (strncmp(url, "http://", 7) == 0) {
    // URL 使用 HTTP 协议
}
```

---

#### `strcasecmp`

忽略大小写比较。

```c
int strcasecmp(const char* s1, const char* s2);
```

**返回值**: 与 `strcmp` 相同

**示例**:
```c
if (strcasecmp(user_input, "yes") == 0) {
    // 接受 "yes", "YES", "Yes", 等
}
```

---

#### `strncasecmp`

忽略大小写比较，有长度限制。

```c
int strncasecmp(const char* s1, const char* s2, size_t n);
```

---

### 1.3 字符串搜索

#### `strchr`

查找字符首次出现。

```c
char* strchr(const char* s, int c);
```

**返回值**:
- 找到：指向该字符的指针
- 未找到：`NULL`

**示例**:
```c
char* dot = strchr(filename, '.');
if (dot) {
    printf("Extension: %s\n", dot + 1);
}
```

---

#### `strrchr`

查找字符最后出现。

```c
char* strrchr(const char* s, int c);
```

**用途**:
- 查找路径中的文件名
- 提取文件扩展名

**示例**:
```c
char* last_slash = strrchr(path, '/');
if (last_slash) {
    printf("Filename: %s\n", last_slash + 1);
}
```

---

#### `strstr`

查找子串。

```c
char* strstr(const char* haystack, const char* needle);
```

**返回值**:
- 找到：指向子串的指针
- 未找到：`NULL`

**示例**:
```c
if (strstr(text, "error")) {
    printf("Error message found\n");
}
```

---

#### `strpbrk`

查找字符集中的任意字符。

```c
char* strpbrk(const char* s, const char* accept);
```

**返回值**:
- 找到：指向第一个匹配字符的指针
- 未找到：`NULL`

**示例**:
```c
char* first_space = strpbrk(text, " \t\n");
if (first_space) {
    // 找到第一个空白字符
}
```

---

#### `strspn`

计算初始段的长度（仅包含指定字符）。

```c
size_t strspn(const char* s, const char* accept);
```

**用途**:
- 跳过前导空白
- 验证格式

**示例**:
```c
size_t leading_spaces = strspn(text, " \t");
```

---

#### `strcspn`

计算初始段的长度（不包含指定字符）。

```c
size_t strcspn(const char* s, const char* reject);
```

---

### 1.4 字符串分割

#### `strtok`

分割字符串（非线程安全）。

```c
char* strtok(char* str, const char* delim);
```

**参数**:
- `str`: 首次调用时传入字符串，后续调用传入 `NULL`
- `delim`: 分隔符集合

**返回值**:
- 下一个 token，或 `NULL` 如果没有更多

**注意**: 修改原字符串（替换分隔符为 `'\0'`）

**示例**:
```c
char str[] = "hello,world,tokens";
char* token = strtok(str, ",");
while (token) {
    printf("Token: %s\n", token);
    token = strtok(NULL, ",");
}
```

**输出**:
```
Token: hello
Token: world
Token: tokens
```

---

#### `strtok_r`

分割字符串（可重入/线程安全）。

```c
char* strtok_r(char* str, const char* delim, char** saveptr);
```

**参数**:
- `str`: 首次调用时传入字符串，后续调用传入 `NULL`
- `delim`: 分隔符集合
- `saveptr`: 保存状态的指针（由调用者提供）

**示例**:
```c
char str[] = "a:b:c";
char* saveptr;
char* token = strtok_r(str, ":", &saveptr);
while (token) {
    printf("Token: %s\n", token);
    token = strtok_r(NULL, ":", &saveptr);
}
```

## 2. 断言系统 API

### 2.1 断言宏

#### `CCOS_ASSERT`

始终启用的断言。

```c
#define CCOS_ASSERT(EXPECTED_EXPR) \
    ccos_assert_impl(EXPECTED_EXPR, #EXPECTED_EXPR, __FILE__, __LINE__, __func__)
```

**行为**:
- 如果表达式为 `false`，显示错误并停止系统
- 在 Debug 和 Release 模式都启用

**用途**:
- 关键检查（非空指针、数组边界等）
- 不变式验证

**示例**:
```c
void process_buffer(char* buffer, size_t size) {
    CCOS_ASSERT(buffer != NULL);
    CCOS_ASSERT(size > 0);
    // ...
}
```

---

#### `CCOS_DEBUG_ASSERT`

仅 Debug 模式启用的断言。

```c
#ifdef NDEBUG
#    define CCOS_DEBUG_ASSERT(EXPECTED_EXPR) (void)(EXPECTED_EXPR)
#else
#    define CCOS_DEBUG_ASSERT(EXPECTED_EXPR) \
        ccos_assert_impl(EXPECTED_EXPR, #EXPECTED_EXPR, __FILE__, __LINE__, __func__)
#endif
```

**行为**:
- Debug 模式：检查断言，失败时停止
- Release 模式：完全移除

**用途**:
- 调试辅助检查
- 性能敏感代码中的临时验证

**示例**:
```c
void sort(int* array, size_t n) {
    // 排序算法
    // ...

    // 调试时验证结果有序
    CCOS_DEBUG_ASSERT(is_sorted(array, n));
}
```

---

### 2.2 后端函数

#### `ccos_assert_impl`

断言实现函数（通常不直接调用）。

```c
void ccos_assert_impl(bool condition, const char* expr_str,
                      const char* file, int line, const char* func);
```

---

#### `assert_backend_to_vga`

VGA 报告后端。

```c
void assert_backend_to_vga(const char* file, int line,
                           const char* func, const char* expr_str);
```

**显示格式**:
```
*** ASSERTION FAILED ***

File: kernel/example.c:42
Function: process_data
Expression: buffer != NULL
```

---

#### `assert_failed_action`

断言失败后的系统动作。

```c
void assert_failed_action(void);
```

**行为**:
- Debug 模式：触发 `int3` 断点
- 所有模式：`cli` + `hlt` 循环

## 3. 测试宏 API

### 3.1 断言宏

#### `TEST_ASSERT_EQ`

相等断言。

```c
#define TEST_ASSERT_EQ(actual, expected, msg)
```

**示例**:
```c
TEST_ASSERT_EQ(strlen("hello"), 5, "strlen: normal string");
```

---

#### `TEST_ASSERT_STR_EQ`

字符串相等断言。

```c
#define TEST_ASSERT_STR_EQ(actual, expected, msg)
```

**示例**:
```c
TEST_ASSERT_STR_EQ(buffer, "hello", "strcpy: basic copy");
```

---

### 3.2 辅助宏

#### `TEST_INFO`

输出信息。

```c
#define TEST_INFO(msg)
```

---

#### `TEST_PASS`

标记测试通过。

```c
#define TEST_PASS(msg)
```

## 5. 性能特性

| 函数 | 时间复杂度 | 空间复杂度 | 备注 |
|------|-----------|-----------|------|
| `strlen` | O(n) | O(1) | 单次遍历 |
| `strcpy` | O(n) | O(1) | 单次遍历 |
| `strcmp` | O(n) | O(1) | 提前退出 |
| `strstr` | O(n×m) | O(1) | 简单算法 |
| `strtok` | O(n) | O(1) | 原地修改 |
