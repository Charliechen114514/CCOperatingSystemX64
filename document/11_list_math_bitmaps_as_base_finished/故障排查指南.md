## 1. 编译问题

### 1.1 隐式声明警告

#### 症状

```
warning: implicit declaration of function 'list_count'
warning: implicit declaration of function 'bitmap_set'
```

#### 原因

缺少头文件包含或函数声明。

#### 解决方案

确保包含正确的头文件：

```c
#include "list/list.h"      // 链表
#include "math/bits.h"      // 位操作
#include "bitmap/bitmap.h"  // 位图
```

### 1.2 重定义错误

#### 症状

```
error: redefinition of 'list_head'
error: redefinition of 'bitmap'
```

#### 原因

头文件被多次包含，缺少 `#pragma once` 或 include guard。

#### 解决方案

确保头文件有保护：

```c
#pragma once

// 或

#ifndef LIST_H
#define LIST_H
// ...
#endif
```

### 1.3 类型不匹配

#### 症状

```
warning: assignment from incompatible pointer type
error: cannot convert 'list_head*' to 'task_t*'
```

#### 原因

直接将 list_head 指针当作结构体指针使用。

#### 解决方案

使用 `list_entry` 宏：

```c
// 错误
task_t* task = ptr;  // ptr 是 list_head*

// 正确
task_t* task = list_entry(ptr, task_t, list);
```

## 2. 链接问题

### 2.1 未定义引用

#### 症状

```
undefined reference to 'list_count'
undefined reference to 'bitmap_set'
undefined reference to 'dump_stack'
```

#### 原因

忘记链接相应的库或源文件。

#### 解决方案

检查 CMakeLists.txt：

```cmake
# 确保添加所有源文件
target_link_libraries(kernel_main PRIVATE
    list
    math
    bitmap
    stacktrace
    klogs
)
```

### 2.2 多重定义

#### 症状

```
multiple definition of 'g_list_head'
multiple definition of 'g_bitmap'
```

#### 原因

全局变量在头文件中定义，被多个源文件包含。

#### 解决方案

在头文件中使用 `extern` 声明：

```c
// 头文件 (list.h)
extern list_head* g_global_list;

// 源文件 (list.c)
list_head* g_global_list = NULL;
```

## 3. 运行时问题

### 3.1 链表操作崩溃

#### 症状

系统重启或出现异常，调试显示在 `list_del` 或 `list_add` 中崩溃。

#### 原因 1：未初始化的链表头

```c
// 错误：链表头未初始化
list_head my_list;
list_add(&node, &my_list);  // 崩溃！
```

**解决方案**:
```c
// 正确：先初始化
list_head my_list;
INIT_LIST_HEAD(&my_list);
list_add(&node, &my_list);
```

#### 原因 2：重复删除节点

```c
// 错误
list_del(&node);
// ... 使用 node
list_del(&node);  // 再次删除，崩溃！
```

**解决方案**:
```c
// 删除后不要使用
list_del(&node);
node.next = NULL;  // 清空指针防止误用
```

#### 原因 3：遍历中删除节点

```c
// 错误
list_head* pos;
list_for_each(pos, head) {
    if (should_delete(pos)) {
        list_del(pos);  // pos->next 已失效！
    }
}
```

**解决方案**:
```c
// 使用 safe 版本
list_head* pos, *n;
list_for_each_safe(pos, n, head) {
    if (should_delete(pos)) {
        list_del(pos);
    }
}
```

### 3.2 list_entry 返回错误值

#### 症状

通过 `list_entry` 获取的结构体指针访问成员时出现异常。

#### 原因

类型参数或成员名称不匹配。

#### 解决方案

```c
// 确保类型和成员名称正确
task_t* task = list_entry(ptr, task_t, list);
//                           ^^^^  ^^^^^^  ^^^^
//                           正确的类型  正确的成员名
```

### 3.3 位图操作越界

#### 症状

访问位图时出现异常或值不正确。

#### 原因

访问超出位图范围的位。

#### 解决方案

添加边界检查：

```c
void bitmap_set_safe(bitmap* bm, size_t bit) {
    if (bit >= bm->nbits) {
        klog_error("bitmap_set: bit %zu >= nbits %zu\n", bit, bm->nbits);
        return;
    }
    bitmap_set(bm, bit);
}
```

### 3.4 栈回溯失败

#### 症状

调用 `dump_stack()` 没有输出或输出异常。

#### 原因 1：编译器优化掉了帧指针

```
编译选项使用了 -fomit-frame-pointer
```

**解决方案**:
```cmake
# 确保不省略帧指针
target_compile_options(kernel PRIVATE -fno-omit-frame-pointer)
```

#### 原因 2：栈范围不正确

```c
#define STACK_BASE    0x80000UL    // 可能不正确
#define STACK_SIZE    0x10000UL
```

**解决方案**:
根据实际内核布局调整这些值，或添加动态检测。

## 4. 数据结构问题

### 4.1 链表环形引用

#### 症状

遍历链表时出现死循环。

#### 原因

链表被错误修改，形成了不正确的环。

#### 调试方法

```c
// 检测链表环
bool list_has_loop(list_head* head) {
    list_head* slow = head;
    list_head* fast = head;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            return true;  // 检测到环
        }
    }
    return false;
}
```

### 4.2 位图状态不一致

#### 症状

`bitmap_test` 返回的值与预期不符。

#### 调试方法

```c
// 打印位图状态
void bitmap_dump(const bitmap* bm) {
    klog_info("Bitmap (%zu bits):\n", bm->nbits);
    for (size_t i = 0; i < bm->nbits; i++) {
        if (i % 64 == 0) {
            klog_info("\n%04zx: ", i);
        }
        klog_info("%d", bitmap_test(bm, i) ? 1 : 0);
    }
    klog_info("\n");
}
```

### 4.3 内存对齐问题

#### 症状

访问对齐的数据时出现性能问题或异常。

#### 调试方法

```c
// 检查指针对齐
bool check_alignment(void* ptr, size_t alignment) {
    return ((uintptr_t)ptr & (alignment - 1)) == 0;
}

// 使用
if (!check_alignment(ptr, 16)) {
    klog_warn("Pointer not 16-byte aligned: %p\n", ptr);
}
```

## 5. 调试技巧

### 5.1 GDB 调试链表

#### 设置断点

```gdb
# 在链表函数设置断点
(gdb) break list_add
(gdb) break list_del
(gdb) break list_count
```

#### 检查链表状态

```gdb
# 查看链表头
(gdb) print *head

# 查看链表结构
(gdb) print head->next
(gdb) print head->prev

# 查看多个节点
(gdb) print *(head->next)
(gdb) print *(head->next->next)
```

#### 遍历链表

```gdb
# 使用 GDB 遍历
(gdb) set $pos = head->next
(gdb) while $pos != head
>print *$pos
>set $pos = $pos->next
>end
```

### 5.2 GDB 调试位图

#### 查看位图结构

```gdb
# 查看位图
(gdb) print *bm

# 查看位数据
(gdb) print bm->bits[0]@16  # 查看前 16 字节

# 十六进制显示
(gdb) x/16bx bm->bits
```

#### 测试单个位

```gdb
# 模拟 bitmap_test
(gdb) print (bm->bits[0] & (1 << 3)) != 0
```

### 5.3 栈回溯调试

#### 在 dump_stack 设置断点

```gdb
(gdb) break dump_stack
(gdb) commands
>print max_frames
>print rbp
>print rsp
>continue
>end
```

#### 手动检查栈帧

```gdb
# 查看 RBP 指向的内容
(gdb) x/2gx $rbp

# 查看 RBP+8 的返回地址
(gdb) x/gx $rbp+8

# 遍历栈帧
(gdb) set $rbp = $rbp
(gdb) while $rbp != 0
> x/2gx $rbp
> set $rbp = *(uintptr_t*)$rbp
>end
```

### 5.4 内存检查

#### 使用 valgrind (如果有用户态测试)

```bash
valgrind --leak-check=full --show-leak-kinds=all ./test_program
```

#### 自定义内存检查


## 6. 常见错误代码

### 6.1 编译错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `implicit declaration` | 缺少头文件 | 添加对应的 `#include` |
| `undefined reference` | 缺少链接 | 检查 CMakeLists.txt |
| `redefinition` | 重复定义 | 使用 `extern` 或 `static` |
| `incompatible pointer type` | 类型不匹配 | 使用 `list_entry` 宏 |

### 6.2 运行时错误

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| 链表操作崩溃 | 链表未初始化 | 调用 `INIT_LIST_HEAD` |
| 死循环 | 遍历中删除 | 使用 `list_for_each_safe` |
| 位置错误 | `list_entry` 参数错误 | 检查类型和成员名 |
| 位图越界 | 访问超出范围 | 检查位索引 |
| 栈回溯失败 | 帧指针被优化 | 添加 `-fno-omit-frame-pointer` |

## 7. 最佳实践

### 7.1 链表使用

```c
// 1. 总是初始化链表头
list_head my_list;
INIT_LIST_HEAD(&my_list);

// 2. 使用类型安全的遍历宏
task_t* task;
list_for_each_entry(task, &task_list, list) {
    // 使用 task
}

// 3. 删除时使用 safe 版本
task_t* task, *tmp;
list_for_each_entry_safe(task, tmp, &task_list, list) {
    if (should_remove(task)) {
        list_del(&task->list);
    }
}

// 4. 删除后清空指针
list_del(&task->list);
task = NULL;
```

### 7.2 位图使用

```c
// 1. 确保缓冲区足够大
size_t bytes = (nbits + 7) / 8;
uint8_t buffer[bytes];

// 2. 初始化后检查
bitmap_init(&bm, buffer, nbits);
CCOS_ASSERT(bitmap_empty(&bm));

// 3. 检查返回值
ssize_t bit = bitmap_find_first_zero(&bm);
if (bit < 0) {
    // 位图已满
    klog_error("Bitmap is full\n");
}
```

### 7.3 位操作使用

```c
// 1. 确保对齐值是 2 的幂次
CCOS_ASSERT(is_power_of_2(alignment));

// 2. 验证对齐结果
size_t aligned = align_up(ptr, 16);
```

