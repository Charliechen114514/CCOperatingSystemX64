## 1. 阶段背景

### 1.1 前一阶段遗留问题

在 Stage 10 (基础库与格式化日志系统) 中，我们实现了：
- 基础的字符串处理库 (`strhelpers`)
- 格式化日志系统 (`klogs`)

但当时缺乏：
- **高效的数据结构** - 没有链表、哈希表等常用数据结构
- **位操作工具** - 内存对齐、2的幂次计算等需要手写
- **位图支持** - 物理内存管理需要位图来跟踪内存页状态
- **栈回溯能力** - 调试时无法查看调用栈

### 1.2 本阶段目标

```
核心目标：建立内核基础数据结构库

1. 侵入式双向链表
   - Linux kernel 风格的 list_head
   - O(1) 插入/删除操作
   - 安全的遍历宏
   - 链表拼接和切割

2. 位操作数学库
   - 2的幂次检测和计算
   - 内存对齐工具
   - 整数除法舍入
   - 常用数学函数

3. 位图数据结构
   - 单比特操作
   - 位扫描功能
   - 位图逻辑运算

4. 栈回溯支持
   - 基于 RBP 的栈帧遍历
   - 符号解析
```

## 2. 设计决策

### 2.1 为什么选择侵入式链表？

#### 传统链表 vs 侵入式链表

**传统链表**:
```c
typedef struct node {
    void* data;
    struct node* next;
    struct node* prev;
} node_t;

// 需要额外分配
node_t* n = malloc(sizeof(node_t));
n->data = &my_data;
```

**侵入式链表**:
```c
typedef struct task {
    int pid;
    list_head list;  // 节点直接嵌入数据结构
} task_t;

// 无需额外分配
list_add(&task1.list, &task_list);
```

#### 决策：采用侵入式链表

**理由**:
1. **内存效率** - 无需额外分配节点
2. **缓存友好** - 数据和链表节点连续存储
3. **多链表支持** - 一个结构体可包含多个 list_head
4. **通用性** - 同一套 API 可操作任何包含 list_head 的结构

### 2.2 为什么自己实现位操作库？

#### 问题

标准库缺失以下功能：
- 2的幂次快速检测
- 高效的内存对齐计算
- 向上取整除法

#### 选择

**方案 A**: 使用 GCC 内置函数
```c
__builtin_popcount()
__builtin_clz()
__builtin_ctz()
```

**方案 B**: 自己实现
```c
static inline bool is_power_of_2(unsigned long n) {
    return n != 0 && (n & (n - 1)) == 0;
}
```

#### 决策：混合使用

- 基础操作自己实现（可移植性好）
- 性能关键场景考虑内置函数
- 提供清晰的接口

### 2.3 位图设计考虑

#### 位图用途

1. **物理内存管理** - 跟踪物理页的使用状态
2. **进程管理** - 跟踪 PID 分配
3. **中断管理** - 跟踪中断状态
4. **设备管理** - 跟踪设备资源

#### 设计要点

```c
typedef struct bitmap {
    byte_t* bits;  // 使用外部缓冲区
    size_t nbits;  // 位数量
} bitmap;
```

**关键设计**:
- 使用外部缓冲区，不分配内存
- 按字节操作，兼顾效率和可读性
- 提供位扫描功能用于分配器

### 2.4 栈回溯实现方式

#### 挑战

内核没有 libc 支持，无法使用 `backtrace()` 函数。

#### 解决方案

使用 x86_64 调用约定：
- RBP 指向当前栈帧
- [RBP] 存储上一个 RBP
- [RBP + 8] 存储返回地址

```c
void dump_stack(int max_frames) {
    uintptr_t rbp = get_rbp();

    while (rbp != 0 && frame < max_frames) {
        uintptr_t* frame_ptr = (uintptr_t*)rbp;
        uintptr_t prev_rbp = frame_ptr[0];
        uintptr_t rip = frame_ptr[1];

        // 打印返回地址
        rbp = prev_rbp;
    }
}
```

## 4. 实现细节

### 4.1 侵入式链表核心操作

#### 插入操作

```c
// 内部函数：在两个节点之间插入新节点
void __list_add(list_head* new_node, list_head* prev, list_head* next) {
    next->prev = new_node;
    new_node->next = next;
    new_node->prev = prev;
    prev->next = new_node;
}

// 公开接口：在链表头部插入
static inline void list_add(list_head* new_node, list_head* head) {
    __list_add(new_node, head, head->next);
}

// 公开接口：在链表尾部插入
static inline void list_add_tail(list_head* new_node, list_head* head) {
    __list_add(new_node, head->prev, head);
}
```

#### 删除操作

```c
// 内部函数：删除两个节点之间的节点
void __list_del(list_head* prev, list_head* next) {
    next->prev = prev;
    prev->next = next;
}

// 公开接口：删除节点
static inline void list_del(list_head* entry) {
    __list_del(entry->prev, entry->next);
}

// 删除并重新初始化节点
void list_del_init(list_head* entry) {
    __list_del(entry->prev, entry->next);
    INIT_LIST_HEAD(entry);
}
```

#### 遍历宏

```c
// 基础遍历
#define list_for_each(pos, head) \
    for ((pos) = (head)->next; (pos) != (head); (pos) = (pos)->next)

// 安全遍历（支持删除当前节点）
#define list_for_each_safe(pos, n, head) \
    for ((pos) = (head)->next, (n) = (pos)->next; \
         (pos) != (head); \
         (pos) = (n), (n) = (pos)->next)

// 类型安全遍历
#define list_for_each_entry(pos, head, member) \
    for ((pos) = list_first_entry(head, typeof(*(pos)), member); \
         (pos) != NULL; \
         (pos) = list_next_entry_safe(pos, head, member))
```

### 4.2 位操作实现

#### 2的幂次检测

```c
// 利用了 2 的幂次二进制表示只有一个 1 的特性
// 例如：8 = 1000, 7 = 0111, 8 & 7 = 0
static inline bool is_power_of_2(unsigned long n) {
    return n != 0 && (n & (n - 1)) == 0;
}
```

#### 向上取整到 2 的幂次

```c
static inline unsigned long round_up_to_power_of_2(unsigned long n) {
    if (n <= 1)
        return 1;
    n--;
    // 将最高位 1 之后的所有位都置为 1
    n |= n >> 1;
    n |= n >> 2;
    n |= n >> 4;
    n |= n >> 8;
    n |= n >> 16;
    n |= n >> 32;
    return n + 1;
}
```

#### 内存对齐

```c
// 向上对齐：要求 alignment 是 2 的幂次
static inline unsigned long align_up(unsigned long value, unsigned long alignment) {
    return (value + alignment - 1) & ~(alignment - 1);
}

// 向下对齐
static inline unsigned long align_down(unsigned long value, unsigned long alignment) {
    return value & ~(alignment - 1);
}

// 对齐检查
static inline bool is_aligned(unsigned long value, unsigned long alignment) {
    return (value & (alignment - 1)) == 0;
}
```

#### 除法舍入

```c
// 向上取整（常用于计算页数）
static inline unsigned long div_round_up(unsigned long n, unsigned long d) {
    return (n + d - 1) / d;
}

// 向最近取整
static inline unsigned long div_round_nearest(unsigned long n, unsigned long d) {
    return (n + d / 2) / d;
}
```

### 4.3 位图实现

#### 单比特操作

```c
// 辅助宏（bitmap_helper.h）
#define BITS_PER_BYTE  (8)
#define bit_byte(bit)  ((bit) / BITS_PER_BYTE)
#define bit_offset(bit) ((bit) % BITS_PER_BYTE)

// 设置位
void bitmap_set(bitmap* bm, size_t bit) {
    bm->bits[bit_byte(bit)] |= (1 << bit_offset(bit));
}

// 清除位
void bitmap_clear(bitmap* bm, size_t bit) {
    bm->bits[bit_byte(bit)] &= ~(1 << bit_offset(bit));
}

// 测试位
bool bitmap_test(const bitmap* bm, size_t bit) {
    return bm->bits[bit_byte(bit)] & (1 << bit_offset(bit));
}
```

#### 位扫描

```c
// 查找第一个零位
ssize_t bitmap_find_next_zero(const bitmap* bm, size_t start) {
    for (size_t i = start; i < bm->nbits; i++)
        if (!bitmap_test(bm, i))
            return (ssize_t)i;
    return -1;
}
```

#### 位图权重（Brian Kernighan 算法）

```c
size_t bitmap_weight(const bitmap* bm) {
    size_t count = 0;
    size_t bytes = bitCntToByteCnt(bm->nbits);

    for (size_t i = 0; i < bytes; i++) {
        uint8_t byte = bm->bits[i];
        // 每次清除最低位的 1，计算需要清除多少次
        while (byte) {
            byte &= byte - 1;
            count++;
        }
    }
    return count;
}
```

### 4.4 栈回溯实现

#### 获取寄存器值

```c
static inline uintptr_t get_rsp(void) {
    uintptr_t rsp;
    __asm__ volatile("mov %%rsp, %0" : "=r"(rsp));
    return rsp;
}

static inline uintptr_t get_rbp(void) {
    uintptr_t rbp;
    __asm__ volatile("mov %%rbp, %0" : "=r"(rbp));
    return rbp;
}
```

#### 帧指针验证

```c
static bool is_valid_frame(uintptr_t ptr) {
    // 检查对齐（x86_64 栈帧应 8 字节对齐）
    if (ptr & 0x7)
        return false;

    // 检查是否在合理栈范围内
    if (ptr > STACK_BASE)
        return false;

    if (ptr < (STACK_BASE - STACK_SIZE))
        return false;

    return true;
}
```

## 5. 常见陷阱

### 5.1 侵入式链表陷阱

#### 陷阱：container_of 类型错误

```c
// 错误：类型不匹配
task_t* task = list_entry(ptr, process_t, list);  // 错误！

// 正确
task_t* task = list_entry(ptr, task_t, list);
```

#### 陷阱：遍历中删除节点

```c
// 错误：删除后无法继续遍历
list_for_each(pos, head) {
    if (should_delete(pos)) {
        list_del(pos);  // pos->next 已被修改！
    }
}

// 正确：使用 safe 版本
list_for_each_safe(pos, n, head) {
    if (should_delete(pos)) {
        list_del(pos);
    }
}
```

#### 陷阱：list_entry 使用空指针

```c
// 危险：如果 pos 为 NULL 会导致崩溃
list_for_each_entry(pos, head, member) {
    // 如果 list_first_entry 返回 NULL
}

// 正确：检查返回值
if (pos != NULL) {
    // 使用 pos
}
```

### 5.2 位操作陷阱

#### 陷阱：对齐不是 2 的幂次

```c
// 错误：alignment = 10
size_t aligned = align_up(ptr, 10);  // 结果不正确！

// 正确：alignment 必须是 2 的幂次
size_t aligned = align_up(ptr, 16);
```

#### 陷阱：除以零

```c
// 危险
size_t pages = div_round_up(bytes, 0);  // 未定义行为

// 正确：检查除数
CCOS_ASSERT(d > 0);
```

### 5.3 位图陷阱

#### 陷阱：位索引越界

```c
// 危险
bitmap_set(&bm, 10000);  // 可能超出范围

// 正确：检查索引
CCOS_ASSERT(bit < bm->nbits);
```

#### 陷阱：缓冲区大小不足

```c
// 错误：缓冲区太小
uint8_t buffer[10];  // 只有 80 位
bitmap bm;
bitmap_init(&bm, buffer, 1024);  // 需要 128 字节！

// 正确：计算所需大小
size_t bytes = (nbits + 7) / 8;
uint8_t buffer[bytes];
```

### 5.4 栈回溯陷阱

#### 陷阱：帧指针优化

```c
// 如果编译器优化掉了帧指针，栈回溯会失败

// 解决方案：编译时禁用帧指针省略
// GCC: -fno-omit-frame-pointer
// 或者使用 __attribute__((no_omit_frame_pointer))
```

#### 陷阱：无限循环

```c
// 如果栈帧损坏，可能导致无限循环

// 解决方案：限制最大帧数
if (frame >= DUMP_STACK_MAX_FRAMES) {
    break;
}

// 检测循环
if (rbp == get_rbp()) {
    break;
}
```

**优点**:

- 允许编译器优化
- 代码可读性好

### 6.2 位操作技巧

#### 快速计算 2 的幂次

```c
// 传统方法：循环
int p = 1;
while (p < n) p *= 2;

// 位操作方法：O(1) 复杂度
n--;
n |= n >> 1;
n |= n >> 2;
// ...
return n + 1;
```

#### Brian Kernighan 算法

```c
// 传统方法：总是循环 8 次
for (int i = 0; i < 8; i++) {
    if (byte & (1 << i)) count++;
}

// Brian Kernighan：循环次数等于 1 的个数
while (byte) {
    byte &= byte - 1;  // 清除最低位的 1
    count++;
}
```

## 8. 经验总结

### 8.1 最大的收获

#### 数据结构设计原则

```
简单性 > 通用性 > 性能

1. 先保证正确性
2. 再考虑通用性
3. 最后优化性能
```

#### 侵入式设计的价值

```
传统容器:
  数据 → 容器 → 访问

侵入式容器:
  数据（含容器节点） → 直接访问

优势：
  - 内存局部性好
  - 无间接访问
  - 支持多容器
```
