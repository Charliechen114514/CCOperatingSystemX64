## 1. 侵入式双向链表

### 1.1 数据结构

#### list_head

```c
typedef struct list_head {
    struct list_head* next;  // 指向下一个节点
    struct list_head* prev;  // 指向前一个节点
} list_head;
```

**设计特点**:
- 节点直接嵌入用户数据结构
- 空链表：next 和 prev 都指向自己
- 循环链表：末尾节点的 next 指向头节点

### 1.2 初始化

#### LIST_HEAD

静态初始化宏，用于编译时初始化：

```c
#define LIST_HEAD(name) \
    list_head name = { &(name), &(name) }

// 使用
LIST_HEAD(task_list);  // 创建一个名为 task_list 的链表头
```

#### INIT_LIST_HEAD

动态初始化函数，用于运行时初始化：

```c
static inline void INIT_LIST_HEAD(list_head* ptr) {
    ptr->next = ptr;
    ptr->prev = ptr;
}

// 使用
list_head my_list;
INIT_LIST_HEAD(&my_list);
```

### 1.3 基本操作

#### list_add

在链表头部添加节点（后插）：

```c
static inline void list_add(list_head* new_node, list_head* head);
```

**图示**:
```
初始状态:  HEAD <-> A <-> B
添加 NEW:  HEAD <-> NEW <-> A <-> B
```

#### list_add_tail

在链表尾部添加节点：

```c
static inline void list_add_tail(list_head* new_node, list_head* head);
```

**图示**:
```
初始状态:  HEAD <-> A <-> B
添加 NEW:  HEAD <-> A <-> B <-> NEW
```

#### list_del

删除节点：

```c
static inline void list_del(list_head* entry);
```

**注意**: 删除后节点指针未清空，不应再访问。

#### list_del_init

删除节点并重新初始化：

```c
void list_del_init(list_head* entry);
```

**效果**: 节点被删除后，next 和 prev 指向自己，可重新使用。

### 1.4 替换操作

#### list_replace

用新节点替换旧节点：

```c
static inline void list_replace(list_head* old_node, list_head* new_node);
```

#### list_replace_init

替换节点并重新初始化旧节点：

```c
void list_replace_init(list_head* old_node, list_head* new_node);
```

### 1.5 查询操作

#### list_is_empty

检查链表是否为空：

```c
static inline bool list_is_empty(const list_head* head);
```

**返回**: `true` 如果链表为空（head->next == head）

#### list_is_singular

检查链表是否只有一个节点：

```c
static inline bool list_is_singular(const list_head* head);
```

#### list_is_last

检查节点是否是链表最后一个节点：

```c
static inline bool list_is_last(const list_head* entry, const list_head* head);
```

#### list_on_list

检查节点是否在某个链表上：

```c
bool list_on_list(const list_head* node);
```

**返回**: `true` 如果节点的 next 和 prev 不指向自己

#### list_count

统计链表节点数量：

```c
size_t list_count(const list_head* head);
```

### 1.6 链表拼接

#### list_splice

将一个链表插入到另一个链表的头部：

```c
void list_splice(const list_head* list, list_head* head);
```

**效果**: `list` 的所有节点插入到 `head` 之后，`list` 变为空链表。

#### list_splice_tail

将一个链表追加到另一个链表的尾部：

```c
void list_splice_tail(const list_head* list, list_head* head);
```

#### list_splice_init

拼接并重新初始化源链表头：

```c
void list_splice_init(list_head* list, list_head* head);
```

#### list_cut_position

切割链表：

```c
void list_cut_position(list_head* list, list_head* head, list_head* entry);
```

**效果**: 将 `head` 中从开头到 `entry` 之前的节点移动到 `list`。

### 1.7 Entry 访问宏

#### list_entry

从 list_head 指针获取包含结构体指针：

```c
#define list_entry(ptr, type, member) \
    ((type*)((char*)(ptr) - (unsigned long)(&((type*)0)->member)))
```

**原理**: `container_of` 宏，通过成员指针和偏移量计算结构体地址。

**示例**:
```c
typedef struct task {
    int pid;
    list_head list;
} task_t;

list_head* ptr = ...;
task_t* task = list_entry(ptr, task_t, list);
```

#### list_first_entry

获取链表第一个节点：

```c
#define list_first_entry(ptr, type, member) \
    (list_is_empty(ptr) ? NULL : list_entry((ptr)->next, type, member))
```

#### list_last_entry

获取链表最后一个节点：

```c
#define list_last_entry(ptr, type, member) \
    (list_is_empty(ptr) ? NULL : list_entry((ptr)->prev, type, member))
```

#### list_next_entry

获取下一个节点：

```c
#define list_next_entry(pos, member) \
    list_entry((pos)->member.next, __typeof__(*(pos)), member)
```

#### list_prev_entry

获取前一个节点：

```c
#define list_prev_entry(pos, member) \
    list_entry((pos)->member.prev, __typeof__(*(pos)), member)
```

### 1.8 遍历宏

#### list_for_each

遍历链表节点：

```c
#define list_for_each(pos, head) \
    for ((pos) = (head)->next; (pos) != (head); (pos) = (pos)->next)
```

#### list_for_each_prev

反向遍历：

```c
#define list_for_each_prev(pos, head) \
    for ((pos) = (head)->prev; (pos) != (head); (pos) = (pos)->prev)
```

#### list_for_each_safe

安全遍历（支持删除）：

```c
#define list_for_each_safe(pos, n, head) \
    for ((pos) = (head)->next, (n) = (pos)->next; \
         (pos) != (head); \
         (pos) = (n), (n) = (pos)->next)
```

#### list_for_each_entry

遍历指定类型的节点：

```c
#define list_for_each_entry(pos, head, member) \
    for ((pos) = list_first_entry(head, __typeof__(*(pos)), member); \
         (pos) != NULL; \
         (pos) = list_next_entry_safe(pos, head, member))
```

**示例**:
```c
task_t* task;
list_for_each_entry(task, &task_list, list) {
    klog_info("PID: %d\n", task->pid);
}
```

#### list_for_each_entry_safe

安全遍历指定类型：

```c
#define list_for_each_entry_safe(pos, n, head, member) \
    for ((pos) = list_first_entry(head, __typeof__(*(pos)), member); \
         (pos) && ((n) = list_next_entry_safe(pos, head, member), 1); \
         (pos) = (n))
```

## 2. 位操作数学库

### 2.1 2 的幂次操作

#### is_power_of_2

检查是否为 2 的幂次：

```c
static inline bool is_power_of_2(unsigned long n);
```

**原理**: 2 的幂次的二进制表示只有一个 1，所以 `n & (n-1) == 0`。

**示例**:
```
n = 8  (1000)
n-1 = 7 (0111)
n & (n-1) = 0000 = 0  → 是 2 的幂次

n = 10 (1010)
n-1 = 9 (1001)
n & (n-1) = 1000 = 8 ≠ 0 → 不是 2 的幂次
```

#### round_up_to_power_of_2

向上取整到下一个 2 的幂次：

```c
static inline unsigned long round_up_to_power_of_2(unsigned long n);
```

**示例**:
```
round_up_to_power_of_2(0)  → 1
round_up_to_power_of_2(1)  → 1
round_up_to_power_of_2(5)  → 8
round_up_to_power_of_2(16) → 16
round_up_to_power_of_2(17) → 32
```

#### round_down_to_power_of_2

向下取整到上一个 2 的幂次：

```c
static inline unsigned long round_down_to_power_of_2(unsigned long n);
```

### 2.2 对齐操作

#### align_up

向上对齐到指定边界：

```c
static inline unsigned long align_up(unsigned long value, unsigned long alignment);
```

**要求**: `alignment` 必须是 2 的幂次。

**示例**:
```
align_up(0x1234, 0x10)  → 0x1240  (16 字节对齐)
align_up(0x1200, 0x100) → 0x1200  (256 字节对齐，已对齐)
align_up(0x1201, 0x100) → 0x1300  (256 字节对齐)
```

#### align_down

向下对齐到指定边界：

```c
static inline unsigned long align_down(unsigned long value, unsigned long alignment);
```

#### is_aligned

检查是否对齐：

```c
static inline bool is_aligned(unsigned long value, unsigned long alignment);
```

### 2.3 除法舍入

#### div_round_up

向上取整除法：

```c
static inline unsigned long div_round_up(unsigned long n, unsigned long d);
```

**用途**: 计算需要的页数、块数等。

**示例**:
```
div_round_up(100, 16)  → 7   (100 / 16 = 6.25 → 7)
div_round_up(96, 16)   → 6   (96 / 16 = 6)
div_round_up(97, 16)   → 7   (97 / 16 = 6.0625 → 7)
```

#### div_round_down

向下取整除法：

```c
static inline unsigned long div_round_down(unsigned long n, unsigned long d);
```

**等价于**: `n / d`

#### div_round_nearest

四舍五入除法：

```c
static inline unsigned long div_round_nearest(unsigned long n, unsigned long d);
```

### 2.4 数学工具函数

#### min / max

```c
#define min(a, b) ((a) < (b) ? (a) : (b))
#define max(a, b) ((a) < (b) ? (b) : (a))
```

#### abs

```c
#define abs(x) ((x) > 0 ? (x) : -(x))
```

#### clamp

```c
int clamp(int val, int min_val, int max_val);
```

**效果**: 将 val 限制在 [min_val, max_val] 范围内。

## 3. 位图数据结构

### 3.1 数据结构

#### bitmap

```c
typedef struct bitmap {
    byte_t* bits;  // 位存储缓冲区
    size_t nbits;  // 总位数
} bitmap;
```

### 3.2 初始化

#### bitmap_init

```c
void bitmap_init(bitmap* bm, void* buffer, size_t nbits);
```

**参数**:
- `bm`: 位图结构指针
- `buffer`: 存储位的缓冲区（由调用者提供）
- `nbits`: 位的数量

**注意**: 函数不分配内存，buffer 必须足够大。

### 3.3 单比特操作

#### bitmap_set

设置指定位：

```c
void bitmap_set(bitmap* bm, size_t bit);
```

#### bitmap_clear

清除指定位：

```c
void bitmap_clear(bitmap* bm, size_t bit);
```

#### bitmap_test

测试指定位：

```c
bool bitmap_test(const bitmap* bm, size_t bit);
```

**返回**: `true` 如果位已设置，`false` 否则。

#### bitmap_flip

翻转指定位：

```c
void bitmap_flip(bitmap* bm, size_t bit);
```

### 3.4 范围操作

#### bitmap_set_range

设置连续位：

```c
void bitmap_set_range(bitmap* bm, size_t start, size_t count);
```

#### bitmap_clear_range

清除连续位：

```c
void bitmap_clear_range(bitmap* bm, size_t start, size_t count);
```

### 3.5 位扫描

#### bitmap_find_first_zero

查找第一个零位：

```c
ssize_t bitmap_find_first_zero(const bitmap* bm);
```

**返回**: 第一个零位的索引，或 -1（全部位已设置）。

#### bitmap_find_first_set

查找第一个设置位：

```c
ssize_t bitmap_find_first_set(const bitmap* bm);
```

#### bitmap_find_next_zero

从指定位置查找下一个零位：

```c
ssize_t bitmap_find_next_zero(const bitmap* bm, size_t start);
```

**参数**:
- `start`: 起始搜索位置（包含）

#### bitmap_find_next_set

从指定位置查找下一个设置位：

```c
ssize_t bitmap_find_next_set(const bitmap* bm, size_t start);
```

### 3.6 逻辑运算

#### bitmap_and

按位与：

```c
void bitmap_and(bitmap* dst, const bitmap* a, const bitmap* b);
```

**效果**: `dst = a & b`

#### bitmap_or

按位或：

```c
void bitmap_or(bitmap* dst, const bitmap* a, const bitmap* b);
```

**效果**: `dst = a | b`

#### bitmap_xor

按位异或：

```c
void bitmap_xor(bitmap* dst, const bitmap* a, const bitmap* b);
```

**效果**: `dst = a ^ b`

#### bitmap_andnot

按位与非：

```c
void bitmap_andnot(bitmap* dst, const bitmap* a, const bitmap* b);
```

**效果**: `dst = a & ~b`

#### bitmap_complement

按位取反：

```c
void bitmap_complement(bitmap* dst, const bitmap* src);
```

**效果**: `dst = ~src`

### 3.7 工具函数

#### bitmap_equal

比较两个位图：

```c
bool bitmap_equal(const bitmap* a, const bitmap* b);
```

**返回**: `true` 如果两个位图完全相同。

#### bitmap_copy

复制位图：

```c
void bitmap_copy(bitmap* dst, const bitmap* src);
```

#### bitmap_weight

计算已设置位的数量：

```c
size_t bitmap_weight(const bitmap* bm);
```

**算法**: Brian Kernighan 算法，复杂度与已设置位数成正比。

#### bitmap_full

检查是否所有位都已设置：

```c
bool bitmap_full(const bitmap* bm);
```

#### bitmap_empty

检查是否所有位都未设置：

```c
bool bitmap_empty(const bitmap* bm);
```

#### bitmap_to_string

将位图转换为字符串：

```c
void bitmap_to_string(char* buf, const bitmap* bm);
```

**效果**: `buf` 包含 "010101..." 形式的字符串。

## 4. 栈回溯支持

### 4.1 常量定义

```c
#define DUMP_STACK_DEFAULT_FRAMES 16  // 默认最大帧数
#define DUMP_STACK_MAX_FRAMES 64      // 绝对最大帧数限制
```

### 4.2 API 函数

#### dump_stack

打印当前栈回溯：

```c
void dump_stack(int max_frames);
```

**参数**:
- `max_frames`: 最大帧数（0 表示使用默认值）

**输出格式**:
```
╔═══════════════════════════════════════════════════════════════╗
║                      Stack Trace                             ║
╠═══════════════════════════════════════════════════════════════╣
║  RSP: 0x00007ffff7e3e000                                    ║
║  RBP: 0x00007ffff7e3dff0                                    ║
╠═══════════════════════════════════════════════════════════════╣
║  #  Address           Function                               ║
╠═══════════════════════════════════════════════════════════════╣
║  0   0xffffffff80001000  kernel_main                         ║
║  1   0xffffffff80001200  task_init+0x10                      ║
║  2   0xffffffff80001500  scheduler_start+0x30                ║
╚═══════════════════════════════════════════════════════════════╝
```

#### dump_stack_full

使用默认帧数打印栈回溯：

```c
void dump_stack_full(void);
```

**等价于**: `dump_stack(DUMP_STACK_DEFAULT_FRAMES)`

### 4.3 实现细节

#### 栈帧结构

```
高地址
    +------------------+
    |  ...             |
    +------------------+
    |  返回地址 (RIP)  |  <- RBP + 8
    +------------------+
    |  保存的 RBP      |  <- RBP
    +------------------+
    |  局部变量        |
    |  ...             |
    +------------------+
    |  返回地址        |
    +------------------+
    |  保存的 RBP      |  <- 当前 RBP
    +------------------+
    |  局部变量        |  <- 当前 RSP
    +------------------+
低地址
```

#### 帧指针验证

```c
static bool is_valid_frame(uintptr_t ptr) {
    // 1. 检查对齐（8 字节）
    if (ptr & 0x7) return false;

    // 2. 检查栈范围
    if (ptr > STACK_BASE) return false;
    if (ptr < (STACK_BASE - STACK_SIZE)) return false;

    return true;
}
```

## 5. 数据结构

### 5.1 链表节点布局

```
数据结构:
┌────────────────────────────────────┐
│ task_t                             │
│ ┌────────┐  ┌──────────┐          │
│ │ pid    │  │ name[32] │          │
│ └────────┘  └──────────┘          │
│ ┌────────────────────────────┐   │
│ │ list_head list              │   │
│ │  ┌──────────┬──────────┐   │   │
│ │  │ next *   │ prev *   │   │   │
│ │  └──────────┴──────────┘   │   │
│ └────────────────────────────┘   │
└────────────────────────────────────┘

链表连接:
┌──────┐  next   ┌──────┐  next   ┌──────┐
│ HEAD │ ──────> │ task1│ ──────> │ task2│ ──────> (循环)
│      │ <────── │      │ <────── │      │ <──────
└──────┘  prev   └──────┘  prev   └──────┘
```

### 5.2 位图内存布局

```
位图 (10 位):
位索引:  9  8  7  6  5  4  3  2  1  0
字节:        [byte 1]      [byte 0]

byte[0]: bits 0-7
byte[1]: bits 8-15

访问:
- 位 3 → byte[0], offset 3
- 位 10 → byte[1], offset 2
```

### 5.3 栈帧布局

```
内存地址
    高
    │
    │    ┌─────────────────┐
    │    │   Previous      │
    │    │   Stack Frame   │
    │    ├─────────────────┤
    │    │   Return Addr   │ ← RBP + 8
    │    ├─────────────────┤
    │    │   Saved RBP     │ ← RBP
    │    ├─────────────────┤
    │    │   Local Vars    │
    │    │   ...           │ ← RSP
    │    └─────────────────┘
    │
    低
```

## 7. 编译配置

```cmake
# 链表库
add_library(list STATIC list.c)
target_include_directories(list PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})

# 数学库
add_library(math STATIC math.c)
target_include_directories(math PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})

# 位图库
add_library(bitmap STATIC bitmap.c)
target_link_libraries(bitmap PRIVATE math)
target_include_directories(bitmap PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})

# 栈回溯
add_library(stacktrace STATIC stacktrace.c)
target_link_libraries(stacktrace PRIVATE symbol klogs)
```

### 7.2 编译选项

```cmake
# 确保帧指针保留（栈回溯需要）
target_compile_options(kernel PRIVATE -fno-omit-frame-pointer)
```
