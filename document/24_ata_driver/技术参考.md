## 1. ATA 硬件基础

### 1.1 ATA 控制器架构

```
┌─────────────────────────────────────────────────────────┐
│                      CPU                                 │
│                     (x86_64)                             │
└────────────────────┬────────────────────────────────────┘
                     │ I/O 端口 0x1F0/0x170
┌────────────────────▼────────────────────────────────────┐
│                   ATA 控制器                              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────────┐           ┌──────────────┐           │
│  │  Bus Master  │           │   命令块     │           │
│  │  DMA 控制    │           │   寄存器     │           │
│  └──────────────┘           └──────────────┘           │
│                                                         │
│  ┌──────────────┐           ┌──────────────┐           │
│  │  Primary     │           │  Secondary   │           │
│  │  Channel     │           │  Channel     │           │
│  │  (IRQ 14)    │           │  (IRQ 15)    │           │
│  ├──────────────┤           ├──────────────┤           │
│  │  Master      │           │  Master      │           │
│  │  Slave       │           │  Slave       │           │
│  └──────────────┘           └──────────────┘           │
│                                                         │
└─────────────────────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                   ATA 设备                               │
│              (HDD / SSD / CD-ROM)                       │
└─────────────────────────────────────────────────────────┘
```

### 1.2 数据传输模式

| 模式 | 传输方式 | 最大速度 | CPU 占用 |
|------|----------|----------|----------|
| PIO Mode 0 | 程序 I/O | 3.3 MB/s | 高 |
| PIO Mode 3 | 程序 I/O | 11.1 MB/s | 高 |
| Multiword DMA Mode 2 | DMA | 16.7 MB/s | 低 |
| Ultra DMA Mode 5 | DMA | 100 MB/s | 低 |

## 2. I/O 端口映射

### 2.1 Primary 通道 (IRQ 14)

| 端口 | 读 | 写 | 描述 |
|------|----|----|------|
| 0x1F0 | Data | Data | 数据端口（16 位） |
| 0x1F1 | Error | Features | 错误/特性寄存器 |
| 0x1F2 | SecCount | SecCount | 扇区计数 |
| 0x1F3 | LBA Lo | LBA Lo | LBA 低字节 |
| 0x1F4 | LBA Mid | LBA Mid | LBA 中字节 |
| 0x1F5 | LBA Hi | LBA Hi | LBA 高字节 |
| 0x1F6 | - | Device | 设备/头寄存器 |
| 0x1F7 | Status | Command | 状态/命令寄存器 |

### 2.2 Secondary 通道 (IRQ 15)

| 端口 | 读 | 写 | 描述 |
|------|----|----|------|
| 0x170 | Data | Data | 数据端口（16 位） |
| 0x171 | Error | Features | 错误/特性寄存器 |
| 0x172 | SecCount | SecCount | 扇区计数 |
| 0x173 | LBA Lo | LBA Lo | LBA 低字节 |
| 0x174 | LBA Mid | LBA Mid | LBA 中字节 |
| 0x175 | LBA Hi | LBA Hi | LBA 高字节 |
| 0x176 | - | Device | 设备/头寄存器 |
| 0x177 | Status | Command | 状态/命令寄存器 |

### 2.3 控制端口

| 端口 | 读 | 写 | 描述 |
|------|----|----|------|
| 0x3F6 / 0x376 | AltStatus | DeviceCtl | 交替状态/设备控制 |

## 3. ATA 寄存器

### 3.1 Status 寄存器 (读)

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | BSY | 设备忙 |
| 6 | DRDY | 设备就绪 |
| 5 | DF | 设备故障 |
| 4 | DSC | 寻道完成 |
| 3 | DRQ | 数据请求（可传输） |
| 2 | CORR | 已纠正数据 |
| 1 | IDX | 索引信号 |
| 0 | ERR | 错误发生 |

### 3.2 Error 寄存器 (读)

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | BBK | 坏块检测 |
| 6 | UNC | 无法纠正的数据错误 |
| 5 | MC | 介质更换 |
| 4 | IDNF | ID 未找到 |
| 3 | MCR | 介质更换请求 |
| 2 | ABRT | 命令中止 |
| 1 | TK0NF | 磁道 0 未找到 |
| 0 | AMNF | 地址标记未找到 |

### 3.3 Device 寄存器 (写)

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | Reserved | 保留 |
| 6 | nIEN | 禁用中断（1 = 禁用） |
| 5 | SRST | 软件复位 |
| 4 | LBA | 使用 LBA 寻址 |
| 3:0 | DEV | LBA27:24 或 设备/头 |

### 3.4 Device Control 寄存器 (写)

| 位 | 名称 | 描述 |
|----|------|------|
| 7:2 | Reserved | 保留 |
| 1 | nIEN | 禁用中断（1 = 禁用） |
| 0 | SRST | 软件复位 |

## 4. ATA 命令集

### 4.1 基础命令

| 命令码 | 名称 | 描述 |
|--------|------|------|
| 0xEC | IDENTIFY | 设备识别 |
| 0x20 | READ SECTORS | 读取扇区（带重试） |
| 0x21 | READ SECTORS NR | 读取扇区（无重试） |
| 0x30 | WRITE SECTORS | 写入扇区（带重试） |
| 0x31 | WRITE SECTORS NR | 写入扇区（无重试） |
| 0xE7 | FLUSH CACHE | 刷新缓存 |
| 0xA1 | IDENTIFY PACKET | ATAPI 设备识别 |

### 4.2 LBA48 扩展命令

| 命令码 | 名称 | 描述 |
|--------|------|------|
| 0x24 | READ SECTORS EXT | 读取扇区扩展 |
| 0x34 | WRITE SECTORS EXT | 写入扇区扩展 |
| 0xEA | FLUSH CACHE EXT | 刷新缓存扩展 |

## 5. ATA 子系统 API

### 5.1 初始化 API

**头文件**: [`kernel/driver/ata/ata.h`](../../kernel/driver/ata/ata.h)

#### `ata_init()`

```c
int ata_init(void);
```

**描述**: 初始化 ATA 驱动（默认同步模式）

**返回**: `0` 成功，负数错误

---

#### `ata_init_ex()`

```c
int ata_init_ex(ata_init_mode_t mode);
```

**描述**: 初始化 ATA 驱动并指定模式

**参数**:
- `mode`: `ATA_MODE_SYNC` 或 `ATA_MODE_ASYNC`

---

#### `ata_init_async_mode()`

```c
ata_result_t ata_init_async_mode(void);
```

**描述**: 启用中断驱动的异步 I/O 模式

---

### 5.2 同步 I/O API

#### `ata_read()`

```c
ata_result_t ata_read(int device, uint64_t lba,
                      void* buffer, uint16_t sectors);
```

**描述**: 从指定设备读取扇区

**参数**:
- `device`: 设备号（0-3）
  - `ATA_PRIMARY_MASTER` (0)
  - `ATA_PRIMARY_SLAVE` (1)
  - `ATA_SECONDARY_MASTER` (2)
  - `ATA_SECONDARY_SLAVE` (3)
- `lba`: 起始 LBA 地址
- `buffer`: 数据缓冲区（至少 sectors * 512 字节）
- `sectors`: 扇区数（1-256）

**返回**: `ATA_OK` 成功，错误码否则

---

#### `ata_write()`

```c
ata_result_t ata_write(int device, uint64_t lba,
                       const void* buffer, uint16_t sectors);
```

**描述**: 向指定设备写入扇区

**参数**: 同 `ata_read()`

---

### 5.3 设备信息 API

#### `ata_device_exists()`

```c
bool ata_device_exists(int device);
```

**描述**: 检查设备是否存在

**返回**: `true` 存在，`false` 不存在

---

#### `ata_get_info()`

```c
ata_result_t ata_get_info(int device, ata_device_info_t* info);
```

**描述**: 获取设备信息

---

#### `ata_get_sector_count()`

```c
uint64_t ata_get_sector_count(int device);
```

**描述**: 获取设备扇区总数

---

### 5.4 异步 I/O API

#### `ata_read_async()`

```c
ata_result_t ata_read_async(int device, uint64_t lba, void* buffer,
                            uint16_t sectors, ata_read_callback_fn callback,
                            void* context);
```

**描述**: 启动异步读操作

**参数**:
- `callback`: 完成回调函数（可为 NULL）
- `context`: 用户上下文传递给回调

---

#### `ata_write_async()`

```c
ata_result_t ata_write_async(int device, uint64_t lba, const void* buffer,
                             uint16_t sectors, ata_write_callback_fn callback,
                             void* context);
```

**描述**: 启动异步写操作

---

#### `ata_async_is_idle()`

```c
bool ata_async_is_idle(int device);
```

**描述**: 检查设备是否空闲（无待处理操作）

---

### 5.5 辅助 API

#### `ata_error_string()`

```c
const char* ata_error_string(ata_result_t result);
```

**描述**: 获取错误描述字符串

## 6. 数据结构

### 6.1 ata_controller_t

```c
typedef struct ata_controller {
    uint16_t io_base;           // I/O 基地址
    uint16_t ctrl_base;         // 控制端口
    uint8_t irq;                // IRQ 号
    bool initialized;           // 初始化标志

    bool master_present;        // Master 存在
    bool slave_present;         // Slave 存在

    uint64_t read_count;        // 读取计数
    uint64_t write_count;       // 写入计数
    uint64_t error_count;       // 错误计数

    bool interrupts_enabled;    // 中断启用
    bool use_async_mode;        // 异步模式
    ata_async_queue_t* queue;   // 操作队列
    irq_descriptor_t irq_desc;  // IRQ 描述符
} ata_controller_t;
```

### 6.2 ata_device_info_t

```c
typedef struct ata_device_info {
    bool exists;                // 设备存在
    bool lba_supported;         // LBA 支持
    bool lba48_supported;       // LBA48 支持
    bool dma_supported;         // DMA 支持

    char model[41];             // 型号
    char serial[21];            // 序列号
    char firmware[9];           // 固件

    uint64_t lba_sectors;       // LBA28 扇区数
    uint64_t lba48_sectors;     // LBA48 扇区数
    uint32_t cylinders;         // 柱面数
    uint32_t heads;             // 磁头数
    uint32_t sectors_per_track; // 每磁道扇区数
} ata_device_info_t;
```

### 6.3 ata_result_t

```c
typedef enum {
    ATA_OK                = 0,
    ATA_ERR_NOT_INIT      = -1,
    ATA_ERR_TIMEOUT       = -2,
    ATA_ERR_NO_DEVICE     = -3,
    ATA_ERR_IO_ERROR      = -4,
    ATA_ERR_INVALID_PARAM = -5,
    ATA_ERR_UNSUPPORTED   = -6
} ata_result_t;
```

## 8. 异步 I/O

### 8.1 回调类型

```c
typedef void (*ata_read_callback_fn)(int device, uint64_t lba,
                                     uint16_t sectors, void* buffer,
                                     ata_result_t result, void* context);

typedef void (*ata_write_callback_fn)(int device, uint64_t lba,
                                      uint16_t sectors, const void* buffer,
                                      ata_result_t result, void* context);
```

### 8.2 异步操作状态

```c
typedef enum {
    ATA_ASYNC_PENDING,     // 已排队
    ATA_ASYNC_IN_PROGRESS, // 执行中
    ATA_ASYNC_COMPLETED,   // 完成
    ATA_ASYNC_ERROR        // 错误
} ata_async_status_t;
```

### 8.3 异步使用示例

```c
// 定义回调
void read_complete(int device, uint64_t lba, uint16_t sectors,
                   void* buffer, ata_result_t result, void* context) {
    if (result == ATA_OK) {
        klog_info("Read %u sectors from LBA %llu\n", sectors, lba);
    }
}

// 启动异步读取
void example_async_read(void) {
    uint8_t buffer[4096];

    ata_read_async(ATA_PRIMARY_MASTER, 0, buffer, 8,
                   read_complete, NULL);

    // 可以做其他工作...
    while (!ata_async_is_idle(ATA_PRIMARY_MASTER)) {
        // 等待完成或做其他事
    }
}
```
