## 🔍 本文档涵盖的功能

### 调试基础设施 (v1.0)

**主要特性**:
- ✅ GDB 远程调试支持
- ✅ VSCode 图形化调试
- ✅ debug.sh 便捷脚本
- ✅ VGA 文本模式驱动
- ✅ ELF 符号文件支持

**代码变更**:
- [scripts/debug.sh](../../scripts/debug.sh) - GDB 调试脚本
- [scripts/launch_qemu_for_vscode_debug.sh](../../scripts/launch_qemu_for_vscode_debug.sh) - VSCode 调试脚本
- [scripts/.gdbinit](../../scripts/.gdbinit) - GDB 初始化配置
- [.vscode/launch.json](../../.vscode/launch.json) - VSCode 调试配置
- [kernel/driver/vga/](../../kernel/driver/vga/) - VGA 驱动
- [kernel/defines/types.h](../../kernel/defines/types.h) - 类型定义

**调试流程**:
```
1. ./scripts/debug.sh 或 launch_qemu_for_vscode_debug.sh
   ↓
2. QEMU 启动 (-s -S)，等待 GDB 连接
   ↓
3. GDB/VSCode 连接到 localhost:1234
   ↓
4. 加载 kernel.elf 符号文件
   ↓
5. 设置断点，开始调试
```

**验证方法**:
- 在 `kernel_main` 设置断点
- 单步执行 C 代码
- 查看变量和寄存器
- VGA 输出调试信息
