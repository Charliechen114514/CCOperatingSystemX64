本文档提供内存操作和串口驱动的完整技术参考。

## 1. 内存操作 API 参考

### 1.1 memset

**函数原型**:
```c
void* memset(void* s, int c, size_t n);
```

**功能**: 将内存块填充为指定字节值

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| s | void* | 目标内存块指针 |
| c | int | 填充值（转换为 unsigned char） |
| n | size_t | 字节数 |

**返回值**: 返回原始指针 `s`

**行为**:
- 设置 `s` 指向的前 `n` 字节为 `(unsigned char)c`
- 如果 `n` 为 0，不修改任何内容

**示例**:
```c
char buffer[100];
memset(buffer, 0, 100);              // 填充为 0
memset(buffer, 0xFF, 50);            // 前 50 字节填充为 0xFF
memset(buffer + 50, 'A', 10);        // 第 50-59 字节填充为 'A'
```

**复杂度**: O(n)

### 1.2 memcpy

**函数原型**:
```c
void* memcpy(void* dest, const void* src, size_t n);
```

**功能**: 拷贝内存块（不检查重叠）

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| dest | void* | 目标内存块指针 |
| src | const void* | 源内存块指针 |
| n | size_t | 字节数 |

**返回值**: 返回 `dest` 指针

**行为**:
- 从 `src` 拷贝 `n` 字节到 `dest`
- **内存区域不能重叠**，否则结果未定义
- 从低地址向高地址拷贝

**示例**:
```c
char src[100] = "Hello, World!";
char dest[100];

memcpy(dest, src, strlen(src) + 1);  // 拷贝字符串
memcpy(dest, src, 100);              // 拷贝整个缓冲区
```

**复杂度**: O(n)

### 1.3 memmove

**函数原型**:
```c
void* memmove(void* dest, const void* src, size_t n);
```

**功能**: 拷贝内存块（支持重叠）

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| dest | void* | 目标内存块指针 |
| src | const void* | 源内存块指针 |
| n | size_t | 字节数 |

**返回值**: 返回 `dest` 指针

**行为**:
- 从 `src` 拷贝 `n` 字节到 `dest`
- **安全处理重叠内存区域**
- 根据 `dest` 和 `src` 的位置自动选择拷贝方向

**拷贝方向**:
```
src < dest:         从后向前拷贝 (避免覆盖)
src >= dest + n:    从前向后拷贝
src == dest:        不拷贝
```

**示例**:
```c
char buffer[100] = "0123456789";

// 安全重叠拷贝
memmove(buffer + 2, buffer, 5);  // 结果: "010123456789"
//                                从位置 2 开始拷贝前 5 字节
```

**复杂度**: O(n)

### 1.4 memcmp

**函数原型**:
```c
int memcmp(const void* s1, const void* s2, size_t n);
```

**功能**: 比较两个内存块

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| s1 | const void* | 第一个内存块 |
| s2 | const void* | 第二个内存块 |
| n | size_t | 比较字节数 |

**返回值**:
| 返回值 | 含义 |
|--------|------|
| < 0 | s1 < s2（首个不同字节较小） |
| 0 | s1 == s2（前 n 字节相同） |
| > 0 | s1 > s2（首个不同字节较大） |

**行为**:
- 逐字节比较 `s1` 和 `s2` 的前 `n` 字节
- 使用 **unsigned char** 比较
- 在第一个不同字节处停止

**示例**:
```c
char a[5] = {1, 2, 3, 4, 5};
char b[5] = {1, 2, 3, 4, 6};

if (memcmp(a, b, 5) < 0) {
    // a < b（因为 5 < 6）
}
```

**复杂度**: O(n)，最坏 O(n)

## 2. 串口驱动 API 参考

### 2.1 UART 16550 寄存器

#### 寄存器映射

| 偏移 | DLAB=0 | DLAB=1 | 访问 |
|------|--------|--------|------|
| +0 | THR (写) / RBR (读) | DLL (除数低字节) | 读/写 |
| +1 | IER | DLM (除数高字节) | 读/写 |
| +2 | FCR (写) / IIR (读) | - | 读/写 |
| +3 | LCR | - | 写 |
| +4 | MCR | - | 写 |
| +5 | LSR | - | 读 |
| +6 | MSR | - | 读 |
| +7 | SCR | - | 读/写 |

#### LCR (线路控制寄存器) - 0x3FB

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | DLAB | 除数锁存访问位 |
| 6 | SB | 设置断点 |
| 5 | SP | 奇偶校验 sticky |
| 4 | EPS | 偶校验选择 |
| 3 | PEN | 奇偶校验使能 |
| 2 | STB | 停止位数量 |
| 1-0 | WLS | 字长选择 |

**WLS (字长)**:
| 值 | 字长 |
|----|------|
| 00 | 5 位 |
| 01 | 6 位 |
| 10 | 7 位 |
| 11 | 8 位 |

**常用值**:
- `0x03` = 8N1（8 位数据，无校验，1 停止位）
- `0x83` = 8N1 + DLAB 使能

#### LSR (线路状态寄存器) - 0x3FD

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | ERROR | 接收线路错误 |
| 6 | TEMT | 发送器为空 |
| 5 | THRE | 发送保持寄存器为空 |
| 4 | BI | 断点中断指示 |
| 3 | FE | 帧错误 |
| 2 | PE | 奇偶校验错误 |
| 1 | OE | 溢出错误 |
| 0 | DR | 接收数据就绪 |

**常用检测**:
```c
// 检查是否可发送
if (inb(LSR) & 0x20) { ... }      // THRE 位

// 检查是否有数据可读
if (inb(LSR) & 0x01) { ... }      // DR 位
```

### 2.2 串口配置宏

```c
// COM1 基地址
#define SERIAL_COM1_BASE 0x3F8

// 寄存器偏移
#define SERIAL_DATA_REG(base)        ((base) + 0)
#define SERIAL_INT_ENABLE_REG(base)  ((base) + 1)
#define SERIAL_FIFO_CTRL_REG(base)   ((base) + 2)
#define SERIAL_LINE_CTRL_REG(base)   ((base) + 3)
#define SERIAL_MODEM_CTRL_REG(base)  ((base) + 4)
#define SERIAL_LINE_STATUS_REG(base) ((base) + 5)

// LSR 位
#define SERIAL_LSR_READY_TO_SEND 0x20  // THRE
```

### 2.3 串口函数

#### serial_init

**函数原型**:
```c
bool serial_init(void);
```

**功能**: 初始化 COM1 串口为 115200 8N1

**返回值**: 成功返回 `true`

**初始化步骤**:
1. 禁用中断 (IER = 0x00)
2. 启用 DLAB (LCR = 0x80)
3. 设置波特率除数 (DLL=1, DLM=0)
4. 配置 8N1 (LCR = 0x03)
5. 启用 FIFO (FCR = 0xC7)
6. 设置调制解调器 (MCR = 0x0B)

#### sync_serial_puts

**函数原型**:
```c
void sync_serial_puts(const char* str);
```

**功能**: 发送字符串到串口（阻塞）

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| str | const char* | 字符串指针 |

**行为**:
- 逐字符发送直到遇到 `\0`
- 忙等待直到发送就绪
- 如果 `str` 为 NULL，直接返回

**示例**:
```c
serial_init();
sync_serial_puts("Hello, World!\n");

// ANSI 颜色支持
sync_serial_puts("\033[0;32m=== Green Text ===\033[0m\n");
```

## 3. 端口 I/O API 参考

### 3.1 inb

**函数原型**:
```c
uint8_t inb(uint16_t port);
```

**功能**: 从 I/O 端口读取一个字节

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| port | uint16_t | 端口号（0-65535） |

**返回值**: 端口读取的 8 位值

**汇编实现**:
```asm
in al, dx   ; 从 DX 端口读取到 AL
```

**示例**:
```c
uint8_t status = inb(0x3FD);  // 读取 LSR
```

### 3.2 outb

**函数原型**:
```c
void outb(uint16_t port, uint8_t data);
```

**功能**: 向 I/O 端口写入一个字节

**参数**:
| 参数 | 类型 | 描述 |
|------|------|------|
| port | uint16_t | 端口号（0-65535） |
| data | uint8_t | 要写入的数据 |

**汇编实现**:
```asm
out dx, al   ; 从 AL 写入到 DX 端口
```

**示例**:
```c
outb(0x3F8, 'A');  // 向 THR 写入字符
```

## 4. 测试框架 API 参考

### 4.1 测试宏

#### TEST_ASSERT_EQ

```c
#define TEST_ASSERT_EQ(a, b, msg)
```

**功能**: 断言两个值相等

**行为**:
- 相等时增加 `g_test_passed`
- 不相等时增加 `g_test_failed` 并输出消息

#### TEST_ASSERT_TRUE

```c
#define TEST_ASSERT_TRUE(cond, msg)
```

**功能**: 断言条件为真

#### TEST_RUNNER_BEGIN/END

```c
#define TEST_RUNNER_BEGIN(name)
#define TEST_RUNNER_END()
```

**功能**: 定义测试主函数

**示例**:
```c
int main(void) {
    TEST_RUNNER_BEGIN("Memory Tests");

    test_memset();
    test_memcpy();
    test_memmove();
    test_memcmp();

    TEST_RUNNER_END();
}
```

### 4.2 测试桩

#### ccos_assert_impl

```c
void ccos_assert_impl(bool condition, const char* expr_str,
                      const char* file, int line, const char* func);
```

**功能**: 主机端断言实现

**行为**:
- 条件为真时直接返回
- 条件为假时打印错误信息并调用 `abort()`
