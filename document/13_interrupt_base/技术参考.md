## 1. x86 中断基础

### 1.1 中断与异常的区别

| 类型 | 触发源 | 同步性 | 可屏蔽 | 向量范围 |
|------|--------|--------|--------|----------|
| **异常** | CPU 执行指令 | 同步 | 不可屏蔽 | 0-31 |
| **硬件中断** | 外部设备 | 异步 | 部分可屏蔽 | 32-255 |
| **软件中断** | INT 指令 | 同步 | 不可屏蔽 | 0-255 |

### 1.2 x86_64 中断处理流程

```
1. 硬件/异常发生
       ↓
2. CPU 检查中断权限
       ↓
3. CPU 读取 IDT 条目
       ↓
4. CPU 自动推送栈帧
       ↓
5. 跳转到中断处理函数
       ↓
6. 处理函数执行
       ↓
7. IRETQ 返回
```

### 1.3 IDT 条目结构

x86_64 模式下，IDT 条目为 16 字节：

```
┌─────────────────────────────────────────────────────────────────┐
│ IDT Entry (16 bytes)                                            │
├─────────────────────────────────────────────────────────────────┤
│ Bytes 0-1   │ Offset Low  (handler address bits 0-15)          │
│ Bytes 2-3   │ Segment Selector (code segment)                   │
│ Byte 4      │ IST (bits 0-2) | Zero (bits 3-7)                 │
│ Byte 5      │ Type Attributes                                  │
│ Bytes 6-7   │ Offset Middle (handler address bits 16-31)       │
│ Bytes 8-11  │ Offset High (handler address bits 32-63)         │
│ Bytes 12-15 │ Reserved (must be 0)                             │
└─────────────────────────────────────────────────────────────────┘
```

### 1.4 中断栈帧

CPU 在中断发生时自动推送的栈帧：

```c
typedef struct PACKED {
    uint64_t error_code;      // 错误码（仅部分异常）
    uint64_t rip;             // 返回地址
    uint64_t cs;              // 代码段选择子
    uint64_t rflags;          // RFLAGS 寄存器
    uint64_t rsp;             // 栈指针
    uint64_t ss;              // 栈段选择子（仅特权级改变时）
} interrupt_frame_t;
```

## 2. 8259 PIC 技术参考

### 2.1 硬件架构

```
            ┌──────────────┐
            │     CPU      │
            └──────┬───────┘
                   │
         ┌─────────┴─────────┐
         │                   │
    ┌────▼────┐         ┌────▼────┐
    │ Master  │◄───────►│ Slave   │
    │  PIC    │         │  PIC    │
    └────┬────┘         └────┬────┘
         │                   │
    IRQ 0-7              IRQ 8-15
```

### 2.2 I/O 端口映射

| PIC | 命令端口 | 数据端口 |
|-----|----------|----------|
| Master | 0x20 | 0x21 |
| Slave | 0xA0 | 0xA1 |

### 2.3 初始化命令字 (ICW)

#### ICW1 (初始化开始)

```
Bit 7-5: 0 (x86 模式)
Bit 4:   1 (需要 ICW4)
Bit 3:   0 (边缘触发模式)
Bit 2:   0
Bit 1:   1 (需要 ICW3 - 级联模式)
Bit 0:   1 (初始化)

ICW1 = 0x11 (PIC_INIT)
```

#### ICW2 (向量偏移)

```
Master: IRQ 基准向量 (通常 32 = 0x20)
Slave:  IRQ 基准向量 (通常 40 = 0x28)
```

#### ICW3 (级联配置)

```
Master: 0x04 (IR2 连接从 PIC)
Slave:  0x02 (级联标识)
```

#### ICW4 (模式配置)

```
Bit 7-5: 0
Bit 4:   0
Bit 3-2: 0
Bit 1:   0
Bit 0:   1 (8086 模式)

ICW4 = 0x01 (PIC_ICW4_8086)
```

### 2.4 操作命令字 (OCW)

#### OCW2 (EOI 命令)

```
Bit 7-5: 001 (非特定 EOI)
Bit 4:   0
Bit 3:   0
Bit 2-0: 0

OCW2 = 0x20 (PIC_EOI)
```

#### OCW3 (屏蔽操作)

```
读/写 IMR (中断屏蔽寄存器):
- 读: inb(PORT_DATA)
- 写: outb(PORT_DATA, mask)
```

### 2.5 IRQ 默认分配

| IRQ | 设备 | 优先级 |
|-----|------|--------|
| 0 | 定时器 | 最高 |
| 1 | 键盘 | |
| 2 | 级联 | |
| 3 | COM2 | |
| 4 | COM1 | |
| 5 | LPT2 | |
| 6 | 软盘 | |
| 7 | LPT1 | |
| 8 | RTC | |
| 9 | 保留/SCSI | |
| 10 | 保留/SCSI | |
| 11 | 保留/SCSI | |
| 12 | PS/2 鼠标 | |
| 13 | FPU | |
| 14 | 主 ATA | |
| 15 | 从 ATA | 最低 |

## 3. 中断子系统 API

### 3.1 PIC 驱动 API

**头文件**: [`kernel/driver/pic/pic.h`](../../kernel/driver/pic/pic.h)

#### `pic_init()`

```c
void pic_init(uint8_t offset1, uint8_t offset2);
```

**描述**: 初始化并重映射 8259 PIC

**参数**:
- `offset1`: Master PIC 基准向量（通常 32）
- `offset2`: Slave PIC 基准向量（通常 40）

**示例**:
```c
pic_init(0x20, 0x28);  // IRQ 0-15 → 向量 32-47
```

---

#### `pic_send_eoi()`

```c
void pic_send_eoi(uint8_t irq);
```

**描述**: 发送中断结束（EOI）信号

**参数**:
- `irq`: IRQ 号（0-15）

**注意**: IRQ ≥ 8 时会自动向两个 PIC 发送 EOI

**示例**:
```c
void timer_handler(interrupt_frame_t* frame) {
    timer_ticks++;
    pic_send_eoi(0);  // 必须调用！
}
```

---

#### `pic_disable_irq()`

```c
void pic_disable_irq(uint8_t irq);
```

**描述**: 屏蔽（禁用）指定 IRQ

**参数**:
- `irq`: IRQ 号（0-15）

---

#### `pic_enable_irq()`

```c
void pic_enable_irq(uint8_t irq);
```

**描述**: 取消屏蔽（启用）指定 IRQ

**参数**:
- `irq`: IRQ 号（0-15）

---

#### `pic_is_irq_masked()`

```c
bool pic_is_irq_masked(uint8_t irq);
```

**描述**: 检查 IRQ 是否被屏蔽

**参数**:
- `irq`: IRQ 号（0-15）

**返回值**: `true` 表示被屏蔽，`false` 表示已启用

---

#### `pic_disable_all()`

```c
void pic_disable_all(void);
```

**描述**: 屏蔽所有 IRQ

---

#### `pic_enable_all()`

```c
void pic_enable_all(void);
```

**描述**: 启用所有 IRQ

---

### 3.2 IDT API

**头文件**: [`kernel/interrupt/idt.h`](../../kernel/interrupt/idt.h)

#### `idt_init()`

```c
void idt_init(void);
```

**描述**: 初始化 IDT 并加载到 CPU

**功能**:
- 清空 IDT
- 为 32 个 CPU 异常设置处理程序
- 为 16 个 IRQ 设置处理程序
- 使用 `lidt` 指令加载 IDT

---

#### `idt_set_gate()`

```c
void idt_set_gate(uint8_t vector, uint64_t handler,
                  uint8_t type_attr, uint16_t segment_selector);
```

**描述**: 设置 IDT 条目

**参数**:
- `vector`: 中断向量号（0-255）
- `handler`: 处理函数地址
- `type_attr`: 门类型属性（见常量定义）
- `segment_selector`: 代码段选择子（内核通常 0x18）

---

#### `idt_register_handler()`

```c
void idt_register_handler(uint8_t vector, interrupt_handler_fn handler);
```

**描述**: 注册自定义中断处理函数

**参数**:
- `vector`: 中断向量号
- `handler`: 处理函数指针

**处理函数签名**:
```c
typedef void (*interrupt_handler_fn)(interrupt_frame_t* frame, uint64_t error_code);
```

**示例**:
```c
void my_keyboard_handler(interrupt_frame_t* frame, uint64_t error_code) {
    // 处理键盘输入
    pic_send_eoi(1);
}

idt_register_handler(33, my_keyboard_handler);
```

---

#### `idt_get_exception_name()`

```c
const char* idt_get_exception_name(uint8_t vector);
```

**描述**: 获取异常名称

**参数**:
- `vector`: 异常向量号

**返回值**: 异常名称字符串，未知异常返回 "Unknown"

### 3.4 中断子系统 API

**头文件**: [`kernel/interrupt/interrupt.h`](../../kernel/interrupt/interrupt.h)

#### `interrupt_init()`

```c
void interrupt_init(void);
```

**描述**: 初始化整个中断子系统

**初始化流程**:
1. 初始化并重映射 PIC
2. 禁用所有 IRQ
3. 初始化 IDT
4. 注册定时器处理程序
5. 启用所有 IRQ
6. 启用中断

---

#### `timer_get_ticks()`

```c
uint64_t timer_get_ticks(void);
```

**描述**: 获取定时器滴答计数

**返回值**: 自启动以来的定时器中断次数

## 4. 数据结构

### 4.1 interrupt_frame_t

```c
typedef struct PACKED {
    uint64_t error_code;      // 错误码
    uint64_t rip;             // 指令指针
    uint64_t cs;              // 代码段
    uint64_t rflags;          // RFLAGS 寄存器
    uint64_t rsp;             // 栈指针
    uint64_t ss;              // 栈段
} interrupt_frame_t;
```

**栈布局**:
```
高地址
    +------------------+
    |   SS (可选)      |
    +------------------+
    |   RSP            |
    +------------------+
    |   RFLAGS         |
    +------------------+
    |   CS             |
    +------------------+
    |   RIP            |
    +------------------+
    |   Error Code     |
    +------------------+
低地址
```

### 4.2 idt_entry_t

```c
typedef struct PACKED {
    uint16_t offset_low;       // Handler 地址 bits 0-15
    uint16_t segment_selector; // 代码段选择子
    uint8_t ist;               // IST 偏移
    uint8_t type_attr;         // 类型属性
    uint16_t offset_middle;    // Handler 地址 bits 16-31
    uint32_t offset_high;      // Handler 地址 bits 32-63
    uint32_t reserved;         // 保留（必须为 0）
} idt_entry_t;
```

| 8 | Double Fault | #DF | 双重故障 | 有（始终为 0） |
| 9 | Coprocessor Segment Overrun | #CSO | 协处理器段越界 | 无 |
| 10 | Invalid TSS | #TS | 无效 TSS | 有 |
| 11 | Segment Not Present | #NP | 段不存在 | 有 |
| 12 | Stack-Segment Fault | #SS | 栈段错误 | 有 |
| 13 | General Protection Fault | #GP | 通用保护错误 | 有 |
| 14 | Page Fault | #PF | 页错误 | 有 |
| 15 | x87 FPU Error | #MF | x87 FPU 错误 | 无 |
| 16 | Alignment Check | #AC | 对齐检查 | 有 |
| 17 | Machine Check | #MC | 机器检查 | 无 |
| 18 | SIMD FP Exception | #XM | SIMD 浮点异常 | 无 |
| 19 | Virtualization Exception | #VE | 虚拟化异常 | 无 |
| 20 | Control Protection | #CP | 控制保护异常 | 有 |
| 21-31 | Reserved | - | 保留 | - |

### 5.2 IRQ 向量 (32-47)

PIC 重映射后的向量：

| 向量 | IRQ | 设备 |
|------|-----|------|
| 32 | 0 | 定时器 |
| 33 | 1 | 键盘 |
| 34 | 2 | 级联（内部使用） |
| 35 | 3 | COM2 |
| 36 | 4 | COM1 |
| 37 | 5 | LPT2 |
| 38 | 6 | 软盘 |
| 39 | 7 | LPT1 |
| 40 | 8 | CMOS RTC |
| 41 | 9 | 保留/外围设备 |
| 42 | 10 | 保留/外围设备 |
| 43 | 11 | 保留/外围设备 |
| 44 | 12 | PS/2 鼠标 |
| 45 | 13 | FPU |
| 46 | 14 | 主 ATA |
| 47 | 15 | 从 ATA |

### 5.3 IDT 门类型属性

| 类型 | 值 | 描述 |
|------|-----|------|
| 任务门 | 0x5 | 任务切换（x86_64 不常用） |
| 中断门 | 0xE | 自动禁用中断 |
| 陷阱门 | 0xF | 保持中断状态 |

### 5.4 DPL (Descriptor Privilege Level)

| 级别 | 值 | 描述 |
|------|-----|------|
| 内核级 | 0x0 | 最高权限 |
| 用户级 | 0x3 | 最低权限 |

### 5.5 组合属性宏

```c
// 内核中断门（最常用）
#define IDT_KERNEL_INTERRUPT_GATE \
    (IDT_PRESENT | IDT_DPL_KERNEL | IDT_STORAGE_SEGMENT | IDT_TYPE_INTERRUPT_GATE)
// 值: 0x8E

// 用户中断门（系统调用）
#define IDT_USER_INTERRUPT_GATE \
    (IDT_PRESENT | IDT_DPL_USER | IDT_STORAGE_SEGMENT | IDT_TYPE_INTERRUPT_GATE)
// 值: 0xEE

// 内核陷阱门（断点、溢出）
#define IDT_KERNEL_TRAP_GATE \
    (IDT_PRESENT | IDT_DPL_KERNEL | IDT_STORAGE_SEGMENT | IDT_TYPE_TRAP_GATE)
// 值: 0x8F

// 存在位
#define IDT_PRESENT 0x80
```

## 6. 汇编接口

**文件**: [`kernel/interrupt/interrupt.asm`](../../kernel/interrupt/interrupt.asm)

### 6.1 ISR Stub 宏

```asm
%macro ISR_NOERRCODE 1
  global isr%1
  isr%1:
    push qword 0         ; 虚拟错误码
    push qword %1        ; 向量号
    push qword 0         ; 对齐 dummy
    jmp interrupt_common
%endmacro

%macro ISR_ERRCODE 1
  global isr%1
  isr%1:
    ; CPU 已推送错误码
    push qword %1        ; 向量号
    push qword 0         ; 对齐 dummy
    jmp interrupt_common
%endmacro
```

### 6.2 IRQ Stub 宏

```asm
%macro IRQ 2
  global irq%1
  irq%1:
    push qword 0         ; 虚拟错误码
    push qword %2        ; 向量号
    push qword 0         ; 对齐 dummy
    jmp interrupt_common
%endmacro
```

### 6.3 idt_load 函数

```asm
global idt_load
idt_load:
    lidt [rdi]           ; 加载 IDTR
    ret
```

**参数**: `RDI` = 指向 `idt_ptr_t` 的指针

### 6.4 导出的处理程序表

```asm
section .rodata

global isr_handler_table
isr_handler_table:
    %assign i 0
    %rep 32
        dq isr %+ i
        %assign i i+1
    %endrep

global irq_handler_table
irq_handler_table:
    %assign i 0
    %rep 16
        dq irq %+ i
        %assign i i+1
    %endrep
```
