# 退出调试

## 退出 GDB

```gdb
quit
```

或简写：
```gdb
q
```

## scripts/debug.sh 的自动清理

当你退出 GDB 后，`scripts/debug.sh` 脚本会自动：

1. 关闭 QEMU 进程
2. 清理后台资源

你会看到：
```
正在关闭 QEMU...
调试会话结束
```

## 强制退出

如果 GDB 无响应，可以在终端按 `Ctrl+C` 发送中断信号。

## 手动清理 QEMU

如果 `scripts/debug.sh` 没有正常退出 QEMU，可以手动清理：

```bash
ps aux | grep qemu
killall qemu-system-x86_64
```
