# 查看调用栈

## 显示调用栈

```gdb
backtrace
```

或简写：
```gdb
bt
```

输出示例：
```
#0  kernel_main () at kernel/kernel_main.c:15
#1  0x000000000001001a in kernel_start ()
#2  0x0000000000007c00 in ?? ()
#3  0x000000000000fff0 in ?? ()
```

## 查看栈帧详情

### 选择栈帧

```gdb
frame 0
```

或简写：
```gdb
f 0
```

### 查看当前栈帧的局部变量

```gdb
info locals
```

### 查看当前栈帧的参数

```gdb
info args
```

## 向上/向下切换栈帧

```gdb
up      # 向上一级（调用者）
down    # 向下一级（被调用者）
```

## 完整回溯信息

```gdb
info frame
```

会显示当前栈帧的详细地址、保存的寄存器等信息。
