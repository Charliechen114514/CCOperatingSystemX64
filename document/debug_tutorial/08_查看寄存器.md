# 查看寄存器

## 查看所有寄存器

```gdb
info registers
```

输出示例：
```
rax            0x1005b                 66681
rbx            0x0                     0
rcx            0x0                     0
rdx            0xffffffffffffffe4      -28
rsi            0x0                     0
rdi            0x0                     0
rbp            0x7000                  0x7000
rsp            0x7000                  0x7000
...
rip            0x1005b                 0x1005b <kernel_main+30>
eflags         0x202                   [ IF ]
...
```

## 查看单个寄存器

```gdb
info registers rip
info registers rax
info registers rsp
```

## 查看特定段寄存器

```gdb
info registers cs
info registers ds
info registers ss
```

## 修改寄存器值（高级用法）

```gdb
set $rax = 0x1000
set $rsp += 8
```

## 常用寄存器说明

| 寄存器 | 用途 |
|--------|------|
| `rip` | 指令指针（程序计数器） |
| `rsp` | 栈指针 |
| `rbp` | 基址指针（帧指针） |
| `rax` | 返回值 / 通用寄存器 |
| `rdi, rsi, rdx, rcx, r8, r9` | 函数参数寄存器（按顺序） |
