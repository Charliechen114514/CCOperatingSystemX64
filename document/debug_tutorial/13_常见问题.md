# 常见问题

## Q1: 符号表找不到

**问题**：显示 `No symbol table is loaded` 或断点设置失败

**解决**：
```bash
# 确认使用 Debug 模式构建
cmake -DCMAKE_BUILD_TYPE=Debug -B build
cmake --build build

# 确认 GDB 加载了正确的 ELF 文件
gdb build/kernel.elf
```

## Q2: 连接 QEMU 失败

**问题**：`Remote connection refused` 或 `Connection timed out`

**解决**：
1. 确认 QEMU 正在运行：`ps aux | grep qemu`
2. 确认端口未被占用：`netstat -tuln | grep 1234`
3. 重新运行 `./scripts/debug.sh`

## Q3: 地址不匹配

**问题**：断点设置成功但从未命中

**解决**：
- 检查 `linker.ld` 中的内核加载地址
- 确认 `.gdbinit` 中的符号文件地址正确
- 使用 `b *0x10000` 而不是函数名来测试

## Q4: 显示乱码

**问题**：GDB 输出显示中文乱码

**解决**：
```bash
export LANG=en_US.UTF-8
./scripts/debug.sh
```

## Q5: 单步执行很慢

**问题**：`step` 或 `next` 命令响应很慢

**解决**：
- 使用 `nexti` 或 `stepi` 进行汇编级单步
- 减少自动显示（`disable display`）
- 在关键位置使用断点而不是单步

## Q6: 看不到 VGA 输出

**问题**：QEMU 窗口没有显示内容

**解决**：
- 检查是否使用了 `-nographic` 选项
- 或者改用 `-serial stdio` 来查看串口输出
- 确认显存地址 `0xB8000` 写入正确

## Q7: .gdbinit 语法错误

**问题**：`.gdbinit:xx: Error in sourced command file`

**解决**：
- 检查 `.gdbinit` 语法
- 某些 GDB 版本命令格式不同，尝试去掉 `on` 关键字
- 逐行测试找出问题命令
