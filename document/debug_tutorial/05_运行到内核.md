# 运行到内核

## 继续执行到断点

```gdb
c
```

（`c` 是 `continue` 的缩写）

## 命中断点的输出

```
READY TO BOOT CCOS
[1] Stage 1: Loading second stage...
[2] Stage 2: Loading kernel...
[I] Kernel Load Success, About Ente
Breakpoint 1, 0x0000000000010000 in kernel_start ()
1: x/i $pc
=> 0x10000 <kernel_start>:  cli
(gdb)
```

## 这里的输出说明

- **Bootloader 输出** - QEMU 窗口显示的启动信息
- **`Breakpoint 1`** - 成功命中内核入口点断点
- **`kernel_start`** - GDB 找到了符号信息
- **`cli`** - 当前指令是清除中断标志（Clear Interrupts）

## 继续到 kernel_main

```gdb
c
```

输出：
```
Breakpoint 2, kernel_main () at kernel/kernel_main.c:9
9           volatile char* video = (char*)0xB8000;
1: x/i $pc
=> 0x1005b <kernel_main+30>:  mov    QWORD PTR [rbp-0x18],0xb8000
```

现在你已经在内核的 C 代码中了！
