# 查看变量

## 打印变量值

### `print` (或 `p`)

打印变量的值：

```gdb
p video
```

输出：
```
$1 = 0xb8000 "R\017E\017Z\017..."
```

### 打印多个变量

```gdb
p video
p msg
p i
```

## 查看数组/字符串

```gdb
p msg[0]
p *msg
```

## 查看内存

### `x` - 检查内存

```gdb
x/10x 0xb8000      # 以十六进制显示 10 个字节
x/10i $pc          # 显示当前指令及后续 9 条
x/s 0xb8000        # 显示字符串
```

格式说明：
- `x` - 十六进制
- `i` - 指令
- `s` - 字符串
- `/10` - 显示 10 项

## 自动打印变量

每次单步时自动显示变量：

```gdb
display video
display msg
```

查看自动显示列表：
```gdb
info display
```

取消自动显示：
```gdb
undisplay 1
```
