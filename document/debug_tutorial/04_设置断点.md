# 设置断点

## 在内核入口点设置断点

内核加载地址是 `0x10000`，在此处设置断点：

```gdb
b *0x10000
```

输出：
```
Breakpoint 1 at 0x10000
```

## 在函数入口设置断点

可以直接用函数名设置断点（需要符号表）：

```gdb
b kernel_main
```

输出：
```
Breakpoint 2 at 0x1005b: file kernel/kernel_main.c, line 9.
```

## 查看已设置的断点

```gdb
info breakpoints
```

输出示例：
```
Num     Type           Disp Enb Address    What
1       breakpoint     keep y   0x0000000000010000
2       breakpoint     keep y   0x000000000001005b kernel_main
```

## 删除断点

```gdb
delete breakpoints 1    # 删除断点 1
delete breakpoints       # 删除所有断点
```
