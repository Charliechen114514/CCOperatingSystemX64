# 反汇编

## 反汇编当前函数

```gdb
disassemble
```

输出示例：
```
Dump of assembler code for function kernel_main:
=> 0x000000000001005b <+30>:    mov    QWORD PTR [rbp-0x18],0xb8000
   0x0000000000010063 <+38>:    lea    rax,[rip+0x115a]    # 0x111c4
   0x000000000001006a <+45>:    mov    QWORD PTR [rbp-0x20],rax
   0x000000000001006e <+49>:    mov    rax,QWORD PTR [rbp-0x18]
   ...
End of assembler dump.
```

## 反汇编指定范围

```gdb
disassemble 0x10000, 0x10100
disassemble kernel_start
```

## 反汇编并显示源代码

```gdb
disassemble /s
```

或：
```gdb
disassemble /m
```

这会在汇编代码中穿插显示源代码。

## 查看内存为指令

```gdb
x/10i $pc        # 从当前 PC 开始显示 10 条指令
x/5i kernel_main # 从函数开始显示 5 条指令
```

## 语法设置

`.gdbinit` 已设置为 Intel 语法（更易读）：

```gdb
set disassembly-flavor intel
```

如需切换回 AT&T 语法：
```gdb
set disassembly-flavor att
```
