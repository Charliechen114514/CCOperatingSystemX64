# 单步调试

## 源代码级单步执行

### `next` (或 `n`) - 下一行

执行当前行，不进入函数调用：

```gdb
n
```

输出：
```
10          const char* msg = "CCOS KERNEL RUNNING!";
1: x/i $pc
=> 0x10063 <kernel_main+38>:  movabs rdx,0xffffffffffffffe4
```

### `step` (或 `s`) - 步入

执行当前行，会进入函数调用：

```gdb
s
```

当一行代码调用函数时，`s` 会进入函数内部，而 `n` 会跳过函数调用。

## 汇编级单步执行

### `stepi` (或 `si`) - 单步指令

执行一条汇编指令：

```gdb
si
```

### `nexti` (或 `ni`) - 下一条指令

执行一条汇编指令，但不进入函数调用：

```gdb
ni
```

## 自动显示当前指令

`.gdbinit` 已配置 `display/i $pc`，每步都会自动显示当前指令。要关闭：

```gdb
disable display 1
```

重新启用：
```gdb
enable display 1
```
