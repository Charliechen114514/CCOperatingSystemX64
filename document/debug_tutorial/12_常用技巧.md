# 常用技巧

## 条件断点

只在满足条件时触发断点：

```gdb
b kernel_main.c:15 if i == 5
```

## 临时断点

只触发一次的断点：

```gdb
tbreak kernel_main
```

## 硬件断点

使用调试寄存器的断点（有限数量）：

```gdb
hbreak *0x10000
```

## 观察点（Watchpoint）

当变量值改变时触发：

```gdb
watch variable_name
```

只读变量：
```gdb
rwatch variable_name
```

读写时触发：
```gdb
awatch variable_name
```

## 定义宏

简化常用命令：

```gdb
define hello
  echo Hello, CCOS!\n
end
```

然后直接输入 `hello` 即可。

## 日志断点

不中断，只记录信息：

```gdb
b kernel_main.c:10
commands
  silent
  printf "video = %p\n", video
  cont
end
```

## TUI 模式

GDB 的文本界面模式：

```gdb
layout src    # 显示源代码
layout asm    # 显示汇编
layout split  # 同时显示源代码和汇编
layout regs   # 显示寄存器
```

按 `Ctrl+X` 然后 `A` 退出 TUI 模式。

## 保存历史

GDB 会自动保存命令历史到 `~/.gdb_history`，可以用上下箭头查看历史命令。

## 命令补全

输入命令前几个字符后按 `Tab` 键可以自动补全。

## 帮助

```gdb
help        # 查看所有命令类别
help breakpoints
help stack
help breakpoints
```
