# 启动调试环境

## 使用调试脚本

项目提供了 `debug.sh` 脚本，可以自动启动 QEMU 和 GDB：

```bash
./scripts/debug.sh
```

## 脚本做了什么

1. **检查构建文件** - 验证 `kernel.elf` 和 `boot.img` 存在
2. **启动 QEMU** - 以调试模式运行，监听端口 1234
   - `-s` : 启用 GDB server（等效于 `-gdb tcp::1234`）
   - `-S` : 启动时暂停 CPU，等待 GDB 连接
   - `-nographic` : 不使用图形界面
3. **启动 GDB** - 加载 `.gdbinit` 配置和内核符号表

## 你会看到的输出

```
========================================
CCOS Kernel 调试环境启动脚本
========================================

正在启动 QEMU 调试模式...
QEMU 将在端口 1234 等待 GDB 连接
QEMU 已启动 (PID: xxxxx)

========================================
正在启动 GDB...
========================================
```

接着是 GDB 的欢迎信息和源代码列表。
