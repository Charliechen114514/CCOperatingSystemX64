
### 1.2 VSCode 配置文件

#### `.vscode/launch.json`

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "cppdbg",
            "request": "launch",
            "name": "CCOS Debug (QEMU)",
            "program": "${workspaceFolder}/build/kernel.elf",
            "miDebuggerServerAddress": "localhost:1234",
            "miDebuggerPath": "/usr/bin/gdb",
            "MIMode": "gdb",
            "cwd": "${workspaceFolder}",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "Set disassembly flavor",
                    "text": "-gdb-set disassembly-flavor intel",
                    "ignoreFailures": true
                }
            ]
        }
    ]
}
```

**配置说明**:
- `miDebuggerServerAddress`: GDB 远程调试地址
- `program`: 符号文件路径（必须是 ELF 格式）
- `setupCommands`: GDB 启动时执行的命令

## 5. 常见问题解决

### 5.1 VGA 显示不更新

**症状**: 代码执行但屏幕无变化

**可能原因**:
1. 缓冲区地址错误
2. 颜色编码错误
3. 坐标超出边界

**调试方法**:
```gdb
# 检查缓冲区地址
print vga_instance()->base_addr

# 直接写内存测试
set *(uint16_t*)0xb8000 = 0x1f54  # 应显示 'T'

# 检查颜色编码
print vga_make_entry('A', 15, 0)  # 应返回 0x0f41
```

### 5.2 动画效果不显示

**症状**: 动画代码执行但看不到效果

**可能原因**:
1. 延迟时间太短
2. VNC 刷新问题
3. 代码被优化掉

**调试方法**:
```c
// 增加延迟
vga_delay(10000000);  // 增加到 10M

// 添加内存屏障
__asm__ volatile("" ::: "memory");

// 使用 volatile 防止优化
volatile int delay = 10000000;
while (delay--);
```

### 5.3 VSCode 无法连接

**症状**: VSCode 显示 "Connection refused"

**解决方法**:
1. 检查 QEMU 是否运行
2. 检查端口 1234 是否被占用
3. 重启调试脚本

```bash
# 检查 QEMU 状态
./scripts/launch_qemu_for_vscode_debug.sh --status

# 检查端口
lsof -i:1234

# 重启
./scripts/launch_qemu_for_vscode_debug.sh --stop
./scripts/launch_qemu_for_vscode_debug.sh
```
