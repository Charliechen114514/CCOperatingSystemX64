## 1. VGA GUI Helper API 参考

### 1.1 基础绘图函数

#### `vga_draw_rect`

绘制空心矩形边框。

```c
void vga_draw_rect(CCOS_VGA* vga, vga_sz_t x, vga_sz_t y,
                   vga_sz_t width, vga_sz_t height, vga_color_t color);
```

**参数**:
- `vga`: VGA 实例指针
- `x`, `y`: 矩形左上角坐标（字符单位）
- `width`: 矩形宽度（必须 ≥ 2）
- `height`: 矩形高度（必须 ≥ 2）
- `color`: 边框颜色

**行为**:
- 绘制由 `+`, `-`, `|` 组成的 ASCII 艺术边框
- 四角使用 `+` 字符
- 顶部和底部使用 `-` 字符
- 左侧和右侧使用 `|` 字符

**示例**:
```c
vga_draw_rect(vga, 10, 5, 40, 10, VGA_COLOR_BRIGHT_CYAN);
```

**输出效果**:
```
+--------------------------------------+
|                                      |
|                                      |
+--------------------------------------+
```

### 1.2 面板系统

#### `vga_panel_t` 结构体

面板属性定义。

```c
typedef struct {
    vga_sz_t x;                // 左上角 x 坐标
    vga_sz_t y;                // 左上角 y 坐标
    vga_sz_t width;            // 面板宽度
    vga_sz_t height;           // 面板高度
    vga_color_t border_color;  // 边框颜色
    vga_color_t bg_color;      // 背景色（未使用，预留）
    vga_color_t text_color;    // 文本颜色
    const char* title;         // 面板标题（可为 NULL）
} vga_panel_t;
```

---

#### `vga_draw_panel`

绘制带标题的面板。

```c
void vga_draw_panel(CCOS_VGA* vga, const vga_panel_t* panel);
```

**行为**:
1. 调用 `vga_draw_rect` 绘制边框
2. 如果 `title` 非 NULL，在顶部边框绘制 `[标题]`
3. 标题居中显示

**示例**:
```c
vga_panel_t panel = {
    .x = 10,
    .y = 5,
    .width = 40,
    .height = 10,
    .border_color = VGA_COLOR_BRIGHT_CYAN,
    .bg_color = VGA_COLOR_BLACK,
    .text_color = VGA_COLOR_WHITE,
    .title = "System Info"
};
vga_draw_panel(vga, &panel);
```

**输出效果**:
```
+-------- [ System Info ] --------------+
|                                        |
|                                        |
+----------------------------------------+
```

## 2. VGA Helpers API 参考

### 2.1 核心辅助函数

#### `vga_put_char_at`

在指定位置绘制字符。

```c
void vga_put_char_at(CCOS_VGA* vga, vga_sz_t x, vga_sz_t y,
                     char c, vga_color_t font, vga_color_t bg);
```

**参数**:
- `vga`: VGA 实例指针
- `x`, `y`: 字符坐标
- `c`: 要绘制的字符
- `font`: 前景色（0-15）
- `bg`: 背景色（0-15）

**边界检查**:
```c
if (vga == NULL || x >= vga->width || y >= vga->height)
    return;
```

**实现**:
```c
volatile uint16_t* video = (volatile uint16_t*)vga->base_addr;
uint16_t entry = (uint16_t)c | ((uint16_t)(bg << 4 | font) << 8);
video[y * vga->width + x] = entry;
```

---

#### `vga_delay`

简单忙等待延迟。

```c
void vga_delay(uint32_t count);
```

**参数**:
- `count`: 延迟计数（大约 CPU 周期数）

**实现**:
```c
for (volatile uint32_t i = 0; i < count; i++) {
    __asm__ volatile("nop");
}
```

**注意**:
- 延迟时间取决于 CPU 速度
- QEMU 环境下与真实硬件不同
- 仅适用于粗略计时

---

### 2.2 内联辅助函数

#### `vga_cursor_x`

提取光标的 x 坐标。

```c
static inline vga_sz_t vga_cursor_x(const CCOS_VGA* vga) {
    return (vga_sz_t)((vga->native_cursor_pos & 0xFF00) >> 8);
}
```

#### `vga_cursor_y`

提取光标的 y 坐标。

```c
static inline vga_sz_t vga_cursor_y(const CCOS_VGA* vga) {
    return (vga_sz_t)(vga->native_cursor_pos & 0x00FF);
}
```

#### `vga_make_entry`

创建 VGA 条目（字符 + 颜色）。

```c
static inline uint16_t vga_make_entry(char c, vga_color_t font, vga_color_t background) {
    return (uint16_t)c | ((uint16_t)(background << 4 | font) << 8);
}
```

**编码格式**:
```
位 15-8: 颜色属性
  位 7-4: 背景色
  位 3-0: 前景色
位 7-0: ASCII 字符
```

## 4. VSCode 调试脚本参考

### 4.1 `launch_qemu_for_vscode_debug.sh`

完整命令参考：

```bash
./scripts/launch_qemu_for_vscode_debug.sh [选项]
```

**选项**:
- 无参数: 启动 QEMU 调试服务器（自动构建）
- `--stop`, `-s`: 停止运行中的 QEMU
- `--status`, `--st`: 查看 QEMU 状态
- `--help`, `-h`: 显示帮助信息

**环境变量**:
- `BUILD_DIR`: 构建目录（默认 `$PROJECT_ROOT/build`）
- `PROJECT_ROOT`: 项目根目录（自动检测）

### 4.2 工作流程

```
1. 清理构建目录
   ↓
2. CMake 配置 (Debug 模式)
   ↓
3. CMake 构建
   ↓
4. 检查文件存在性
   ↓
5. 清理孤立的 QEMU 进程
   ↓
6. 启动 QEMU (后台运行)
   ↓
7. 保存 PID 到文件
   ↓
8. 验证 QEMU 正常运行
   ↓
9. 启动 GDB 连接监控
   ↓
10. 等待 VSCode 连接
```

### 4.3 关键函数

#### `monitor_gdb_connection`

监控 GDB 连接状态的核心函数。

```bash
monitor_gdb_connection() {
    local qemu_pid=$1

    while true; do
        # 检查 QEMU 进程
        if ! ps -p "$qemu_pid" > /dev/null 2>&1; then
            break
        fi

        # 检查端口连接
        if ss -tnH state established '( sport = 1234 or dport = 1234 )' 2>/dev/null | grep -q .; then
            has_connection=true
        fi

        # 状态转换处理
        ...

        sleep 0.5
    done
}
```

**检测命令**:
- `ss -tnH state established`: 检查已建立的 TCP 连接
- `lsof -ti:1234`: 查找监听端口的进程

## 6. VGA 内存布局详解

### 6.1 文本模式缓冲区

**基地址**: `0xB8000`

**格式**: 每个字符 2 字节
```
偏移 0: ASCII 字符
偏移 1: 颜色属性
```

**计算公式**:
```c
offset = (y * width + x) * 2
video[offset] = character
video[offset + 1] = attribute
```

### 6.2 颜色属性编码

```
位 7: 闪烁 (0=不闪烁, 1=闪烁)
位 6-4: 背景色 (0-15)
位 3: 高亮 (0=正常, 1=加亮)
位 2-0: 前景色 (0-7)
```

**示例**:
```c
// 白字黑底
attribute = 0x0F  // 0000 1111

// 黑字白底
attribute = 0xF0  // 1111 0000

// 亮红字黑底
attribute = 0x0C  // 0000 1100
```

## 7. 动画实现原理

### 7.1 颜色循环动画

```c
vga_color_t colors[] = {C1, C2, C3, C4, C5, C6};
int num_colors = 6;

for (int cycle = 0; cycle < 3; cycle++) {
    for (int i = 0; i < num_colors; i++) {
        for (vga_sz_t pos = 0; pos < width; pos++) {
            vga_color_t color = colors[(i + pos / 5) % num_colors];
            // 绘制...
        }
    }
}
```

**效果**: 颜色沿位置"流动"

**数学**:
- `pos / 5`: 每 5 个位置换一个颜色索引
- `(i + pos / 5) % num_colors`: 循环颜色数组

### 7.2 打字机效果

```c
void typewriter_print(CCOS_VGA* vga, vga_sz_t x, vga_sz_t y,
                      const char* text, vga_color_t color) {
    for (int i = 0; text[i] != '\0'; i++) {
        vga_put_char_at(vga, x + i, y, text[i], color, VGA_COLOR_BLACK);
        vga_delay(1000000);  // 延迟创造打字效果
    }
}
```
