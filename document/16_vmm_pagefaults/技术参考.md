## x86_64 分页机制

### 1. 四级页表结构

x86_64 架构使用四级页表进行地址转换：

```
┌────────────────────────────────────────────────────────────────┐
│                         64 位虚拟地址                           │
├─────┬─────┬─────┬─────┬────────────────────────────────────────┤
│ PML4│ PDPT│ PD  │ PT  │            页内偏移                      │
│ 9b  │ 9b  │ 9b  │ 9b  │              12b                        │
└──┬──┴──┬──┴──┬──┴──┬──┴────────────────────────────────────────┘
   │     │     │     │
   v     v     v     v
┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
│PML4 │→│PDPT │→│ PD  │→│ PT  │→ 物理页 + 偏移
└─────┘ └─────┘ └─────┘ └─────┘
```

### 2. 地址转换步骤

1. **CR3** → PML4 物理地址
2. **PML4[9:0]** → PDPT 物理地址
3. **PDPT[18:9]** → PD 物理地址
4. **PD[27:18]** → PT 物理地址
5. **PT[36:27]** → 物理页地址
6. **物理页 + 偏移[47:39]** → 最终物理地址

### 3. 页表项格式

| 位 | 名称 | 说明 |
|-----|------|------|
| 0 | P (Present) | 页是否在内存中 |
| 1 | R/W (Read/Write) | 0=只读, 1=可写 |
| 2 | U/S (User/Supervisor) | 0=内核, 1=用户 |
| 3 | PWT (Page-Level Write-Through) | 写通策略 |
| 4 | PCD (Page-Level Cache Disable) | 禁用缓存 |
| 5 | A (Accessed) | 是否被访问（硬件设置） |
| 6 | D (Dirty) | 是否被修改（硬件设置） |
| 7 | PS (Page Size) | 0=4KB, 1=巨大页 |
| 8 | G (Global) | 全局页（TLB不刷新） |
| 9-11 | Available | 操作系统可用 |
| 12-51 | Page Frame Number | 物理页号 |
| 52-62 | Available | 操作系统可用 |
| 63 | XD (Execute Disable) | 禁止执行 |

### 4. 巨�大页支持

| 类型 | 大小 | 所在级别 | PS 位位置 |
|------|------|----------|-----------|
| 4KB 页 | 4KB | PT | - |
| 2MB 页 | 2MB | PD | PD.PS = 1 |
| 1GB 页 | 1GB | PDPT | PDPT.PS = 1 |

## 虚拟地址空间布局

### 1. 规范地址 (Canonical Addresses)

x86_64 要求虚拟地址的位 63:48 必须全为 0 或全为 1：

```
用户空间 (全 0):
0x0000000000000000 - 0x00007FFFFFFFFFFF
(实际从 0x400000 开始，跳过 NULL 页)

内核空间 (全 1):
0xFFFF800000000000 - 0xFFFFFFFFFFFFFFFF

非规范空洞:
0x00007FFFFFFFFFFF - 0xFFFF800000000000 (无效)
```

### 2. CCOS 内核地址空间布局

```c
// 直接物理映射 (256MB)
#define KERNEL_VIRT_BASE   0xFFFF800000000000ULL
#define KERNEL_VIRT_END    0xFFFF800001000000ULL

// 内核代码 (2MB)
#define KERNEL_TEXT_BASE   0xFFFFFFFF80000000ULL
#define KERNEL_TEXT_SIZE   (2 * 1024 * 1024)

// 内核数据 (2MB)
#define KERNEL_DATA_BASE   0xFFFFFFFF80200000ULL
#define KERNEL_DATA_SIZE   (2 * 1024 * 1024)

// 内核堆 (128MB)
#define KERNEL_HEAP_BASE   0xFFFFFFFF81000000ULL
#define KERNEL_HEAP_MAX    0xFFFFFFFF89000000ULL

// 用户空间
#define USER_BASE          0x0000000000400000ULL  // 4MB
#define USER_END           0x00007FFFFFFFFFFFULL
```

### 3. 地址转换宏

```c
// 物理地址到内核虚拟地址
static inline virtual_addr_t phys_to_virt(physical_addr_t phys) {
    return phys + PHYS_MAP_OFFSET;  // 0xFFFF800000000000
}

// 内核虚拟地址到物理地址
static inline physical_addr_t virt_to_phys(virtual_addr_t virt) {
    return virt - PHYS_MAP_OFFSET;
}

// 检查是否为内核地址
static inline bool vmm_is_kernel_addr(virtual_addr_t addr) {
    return addr >= KERNEL_VIRT_BASE;
}

// 检查是否为用户地址
static inline bool vmm_is_user_addr(virtual_addr_t addr) {
    return addr >= USER_BASE && addr < USER_END;
}

// 检查是否为规范地址
static inline bool vmm_is_canonical(virtual_addr_t addr) {
    return ((addr >> 48) == 0) || ((addr >> 48) == 0xFFFF);
}
```

__asm__ volatile("mfence" ::: "memory");  // 内存屏障
