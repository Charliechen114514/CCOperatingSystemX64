## 1. 编译问题

### 1.1 隐式声明警告

#### 症状

```
warning: implicit declaration of function 'va_start'
warning: implicit declaration of function 'va_arg'
warning: implicit declaration of function 'va_end'
```

#### 原因

编译器找不到 `stdarg.h` 或等效的变长参数头文件。

#### 解决方案

确保定义了 `varargs.h`，包含必要的宏：

```c
// kernel/base/varargs.h
#pragma once

// GCC/Clang 内置支持
typedef __builtin_va_list va_list;
#define va_start(ap, last) __builtin_va_start(ap, last)
#define va_arg(ap, type)   __builtin_va_arg(ap, type)
#define va_end(ap)         __builtin_va_end(ap)
```

### 1.2 静态函数未使用警告

#### 症状

```
warning: 'reverse_str' defined but not used
```

#### 原因

静态函数只在当前文件可见，没有被调用。

#### 解决方案

1. 确保函数被正确调用
2. 或使用 `__attribute__((unused))` 标记

```c
__attribute__((unused))
static void reverse_str(char* str, int len) { ... }
```

### 1.3 格式化字符串警告

#### 症状

```
warning: format '%d' expects argument of type 'int', but argument 2 has type 'long'
```

#### 原因

格式化字符串与参数类型不匹配。

#### 解决方案

1. 确保类型匹配
2. 使用正确的格式符

```c
// 错误
klog_info("Value: %d", ptr);  // ptr 是 void*

// 正确
klog_info("Value: %p", ptr);  // 使用 %p
```

## 2. 链接问题

### 2.1 未定义引用

#### 症状

```
undefined reference to 'sync_serial_puts'
undefined reference to 'klog_serial_backend_init'
```

#### 原因

链接时缺少必要的对象文件或库。

#### 解决方案

检查 CMakeLists.txt 确保正确链接：

```cmake
# 确保串口驱动被链接
target_link_libraries(klogs PRIVATE serial)

# 确保日志系统被链接
target_link_libraries(kernel_main PRIVATE klogs)
```

### 2.2 重复定义

#### 症状

```
multiple definition of 'g_log_level'
```

#### 原因

全局变量在头文件中定义，被多个源文件包含。

#### 解决方案

在头文件中使用 `extern` 声明，在源文件中定义：

```c
// 头文件 (kprintf.h)
extern klog_level_t g_log_level;

// 源文件 (kprintf.c)
klog_level_t g_log_level = KLOG_LEVEL_TRACE;
```

或使用 `static` 限制作用域：

```c
// kprintf.c
static klog_level_t g_log_level = KLOG_LEVEL_TRACE;
```

## 3. 运行时问题

### 3.1 无日志输出

#### 症状

系统启动后，串口没有任何输出。

#### 诊断步骤

1. **检查串口初始化**
   ```c
   // 确保串口已初始化
   if (!klog_serial_backend_init()) {
       // 初始化失败
   }
   ```

2. **检查后端注册**
   ```c
   // 确保后端已注册
   const KLogBackendOps* ops = klog_get_backend_ops(KLOG_BACKEND_SERIAL);
   if (ops == NULL) {
       // 后端未注册
   }
   ```

3. **检查后端就绪状态**
   ```c
   if (!ops->is_ready()) {
       // 后端未就绪
   }
   ```

4. **检查日志级别过滤**
   ```c
   klog_level_t level = klog_get_level();
   // 确保日志级别不过滤
   ```

#### 解决方案

```c
// 正确的初始化顺序
void kernel_main(void) {
    // 1. 初始化硬件
    serial_init();

    // 2. 初始化日志系统
    klog_init(KLOG_BACKEND_SERIAL);

    // 3. 设置日志级别
    klog_set_level(KLOG_LEVEL_TRACE);

    // 4. 现在可以使用日志
    klog_info("System initialized\n");
}
```

### 3.2 日志输出不完整

#### 症状

日志被截断，只显示部分内容。

#### 原因

1. 缓冲区太小 (`KPRINTF_BUFFER_SIZE`)
2. 格式化字符串过长

#### 解决方案

1. 增加缓冲区大小
   ```c
   // kprintf_config.h
   #define KPRINTF_BUFFER_SIZE (1024)  // 从 512 增加到 1024
   ```

2. 分段输出长内容
   ```c
   // 不要一次性输出超长内容
   klog_info("Part 1: %s", part1);
   klog_info("Part 2: %s", part2);
   ```

### 3.3 颜色代码显示为原始字符

#### 症状

输出显示为 `\033[31mError\033[0m` 而不是红色文本。

#### 原因

终端不支持 ANSI 转义序列，或转义序列被错误处理。

#### 解决方案

1. 确保终端支持 ANSI
   - PuTTY: 启用 "Implicit CR in every LF"
   - minicom: 确保终端类型为 `ansi` 或 `xterm`

2. 检查转义序列格式
   ```c
   // 正确: 使用八进制 033
   #define ANSI_ESCAPE "\033["

   // 正确: 使用十六进制 1B
   #define ANSI_ESCAPE "\x1B["
   ```

3. 原子输出转义序列
   ```c
   // 错误: 分段输出
   sync_serial_puts("\033[");
   sync_serial_puts("31m");
   sync_serial_puts("Error");

   // 正确: 一次输出
   sync_serial_puts("\033[31mError\033[0m");
   ```

## 4. 日志输出异常

### 4.1 格式化输出错误

#### 症状

```
[INFO] Value: (null)
```

显示 `(null)` 而不是实际值。

#### 原因

1. 字符串指针为 NULL
2. 格式符与参数不匹配

#### 解决方案

```c
// 检查字符串指针
const char* str = get_string();
klog_info("Value: %s", str ? str : "(null)");

// 使用安全的格式化
if (ptr != NULL) {
    klog_info("Value: %s", ptr);
} else {
    klog_info("Value: (null)");
}
```

### 4.2 数字显示不正确

#### 症状

```
Expected: 255
Got: -1
```

#### 原因

有符号/无符号类型混淆。

#### 解决方案

```c
// 错误
unsigned char val = 255;
klog_info("Value: %d", val);  // 可能为 -1

// 正确
klog_info("Value: %u", val);  // 使用 %u
klog_info("Value: 0x%x", val);  // 或使用 %x
```

### 4.3 指针显示错误

#### 症状

```
Expected: 0x7C00
Got: 0x7c00
```

大小写不一致（小问题，但可能影响日志分析）。

#### 解决方案

```c
// 统一使用小写
uitoa((uintptr_t)ptr, buffer, 16);

// 或统一使用大写
// 需要修改 uitoa 实现，添加大小写参数
```

## 5. 调试技巧

### 5.1 GDB 调试日志系统

#### 设置断点

```gdb
# 在 klog_log 函数设置断点
break klog_log

# 运行
continue

# 查看参数
print level
print format

# 单步执行
next
```

#### 查看静态变量

```gdb
# 查看全局日志级别
print g_log_level

# 查看格式化缓冲区
print buffer
```

### 5.2 串口监控

#### 使用 picocom

```bash
# 连接到串口
picocom -b 115200 /dev/ttyS0

# 退出: Ctrl+A, Ctrl+X
```

#### 使用 minicom

```bash
# 配置串口
minicom -s

# 设置: 115200 8N1

# 保存并运行
```

### 5.3 内存检查

#### 检查缓冲区溢出

```c
// 在缓冲区末尾添加标记
#define CANARY 0xDEADBEEF

static char buffer[KPRINTF_BUFFER_SIZE];
uint32_t* canary = (uint32_t*)(buffer + KPRINTF_BUFFER_SIZE);
*canary = CANARY;

// 使用后检查
if (*canary != CANARY) {
    klog_error("Buffer overflow detected!\n");
}
```

### 5.4 性能分析

#### 简单的计时

```c
uint64_t start = rdtsc();

klog_info("Performance test message\n");

uint64_t end = rdtsc();
uint64_t cycles = end - start;

klog_info("Cycles: %lu\n", cycles);
```

## 6. 常见错误代码

### 6.1 编译错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `implicit declaration` | 缺少头文件 | 添加对应的头文件 |
| `undefined reference` | 缺少链接 | 检查 CMakeLists.txt |
| `conflicting types` | 重复定义 | 使用 `extern` 或 `static` |

### 6.2 运行时错误

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| 无输出 | 后端未初始化 | 调用 `klog_init()` |
| 输出截断 | 缓冲区太小 | 增加 `KPRINTF_BUFFER_SIZE` |
| 显示 `\033[` | 终端不支持 ANSI | 使用兼容终端或移除颜色 |

## 7. 最佳实践

### 7.1 初始化顺序

```c
// 正确的初始化顺序
void kernel_main(void) {
    // 1. 硬件初始化
    serial_init();
    vga_init();

    // 2. 基础库初始化
    // (strhelpers 无需初始化)

    // 3. 日志系统初始化
    klog_init(KLOG_BACKEND_SERIAL);
    klog_set_level(KLOG_LEVEL_INFO);

    // 4. 其他模块初始化
    memory_init();
    // ...

    // 5. 启动完成
    klog_info("Kernel initialized\n");
}
```

### 7.2 错误处理

```c
// 总是检查返回值
if (!klog_init(KLOG_BACKEND_SERIAL)) {
    // 降级处理：尝试其他后端
    if (!klog_init(KLOG_BACKEND_VGA)) {
        // 完全无法输出
        halt();
    }
}
```

### 7.3 日志级别使用

```c
// TRACE: 详细的执行流程
klog_trace("Entering function foo, param x=%d\n", x);

// DEBUG: 调试信息
klog_debug("Buffer content: %s\n", buffer);

// INFO: 一般信息
klog_info("System started successfully\n");

// WARN: 警告（不影响运行）
klog_warn("Memory usage high: %u%%\n", usage);

// ERROR: 错误（影响功能）
klog_error("Failed to open device: %s\n", device_name);
```
