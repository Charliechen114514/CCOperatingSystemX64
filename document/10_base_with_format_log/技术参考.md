## 1. 字符串处理库

### 1.1 字符分类函数

#### isspace

判断字符是否为空白字符。

```c
bool isspace(char ch);
```

**参数**:
- `ch`: 要判断的字符

**返回值**:
- `true`: 字符为空白字符
- `false`: 字符不为空白字符

**空白字符定义**:
```
空格  ' '  (0x20)
制表  '\t' (0x09)
换行  '\n' (0x0A)
垂直制表 '\v' (0x0B)
换页  '\f' (0x0C)
回车  '\r' (0x0D)
```

#### isdigit

判断字符是否为十进制数字。

```c
bool isdigit(char ch);
```

**参数**:
- `ch`: 要判断的字符

**返回值**:
- `true`: 字符为 '0'-'9'
- `false`: 字符不为数字

---

### 1.2 字符串转数值

#### strtol

将字符串转换为 `long` 整数。

```c
long strtol(const char* nptr, char** endptr, int base);
```

**参数**:
- `nptr`: 要转换的字符串
- `endptr`: 指向第一个未转换字符的指针 (可为 NULL)
- `base`: 数值基数 (2-36，或 0 表示自动检测)

**返回值**: 转换后的整数值

**基数检测规则** (当 `base=0` 时):
```
字符串以 "0x" 或 "0X" 开头 → 十六进制 (base=16)
字符串以 "0" 开头         → 八进制 (base=8)
其他                     → 十进制 (base=10)
```

**示例**:
```c
strtol("123", NULL, 10);      // → 123
strtol("-255", NULL, 10);     // → -255
strtol("0xFF", NULL, 0);      // → 255 (自动检测为十六进制)
strtol("0755", NULL, 0);      // → 493 (自动检测为八进制)
strtol("  42abc", &end, 10);  // → 42, end 指向 "abc"
```

#### strtoul

将字符串转换为 `unsigned long` 整数。

```c
unsigned long strtoul(const char* nptr, char** endptr, int base);
```

**参数**: 与 `strtol` 相同

**返回值**: 转换后的无符号整数值

#### atoi

将字符串转换为 `int` 整数 (简化版)。

```c
int atoi(const char* nptr);
```

**参数**:
- `nptr`: 要转换的字符串

**返回值**: 转换后的整数值

**说明**: 等价于 `strtol(nptr, NULL, 10)`

---

### 1.3 数值转字符串

#### itoa

将 `int` 整数转换为字符串。

```c
char* itoa(int value, char* str, int base);
```

**参数**:
- `value`: 要转换的整数值
- `str`: 存储结果的缓冲区
- `base`: 数值基数 (2-36)

**返回值**: 指向 `str` 的指针

**示例**:
```c
char buf[32];
itoa(123, buf, 10);   // buf = "123"
itoa(-42, buf, 10);   // buf = "-42"
itoa(255, buf, 16);   // buf = "ff"
itoa(31, buf, 2);     // buf = "11111"
```

#### uitoa

将 `unsigned int` 整数转换为字符串。

```c
char* uitoa(unsigned int value, char* str, int base);
```

**参数**: 与 `itoa` 相同 (但 `value` 为无符号)

#### reverse_str

反转字符串 (内部辅助函数)。

```c
void reverse_str(char* str, int len);
```

**参数**:
- `str`: 要反转的字符串
- `len`: 字符串长度

## 2. 格式化日志系统

### 2.1 日志级别

```c
typedef enum {
    KLOG_LEVEL_TRACE = 0,  // 跟踪信息
    KLOG_LEVEL_DEBUG = 1,  // 调试信息
    KLOG_LEVEL_INFO  = 2,  // 一般信息
    KLOG_LEVEL_WARN  = 3,  // 警告
    KLOG_LEVEL_ERROR = 4,  // 错误
} klog_level_t;
```

### 2.2 核心接口

#### klog_init

初始化日志系统。

```c
bool klog_init(klog_backend_t backend);
```

**参数**:
- `backend`: 默认后端类型

**返回值**:
- `true`: 初始化成功
- `false`: 初始化失败

#### klog_set_level / klog_get_level

设置/获取最小日志级别。

```c
void klog_set_level(klog_level_t level);
klog_level_t klog_get_level(void);
```

**过滤规则**: 只有 `level >= g_log_level` 的日志才会输出。

#### klog_level_name

获取日志级别的字符串表示。

```c
const char* klog_level_name(klog_level_t level);
```

**返回值**:
```c
KLOG_LEVEL_TRACE → "TRACE"
KLOG_LEVEL_DEBUG → "DEBUG"
KLOG_LEVEL_INFO  → "INFO "
KLOG_LEVEL_WARN  → "WARN "
KLOG_LEVEL_ERROR → "ERROR"
```

### 2.3 日志宏

```c
klog_trace(format, ...)  // 等价于 klog_log(KLOG_LEVEL_TRACE, format, ##__VA_ARGS__)
klog_debug(format, ...)  // 等价于 klog_log(KLOG_LEVEL_DEBUG, format, ##__VA_ARGS__)
klog_info(format, ...)   // 等价于 klog_log(KLOG_LEVEL_INFO, format, ##__VA_ARGS__)
klog_warn(format, ...)   // 等价于 klog_log(KLOG_LEVEL_WARN, format, ##__VA_ARGS__)
klog_error(format, ...)  // 等价于 klog_log(KLOG_LEVEL_ERROR, format, ##__VA_ARGS__)
```

### 2.4 格式化字符串

#### 支持的格式符

| 格式符 | 类型 | 参数类型 | 示例输入 | 示例输出 |
|--------|------|----------|----------|----------|
| `%%` | 字面量 `%` | - | `"100%%"` | `"100%"` |
| `%c` | 字符 | `int` | `'A'` | `"A"` |
| `%s` | 字符串 | `const char*` | `"hello"` | `"hello"` |
| `%d` | 有符号整数 | `int` | `-42` | `"-42"` |
| `%i` | 有符号整数 | `int` | `42` | `"42"` |
| `%u` | 无符号整数 | `unsigned int` | `42` | `"42"` |
| `%x` | 十六进制 (小写) | `unsigned int` | `255` | `"ff"` |
| `%p` | 指针 | `void*` | `0x7C00` | `"0x7c00"` |

#### 格式化示例

```c
klog_info("Value: %d", 42);              // "Value: 42"
klog_info("Hex: %x", 255);               // "Hex: ff"
klog_info("Ptr: %p", (void*)0x7C00);     // "Ptr: 0x7c00"
klog_info("String: %s, Char: %c", "ABC", 'X');  // "String: ABC, Char: X"
klog_info("Percent: 100%%");             // "Percent: 100%"
```

## 3. 后端架构

### 3.1 后端类型

```c
typedef enum {
    KLOG_BACKEND_NONE    = 0,  // 无输出
    KLOG_BACKEND_SERIAL  = 1,  // 串口 (COM1)
    KLOG_BACKEND_VGA     = 2,  // VGA 文本模式 (未来)
} klog_backend_t;
```

### 3.2 后端操作表

```c
typedef struct {
    /**
     * @brief 处理格式化后的字符串
     * @param str 格式化后的字符串
     * @param level 日志级别 (-1 表示无特定级别)
     */
    void (*process)(const char* str, int level);

    /**
     * @brief 检查后端是否可用
     * @return true 可用, false 不可用
     */
    bool (*is_ready)(void);
} KLogBackendOps;
```

### 3.3 后端管理 API

#### klog_register_backend

注册后端。

```c
bool klog_register_backend(klog_backend_t backend_type,
                           const KLogBackendOps* ops);
```

#### klog_get_backend_ops

获取后端操作表。

```c
const KLogBackendOps* klog_get_backend_ops(klog_backend_t backend);
```

#### klog_set_default_backend / klog_get_default_backend

设置/获取默认后端。

```c
void klog_set_default_backend(klog_backend_t backend);
klog_backend_t klog_get_default_backend(void);
```

## 4. ANSI 颜色系统

### 4.1 颜色定义

```c
typedef enum {
    SERIAL_COLOR_RESET        = 0,   // 重置
    SERIAL_COLOR_BLACK        = 30,  // 黑色
    SERIAL_COLOR_RED          = 31,  // 红色
    SERIAL_COLOR_GREEN        = 32,  // 绿色
    SERIAL_COLOR_YELLOW       = 33,  // 黄色
    SERIAL_COLOR_BLUE         = 34,  // 蓝色
    SERIAL_COLOR_MAGENTA      = 35,  // 品红
    SERIAL_COLOR_CYAN         = 36,  // 青色
    SERIAL_COLOR_WHITE        = 37,  // 白色
    SERIAL_COLOR_GRAY         = 90,  // 灰色 (亮黑)
    SERIAL_COLOR_BRIGHT_RED   = 91,  // 亮红
    SERIAL_COLOR_BRIGHT_GREEN = 92,  // 亮绿
    SERIAL_COLOR_BRIGHT_YELLOW= 93,  // 亮黄
    SERIAL_COLOR_BRIGHT_BLUE  = 94,  // 亮蓝
    SERIAL_COLOR_BRIGHT_MAGENTA= 95, // 亮品红
    SERIAL_COLOR_BRIGHT_CYAN  = 96,  // 亮青
    SERIAL_COLOR_BRIGHT_WHITE = 97,  // 亮白
} serial_color_t;
```

### 4.2 ANSI 转义序列格式

```
\033[<code>m

ESC (八进制 033, 十进制 27) + "[" + <code> + "m"
```

### 4.3 颜色 API

#### serial_color_ansi

获取颜色的 ANSI 转义序列。

```c
const char* serial_color_ansi(serial_color_t color);
```

**返回值**: 静态字符串，包含 ANSI 转义序列

#### serial_color_for_log_level

根据日志级别获取对应的颜色。

```c
const char* serial_color_for_log_level(int level);
```

**颜色映射**:
```
TRACE (0)  → SERIAL_COLOR_GRAY (90)
DEBUG (1)  → SERIAL_COLOR_MAGENTA (35)
INFO (2)   → SERIAL_COLOR_GREEN (32)
WARN (3)   → SERIAL_COLOR_YELLOW (33)
ERROR (4)  → SERIAL_COLOR_RED (31)
other      → SERIAL_COLOR_RESET (0)
```

### 4.4 使用示例

```c
#include "driver/serial/serial_color.h"

// 输出红色文本
sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RED));
sync_serial_puts("Error message\n");
sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RESET));

// 输出带颜色的日志
const char* color = serial_color_for_log_level(KLOG_LEVEL_ERROR);
sync_serial_puts(color);
sync_serial_puts("[ERROR] ");
sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RESET));
sync_serial_puts(message);
```


```
─────────────────────────────────
0x...        512 B     kprintf 格式化缓冲区
0x...        32 B      数字转换缓冲区
```

```
函数                    最大栈使用
─────────────────────────────────
format_string()         ~32 B   (局部变量)
klog_log()              ~64 B   (va_list + 局部变量)
strtol()                ~24 B   (局部变量)
itoa()                  ~12 B   (局部变量)
```

## 9. 性能特征

### 9.1 时间复杂度

| 函数 | 复杂度 | 说明 |
|------|--------|------|
| `format_string` | O(n) | n 为格式化字符串长度 |
| `strtol` | O(n) | n 为输入字符串长度 |
| `itoa` | O(log n) | n 为数值大小 |
| `klog_log` | O(n) | n 为输出字符串长度 |

### 9.2 空间复杂度

| 函数 | 空间 | 说明 |
|------|------|------|
| `format_string` | O(1) | 使用静态缓冲区 |
| `strtol` | O(1) | 仅使用局部变量 |
| `itoa` | O(1) | 就地反转，使用静态缓冲区 |
