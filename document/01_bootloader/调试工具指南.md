## 1. 汇编与构建工具

### NASM (Netwide Assembler)

#### 基本信息
- **功能**: x86/x86_64 汇编器
- **项目主页**: https://www.nasm.us/
- **文档**: https://www.nasm.us/docs.php

#### 常用命令

##### 基本汇编
```bash
# 汇编单个文件
nasm -f bin boot.asm -o boot.bin

# 指定输出格式
nasm -f elf64 kernel.asm -o kernel.o    # ELF64 格式
nasm -f bin boot.asm -o boot.bin         # 纯二进制
```

##### 列表输出
```bash
# 生成列表文件（包含机器码和源码）
nasm -f bin boot.asm -o boot.bin -l boot.lst

# 查看列表文件
cat boot.lst
```

##### 调试信息
```bash
# 生成带调试信息的文件
nasm -f elf64 -F dwarf kernel.asm -o kernel.o
```

#### CCOS 项目使用

##### Makefile 中的使用
```makefile
AS = nasm
ASFLAGS = -f bin

boot.bin: boot.asm
    @echo "Building Stage 1 (MBR)..."
    $(AS) $(ASFLAGS) $< -o $@
    @echo "Stage 1 size:"
    @ls -lh $@
```

##### 不同 bits 指令的影响
```asm
; 在 boot2.asm 中

bits 16              ; 生成 16 位代码
mov ax, 0x1234      ; 机器码: B8 34 12

bits 32              ; 生成 32 位代码
mov eax, 0x1234    ; 机器码: 66 B8 34 12 00 00

bits 64              ; 生成 64 位代码
mov rax, 0x1234    ; 机器码: 48 B8 34 12 00 00 00 00 00
```

**注意**: `bits` 只影响指令编码，不影响标签计算。

### Make

#### 基本用法
```bash
# 执行默认目标
make

# 清理构建产物
make clean

# 运行测试
make run

# 调试运行
make debug
```

#### CCOS Makefile 结构
```makefile
AS = nasm
ASFLAGS = -f bin
QEMU = qemu-system-x86_64

.PHONY: all clean run debug

all: boot.img

boot.bin: boot.asm
    $(AS) $(ASFLAGS) $< -o $@

boot2.bin: boot2.asm
    $(AS) $(ASFLAGS) $< -o $@

boot.img: boot.bin boot2.bin
    dd if=boot.bin of=boot.img bs=512 count=1 conv=notrunc 2>/dev/null
    dd if=boot2.bin of=boot.img bs=512 seek=1 conv=notrunc 2>/dev/null

clean:
    rm -f boot.img boot.bin boot2.bin *.o

run: boot.img
    $(QEMU) -drive format=raw,file=boot.img,if=floppy -nographic

debug: boot.img
    $(QEMU) -drive format=raw,file=boot.img,if=floppy -nographic -s -S
```

## 2. 反汇编工具

### ndisasm

#### 基本信息
- **全称**: Netwide Disassembler
- **功能**: 将二进制文件反汇编为汇编代码
- **隶属**: NASM 套件的一部分

#### 基本用法

##### 指定位模式
```bash
# 反汇编为 16 位代码
ndisasm -b 16 boot.bin

# 反汇编为 32 位代码
ndisasm -b 32 kernel.bin

# 反汇编为 64 位代码
ndisasm -b 64 kernel64.bin
```

##### 指定起始地址
```bash
# 文件从 0x7C00 开始（MBR 加载地址）
ndisasm -b 16 -o 0x7C00 boot.bin

# Stage 2 从 0x7E00 开始
ndisasm -b 16 -o 0x7E00 boot2.bin
```

##### 输出控制
```bash
# 只显示前 100 行
ndisasm -b 16 boot.bin | head -100

# 显示特定范围
ndisasm -b 16 boot.bin | sed -n '50,80p'

# 搜索特定指令
ndisasm -b 16 boot.bin | grep "EA"     # 查找 JMP FAR
ndisasm -b 16 boot.bin | grep "0F 01"  # 查找 LGDT/LIDT
```

##### 输出到文件
```bash
ndisasm -b 16 -o 0x7C00 boot.bin > boot.dis
```

#### CCOS 实战案例

##### 案例 1: 检查 far jump 指令
```bash
# 查找 far jump 指令
ndisasm -b 16 boot2.bin | grep -A 2 -B 2 "EA"

# 输出示例：
# 00000067  66EA7A7E0800    jmp word 0x8:word 0x7e7a
#            ^^ 检查这里是否是 66 EA (正确的 32 位偏移)
```

##### 案例 2: 验证 GDT 加载
```bash
# 查找 LGDT 指令
ndisasm -b 16 boot2.bin | grep "0F 01"

# 输出示例：
# 00000052  0F01162B7E    lgdt word [0x7e2b]
#                             ^^ 确认这个地址是 gdt_ptr 的位置
```

##### 案例 3: 检查数据结构
```bash
# 反汇编并查看 GDT 数据区域
ndisasm -b 16 boot2.bin | head -30

# 输出分析：
# 00000000  EB3E              jmp short 0x40
# 00000002  90                nop
# 00000003  0000              add [bx+si],al
# ...
# GDT 数据从 0x03 开始（8 字节对齐）
```

#### 输出解读

##### 反汇编输出格式
```
地址        机器码             汇编指令
00000000   B90100            mov cx, 0x1
^^^^^^^^   ^^^^^^^^^^^^      ^^^^^^^^^^^^^
偏移      十六进制字节      可读指令
```

##### 常见指令模式
```
EA XX XX XX XX    JMP FAR ptr16:16
66 EA XX XX XX XX XX XX XX    JMP FAR ptr16:32 (with 0x66 prefix)
0F 01 /1         LGDT m16&32
0F 01 /0         LIDT m16&32
0F 20 C0         MOV EAX, CR0
0F 22 C0         MOV CR0, EAX
0F 01 D5         INVLPG
```

## 3. 十六进制查看工具

### xxd

#### 基本信息
- **功能**: 十六进制查看器
- **包**: vim-common (通常预装)
- **替代工具**: `hexdump`, `od`

#### 基本用法

##### 查看整个文件
```bash
# 默认输出（十六进制 + ASCII）
xxd boot.bin

# 只显示十六进制（无 ASCII）
xxd -p boot.bin

# 显示为 little-endian
xxd -e boot.bin
```

##### 显示特定部分
```bash
# 从偏移 0x20 开始显示
xxd -s 0x20 boot.bin

# 只显示 64 字节
xxd -l 64 boot.bin

# 从 0x20 开始，显示 80 字节
xxd -s 0x20 -l 80 boot.bin
```

##### 每行字节数控制
```bash
# 每行 8 字节（默认 16）
xxd -g 1 boot.bin

# 每行 4 字节
xxd -g 4 boot.bin
```

#### CCOS 实战案例

##### 案例 1: 检查 GDT 结构
```bash
# 查看 GDT 数据（从偏移 0x03 开始）
xxd boot2.bin | head -10

# 输出分析：
00000000: eb3e 9000 0000 0000 0000 00ff ff00 0000  .>..............
#         ^^^^ ^^^^ ^^^^ ^^^0
#         jmp  nop  GDT 开始 (8 字节 null 描述符)
#
00000010: 9acf 00ff ff00 0000 92cf 00ff ff00 0000  ................
#         ^^^^ ^^^^ ^^^^ ^^^0
#         gdt_code (8 字节)
```

##### 案例 2: 验证 MBR 签名
```bash
# 查看文件末尾（MBR 签名）
xxd boot.bin | tail -3

# 正确输出：
000001f0: 0000 0000 0000 0000 0000 0000 0000 0000  ................
00000200: 55aa                                       .U.
#                                     ^^^^
#                                     0xAA55 (小端序)
```

##### 案例 3: 检查 GDT 指针
```bash
# 查找 GDT pointer（在 GDT 之后）
xxd boot2.bin | grep "27 00"

# 输出分析：
00000020: 9aaf 00ff ff00 0000 92cf 0027 0003 fc00  ...........'....
#                                     ^^ ^^ ^^ ^^
#                                     limit=0x0027 base=0x00007E03
#
# 验证：limit = 5 × 8 - 1 = 39 = 0x27 ✓
#        base = 0x7E00 + 0x03 = 0x7E03 ✓
```

##### 案例 4: 检查 far jump 编码
```bash
# 查找 0x66 0xEA 序列（带前缀的 far jump）
xxd boot2.bin | grep "66 ea"

# 正确输出：
00000060: 6683 c801 0f22 c066 ea7d 7e00 0008 0060  f....".f.}~....`
#                                 ^^ ^^ ^^ ^^ ^^ ^^
#                                 66 ea 7d 7e 00 00 08 00
#                                 prefix op  offset(32) segment
#
# 0x66 = operand-size prefix（32 位偏移）
# 0xEA = JMP FAR opcode
# 0x7E00... = offset（32 位，小端序）
# 0x0008 = segment selector
```

##### 案例 5: 搜索模式
```bash
# 搜索特定字节序列
xxd boot2.bin | grep "55 aa"     # MBR 签名
xxd boot2.bin | grep "0f 01"    # LGDT/LIDT
xxd boot2.bin | grep "cd 10"    # INT 10h

# 使用正则表达式
xxd boot2.bin | grep "ea:7e"    # 跳转到 0x7E00 附近
```

#### 高级技巧

##### 与其他工具组合
```bash
# 提取特定字节
xxd -p boot2.bin | tr -d ' \n' | cut -c1-2  # 第一个字节

# 计算文件大小
xxd boot2.bin | tail -1 | awk '{print $1}' | tr -d ':'

# 统计特定字节出现次数
xxd -p boot2.bin | grep -o "00" | wc -l
```

##### 对比两个文件
```bash
# 并排对比
xxd boot1.bin > /tmp/boot1.txt
xxd boot2.bin > /tmp/boot2.txt
diff /tmp/boot1.txt /tmp/boot2.txt

# 使用 vimdiff
vimdiff <(xxd boot1.bin) <(xxd boot2.bin)
```

## 4. 调试器 (GDB)

### GDB 基础

#### 启动 GDB 会话

##### 方式 1: 通过 QEMU GDB server
```bash
# 终端 1: 启动 QEMU with GDB server
qemu-system-x86_64 -drive format=raw,file=boot.img,if=floppy \
    -nographic -s -S

# -s: 启用 GDB server（默认端口 1234）
# -S: 启动时暂停，等待 GDB 连接

# 终端 2: 连接 GDB
gdb
(gdb) target remote localhost:1234
```

##### 方式 2: 自动启动脚本
```bash
# 创建 GDB 脚本
cat > /tmp/gdb_boot.txt << EOF
target remote localhost:1234
set architecture i8086
display/i $pc
si 100
info registers
quit
EOF

# 启动 QEMU 并执行脚本
qemu-system-x86_64 ... -s -S &
sleep 1
gdb -batch -x /tmp/gdb_boot.txt
```

#### 常用 GDB 命令

##### 基础命令
```gdb
(gdb) help              # 显示帮助
(gdb) quit             # 退出 GDB
(gdb) detach           # 断开连接但不退出
```

##### 执行控制
```gdb
(gdb) si                # 单步执行一条指令
(gdb) si 10            # 单步执行 10 条指令
(gdb) continue          # 继续执行
(gdb) stepi            # 步入（进入函数）
(gdb) nexti            # 步过（跳过函数）
```

##### 信息查看
```gdb
(gdb) info registers   # 显示所有寄存器
(gdb) info registers eax ebx ecx  # 显示特定寄存器
(gdb) x/10i $pc       # 查看当前指令（10 条）
(gdb) x/5i 0x7C00    # 查看指定地址的指令
(gdb) x/10x 0x7E00    # 查看内存（16 进制）
(gdb) x/10d 0x7E00    # 查看内存（10 进制）
```

##### 断点
```gdb
(gdb) break *0x7E00    # 在地址设置断点
(gdb) break main        # 在标签设置断点
(gdb) continue          # 继续到断点
(gdb) delete           # 删除所有断点
```

#### CCOS 实战案例

##### 案例 1: 调试 MBR 执行
```bash
# 启动 QEMU
qemu-system-x86_64 -drive format=raw,file=boot.img,if=floppy -nographic -s -S &
QEMU_PID=$!

# 连接 GDB 并调试
gdb << 'EOF'
target remote localhost:1234
set architecture i8086

# 设置断点在 Stage 1 加载后
break *0x7C20

# 继续执行
continue

# 查看寄存器
info registers

# 查看接下来 5 条指令
x/5i $pc

quit
EOF

# 清理
kill $QEMU_PID 2>/dev/null
```

##### 案例 2: 调试保护模式切换
```bash
# GDB 脚本
cat > /tmp/debug_pm.txt << 'EOF'
target remote localhost:1234
set architecture i8086

# 执行到 GDT 加载
break *0x7E52
continue

# 查看 GDT pointer 内容
x/2wx 0x7E2B
# 应该显示：
# 0x7e2b: 0x0027    (limit)
# 0x7e2d: 0x00007e03 (base)

# 单步执行 far jump
si
si

# 切换到 32 位模式
set architecture i386

# 继续执行
x/10i $pc

quit
EOF

qemu-system-x86_64 ... -s -S &
sleep 1
gdb -batch -x /tmp/debug_pm.txt
```

##### 案例 3: 查看内存内容
```gdb
# 查看 GDT 结构
(gdb) x/10gx 0x7E03
# 0x7e03: 0x0000000000000000000
# 0x7e0b: 0x00cf9a000000ffff
# 0x7e13: 0x00cf92000000ffff
# ...

# 查看 stack
(gdb) x/10wx $sp    # 查看 stack top 10 个 word

# 查看 VGA 显存
(gdb) x/10wx 0xB8000
```

#### 高级技巧

##### 自动化调试脚本
```bash
#!/bin/bash
# debug_boot.sh

QEMU_PID=""

cleanup() {
    kill $QEMU_PID 2>/dev/null
}

trap cleanup EXIT

# 启动 QEMU
qemu-system-x86_64 \
    -drive format=raw,file=boot.img,if=floppy \
    -nographic -s -S &
QEMU_PID=$!

sleep 1

# 执行调试
gdb -batch -x debug_script.gdb
```

##### GDB Python 脚本
```python
# custom_gdb.py
import gdb

class PrintMemMap(gdb.Command):
    """Print memory map"""

    def invoke(self, arg, from_tty):
        # GDT base
        gdt_base = 0x00007E03
        gdb.write(f"GDT at 0x{gdt_base:X}\n")

        # Read GDT limit
        limit = gdb.parse_and_eval(f"*(short *)0x7E2B")
        gdb.write(f"Limit: {limit}\n")

PrintMemMap()
```

## 5. 模拟器 (QEMU)

### QEMU 基础

#### 常用命令行选项

##### 基本选项
```bash
# 启动虚拟机
qemu-system-x86_64 -drive format=raw,file=boot.img,if=floppy

# 指定内存大小
qemu-system-x86_64 -m 128M -drive ...

# 禁用图形界面
qemu-system-x86_64 -nographic -drive ...

# 使用串口
qemu-system-x86_64 -serial stdio -drive ...
```

##### 磁盘选项
```bash
# 软盘模式（if=floppy）
qemu-system-x86_64 -drive format=raw,file=boot.img,if=floppy

# 硬盘模式（if=ide）
qemu-system-x86_64 -drive format=raw,file=disk.img,if=ide

# SATA 模式
qemu-system-x86_64 -drive format=raw,file=disk.img,if=sata
```

##### 调试选项
```bash
# 启用 GDB server（端口 1234）
qemu-system-x86_64 -s -drive ...

# 启动时暂停（等待 GDB 连接）
qemu-system-x86_64 -s -S -drive ...

# 指定 GDB 端口
qemu-system-x86_64 -s -gdb tcp::1234 -drive ...
```

##### 显示选项
```bash
# SDL 图形界面
qemu-system-x86_64 -display sdl -drive ...

# VNC 服务器
qemu-system-x86_64 -vnc :1 -drive ...
# 连接: vncviewer localhost:5901

# GTK 图形界面
qemu-system-x86_64 -display gtk -drive ...

# curses 界面（终端内）
qemu-system-x86_64 -display curses -drive ...
```

#### CCOS Makefile 集成

```makefile
QEMU = qemu-system-x86_64

# 运行（文本模式）
run: boot.img
    @echo "Running with QEMU..."
    $(QEMU) -drive format=raw,file=$<,if=floppy -nographic

# 运行（图形模式）
run-gui: boot.img
    @echo "Running with QEMU (GUI)..."
    $(QEMU) -drive format=raw,file=$<,if=floppy

# 调试模式
debug: boot.img
    @echo "Running with QEMU (debug)..."
    $(QEMU) -drive format=raw,file=$<,if=floppy -nographic -s -S
```

### QEMU Monitor

#### 访问 Monitor

##### 键盘快捷键
```
Ctrl+Alt+1    # 切换到控制台

Ctrl+Alt+F    # 切换全屏
```

##### 常用 Monitor 命令

### QEMU 实战技巧

##### 技巧 1: 使用 timeout 限制运行时间
```bash
# 防止 QEMU 无限运行
timeout 5 qemu-system-x86_64 -drive ... -nographic
# 5 秒后自动终止

# 检查是否成功
timeout 5 qemu-system-x86_64 -drive ... -nographic 2>&1 || echo "Failed or timeout"
```

##### 技巧 2: 后台运行 QEMU
```bash
# 启动 QEMU 并获取 PID
qemu-system-x86_64 -drive ... -nographic &
QEMU_PID=$!

# 等待一段时间
sleep 3

# 停止 QEMU
kill $QEMU_PID 2>/dev/null
```

##### 技巧 3: 重定向输出
```bash
# 保存 QEMU 输出到文件
qemu-system-x86_64 -drive ... -nographic > output.log 2>&1

# 只保存错误输出
qemu-system-x86_64 -drive ... -nographic 2> error.log

# 同时输出到终端和文件
qemu-system-x86_64 -drive ... -nographic 2>&1 | tee output.log
```

##### 技巧 4: 检查系统状态
```bash
# 在另一个终端连接到 monitor
echo "info registers" | nc -U /tmp/qemu-monitor

# 或使用 QMP (QEMU Machine Protocol)
echo '{"execute": "human-monitor-command", "arguments": {"command-line": "info registers"}}' | \
    nc -U /tmp/qemu-monitor-socket
```

## 6. 其他实用工具

### ls 和 wc

##### 检查文件大小
```bash
# 人类可读格式
ls -lh boot.bin boot2.bin

# 只显示大小
ls -l boot.bin | awk '{print $5}'

# 统计字节数
wc -c boot2.bin

# 计算扇区数（假设 512 字节/扇区）
echo $(($(wc -c < boot2.bin) / 512 + 1))
```

### grep 和 sed

##### 搜索汇编代码
```bash
# 在源码中搜索指令
grep "lgdt" boot2.asm

# 搜索并显示上下文
grep -B 5 -A 5 "protected_mode" boot2.asm

# 搜索多个文件
grep "mov cr0" *.asm

# 只显示匹配的行号
grep -n "jmp" boot2.asm
```

##### 提取反汇编部分
```bash
# 提取特定行
ndisasm -b 16 boot2.bin | sed -n '50,80p'

# 提取包含特定模式的部分
ndisasm -b 16 boot2.bin | sed -n '/EA/,/ret/p'

# 删除特定行
ndisasm -b 16 boot2.bin | sed '/db/d'
```

### file 和 strings

##### 识别文件类型
```bash
# 查看文件类型
file boot.bin
# 输出: boot.bin: DOS/MBR boot sector

# 查看多个文件
file *.bin
```

##### 提取可打印字符串
```bash
# 查找所有 ASCII 字符串
strings boot2.bin

# 只显示长度 >= 10 的字符串
strings -n 10 boot2.bin

# 查找特定字符串
strings boot2.bin | grep "Stage"
```

## 7. 工作流最佳实践

### 典型调试流程

```bash
# 1. 修改源码
vim boot2.asm

# 2. 清理并重新构建
make clean && make

# 3. 检查文件大小
ls -lh boot.bin boot2.bin boot.img

# 4. 反汇编验证关键指令
ndisasm -b 16 boot2.bin | grep "EA"

# 5. 十六进制验证数据结构
xxd boot2.bin | head -10

# 6. 启动 QEMU 测试
timeout 5 qemu-system-x86_64 -drive format=raw,file=boot.img,if=floppy -nographic

# 7. 如果出错，使用 GDB 调试
qemu-system-x86_64 ... -s -S &
sleep 1
gdb -x debug_script.gdb
```

### 快速验证检查清单

```bash
# ✓ MBR 签名检查
xxd boot.bin | tail -1 | grep "55 aa" && echo "MBR OK"

# ✓ Stage 2 大小检查
[ $(wc -c < boot2.bin) -le 512 ] && echo "Stage 2 size OK"

# ✓ GDT pointer 检查
xxd boot2.bin | grep "27 00" && echo "GDT limit OK"
xxd boot2.bin | grep "03 00 7e 00" && echo "GDT base OK"

# ✓ Far jump 检查
xxd boot2.bin | grep "66 ea" && echo "Far jump encoding OK"
```
