## 1. PS/2 键盘协议

### 1.1 硬件接口

#### I/O 端口

| 端口 | 名称 | 方向 | 描述 |
|------|------|------|------|
| 0x60 | 数据寄存器 | 双向 | 传输数据 |
| 0x64 | 状态/命令寄存器 | 输入/命令 | 状态/命令 |

#### 状态寄存器 (0x64)

| 位 | 名称 | 描述 |
|----|------|------|
| 0 | 输出满 | 1 = 数据可读 |
| 1 | 输入满 | 1 = 等待发送 |
| 2 | 系统标志 | 0 = 上电复位 |
| 3 | 命令/数据 | 1 = 数据是命令 |

### 1.2 扫描码集 1

#### Make/Break 代码

- **Make Code**: 按键时发送的单字节码
- **Break Code**: 释放时发送的 Make Code | 0x80

#### 常用扫描码

| 按键 | 扫描码 | 按键 | 扫描码 |
|------|--------|------|--------|
| Esc | 0x01 | Enter | 0x1C |
| Backspace | 0x0E | Tab | 0x0F |
| Space | 0x39 | 1-9 | 0x02-0x0A |
| A-Z | 0x1E-0x26 (ASDF行) | Q-P | 0x10-0x1C (QWERTY行) |
| LShift | 0x2A | RShift | 0x36 |
| LCtrl | 0x1D | LAlt | 0x38 |
| CapsLock | 0x3A | | |

### 1.3 键盘驱动 API

**头文件**: [`kernel/driver/keyboard/keyboard.h`](../../kernel/driver/keyboard/keyboard.h)

#### `keyboard_init()`

```c
int keyboard_init(void);
```

**描述**: 初始化 PS/2 键盘驱动

**初始化步骤**:
1. 注册 IRQ 1 处理程序
2. 启用键盘中断
3. 发送扫描命令

**返回**: 0 成功，负数失败

---

#### `keyboard_haschar()`

```c
bool keyboard_haschar(void);
```

**描述**: 检查是否有可用字符

**返回**: true 表示有数据

---

#### `keyboard_getchar()`

```c
char keyboard_getchar(void);
```

**描述**: 阻塞读取字符

**返回**: 读取的 ASCII 字符

---

#### `keyboard_try_getchar()`

```c
int keyboard_try_getchar(char* c);
```

**描述**: 非阻塞尝试读取

**参数**:
- `c`: 存储字符的指针

**返回**: 0 成功，-1 无数据

## 2. CMOS RTC 技术参考

### 2.1 硬件接口

#### I/O 端口

| 端口 | 名称 | 描述 |
|------|------|------|
| 0x70 | 地址寄存器 | 选择 CMOS 寄存器（bit 7 = NMI 禁用） |
| 0x71 | 数据寄存器 | 读/写选中寄存器的数据 |

#### 寄存器映射

| 索引 | 名称 | 描述 |
|------|------|------|
| 0x00 | RTC_SECONDS | 秒 (0-59, BCD) |
| 0x02 | RTC_MINUTES | 分 (0-59, BCD) |
| 0x04 | RTC_HOURS | 时 (模式相关, BCD) |
| 0x06 | RTC_DAY_OF_WEEK | 星期 (1-7) |
| 0x07 | RTC_DAY_OF_MONTH | 日 (1-31) |
| 0x08 | RTC_MONTH | 月 (1-12) |
| 0x09 | RTC_YEAR | 年 (0-99) |
| 0x0A | RTC_REG_A | 状态 A |
| 0x0B | RTC_REG_B | 状态 B |
| 0x0C | RTC_REG_C | 状态 C |
| 0x0D | RTC_REG_D | 状态 D |

### 2.2 寄存器 A (0x0A)

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | UIP | 更新进行中 |
| 6-4 | DV | 分频器控制 |
| 3-0 | RS | 速率选择器 |

#### RS 值与频率

| RS 值 | 频率 | 周期 |
|-------|------|------|
| 0x0 | 8192 Hz | 122 μs |
| 0x1 | 4096 Hz | 244 μs |
| 0x2 | 2048 Hz | 488 μs |
| 0x3 | 1024 Hz | 976 μs |
| 0x4 | 512 Hz | 1.95 ms |
| 0x5 | 256 Hz | 3.9 ms |
| 0x6 | 128 Hz | 7.8 ms |
| 0x7 | 64 Hz | 15.6 ms |
| 0x8 | 32 Hz | 31.3 ms |
| 0x9 | 16 Hz | 62.5 ms |
| 0xA | 8 Hz | 125 ms |
| 0xB | 4 Hz | 250 ms |
| 0xC | 2 Hz | 500 ms |
| 0xD | 1 Hz | 1 s |
| 0xE | 0.5 Hz | 2 s |
| 0xF | 0.25 Hz | 4 s |

### 2.3 寄存器 B (0x0B)

| 位 | 名称 | 描述 |
|----|------|------|
| 7 | SET | 设置模式 |
| 6 | PIE | 周期中断使能 |
| 5 | AIE | 闹钟中断使能 |
| 4 | UIE | 更新结束中断使能 |
| 3 | SQWE | 方波使能 |
| 2 | DM | 数据模式 (0=BCD, 1=二进制) |
| 1 | 24HR | 24 小时模式 |
| 0 | DSE | 夏令时使能 |

### 2.4 RTC 驱动 API

**头文件**: [`kernel/driver/rtc/rtc.h`](../../kernel/driver/rtc/rtc.h)

#### `rtc_init()`

```c
int rtc_init(void);
```

**描述**: 初始化 RTC 驱动

**初始化步骤**:
1. 检查电池状态
2. 检测数据模式 (BCD/二进制)
3. 设置 24 小时模式
4. 注册 IRQ 8 处理程序

**返回**: 0 成功，负数失败

---

#### `rtc_get_time()`

```c
int rtc_get_time(rtc_time_t* time);
```

**描述**: 读取当前时间

**参数**:
- `time`: 存储时间的结构体指针

**返回**: 0 成功，负数失败

---

#### `rtc_set_time()`

```c
int rtc_set_time(const rtc_time_t* time);
```

**描述**: 设置 RTC 时间

**返回**: 0 成功，负数失败

---

#### `rtc_enable_periodic()`

```c
int rtc_enable_periodic(uint8_t rate_div, rtc_periodic_callback_fn callback, void* context);
```

**描述**: 启用周期性中断

**参数**:
- `rate_div`: 速率除数 (RTC_RATE_* 宏)
- `callback`: 回调函数
- `context`: 上下文指针

**返回**: 0 成功，负数失败

---

#### `rtc_set_alarm()`

```c
int rtc_set_alarm(uint8_t hours, uint8_t minutes, uint8_t seconds,
                  rtc_alarm_callback_fn callback, void* context);
```

**描述**: 设置闹钟

**参数**:
- `hours`: 小时 (0-23 或 0xC0 忽略)
- `minutes`: 分钟 (0-59 或 0xC0 忽略)
- `seconds`: 秒 (0-59 或 0xC0 忽略)
- `callback`: 回调函数
- `context`: 上下文指针

**返回**: 0 成功，负数失败

## 3. PIT 定时器参考

### 3.1 硬件接口

#### I/O 端口

| 端口 | 名称 | 描述 |
|------|------|------|
| 0x40 | 通道 0 数据 | 系统定时器 |
| 0x41 | 通道 1 数据 | (未使用) |
| 0x42 | 通道 2 数据 | PC 扬声器 |
| 0x43 | 命令寄存器 | 控制寄存器 |

### 3.2 命令寄存器 (0x43)

```
┌─────────┬──────────┬─────────┬──────────────┐
│   SC    │   RW     │   Mode   │     BCD      │
│  (bits 6-7) │ (bits 4-5) │ (bits 1-3) │  (bit 0) │
└─────────┴──────────┴─────────┴──────────────┘
```

#### SC (通道选择)

| 值 | 通道 |
|----|------|
| 0x00 | 通道 0 |
| 0x40 | 通道 1 |
| 0x80 | 通道 2 |
| 0xC0 | 读回命令 |

#### RW (访问模式)

| 值 | 模式 |
|----|------|
| 0x00 | 锁存计数值 |
| 0x10 | 低字节 |
| 0x20 | 高字节 |
| 0x30 | 先低后高 |

#### Mode (操作模式)

| 值 | 模式 |
|----|------|
| 0x00 | 模式 0: 终止计数中断 |
| 0x02 | 模式 1: 硬件可重触发单稳 |
| 0x04 | 模式 2: 速率发生器 |
| 0x06 | 模式 3: 方波发生器 |
| 0x08 | 模式 4: 软件触发选通 |
| 0x0A | 模式 5: 硬件触发选通 |

### 3.3 频率计算

```
divisor = PIT_BASE_FREQUENCY / desired_frequency
         = 1193180 / desired_frequency

示例:
  - 1000 Hz: divisor = 1193180 / 1000 = 1193
  - 100 Hz:  divisor = 1193180 / 100 = 11931
```

## 4. UART 中断参考

### 4.1 硬件接口

#### COM1 端口

| 端口偏移 | 名称 | 描述 |
|----------|------|------|
| +0 | 数据寄存器 | 发送/接收数据 |
| +1 | 中断使能寄存器 | 控制中断源 |
| +2 | FIFO 控制 | FIFO 配置 |
| +3 | 线路控制 | 波特率等 |
| +4 | 调制解调控制 | 流控 |
| +5 | 线路状态 | 状态信息 |

### 4.2 中断使能寄存器 (IER, +1)

| 位 | 名称 | 描述 |
|----|------|------|
| 0 | RX_READY | 接收数据可用 |
| 1 | TX_EMPTY | 发送保持寄存器空 |
| 2 | RX_STATUS | 接收线状态 |
| 3 | MODEM | 调制解调状态 |

### 4.3 中断识别寄存器 (IIR, +2)

| 位 | 名称 | 描述 |
|----|------|------|
| 0 | PENDING | 0 = 有中断，1 = 无中断 |
| 1-3 | SOURCE | 中断源 |

#### 中断源代码

| 值 | 源 | 描述 |
|----|------|------|
| 0x06 | RX_STATUS | 接收线状态 |
| 0x04 | RX_READY | 接收数据可用 |
| 0x0C | RX_TIMEOUT | 字符超时 (FIFO) |
| 0x02 | TX_EMPTY | 发送保持寄存器空 |
| 0x00 | MODEM | 调制解调状态 |

### 4.4 线路状态寄存器 (LSR, +5)

| 位 | 名称 | 描述 |
|----|------|------|
| 0 | DATA_READY | 接收数据可用 |
| 1 | OVERRUN | 溢出错误 |
| 2 | PARITY | 奇偶错误 |
| 3 | FRAME | 帧错误 |
| 4 | BREAK | 中断检测 |
| 5 | THRE | 发送保持寄存器空 |
| 6 | TEMT | 发送器空 |
| 7 | FIFO_ERROR | FIFO 中的错误 |

## 5. Shell API 参考

### 5.1 后端接口

```c
typedef struct shell_backend {
    const char* name;
    void (*puts)(const char* str);
    void (*putc)(char c);
    bool (*haschar)(void);
    char (*getchar)(void);
    void (*clear)(void);
} shell_backend_t;
```

### 5.2 Shell 核心 API

**头文件**: [`kernel/shell/shell.h`](../../kernel/shell/shell.h)

#### `shell_run()`

```c
int shell_run(const shell_backend_t* backend);
```

**描述**: 运行 Shell 主循环

**参数**:
- `backend`: 后端接口指针

**返回**: 0 正常退出

---

#### `shell_create()`

```c
shell_context_t* shell_create(const shell_backend_t* backend);
```

**描述**: 创建 Shell 上下文

**参数**:
- `backend`: 后端接口指针

**返回**: Shell 上下文指针

---

#### `shell_step()`

```c
bool shell_step(shell_context_t* ctx);
```

**描述**: 处理一次 Shell 迭代

**参数**:
- `ctx`: Shell 上下文

**返回**: true 继续运行，false 退出

---

#### `shell_register_command()`

```c
int shell_register_command(const char* name, const char* description,
                           int (*handler)(int argc, char* argv[]));
```

**描述**: 注册自定义命令

**参数**:
- `name`: 命令名
- `description`: 帮助描述
- `handler`: 处理函数

**返回**: 0 成功，-1 失败

---

### 5.3 命令处理函数签名

```c
int cmd_handler(int argc, char* argv[]);
```

**返回**: 0 正常，1 退出 Shell

## 6. 数据结构

### 6.1 rtc_time_t

```c
typedef struct {
    uint8_t seconds;      // 0-59
    uint8_t minutes;      // 0-59
    uint8_t hours;        // 0-23
    uint8_t day_of_week;  // 1-7 (1=Sunday)
    uint8_t day_of_month; // 1-31
    uint8_t month;        // 1-12
    uint16_t year;        // 完整年份 (如 2024)
} rtc_time_t;
```

### 6.2 shell_context_t

```c
typedef struct {
    const shell_backend_t* backend;
    char cmd_buffer[128];
    int cmd_pos;
    char prompt[32];
    bool running;
} shell_context_t;
```

### 6.3 vga_soft_cursor_t

```c
typedef struct {
    bool enabled;
    bool visible;
    vga_sz_t x, y;
    vga_color_t fg_color, bg_color;
    uint16_t saved_char;
    bool has_saved_char;
} vga_soft_cursor_t;
```
