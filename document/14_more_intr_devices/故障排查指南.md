## 1. 键盘输入问题

### 1.1 键盘无响应

#### 症状

按键后没有任何字符输出。

#### 原因分析

1. IRQ 1 被屏蔽
2. 键盘处理程序未注册
3. PS/2 端口未正确初始化
4. 扫描命令未发送

#### 诊断步骤

```c
// 1. 检查 IRQ 1 是否启用
uint8_t mask1 = inb(PIC1_DATA);
if (mask1 & 0x02) {
    klog_error("IRQ 1 (keyboard) is MASKED\n");
}

// 2. 检查键盘状态端口
uint8_t status = inb(KEYBOARD_STATUS_PORT);
if (!(status & KBD_STATUS_OUTPUT_FULL)) {
    klog_debug("No keyboard data available\n");
}

// 3. 检查初始化状态
if (!kb_initialized) {
    klog_error("Keyboard not initialized\n");
}
```

#### 解决方案

```c
// 确保按正确顺序初始化
void init_keyboard_subsystem(void) {
    // 1. 先注册 IRQ 处理程序
    int result = irq_register_handler(KEYBOARD_IRQ, &keyboard_irq_desc);
    if (result != 0) {
        klog_error("Failed to register keyboard IRQ: %d\n", result);
    }

    // 2. 启用键盘扫描
    outb(KEYBOARD_DATA_PORT, KBD_CMD_ENABLE);

    // 3. 启用 IRQ 1
    pic_enable_irq(KEYBOARD_IRQ);
}
```

### 1.2 字符输出错误

#### 症状

输入的字符与显示不符。

#### 原因

1. 扫描码表错误
2. Shift/Caps Lock 状态不正确
3. BCD 转换问题

#### 解决方案

```c
// 调试：打印扫描码
void debug_scancode(uint8_t scancode) {
    klog_debug("Scancode: 0x%02X, Break: %d, ASCII: %c\n",
               scancode, !!(scancode & 0x80),
               scancode_to_ascii(scancode));
}
```

### 1.3 缓冲区溢出

#### 症状

快速打字时丢失字符。

#### 原因

环形缓冲区太小或处理太慢。

#### 解决方案

1. 增大缓冲区：
```c
#define KEYBOARD_BUFFER_SIZE 512  // 原来是 256
```

2. 添加溢出检测：
```c
if (ring_kb_is_full(&kb_buffer)) {
    klog_warn("Keyboard buffer overflow!\n");
}
```

## 2. RTC 时间问题

### 2.1 时间读取异常

#### 症状

读取的时间明显错误（如小时 > 23）。

#### 原因

1. 在更新期间读取
2. BCD 转换错误
3. 数据模式判断错误

#### 解决方案

```c
// 等待更新完成
while (rtc_is_updating()) {
    __asm__ volatile("pause");
}

// 检查数据模式
uint8_t reg_b = cmos_read(RTC_REG_B);
bool binary_mode = (reg_b & RTC_REG_B_DM) != 0;

// 根据模式转换
uint8_t value = cmos_read(reg);
if (!binary_mode) {
    value = bcd_to_binary(value);
}
```

### 2.2 RTC 中断不触发

#### 症状

注册周期中断后没有回调。

#### 原因分析

1. IRQ 8 被屏蔽
2. 周期中断未启用
3. 未读取寄存器 C 清除标志

#### 诊断步骤

```c
// 检查 IRQ 8
uint8_t mask2 = inb(PIC2_DATA);
if (mask2 & 0x01) {
    klog_error("IRQ 8 (RTC) is MASKED\n");
}

// 检查寄存器 B
uint8_t reg_b = cmos_read(RTC_REG_B);
if (!(reg_b & RTC_REG_B_PIE)) {
    klog_error("Periodic interrupt not enabled\n");
}
```

#### 解决方案

```c
int rtc_enable_periodic(uint8_t rate_div, callback_fn cb, void* ctx) {
    pic_disable_irq(8);  // 配置时先禁用

    // 设置频率
    uint8_t reg_a = cmos_read(RTC_REG_A);
    reg_a = (reg_a & ~RTC_REG_A_RS_MASK) | rate_div;
    cmos_write(RTC_REG_A, reg_a);

    // 启用周期中断
    uint8_t reg_b = cmos_read(RTC_REG_B);
    reg_b |= RTC_REG_B_PIE;
    cmos_write(RTC_REG_B, reg_b);

    // 清除待处理中断（重要！）
    cmos_read(RTC_REG_C);

    pic_enable_irq(8);  // 重新启用
    return 0;
}
```

## 3. 定时器问题

### 3.1 定时器频率错误

#### 症状

实际频率与设置不符。

#### 原因

除数计算错误或写入顺序错误。

#### 解决方案

```c
static void pit_set_frequency(uint32_t frequency) {
    uint32_t divisor = PIT_BASE_FREQUENCY / frequency;

    // 发送控制字
    outb(PIT_CMD_PORT, PIT_CHANNEL_0 | PIT_MODE_3 | PIT_ACCESS_WORD);

    // 先低字节后高字节
    outb(PIT_CHANNEL_0_DATA, divisor & 0xFF);
    outb(PIT_CHANNEL_0_DATA, (divisor >> 8) & 0xFF);
}
```

### 3.2 timer_mdelay 不准确

#### 症状

延时明显偏长或偏短。

#### 原因

定时器频率变化但未更新计算。

#### 解决方案

```c
void timer_mdelay(uint32_t milliseconds) {
    uint64_t start = timer_ticks;
    // 使用当前频率计算
    uint64_t target_ticks = start + (milliseconds * timer_frequency) / 1000;

    while (timer_ticks < target_ticks) {
        __asm__ volatile("pause");
    }
}
```

## 4. 串口中断问题

### 4.1 串口无输出

#### 症状

调用 async_serial_puts 后没有输出。

#### 原因分析

1. TX 中断未启用
2. FIFO 未初始化
3. THR 不为空

#### 诊断步骤

```c
void debug_uart_status(void) {
    const uint16_t base = SERIAL_COM1_BASE;
    uint8_t ier = inb(SERIAL_INT_ENABLE_REG(base));
    uint8_t lsr = inb(SERIAL_LINE_STATUS_REG(base));
    uint8_t iir = inb(SERIAL_INT_ID_REG(base));

    klog_debug("UART: IER=0x%02X LSR=0x%02X IIR=0x%02X\n", ier, lsr, iir);
}
```

#### 解决方案

```c
int uart_init_intr_mode(void) {
    const uint16_t base = SERIAL_COM1_BASE;

    // 1. 使能 FIFO (0xC7)
    outb(SERIAL_FIFO_CTRL_REG(base), 0xC7);

    // 2. 注册 IRQ
    irq_register_handler(UART_COM1_IRQ, &uart_irq_desc);

    // 3. 启用中断
    outb(SERIAL_INT_ENABLE_REG(base),
         SERIAL_IER_RX_READY | SERIAL_IER_RX_STATUS);

    pic_enable_irq(UART_COM1_IRQ);
    return 0;
}
```

### 4.2 TX 中断风暴

#### 症状

串口疯狂触发中断，系统无响应。

#### 原因

TX 空中断一直启用。

#### 解决方案

```c
case SERIAL_IIR_TX_EMPTY:
    if (!ring_tx_is_empty(&tx_buffer)) {
        char c = ring_tx_read(&tx_buffer);
        outb(SERIAL_DATA_REG(base), (uint8_t)c);
    } else {
        // 缓冲区空，禁用 TX 中断！
        uint8_t ier = inb(SERIAL_INT_ENABLE_REG(base));
        outb(SERIAL_INT_ENABLE_REG(base), ier & ~SERIAL_IER_TX_EMPTY);
    }
    break;
```

### 4.3 FIFO 丢失数据

#### 症状

快速输入时丢失字符。

#### 原因

FIFO 触发阈值设置不当。

#### 解决方案

```c
// 0xC7 = 使能 FIFO + 清空两个 FIFO + 14 字节阈值
// 如果需要更低延迟，可以用 0x87 (1 字节阈值)
outb(SERIAL_FIFO_CTRL_REG(base), 0xC7);
```

## 5. Shell 显示问题

### 5.1 字符回显错误

#### 症状

输入字符后显示不正确。

#### 原因

1. 回显未启用
2. 光标位置错误
3. 滚动处理错误

#### 解决方案

```c
// 确保 backspace 正确处理
case '\b':
case 127:
    if (cmd_pos > 0) {
        cmd_pos--;
```

### 5.2 命令不执行

#### 症状

输入命令后按回车没有反应。

#### 原因

1. 命令解析错误
2. 回车处理错误
3. 命令未注册

#### 诊断

```c
static void debug_execute_command(shell_context_t* ctx) {
    ctx->cmd_buffer[ctx->cmd_pos] = '\0';

    klog_debug("Command: '%s'\n", ctx->cmd_buffer);

    char* argv[SHELL_MAX_ARGS];
    int argc = parse_command(ctx->cmd_buffer, argv);

    klog_debug("Argc: %d\n", argc);
    for (int i = 0; i < argc; i++) {
        klog_debug("  Arg[%d]: '%s'\n", i, argv[i]);
```

## 6. 系统稳定性问题

### 6.1 中断嵌套问题

#### 症状

系统间歇性崩溃。

#### 原因

中断处理程序耗时过长。

#### 解决方案

```c
// 快速处理
void fast_handler(interrupt_frame_t* frame, void* context) {
    // 仅设置标志
    g_pending_work = true;
    pic_send_eoi(irq);
}

// 主循环中处理
void kernel_main(void) {
    while (1) {
        if (g_pending_work) {
            g_pending_work = false;
            process_work();  // 耗时处理
        }
        __asm__ volatile("hlt");
    }
}
```

### 6.2 竞态条件

#### 症状

环形缓冲区数据损坏。

#### 原因

中断和主代码同时访问缓冲区。

#### 解决方案

```c
char safe_read_char(void) {
    // 禁用中断保护临界区
    uint64_t rflags;
    __asm__ volatile("pushfq; popq %0" : "=r"(rflags));
    __asm__ volatile("cli");

    char c = ring_read(&buffer);

    // 恢复中断状态
    if (rflags & 0x200) {
        __asm__ volatile("sti");
    }

    return c;
}
```

```c
typedef struct {
    uint32_t head;
    uint32_t tail;
    uint32_t count;

buffer_stats_t get_buffer_stats(ring_buffer_t* rb) {
    buffer_stats_t stats;
    stats.head = rb->head;
    stats.tail = rb->tail;
```

## 8. 最佳实践

### 8.1 初始化顺序

```c
void kernel_init(void) {
    // 1. 先初始化中断系统
    interrupt_init();

    // 2. 再初始化设备驱动
    timer_init(1000);
    keyboard_init();
    rtc_init();
    uart_init_intr_mode();

    // 3. 最后启用设备功能
    rtc_enable_periodic(RTC_RATE_8Hz, my_callback, NULL);

    // 4. 进入主循环
    kernel_main();
}
```

### 8.2 错误处理

```c
// 始终检查返回值
int result = keyboard_init();
if (result != 0) {
    klog_error("Keyboard init failed: %d\n", result);
    // 继续运行，降级到无键盘模式
}
```
