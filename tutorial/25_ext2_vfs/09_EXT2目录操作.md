# EXT2 目录操作 —— 找到你的文件

有了 inode 操作的基础，现在我们可以实现目录操作了。目录本质上是一种特殊的文件，它的数据是目录项列表。每个目录项记录一个文件名和对应的 inode 号。

目录操作的核心是查找（lookup）和遍历（readdir）。查找用于在目录中根据名字找到文件，遍历用于列出目录中的所有文件。

## EXT2 目录项结构

EXT2 目录项的结构如下：

```c
typedef struct PACKED ext2_dir_entry {
    uint32_t inode;                /* inode 号 */
    uint16_t rec_len;              /* 记录长度 */
    uint16_t name_len;             /* 文件名长度 */
    uint8_t  file_type;            /* 文件类型（可选） */
    char     name[];               /* 文件名（变长） */
} ext2_dir_entry_t;
```

这是一个变长结构，文件名直接跟在固定字段后面。`rec_len` 指向下一个目录项的偏移，这样即使当前目录项没有用完所有空间，下一个目录项也能正确找到。

目录项在目录数据中紧密排列，中间没有空隙：

```
┌────────────────────────────────────────────────────────┐
│ inode │ rec_len │ name_len │ file_type │ name         │
├────────────────────────────────────────────────────────┤
│ 12    │ 12      │ 1        │ 2         │ .            │  当前目录
├────────────────────────────────────────────────────────┤
│ 12    │ 12      │ 2        │ 2         │ ..           │  父目录
├────────────────────────────────────────────────────────┤
│ 1234  │ 16      │ 3        │ 1         │ foo          │  文件
├────────────────────────────────────────────────────────┤
│ 5678  │ 20      │ 7        │ 1         │ README.md    │  文件
└────────────────────────────────────────────────────────┘
```

注意每个目录都包含 `.` 和 `..` 两个特殊项，分别指向当前目录和父目录。

## 在目录中查找文件

`ext2_lookup()` 函数在目录中查找指定名字的文件：

```c
int ext2_lookup(vfs_inode_t* dir, const char* name, vfs_inode_t** result) {
    ext2_fs_info_t* fs_info = dir->i_sb->s_fs_info;
    uint32_t block_size = fs_info->block_size;

    /* 分配缓冲区读取目录数据 */
    uint8_t* dir_buffer = kmalloc(block_size);

    /* 遍历目录的所有数据块 */
    for (uint32_t i = 0; i < (dir->i_size + block_size - 1) / block_size; i++) {
        /* 获取目录数据块 */
        uint64_t block_num;
        if (ext2_get_block(dir, i * block_size, &block_num) != 0 || block_num == 0) {
            continue;
        }

        /* 读取块 */
        block_read_sync(fs_info->device, block_num * (block_size / 512),
                        dir_buffer, block_size / 512);

        /* 遍历块中的目录项 */
        uint32_t offset = 0;
        while (offset < block_size) {
            ext2_dir_entry_t* entry = (ext2_dir_entry_t*)(dir_buffer + offset);

            /* 检查是否匹配 */
            if (entry->inode != 0 &&
                entry->name_len == strlen(name) &&
                strncmp(entry->name, name, entry->name_len) == 0) {
                /* 找到了！获取 inode */
                vfs_inode_t* inode = vfs_iget(dir->i_sb, entry->inode);
                if (inode) {
                    *result = inode;
                    kfree(dir_buffer);
                    return 0;
                }
            }

            /* 移动到下一个目录项 */
            offset += entry->rec_len;
        }
    }

    kfree(dir_buffer);
    return -1;  /* 未找到 */
}
```

这个函数遍历目录的所有数据块，在每个块中遍历所有目录项，查找名字匹配的项。找到后获取对应的 inode 并返回。

## 遍历目录内容

`ext2_readdir()` 函数用于列出目录中的所有文件：

```c
int ext2_readdir(struct file* file, void* dirent, filldir_t filldir) {
    vfs_inode_t* dir = file->f_inode;
    ext2_fs_info_t* fs_info = dir->i_sb->s_fs_info;
    uint32_t block_size = fs_info->block_size;

    uint8_t* dir_buffer = kmalloc(block_size);

    /* 获取当前读取位置 */
    uint64_t offset = file->f_pos;

    /* 遍历目录块 */
    for (uint32_t i = offset / block_size; i < (dir->i_size + block_size - 1) / block_size; i++) {
        /* 获取块 */
        uint64_t block_num;
        if (ext2_get_block(dir, i * block_size, &block_num) != 0 || block_num == 0) {
            continue;
        }

        block_read_sync(fs_info->device, block_num * (block_size / 512),
                        dir_buffer, block_size / 512);

        /* 遍历目录项 */
        uint32_t block_offset = (i == offset / block_size) ? offset % block_size : 0;

        while (block_offset < block_size) {
            ext2_dir_entry_t* entry = (ext2_dir_entry_t*)(dir_buffer + block_offset);

            /* 跳过已删除的项 */
            if (entry->inode != 0 && entry->name_len > 0) {
                /* 调用填充函数 */
                if (filldir(dirent, entry->name, entry->name_len,
                           file->f_pos, entry->inode, entry->file_type)) {
                    break;  /* 缓冲区满 */
                }
            }

            /* 更新文件位置 */
            file->f_pos += entry->rec_len;
            block_offset += entry->rec_len;
        }
    }

    kfree(dir_buffer);
    return 0;
}
```

这个函数使用 `filldir` 回调函数来处理每个目录项。这种设计让 VFS 可以控制如何处理目录项，比如把它复制到用户缓冲区或者进行其他操作。

## 目录项的文件类型

EXT2 目录项的 `file_type` 字段记录文件类型，避免额外的 inode 查询：

```c
#define EXT2_FT_UNKNOWN   0
#define EXT2_FT_REG_FILE  1
#define EXT2_FT_DIR       2
#define EXT2_FT_CHRDEV    3
#define EXT2_FT_BLKDEV    4
#define EXT2_FT_FIFO      5
#define EXT2_FT_SOCK      6
#define EXT2_FT_SYMLINK   7
```

这个字段是可选的，取决于文件系统的特性标志。如果文件系统没有设置 `EXT2_FEATURE_INCOMPAT_FILETYPE`，这个字段不可用，需要通过 inode 来判断类型。

## 目录操作表

目录的操作通过函数指针表注册：

```c
/* 目录 inode 操作 */
const inode_operations_t ext2_dir_inode_ops = {
    .lookup = ext2_lookup,
    .create = ext2_create,
    .mkdir = ext2_mkdir,
    /* ... */
};

/* 目录文件操作 */
const file_operations_t ext2_dir_ops = {
    .llseek = NULL,
    .read = NULL,  /* 目录不能读 */
    .readdir = ext2_readdir,
    /* ... */
};
```

注意目录没有 `read` 操作，读取目录内容必须通过 `readdir`。这是因为目录的数据结构是特殊的，不应该作为普通数据读取。

## 小结

目录操作是文件系统查找文件的基础。通过遍历目录项，我们可以根据文件名找到对应的 inode。目录项缓存加速了这个过程，避免每次都访问磁盘。

`lookup` 和 `readdir` 是最基本的目录操作。`lookup` 用于路径解析，`readdir` 用于列出目录内容。两者结合，实现了文件系统的查找和遍历功能。
