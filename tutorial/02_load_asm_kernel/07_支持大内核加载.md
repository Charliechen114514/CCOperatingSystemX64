# 支持大内核加载

## 前言：20 字节玩够了

如果你跟着前面的教程做，现在应该有一个能工作的 20 字节内核。但说实话，这没什么用——一个真正的内核起码要几 KB，甚至几十 KB。你想写点实际功能，比如字符串输出、内存管理、中断处理，这些都需要不少代码。

当前的问题是我们的 `load_kernel` 函数只读取 1 个扇区（512 字节）。如果内核超过 512 字节，会被截断，后面的代码根本加载不到内存里。这显然不够。

今天我们要解决几个问题：实现 LBA Extended Read 来支持多扇区读取，自动计算内核大小并动态读取，添加 LBA/CHS 自动降级确保兼容性，添加串口输出方便调试，实现自动化配置生成让编译更省心。

---

## LBA Extended Read：突破 512 字节限制

LBA Extended Read（INT 13h, AH=42h）是 BIOS 扩展磁盘读取功能，支持最多 127 个扇区的单次读取。相比古老的 CHS 方式，LBA 用连续的扇区号访问磁盘，不需要关心柱面、磁头这些物理细节，而且支持大容量磁盘。

这个功能使用 DAP（Disk Address Packet）结构来传递参数。DAP 是一个 16 字节的数据结构，包含了读取操作的所有信息：数据包大小、块数、目标缓冲区地址、起始 LBA。看起来大概是这样：

```nasm
; 读取从 LBA 3 开始的 127 个扇区到 0x10000

mov si, dap              ; DS:SI 指向 DAP
mov ah, 0x42             ; 扩展读取功能
mov dl, 0x80             ; 第一个硬盘
int 0x13                 ; 调用 BIOS

; DAP 内容：
dap:
    db 16                ; size = 16
    db 0                 ; reserved = 0
    dw 127               ; block_count = 127
    dw 0x0000            ; offset = 0
    dw 0x1000            ; segment = 0x1000 (地址 = 0x10000)
    dq 3                 ; lba = 3
```

这里有个细节：目标地址是用 segment:offset 表示的。segment 0x1000 和 offset 0x0000 组合起来就是线性地址 0x10000（segment × 16 + offset）。这是 16 位实模式下的地址计算方式。

## 添加配置文件

为了让 bootloader 知道内核的大小和位置，我们添加一个配置文件。这个文件会在编译时自动生成，包含内核的实际大小。

```nasm
; ==============================================================================
; CCOS Bootloader Configuration
; ==============================================================================
; This file is AUTO-GENERATED during build
; ==============================================================================

; 内核磁盘位置（LBA）
%define KERNEL_LBA_START          3
%define KERNEL_SECTOR_COUNT       1    ; 默认值，会被覆盖

; 内存布局
%define KERNEL_LOAD_SEGMENT       0x1000
%define KERNEL_LOAD_OFFSET        0x0000

; Bootloader 大小信息
%define BOOTLOADER_SECTORS        3

; 最大内核大小（64MB）
%define KERNEL_MAX_SECTORS        131072

; CHS 几何（用于 CHS 降级）
%define SECTORS_PER_TRACK         63
%define HEADS                     16
```

这些 `%define` 是 NASM 的宏定义，可以在代码中像常量一样使用。`KERNEL_LBA_START` 是内核在磁盘上的起始扇区，`KERNEL_SECTOR_COUNT` 是内核占用的扇区数。这些值会在编译时根据实际文件大小计算出来。

## 实现多扇区读取

首先我们来实现单次 LBA 读取函数，它最多读取 127 个扇区：

```nasm
; ============================================================================
; read_sectors_lba - 使用 LBA 扩展读取
; 输入：EAX = 起始 LBA
;      CX  = 要读取的扇区数
;      ES:BX = 目标缓冲区
; 输出：CF=0 成功，CF=1 失败
; ============================================================================
bits 16
read_sectors_lba:
    pusha

    ; 验证扇区数（最多 127）
    cmp cx, 0
    je .error
    cmp cx, 127
    jbe .count_ok
    mov cx, 127             ; 最多读 127 个扇区
.count_ok:

    ; 设置 DS 指向我们的代码段
    push ax
    mov ax, cs
    mov ds, ax
    pop ax

    ; 填充 DAP
    mov byte [dap + 2], cl      ; block count (低字节)
    mov byte [dap + 3], 0       ; block count (高字节)

    mov [dap + 4], bx           ; offset
    mov word [dap + 6], es      ; segment

    mov dword [dap + 8], eax    ; LBA (低 32 位)
    mov dword [dap + 12], 0     ; LBA (高 32 位) = 0

    ; 执行 LBA 读取
    mov si, dap
    mov dl, 0x80
    mov ah, 0x42
    int 0x13

    ; 恢复 DS
    push ax
    xor ax, ax
    mov ds, ax
    pop ax

    jc .error

    popa
    clc
    ret

.error:
    ; 恢复 DS
    push ax
    xor ax, ax
    mov ds, ax
    pop ax
    popa
    stc
    ret
```

这个函数首先检查扇区数是否合法（1-127），然后填充 DAP 结构，最后调用 BIOS 扩展读取。`pusha` 和 `popa` 保存和恢复所有通用寄存器，这是汇编函数的标准做法。

但一个函数还不够。如果内核很大（超过 127 扇区），我们需要循环读取。这就是 `load_kernel_lba` 函数的作用：

```nasm
; ============================================================================
; load_kernel_lba - 使用 LBA 加载内核（支持多扇区）
; 输入：使用 KERNEL_LBA_START 和 KERNEL_SECTOR_COUNT
; 输出：CF=0 成功，CF=1 失败
; ============================================================================
bits 16
load_kernel_lba:
    pusha

    ; 设置目标地址
    mov ax, KERNEL_LOAD_SEGMENT
    mov es, ax
    mov bx, KERNEL_LOAD_OFFSET

    ; 初始化跟踪变量
    mov di, KERNEL_SECTOR_COUNT     ; DI = 剩余扇区数
    mov si, KERNEL_LBA_START        ; SI = 当前 LBA

.read_loop:
    ; 检查是否读完
    cmp di, 0
    je .read_complete

    ; 计算本次读取的扇区数（最多 127）
    mov cx, di
    cmp cx, 127
    jbe .sectors_ok
    mov cx, 127
.sectors_ok:

    ; 保存扇区数
    mov bp, cx

    ; 调用 LBA 读取
    mov ax, si
    call read_sectors_lba
    jc .read_error

    ; 更新跟踪变量
    sub di, bp              ; 减少剩余扇区数
    add si, bp              ; 前进 LBA

    ; 前进缓冲区指针（ES:BX += BP * 512）
    push ax
    push dx
    mov ax, bp
    xor dx, dx
    mov cx, 512
    mul cx                  ; DX:AX = 读取的字节数
    add bx, ax              ; 前进 BX
    pop dx
    pop ax

    jmp .read_loop

.read_complete:
    popa
    clc
    ret

.read_error:
    popa
    stc
    ret
```

这个函数用循环来处理大内核。每次循环最多读取 127 个扇区，然后更新剩余扇区数、当前 LBA 和缓冲区指针。当所有扇区都读完时，返回成功。

## 添加 CHS 降级

不是所有 BIOS 都支持 LBA Extended Read。为了兼容性，我们需要 CHS 降级方案。CHS（Cylinder-Head-Sector）是古老的磁盘寻址方式，虽然限制多，但几乎所有 BIOS 都支持。

首先我们需要 LBA 到 CHS 的转换函数：

```nasm
; ============================================================================
; lba_to_chs - 将 LBA 转换为 CHS 地址
; 输入：AX = LBA 地址（0-based）
; 输出：CH = 柱面，CL = 扇区（1-based，bits 0-5），DH = 磁头
; ============================================================================
bits 16
lba_to_chs:
    push bx

    ; 保存 LBA
    mov bx, ax

    ; 计算 LBA / SECTORS_PER_TRACK
    xor dx, dx
    mov ax, bx
    mov cx, SECTORS_PER_TRACK
    div cx                  ; AX = LBA / SPT, DX = LBA % SPT

    ; 保存余数（扇区索引 0-based）
    push dx

    ; 计算 柱面 = (LBA / SPT) / HEADS
    xor dx, dx
    mov cx, HEADS
    div cx                  ; AX = 柱面, DX = 磁头

    mov ch, al              ; CH = 柱面（低 8 位）
    mov dh, dl              ; DH = 磁头

    ; 计算 扇区 = (LBA % SPT) + 1
    pop dx                  ; 恢复扇区索引
    mov cl, dl              ; CL = 扇区（0-based）
    add cl, 1               ; 转换为 1-based

    pop bx
    ret
```

这个函数的数学原理是这样的。首先 LBA / SECTORS_PER_TRACK 得到"完整磁道数"和"磁道内偏移"。然后"完整磁道数" / HEADS 得到柱面号和磁头号。最后"磁道内偏移" + 1 得到扇区号（因为 CHS 扇区号是 1-based 的）。

然后是 CHS 读取函数：

```nasm
; ============================================================================
; load_kernel_chs - 使用 CHS 加载内核（支持多扇区）
; 输入：使用 KERNEL_LBA_START 和 KERNEL_SECTOR_COUNT
; 输出：CF=0 成功，CF=1 失败
; ============================================================================
bits 16
load_kernel_chs:
    pusha

    ; 设置目标地址
    mov ax, KERNEL_LOAD_SEGMENT
    mov es, ax
    mov bx, KERNEL_LOAD_OFFSET

    ; 初始化跟踪变量
    mov di, KERNEL_SECTOR_COUNT
    mov si, KERNEL_LBA_START

.read_loop:
    ; 检查是否读完
    cmp di, 0
    je .read_complete

    ; 计算本次读取的扇区数
    mov cx, di
    cmp cx, 127
    jbe .sectors_ok
    mov cx, 127
.sectors_ok:

    ; 保存扇区数
    mov bp, cx

    ; 转换 LBA 到 CHS
    mov ax, si
    call lba_to_chs         ; CH=柱面, DH=磁头, CL=扇区(1-based)

    ; 执行 CHS 读取
    mov ah, 0x02
    mov al, bl              ; BL = 扇区数（从 CX 复制的）
    mov dl, 0x80
    int 0x13
    jc .read_error

    ; 验证扇区数
    cmp al, bl
    jne .read_mismatch

    ; 更新跟踪变量
    sub di, bp
    add si, bp

    ; 前进缓冲区
    push ax
    push dx
    mov ax, bp
    xor dx, dx
    mov cx, 512
    mul cx
    add bx, ax
    pop dx
    pop ax

    jmp .read_loop

.read_complete:
    popa
    clc
    ret

.read_error:
.read_mismatch:
    popa
    stc
    ret
```

CHS 读取的逻辑和 LBA 类似，也是循环读取，每次最多 127 个扇区。区别在于需要先调用 `lba_to_chs` 转换地址，然后用传统的 `int 0x13, ah=0x02` 读取。

## 自动选择 LBA/CHS

现在我们有了两种读取方式，接下来是自动选择逻辑：

```nasm
; ============================================================================
; load_kernel_auto - 自动选择 LBA/CHS 加载内核
; 输出：CF=0 成功，CF=1 失败
; ============================================================================
bits 16
load_kernel_auto:
    pusha

    ; 先尝试 LBA
    call check_lba_support
    jc .try_chs

    ; LBA 可用
    call load_kernel_lba
    jnc .success

    ; LBA 失败，回退到 CHS
.try_chs:
    call load_kernel_chs
    jc .error

.success:
    popa
    clc
    ret

.error:
    popa
    stc
    ret
```

这个函数首先检查 LBA 是否可用。如果可用，就用 LBA 读取。如果 LBA 读取失败，或者 BIOS 不支持 LBA，就回退到 CHS。这样既能在现代硬件上发挥 LBA 的优势，又能保证在老硬件上正常工作。

## 添加串口调试输出

VGA 输出虽然直观，但有时候不够方便。串口输出可以重定向到文件，或者通过网络传输，调试时非常实用。我们来添加串口支持。

首先是串口初始化：

```nasm
; ============================================================================
; Serial Port Constants
; ============================================================================
SERIAL_PORT    equ 0x3F8
SERIAL_THR     equ 0x03F8
SERIAL_LCR     equ 0x03FB
SERIAL_DLAB    equ 0x80
LCR_8BIT       equ 0x03

; ============================================================================
; serial_init - 初始化串口
; ============================================================================
bits 16
serial_init:
    push dx

    ; 设置波特率（115200）
    mov dx, SERIAL_LCR
    mov al, SERIAL_DLAB | LCR_8BIT
    out dx, al

    mov dx, 0x3F8
    mov al, 0x01
    out dx, al

    mov dx, 0x3F9
    mov al, 0x00
    out dx, al

    ; 设置 8N1
    mov dx, SERIAL_LCR
    mov al, LCR_8BIT
    out dx, al

    pop dx
    ret
```

串口初始化涉及几个寄存器。LCR（Line Control Register）控制串口参数，DLAB 位允许访问除数寄存器来设置波特率。我们设置 115200 波特率、8 位数据位、无校验、1 停止位（8N1），这是最常用的配置。

然后是写一个字符到串口：

```nasm
; ============================================================================
; serial_write_char - 写一个字符到串口
; ============================================================================
bits 16
serial_write_char:
    push dx
    push ax
.write_loop:
    mov dx, 0x3FD
    in al, dx
    test al, 0x20
    jz .write_loop
    pop ax
    mov dx, SERIAL_THR
    out dx, al
    pop dx
    ret
```

这个函数首先等待串口准备好（LSR 的 bit 5 为 1 表示发送缓冲区空），然后把字符写到 THR（Transmit Holding Register）。

打印数字也很有用：

```nasm
; ============================================================================
; print_decimal - 打印 AX 为十进制
; ============================================================================
bits 16
print_decimal:
    push bx
    push cx
    push dx

    mov bx, 10
    xor cx, cx
.div_loop:
    xor dx, dx
    div bx
    push dx
    inc cx
    test ax, ax
    jnz .div_loop
.print_loop:
    pop ax
    add al, '0'
    call serial_write_char
    loop .print_loop

    pop dx
    pop cx
    pop bx
    ret
```

这个函数用反复除以 10 的方式把数字转换为十进制字符串，然后逐个字符打印。先把余数压栈（从低位到高位），然后依次弹出并打印（从高位到低位）。

## 更新 Stage 2 主函数

现在我们在 Stage 2 主函数中使用新的加载函数：

```nasm
stage2_main:
    cli
    xor ax, ax
    mov ds, ax
    mov es, ax
    mov ss, ax
    mov sp, 0x7E00

    ; 初始化串口
    call serial_init

    ; 打印消息
    mov si, msg_stage2
    call print_string
    mov si, msg_stage2
    call serial_write_string

    ; 加载内核
    call load_kernel_auto
    jc load_error

    ; 打印成功消息
    mov si, msg_ok
    call print_string
    mov si, msg_ok
    call serial_write_string

    ; ... 继续后续流程 ...
```

我们同时输出到 VGA 和串口，这样无论用什么方式调试都能看到输出。`serial_write_string` 和 `print_string` 类似，只是输出到串口而不是 VGA。

## 自动化配置生成

手动更新 `boot_config.inc` 很麻烦，而且容易出错。我们来写个脚本自动生成：

```bash
#!/bin/bash
# gen_boot_config.sh

KERNEL_BIN="build/kernel.bin"
BOOTLOADER_BIN="build/bootloader.bin"
OUTPUT_FILE="boot/boot_config.inc"

# 计算内核扇区数
KERNEL_SIZE=$(stat -c%s "$KERNEL_BIN" 2>/dev/null || echo 0)
KERNEL_SECTORS=$(( (KERNEL_SIZE + 511) / 512 ))

# 计算 bootloader 扇区数
BOOTLOADER_SIZE=$(stat -c%s "$BOOTLOADER_BIN" 2>/dev/null || echo 0)
BOOTLOADER_SECTORS=$(( (BOOTLOADER_SIZE + 511) / 512 ))

# 生成配置文件
cat > "$OUTPUT_FILE" << EOF
; CCOS Bootloader Configuration
; AUTO-GENERATED - DO NOT EDIT

; 内核位置
%define KERNEL_LBA_START          $BOOTLOADER_SECTORS
%define KERNEL_SECTOR_COUNT       $KERNEL_SECTORS

; 内存布局
%define KERNEL_LOAD_SEGMENT       0x1000
%define KERNEL_LOAD_OFFSET        0x0000

; Bootloader 大小
%define BOOTLOADER_SECTORS        $BOOTLOADER_SECTORS

; CHS 几何
%define SECTORS_PER_TRACK         63
%define HEADS                     16
EOF

echo "Generated boot_config.inc:"
echo "  Kernel: $KERNEL_SIZE bytes = $KERNEL_SECTORS sectors"
echo "  Bootloader: $BOOTLOADER_SIZE bytes = $BOOTLOADER_SECTORS sectors"
echo "  Kernel LBA start: $BOOTLOADER_SECTORS"
```

这个脚本用 `stat` 命令获取文件大小，然后计算扇区数（向上取整）。最后生成配置文件，并打印一些有用的信息。

然后更新 Makefile 来调用这个脚本：

```makefile
# 生成配置
BOOT_CONFIG_INC := $(BOOT_DIR)/boot_config.inc

$(BOOT_CONFIG_INC): $(BOOTLOADER_BIN) $(KERNEL_BIN)
	@echo "Generating boot configuration..."
	@bash scripts/gen_boot_config.sh

$(BOOTLOADER_BIN): $(BOOT_CONFIG_INC) $(BOOTLOADER_ASM) | prepare
	@echo "Assembling bootloader..."
	$(AS) $(ASFLAGS) $< -o $@
```

## 一些容易踩的坑

说几个实现过程中容易出错的地方。

127 扇区限制很重要。INT 13h AH=42h 一次最多读取 127 个扇区，不是 128，也不是 256。超过这个数需要循环读取。我第一次做的时候没注意这个限制，结果大内核总是加载失败。

缓冲区溢出要小心。多扇区读取会前进缓冲区指针，如果计算错了可能会写到错误的地址。一定要检查 `ES:BX` 不会溢出，或者至少保证不会覆盖重要内存区域。

LBA vs CHS 扇区编号容易混淆。LBA 的扇区 0 是第一个扇区，而 CHS 的扇区 1 是第一个扇区。转换时记得 +1！这个细节很隐蔽，我第一次做转换时忘了 +1，结果读取的扇区总是偏移一个。

配置文件生成顺序会导致循环依赖。bootloader.asm 依赖 boot_config.inc，而 boot_config.inc 依赖 bootloader.bin... 这是循环依赖！解决方法是用上一次的 bootloader.bin 来生成配置，或者第一次编译用默认配置。
