# 实现第一个系统调用 —— Stage 20 系统调用框架实战指南（八）

## 前言

在之前的文章里，我们搭建了系统调用框架的完整基础设施：MSR 配置、汇编入口、C 分发器、系统调用表。现在框架已经就绪，这篇文章我们要真正实现一些有用的系统调用。

说实话，看到第一个系统调用从用户程序发出，经过内核处理，然后返回结果，那种成就感是无可比拟的。我们会实现几个基础但实用的系统调用：write、getpid、exit。虽然它们的实现目前还很简陋，但足以验证整个系统调用链路是否正常工作。

## 写入系统调用 (sys_write)

`write` 是最常用的系统调用之一，用于向文件描述符写入数据。在早期开发阶段，我们可以先实现一个简化版本：只支持 stdout（文件描述符 1）和 stderr（文件描述符 2），直接输出到内核日志。

打开 `syscall_table.c`，找到 `sys_write` 函数，替换为以下实现：

```c
/**
 * @brief Write to a file descriptor
 *
 * @param fd    File descriptor (1=stdout, 2=stderr)
 * @param buf   Buffer containing data to write
 * @param count Number of bytes to write
 * @return Number of bytes written, or negative error code
 */
static int64_t sys_write(syscall_frame_t* frame) {
    int fd = (int)frame->arg0;
    const char* buf = (const char*)frame->arg1;
    size_t count = (size_t)frame->arg2;

    /* Validate parameters */
    if (count > 4096) {
        /* Limit write size for safety */
        count = 4096;
    }

    /* Handle stdout and stderr */
    if (fd == 1 || fd == 2) {
        /* Direct output to kernel log */
        klog_info("[USER OUT] %.*s\n", (int)count, buf);
        return (int64_t)count;
    }

    /* Invalid file descriptor */
    klog_warn("[SYSCALL] write: invalid fd %d\n", fd);
    return SYS_ERR_NFILE;  /* Bad file descriptor */
}
```

这个实现做了几件事：首先验证参数，限制写入大小为 4096 字节（防止恶意程序传递巨大的 count 值）。然后检查文件描述符，如果是 stdout 或 stderr，就输出到内核日志。否则返回错误。

你可能注意到这里使用了 `%.*s` 格式说明符，这是一个很有用的技巧：`%.*s` 允许我们指定字符串长度，避免缓冲区没有 null 终止符的问题。

## 获取进程 ID (sys_getpid)

`getpid` 返回当前进程的 ID。在没有实现完整进程管理的情况下，我们可以返回一个固定的值：

```c
/**
 * @brief Get process ID
 *
 * @return Process ID (dummy value for now)
 */
static int64_t sys_getpid(syscall_frame_t* frame) {
    (void)frame;

    /* TODO: Return actual process ID when process management is implemented */
    /* For now, return a fixed value */
    return 1;
}
```

这个实现非常简单，直接返回 1。在未来的进程管理实现中，我们会从当前进程的 PCB（Process Control Block）中读取真实的 PID。

---

## 退出系统调用 (sys_exit)

`exit` 终止当前进程。在没有实现完整进程管理的情况下，我们只能打印日志然后返回：

```c
/**
 * @brief Exit current process
 *
 * @param exit_code Exit status code
 */
static int64_t sys_exit(syscall_frame_t* frame) {
    int exit_code = (int)frame->arg0;

    klog_info("[SYSCALL] exit(%d) called\n", exit_code);
    klog_warn("[SYSCALL] Process termination not fully implemented yet\n");
    klog_warn("[SYSCALL] System will continue running (but should have stopped)\n");

    /* TODO: Implement proper process termination:
     * 1. Close all open file descriptors
     * 2. Free memory used by the process
     * 3. Notify parent process
     * 4. Schedule another process
     * 5. Never return to user space
     */

    return SYS_OK;
}
```

这个实现目前只是打印日志。真正的 exit 实现需要完整的进程管理支持，这超出了本阶段的范围。

---

## 获取父进程 ID (sys_getppid)

与 `getpid` 类似，`getppid` 返回父进程的 ID：

```c
/**
 * @brief Get parent process ID
 *
 * @return Parent process ID (dummy value for now)
 */
static int64_t sys_getppid(syscall_frame_t* frame) {
    (void)frame;

    /* TODO: Return actual parent process ID */
    /* For now, return 0 (no parent) */
    return 0;
}
```

返回 0 表示"没有父进程"，这在 init 进程（PID 1）的情况下是合理的。

## 其他系统调用的占位实现

对于其他系统调用，我们可以提供占位实现，返回"未实现"错误：

```c
/**
 * @brief Read from a file descriptor
 */
static int64_t sys_read(syscall_frame_t* frame) {
    (void)frame;
    klog_warn("[SYSCALL] read: not implemented\n");
    return SYS_ERR_NOTIMPL;
}

/**
 * @brief Open a file
 */
static int64_t sys_open(syscall_frame_t* frame) {
    (void)frame;
    klog_warn("[SYSCALL] open: not implemented\n");
    return SYS_ERR_NOTIMPL;
}

/**
 * @brief Close a file descriptor
 */
static int64_t sys_close(syscall_frame_t* frame) {
    (void)frame;
    /* Silently succeed - close is often called even if fd is invalid */
    return SYS_OK;
}

/**
 * @brief Change data segment size (brk)
 */
static int64_t sys_brk(syscall_frame_t* frame) {
    void* new_brk = (void*)frame->arg0;
    (void)new_brk;
    klog_warn("[SYSCALL] brk: not implemented\n");
    return SYS_ERR_NOTIMPL;
}

/**
 * @brief Get system information (uname)
 */
static int64_t sys_uname(syscall_frame_t* frame) {
    (void)frame;
    klog_warn("[SYSCALL] uname: not implemented\n");
    return SYS_ERR_NOTIMPL;
}
```

注意 `sys_close` 的实现返回 `SYS_OK` 而不是 `SYS_ERR_NOTIMPL`。这是故意的：很多程序会尝试关闭一个可能未打开的文件描述符，如果这里返回错误，可能会产生误导性的日志。静默成功是一个合理的选择。

## 添加测试系统调用

为了方便测试，我们可以添加一个"回显"系统调用，它简单地返回第一个参数：

```c
/**
 * @brief Test syscall (echo back the argument)
 *
 * This is useful for testing the syscall mechanism without
 * implementing actual functionality.
 */
static int64_t sys_test(syscall_frame_t* frame) {
    uint64_t value = frame->arg0;
    klog_info("[SYSCALL] test: received 0x%llx\n", value);
    return (int64_t)value;
}
```

在 `syscall_register_all()` 中注册这个系统调用：

```c
syscall_register_handler(SYS_TEST, sys_test, "test");
```

---

## 更新 syscall_register_all

确保 `syscall_register_all()` 函数注册了所有系统调用：

```c
void syscall_register_all(void) {
    /* Process management */
    syscall_register_handler(SYS_EXIT, sys_exit, "exit");
    syscall_register_handler(SYS_GETPID, sys_getpid, "getpid");
    syscall_register_handler(SYS_GETPPID, sys_getppid, "getppid");

    /* File I/O */
    syscall_register_handler(SYS_WRITE, sys_write, "write");
    syscall_register_handler(SYS_READ, sys_read, "read");
    syscall_register_handler(SYS_OPEN, sys_open, "open");
    syscall_register_handler(SYS_CLOSE, sys_close, "close");

    /* Memory management */
    syscall_register_handler(SYS_BRK, sys_brk, "brk");

    /* System information */
    syscall_register_handler(SYS_UNAME, sys_uname, "uname");

    /* Testing */
    syscall_register_handler(SYS_TEST, sys_test, "test");
}
```

## 从内核代码测试系统调用

在实现用户态程序之前，我们可以先从内核代码中测试系统调用。创建一个简单的测试函数：

```c
/* Test function to verify syscall mechanism */
void test_syscall_from_kernel(void) {
    klog_info("[TEST] Testing syscall mechanism from kernel\n");

    /* Prepare a syscall frame */
    syscall_frame_t frame;
    frame.syscall_number = SYS_TEST;
    frame.arg0 = 0xDEADBEEF;

    /* Call the dispatcher directly */
    int64_t result = syscall_dispatch(&frame, 0);

    klog_info("[TEST] syscall returned: 0x%llx (expected: 0xDEADBEEF)\n", result);

    /* Test write syscall */
    frame.syscall_number = SYS_WRITE;
    frame.arg0 = 1;  /* stdout */
    frame.arg1 = (uint64_t)"Hello from kernel!\n";
    frame.arg2 = 19;

    result = syscall_dispatch(&frame, 0);
    klog_info("[TEST] write returned: %lld (expected: 19)\n", result);

    /* Test getpid syscall */
    frame.syscall_number = SYS_GETPID;
    result = syscall_dispatch(&frame, 0);
    klog_info("[TEST] getpid returned: %lld (expected: 1)\n", result);
}
```

在 `kernel_init()` 中调用这个测试函数：

```c
/* After syscall_init() */
test_syscall_from_kernel();
```

运行后你应该看到类似的输出：

```
[TEST] Testing syscall mechanism from kernel
[SYSCALL] test: received 0xdeadbeef
[TEST] syscall returned: 0xdeadbeef (expected: 0xDEADBEEF)
[USER OUT] Hello from kernel!
[TEST] write returned: 19 (expected: 19)
[TEST] getpid returned: 1 (expected: 1)
```

如果看到这样的输出，说明系统调用机制工作正常！
