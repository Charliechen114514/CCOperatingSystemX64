# C 语言分发器 —— Stage 20 系统调用框架实战指南（七）

## 前言

在之前的几篇文章里，我们实现了汇编入口代码，处理了寄存器保存、栈对齐、数据结构构造等底层细节。现在汇编代码已经准备好调用 C 函数了，这篇文章我们要实现这个 C 函数——系统调用分发器。

分发器的工作听起来简单：根据系统调用号查表，找到对应的处理函数，然后调用它。但实际实现时有一些细节需要注意：边界检查、错误处理、统计信息更新。别担心，我们会一步步来。

---

## 分发器的工作流程

`syscall_dispatch` 函数从汇编代码接收一个 `syscall_frame_t*` 参数和 arg5（R9 寄存器），然后执行以下步骤：

1. 更新统计信息（总调用次数 +1）
2. 读取系统调用号
3. 检查系统调用号是否在有效范围内（0-255）
4. 将 arg5 存入 frame 结构（统一接口）
5. 更新该系统调用的调用计数
6. 查找系统调用表，获取处理函数
7. 检查处理函数是否已注册
8. 如果未注册，调用 `syscall_not_impl` 返回"未实现"错误
9. 如果已注册，调用处理函数
10. 返回处理函数的返回值

这个流程确保了系统的健壮性：即使收到无效或未实现的系统调用，也不会崩溃，而是返回一个错误码。

## 实现 syscall_dispatch

打开 `syscall.c`，在 `syscall_register_handler()` 函数之后添加以下代码：

```c
int64_t syscall_dispatch(syscall_frame_t* frame, uint64_t arg5) {
    /* Step 1: Update statistics */
    s_stats.total_calls++;

    /* Step 2: Read syscall number */
    uint64_t number = frame->syscall_number;

    /* Step 3: Boundary check */
    if (number >= SYS_MAX) {
        s_stats.errors++;
        klog_warn("[SYSCALL] Invalid syscall number: %lu\n", number);
        return SYS_ERR_INVAL;
    }

    /* Step 4: Store arg5 in frame for handler access */
    frame->arg5 = arg5;

    /* Step 5: Update per-syscall counter */
    if (number < 256) {
        s_stats.syscall_calls[number]++;
    }

    /* Step 6: Get handler from table */
    syscall_entry_t* entry = &s_syscall_table[number];

    /* Step 7: Check if handler is registered */
    if (!entry->registered || entry->handler == NULL) {
        /* Step 8: Call not-implemented handler */
        return syscall_not_impl(frame);
    }

    /* Step 9: Call handler */
    return entry->handler(frame);
}
```

这个函数很短，但每一行都有它的作用。让我解释一下几个关键点。

**边界检查**。我们检查系统调用号是否小于 `SYS_MAX`（256）。这是必要的，因为系统调用表的大小是固定的，如果调用号超出范围，访问数组会越界。

**arg5 的处理**。你可能注意到 `syscall_frame_t` 结构中 arg5 字段在汇编入口中没有填充（因为 R9 寄存器直接传递给了 C 函数）。这里我们把 arg5 存入 frame，这样处理函数可以通过 `frame->arg5` 访问第六个参数。

**未实现处理**。如果系统调用号没有对应的处理函数，我们调用 `syscall_not_impl`，它会更新统计信息并返回 `SYS_ERR_NOTIMPL` 错误码。

## 系统调用表的设计

系统调用表是一个静态数组，每个元素是一个 `syscall_entry_t` 结构：

```c
typedef struct {
    syscall_handler_fn handler; /* Handler function */
    const char* name;           /* Name for debugging */
    bool registered;            /* Whether handler is registered */
} syscall_entry_t;
```

这个设计有几个优点：

**O(1) 查找**。系统调用号直接作为数组索引，查找时间是常数。

**调试友好**。`name` 字段存储系统调用的名称，在日志和调试时很有用。

**动态注册**。`registered` 标志表示该槽位是否已被注册，支持运行时注册新的系统调用。

## 实现统计信息功能

我们之前声明了 `syscall_dump_stats()` 函数，现在让我们实现它。在 `syscall.c` 文件末尾添加：

```c
void syscall_dump_stats(void) {
    klog_info("[SYSCALL] Statistics:\n");
    klog_info("[SYSCALL]   Total calls: %llu\n", s_stats.total_calls);
    klog_info("[SYSCALL]   Errors:      %llu\n", s_stats.errors);
    klog_info("[SYSCALL]   Not impl:    %llu\n", s_stats.not_impl_count);

    /* Show top 5 most called syscalls */
    klog_info("[SYSCALL]   Top syscalls:\n");

    uint64_t top_counts[5] = {0};
    uint64_t top_numbers[5] = {0};

    /* Find top 5 */
    for (uint64_t i = 0; i < 256; i++) {
        if (s_stats.syscall_calls[i] > top_counts[0]) {
            /* Shift down */
            top_counts[4] = top_counts[3];
            top_numbers[4] = top_numbers[3];
            top_counts[3] = top_counts[2];
            top_numbers[3] = top_numbers[2];
            top_counts[2] = top_counts[1];
            top_numbers[2] = top_numbers[1];
            top_counts[1] = top_counts[0];
            top_numbers[1] = top_numbers[0];
            /* Insert new top */
            top_counts[0] = s_stats.syscall_calls[i];
            top_numbers[0] = i;
        } else if (s_stats.syscall_calls[i] > top_counts[1]) {
            top_counts[4] = top_counts[3];
            top_numbers[4] = top_numbers[3];
            top_counts[3] = top_counts[2];
            top_numbers[3] = top_numbers[2];
            top_counts[2] = top_counts[1];
            top_numbers[2] = top_numbers[1];
            top_counts[1] = s_stats.syscall_calls[i];
            top_numbers[1] = i;
        } else if (s_stats.syscall_calls[i] > top_counts[2]) {
            top_counts[4] = top_counts[3];
            top_numbers[4] = top_numbers[3];
            top_counts[3] = top_counts[2];
            top_numbers[3] = top_numbers[2];
            top_counts[2] = s_stats.syscall_calls[i];
            top_numbers[2] = i;
        } else if (s_stats.syscall_calls[i] > top_counts[3]) {
            top_counts[4] = top_counts[3];
            top_numbers[4] = top_numbers[3];
            top_counts[3] = s_stats.syscall_calls[i];
            top_numbers[3] = i;
        } else if (s_stats.syscall_calls[i] > top_counts[4]) {
            top_counts[4] = s_stats.syscall_calls[i];
            top_numbers[4] = i;
        }
    }

    /* Print top 5 */
    for (int i = 0; i < 5; i++) {
        if (top_counts[i] > 0) {
            const char* name = s_syscall_table[top_numbers[i]].name;
            klog_info("[SYSCALL]     %lu: %llu calls (%s)\n",
                      top_numbers[i], top_counts[i],
                      name ? name : "unknown");
        }
    }
}
```

这个函数首先打印总体统计信息，然后找出调用次数最多的 5 个系统调用并打印。这对于分析系统行为很有用——你可以看到哪些系统调用最频繁，有助于性能优化。
