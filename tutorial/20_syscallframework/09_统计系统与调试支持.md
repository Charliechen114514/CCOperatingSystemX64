# 统计系统与调试支持 —— Stage 20 系统调用框架实战指南（九）

## 前言

在之前的文章里，我们实现了系统调用的核心功能：MSR 配置、汇编入口、C 分发器、处理函数。现在系统调用已经可以工作了，但我们在开发过程中还需要一些辅助功能来调试和分析系统调用行为。

这篇文章要实现的是统计系统和一些调试支持。虽然这些功能不是系统调用框架的核心，但它们在实际开发和调试中非常有用。说实话，当初我调试系统调用的时候，如果没有这些统计信息，可能要花更多时间才能发现问题。

---

## 统计系统的作用

统计系统记录每个系统调用的调用次数、错误次数等信息。这些数据有几个用途：

**性能分析**。通过查看哪些系统调用最频繁，可以找到性能瓶颈。如果 write 调用特别频繁，可能意味着日志输出太多，或者数据应该批量写入。

**调试帮助**。如果某个系统调用返回了很多错误，统计信息可以帮助快速定位问题。

**系统监控**。在生产环境中，统计信息可以用于监控系统行为，发现异常模式。

---

## 统计数据结构

我们在 `syscall.h` 中已经定义了统计结构：

```c
typedef struct {
    uint64_t total_calls;       /* Total syscall invocations */
    uint64_t syscall_calls[256];/* Per-syscall call count */
    uint64_t errors;            /* Total errors */
    uint64_t not_impl_count;    /* Unimplemented syscall count */
} syscall_stats_t;
```

这个结构包含：
- `total_calls`：总调用次数
- `syscall_calls[256]`：每个系统调用的调用次数
- `errors`：错误总数
- `not_impl_count`：未实现系统调用的调用次数

```c
void syscall_get_stats(syscall_stats_t* stats) {
    if (stats) {
        *stats = s_stats;

}
```

这个函数简单地将内部统计结构复制到用户提供的缓冲区。注意我们使用了 `memcpy` 语义的赋值，这比逐个字段复制要高效。

## 实现统计信息导出

有时候我们需要把统计信息导出给用户程序或调试工具。添加一个新函数：

```c
/**
 * @brief Export statistics in a structured format
 *
 * @param buf    Buffer to write to
 * @param size   Size of buffer
 * @return Number of bytes written, or negative error code
 */
int syscall_export_stats(char* buf, size_t size) {
    if (!buf || size == 0) {
        return SYS_ERR_INVAL;
    }

    int written = 0;

    /* Write header */
    int header_len = klog_snprintf(buf, size,
        "=== System Call Statistics ===\n");
    if (header_len < 0) return SYS_ERR_IO;
    written += header_len;
    buf += header_len;
    size -= header_len;

    /* Write total calls */
    int total_len = klog_snprintf(buf, size,
        "Total calls: %llu\n", s_stats.total_calls);
    if (total_len < 0) return SYS_ERR_IO;
    written += total_len;
    buf += total_len;
    size -= total_len;

    /* Write errors */
    int errors_len = klog_snprintf(buf, size,
        "Errors: %llu\n", s_stats.errors);
    if (errors_len < 0) return SYS_ERR_IO;
    written += errors_len;

    return written;
}
```

这个函数将统计信息格式化为字符串，可以用于调试输出或传输给用户程序。

## 添加跟踪功能

跟踪功能可以记录每次系统调用的详细信息，包括参数、返回值、时间戳等。这对于调试非常有用。

在 `syscall.h` 中添加跟踪配置：

```c
/* ============================================================================
 * Debug/Tracing Support
 * ============================================================================ */

/* Enable syscall tracing (define to 1 to enable) */
#define SYSCALL_TRACE_ENABLED 0

/* Trace callback type */
typedef void (*syscall_trace_fn)(uint64_t number, const char* name,
                                 int64_t result, uint64_t arg0,
                                 uint64_t arg1, uint64_t arg2);

/* Set trace callback */
void syscall_set_trace_callback(syscall_trace_fn callback);
```

在 `syscall.c` 中实现：

```c
#if SYSCALL_TRACE_ENABLED
static syscall_trace_fn s_trace_callback = NULL;

void syscall_set_trace_callback(syscall_trace_fn callback) {
    s_trace_callback = callback;
}
#endif
```

然后在 `syscall_dispatch()` 中添加跟踪代码：

```c
int64_t syscall_dispatch(syscall_frame_t* frame, uint64_t arg5) {
    /* ... existing code ... */

    /* Call handler */
    int64_t result = entry->handler(frame);

#if SYSCALL_TRACE_ENABLED
    /* Call trace callback if set */
    if (s_trace_callback) {
        s_trace_callback(number, entry->name, result,
                        frame->arg0, frame->arg1, frame->arg2);
    }
#endif

    return result;
}
```

## 添加性能测量功能

除了统计调用次数，我们还可以测量每个系统调用的执行时间。这对于性能优化很有帮助。

在 `syscall.h` 中添加：

```c
/**
 * @brief System call performance statistics
 */
typedef struct {
    uint64_t total_ns;         /* Total time spent in syscall (nanoseconds) */
    uint64_t call_count;       /* Number of calls */
    uint64_t min_ns;           /* Minimum execution time */
    uint64_t max_ns;           /* Maximum execution time */
} syscall_perf_t;

/**
 * @brief Get performance statistics for a syscall
 *
 * @param number System call number
 * @param perf   Pointer to perf structure to fill
 * @return 0 on success, negative on error
 */
int syscall_get_perf_stats(uint64_t number, syscall_perf_t* perf);

/**
 * @brief Reset performance statistics
 */
void syscall_reset_perf_stats(void);
```

在 `syscall.c` 中实现：

```c
/* Performance statistics for each syscall */
static syscall_perf_t s_perf_stats[256] = {0};

/* Enable/disable performance tracking */
static bool s_perf_enabled = false;

void syscall_enable_perf_tracking(bool enable) {
    s_perf_enabled = enable;
    if (!enable) {
        /* Reset stats when disabling */
        memset(s_perf_stats, 0, sizeof(s_perf_stats));
    }
}

int syscall_get_perf_stats(uint64_t number, syscall_perf_t* perf) {
    if (number >= 256 || !perf) {
        return -1;
    }
    *perf = s_perf_stats[number];
    return 0;
}

void syscall_reset_perf_stats(void) {
    memset(s_perf_stats, 0, sizeof(s_perf_stats));
}
```

在 `syscall_dispatch()` 中添加性能测量代码：

```c
int64_t syscall_dispatch(syscall_frame_t* frame, uint64_t arg5) {
    /* ... existing code ... */

    uint64_t start_time = 0;
    if (s_perf_enabled && number < 256) {
        /* Read TSC (Time Stamp Counter) for performance measurement */
        __asm__ volatile("rdtsc" : "=A"(start_time));
    }

    /* Call handler */
    int64_t result = entry->handler(frame);

    if (s_perf_enabled && number < 256) {
        uint64_t end_time;
        __asm__ volatile("rdtsc" : "=A"(end_time));

        /* Update performance statistics */
        syscall_perf_t* perf = &s_perf_stats[number];
        uint64_t elapsed = end_time - start_time;

        perf->call_count++;
        perf->total_ns += elapsed;  /* Note: TSC cycles, not real nanoseconds */

        if (perf->call_count == 1) {
            perf->min_ns = elapsed;
            perf->max_ns = elapsed;
        } else {
            if (elapsed < perf->min_ns) perf->min_ns = elapsed;
            if (elapsed > perf->max_ns) perf->max_ns = elapsed;
        }
    }

    return result;
}
```

注意这里使用 TSC（Time Stamp Counter）来测量时间，而不是真正的纳秒。TSC 是 CPU 周期数，需要转换为时间单位。这个转换依赖于 CPU 频率，实现比较复杂。对于相对性能比较，TSC 周期数已经足够了。

## 添加断点功能

在调试时，有时候希望在某个特定系统调用被触发时暂停执行。我们可以添加一个"断点"功能：

```c
/* Set a breakpoint on a specific syscall number */
void syscall_set_breakpoint(uint64_t number) {
    /* Implementation depends on your debugger support */
    /* For now, just print a message */
    klog_info("[SYSCALL] Breakpoint set on syscall %lu\n", number);
}
```

在 `syscall_dispatch()` 中添加断点检查：

```c
/* Check for breakpoint */
static uint64_t s_breakpoint_number = (uint64_t)-1;  /* No breakpoint by default */

void syscall_set_breakpoint(uint64_t number) {
    s_breakpoint_number = number;
    klog_info("[SYSCALL] Breakpoint set on syscall %lu\n", number);
}

/* In syscall_dispatch(): */
if (number == s_breakpoint_number) {
    klog_info("[SYSCALL] Breakpoint hit! Syscall %lu (%s)\n",
              number, entry->name ? entry->name : "unknown");
    /* You can add a debug interrupt here if supported */
    /* __asm__ volatile("int $3"); */
}
```

## 测试统计功能

在内核代码中添加一个测试函数：

```c
void test_syscall_stats(void) {
    klog_info("[TEST] Testing syscall statistics\n");

    /* Make some test syscalls */
    syscall_frame_t frame;

    /* Call write 5 times */
    for (int i = 0; i < 5; i++) {
        frame.syscall_number = SYS_WRITE;
        frame.arg0 = 1;
        frame.arg1 = (uint64_t)"Test\n";
        frame.arg2 = 5;
        syscall_dispatch(&frame, 0);
    }

    /* Call getpid 3 times */
    for (int i = 0; i < 3; i++) {
        frame.syscall_number = SYS_GETPID;
        syscall_dispatch(&frame, 0);
    }

    /* Dump statistics */
    syscall_dump_stats();
}
```

在 `kernel_init()` 中调用这个测试函数。你应该看到类似的输出：
