# 实现互斥锁 —— 最常用的同步原语

## 前言

在之前的三篇文章中，我们实现了原子操作、自旋锁和等待队列。现在终于可以开始实现最常用的同步原语：互斥锁（mutex）。

互斥锁和自旋锁的核心区别在于：自旋锁在获取不到锁时忙等待，互斥锁在获取不到锁时进入睡眠。这意味着互斥锁适用于较长的临界区，因为等待的线程不会占用 CPU。

这篇文章会实现一个功能完整的互斥锁，包括快速路径优化、递归锁支持、以及基于等待队列的睡眠机制。

## 第一步——定义 mutex_t 结构

互斥锁需要维护以下信息：锁状态（是否被锁定）、当前所有者（用于递归锁）、递归计数、以及等待队列。

```c
/**
 * @file mutex.h
 * @brief 互斥锁
 * @date 2026-02-18
 */
#pragma once

#include "defines/types.h"
#include "list/list.h"
#include "process/process.h"
#include "sync/atomic.h"
#include "sync/spinlock.h"

/* ==============================================================================
 * 互斥锁类型
 * ==============================================================================
 */

/**
 * @brief 互斥锁结构
 */
typedef struct mutex {
    atomic_t locked;       /* 锁状态：0 = 未锁定, 1 = 已锁定 */
    pcb_t* owner;          /* 当前所有者进程 */
    uint32_t count;        /* 递归计数 */
    spinlock_t wait_lock;  /* 保护 wait_list */
    list_head wait_list;   /* 等待进程链表 */
} mutex_t;

/* ==============================================================================
 * 初始化宏
 * ==============================================================================
 */

#define MUTEX_INIT { \
    .locked = ATOMIC_INIT(0), \
    .owner = NULL, \
    .count = 0, \
    .wait_lock = SPIN_LOCK_INIT, \
    .wait_list = LIST_HEAD_INIT(wait_list) \
}

#define MUTEX_INITIALIZER ((mutex_t)MUTEX_INIT)

/* ==============================================================================
 * 函数声明
 * ==============================================================================
 */

void mutex_init(mutex_t* m);
void mutex_lock(mutex_t* m);
bool mutex_trylock(mutex_t* m);
void mutex_unlock(mutex_t* m);

/* 扩展操作 */
bool mutex_is_locked(const mutex_t* m);
pcb_t* mutex_owner(const mutex_t* m);
```

## 第二步——实现初始化

```c
/**
 * @file mutex.c
 * @brief 互斥锁实现
 * @date 2026-02-18
 */

#include "sync/mutex.h"
#include "sync/atomic.h"
#include "process/process.h"
#include "process/sched.h"

void mutex_init(mutex_t* m) {
    atomic_set(&m->locked, 0);
    m->owner = NULL;
    m->count = 0;
    spin_lock_init(&m->wait_lock);
    INIT_LIST_HEAD(&m->wait_list);
}
```

## 第三步——实现快速路径

快速路径是互斥锁性能优化的关键。当没有竞争时（锁是空闲的），我们可以用一条原子指令直接获取锁，无需操作等待队列。

```c
/**
 * @brief 获取互斥锁
 *
 * 快速路径：如果锁是空闲的，直接获取
 * 慢速路径：如果有竞争，加入等待队列并睡眠
 */
void mutex_lock(mutex_t* m) {
    pcb_t* current = proc_current();

    // 快速路径：无竞争时直接获取
    if (atomic_compare_and_swap(&m->locked, 0, 1)) {
        m->owner = current;
        m->count = 1;
        return;
    }

    // 慢速路径：可能有竞争
    spin_lock(&m->wait_lock);

    // 双重检查：可能在等待之前锁已经被释放
    if (atomic_compare_and_swap(&m->locked, 0, 1)) {
        m->owner = current;
        m->count = 1;
        spin_unlock(&m->wait_lock);
        return;
    }

    // 检查是否为递归锁
    if (m->owner == current) {
        m->count++;
        spin_unlock(&m->wait_lock);
        return;
    }

    // 加入等待队列
    list_add_tail(&current->wait_list, &m->wait_list);

    // 释放 wait_lock
    spin_unlock(&m->wait_lock);

    // 阻塞当前进程
    current->state = PROC_BLOCKED;
    schedule();

    // 被唤醒后，已经持有锁了
}

/**
 * @brief 尝试获取互斥锁
 * @return 成功返回 true，失败返回 false
 */
bool mutex_trylock(mutex_t* m) {
    pcb_t* current = proc_current();

    if (atomic_compare_and_swap(&m->locked, 0, 1)) {
        m->owner = current;
        m->count = 1;
        return true;
    }

    // 检查递归
    if (m->owner == current) {
        m->count++;
        return true;
    }

    return false;
}
```

## 第四步——实现释放锁

释放锁时需要处理递归计数，以及唤醒等待者。

```c
/**
 * @brief 释放互斥锁
 */
void mutex_unlock(mutex_t* m) {
    pcb_t* current = proc_current();

    // 递归释放
    if (m->owner == current && m->count > 1) {
        m->count--;
        return;
    }

    spin_lock(&m->wait_lock);

    // 清除所有者
    m->owner = NULL;
    m->count = 0;

    // 唤醒一个等待者
    if (!list_empty(&m->wait_list)) {
        pcb_t* waiter = list_first_entry(&m->wait_list, pcb_t, wait_list);
        list_del(&waiter->wait_list);

        // 设置新所有者
        m->owner = waiter;
        m->count = 1;

        // 唤醒等待者
        waiter->state = PROC_READY;
        schedule_add(waiter);
    } else {
        // 没有等待者，释放锁
        atomic_set(&m->locked, 0);
    }

    spin_unlock(&m->wait_lock);
}
```

## 第五步——实现辅助函数

```c
/**
 * @brief 检查互斥锁是否已被锁定
 */
bool mutex_is_locked(const mutex_t* m) {
    return atomic_read(&m->locked) != 0;
}

/**
 * @brief 获取互斥锁的当前所有者
 */
pcb_t* mutex_owner(const mutex_t* m) {
    return m->owner;
}
```

## 使用示例

```c
static mutex_t my_mutex = MUTEX_INITIALIZER;

void critical_section(void) {
    mutex_lock(&my_mutex);

    // 临界区代码
    shared_data++;

    mutex_unlock(&my_mutex);
}
```

## 递归锁示例

```c
void recursive_function(int depth) {
    mutex_lock(&my_mutex);

    if (depth > 0) {
        recursive_function(depth - 1);  // 递归获取锁
    }

    // 做一些工作

    mutex_unlock(&my_mutex);
}
```

## 与自旋锁的对比

| 特性 | 自旋锁 | 互斥锁 |
|------|--------|--------|
| 等待方式 | 忙等待 | 睡眠等待 |
| CPU 使用 | 高 | 低 |
| 适用场景 | 短临界区 | 长临界区 |
| 中断处理 | 可以 | 不可以 |
| 递归支持 | 否 | 是 |
