# CCOS Stage 26: 线程同步原语教程

欢迎来到 CCOS 并发编程的世界！本教程将带你从零开始实现完整的线程同步机制，这是构建多线程操作系统最核心的组件之一。

## 教程目录

本教程包含 13 篇文章，按开发顺序排列。建议从头开始依次阅读：

1. [为什么需要线程同步 —— 从竞态条件说起](01_为什么需要线程同步.md)
   - 单线程模型的局限性
   - 竞态条件的真实例子
   - 为什么需要多种同步原语
   - 实现路线图预览

2. [同步设计基础 —— 理解并发编程的核心概念](02_同步设计基础.md)
   - 临界区、互斥、死锁
   - 同步原语分类（忙等待 vs 可睡眠）
   - 经典同步问题
   - 设计决策（为什么选择 GCC 内置原子操作）

3. [从 0 实现原子操作 —— 所有同步原语的基础](03_从0实现原子操作.md)
   - 定义 atomic_t 类型
   - 实现算术操作 (inc/dec/add/sub)
   - 实现 CAS 操作（对比并交换）
   - 实现内存屏障 (mb/rmb/wmb)
   - ABA 问题讨论

4. [实现自旋锁与中断保护 —— 最简单的锁](04_实现自旋锁与中断保护.md)
   - 自旋锁的适用场景（短临界区、中断处理）
   - 使用 __atomic_test_and_set
   - pause 指令的作用
   - 中断安全版本 (irqsave/irqrestore)
   - 递归锁检测

5. [实现等待队列机制 —— 进程阻塞与唤醒](05_实现等待队列机制.md)
   - 等待队列的数据结构
   - sleep_on / wake_up 操作
   - 独占/非独占等待
   - 为后续 mutex/semaphore 做准备

6. [实现互斥锁 —— 最常用的同步原语](06_实现互斥锁.md)
   - 与 spinlock 的区别（可睡眠）
   - mutex_t 结构设计 (locked, owner, count, wait_list)
   - 快速路径优化（无竞争时直接获取）
   - 慢速路径（等待队列）
   - 递归锁支持

7. [实现信号量 —— 资源计数机制](07_实现信号量.md)
   - 信号量 vs 互斥锁
   - semaphore_t 结构 (count, lock, wait_list)
   - P 操作 (sem_wait)
   - V 操作 (sem_post)
   - 生产者-消费者示例

8. [实现条件变量 —— 事件同步](08_实现条件变量.md)
   - 为什么必须与 mutex 配合
   - condvar_t 结构
   - condvar_wait 实现（释放 mutex → 阻塞 → 重新获取）
   - signal vs broadcast
   - 为什么必须用 while 检查条件（信号丢失问题）

9. [实现读写锁 —— 读多写少场景优化](09_实现读写锁.md)
   - 读者优先策略
   - rwlock_t 结构 (readers, writers, lock)
   - 读锁/写锁的实现
   - 写锁降级
   - 写者饥饿问题讨论

10. [创建同步模块脚手架 —— 构建系统配置](10_创建同步模块脚手架.md)
    - 创建 kernel/sync/ 目录
    - 编写 CMakeLists.txt
    - 验证编译通过

11. [扩展线程支持 —— 完整的线程管理](11_扩展线程支持.md)
    - 为什么需要单独的线程支持
    - 扩展 PCB 结构 (tgid, is_thread, join_waiters, detached)
    - 内核线程创建 (proc_create_kernel_thread)
    - 用户线程创建 (proc_create_user_thread)
    - 线程退出 (proc_thread_exit)
    - 线程 join/detach

12. [编写同步演示程序 —— 验证所有功能](12_编写同步演示程序.md)
    - 创建 kernel/demo/sync/ 目录
    - Mutex 并发测试（计数器保护）
    - 信号量生产者-消费者
    - 读写锁测试（多读者并发）
    - 条件变量测试
    - 综合压力测试

13. [系统调用集成与调试 —— 用户态接口与常见问题](13_系统调用集成与调试.md)
    - 注册线程系统调用 (6-9)
    - 编写用户态测试程序
    - 常见问题排查（死锁、优先级反转、忘记释放锁）
    - 性能调优建议

## 前置要求

在开始本教程之前，你应该已经完成：

- **Stage 25**: EXT2 文件系统和 VFS
- **Stage 21**: 基础进程管理
- 熟悉 C 语言和指针操作
- 了解基本的操作系统调度概念

## 核心成果

完成本教程后，你将拥有：

- **原子操作**: 无锁编程的基础设施
- **自旋锁**: 短临界区保护的忙等待锁
- **互斥锁**: 可睡眠的递归互斥锁
- **信号量**: 资源计数和生产者-消费者模式
- **条件变量**: 事件通知机制
- **读写锁**: 读多写少场景优化的锁
- **等待队列**: 进程阻塞/唤醒基础设施
- **线程支持**: 内核线程和用户线程的完整实现
