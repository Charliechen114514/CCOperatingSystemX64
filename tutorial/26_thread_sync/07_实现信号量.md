# 实现信号量 —— 资源计数机制

## 前言

信号量（semaphore）是一种不同于互斥锁的同步原语。互斥锁关注的是"互斥访问"，信号量关注的是"资源计数"。这使得信号量非常适合实现生产者-消费者模式，或者管理有限数量的资源（比如连接池）。

这篇文章会实现一个完整的信号量，包括 P 操作（wait）和 V 操作（post），以及一个经典的生产者-消费者示例。

## 第一步——定义 semaphore_t 结构

信号量的核心是一个计数器，表示可用资源的数量。

```c
/**
 * @file semaphore.h
 * @brief 信号量
 * @date 2026-02-18
 */
#pragma once

#include "defines/types.h"
#include "list/list.h"
#include "sync/atomic.h"
#include "sync/spinlock.h"

/* ==============================================================================
 * 信号量类型
 * ==============================================================================
 */

typedef struct {
    atomic_t count;        /* 资源计数 */
    spinlock_t lock;       /* 保护状态 */
    list_head wait_list;   /* 等待进程链表 */
} semaphore_t;

/* ==============================================================================
 * 函数声明
 * ==============================================================================
 */

void sem_init(semaphore_t* sem, int value);
void sem_wait(semaphore_t* sem);
void sem_post(semaphore_t* sem);
int sem_get_count(const semaphore_t* sem);
```

## 第二步——实现初始化

```c
/**
 * @file semaphore.c
 * @brief 信号量实现
 */

#include "sync/semaphore.h"
#include "process/process.h"
#include "process/sched.h"

void sem_init(semaphore_t* sem, int value) {
    atomic_set(&sem->count, value);
    spin_lock_init(&sem->lock);
    INIT_LIST_HEAD(&sem->wait_list);
}
```

## 第三步——实现 P 操作（wait）

P 操作（也叫 wait）会减少计数器。如果计数器变为负数，进程会进入等待状态。

```c
void sem_wait(semaphore_t* sem) {
    pcb_t* current = proc_current();

    // 快速路径：有资源可用
    if (atomic_sub_if_positive(&sem->count, 1) >= 0) {
        return;
    }

    // 慢速路径：等待资源
    spin_lock(&sem->lock);

    // 双重检查
    while (atomic_read(&sem->count) <= 0) {
        // 加入等待队列
        list_add_tail(&current->wait_list, &sem->wait_list);

        // 阻塞当前进程
        current->state = PROC_BLOCKED;
        spin_unlock(&sem->lock);
        schedule();
        spin_lock(&sem->lock);
    }

    // 获取资源
    atomic_dec(&sem->count);

    spin_unlock(&sem->lock);
}
```

## 第四步——实现 V 操作（post）

V 操作（也叫 post 或 signal）会增加计数器，如果有等待者，会唤醒其中一个。

```c
void sem_post(semaphore_t* sem) {
    spin_lock(&sem->lock);

    atomic_inc(&sem->count);

    // 唤醒一个等待者
    if (!list_empty(&sem->wait_list)) {
        pcb_t* waiter = list_first_entry(&sem->wait_list, pcb_t, wait_list);
        list_del(&waiter->wait_list);
        waiter->state = PROC_READY;
        schedule_add(waiter);
    }

    spin_unlock(&sem->lock);
}
```

## 第五步——实现辅助函数

```c
int sem_get_count(const semaphore_t* sem) {
    return atomic_read(&sem->count);
}
```

## 生产者-消费者示例

信号量是生产者-消费者模式的理想选择。我们需要三个信号量：

```c
#define BUFFER_SIZE 10

static int buffer[BUFFER_SIZE];
static int in = 0, out = 0;

static semaphore_t empty;  /* 空槽位数 */
static semaphore_t full;   /* 满槽位数 */
static mutex_t mutex;      /* 保护 buffer */

// 初始化
void init_bounded_buffer(void) {
    sem_init(&empty, BUFFER_SIZE);  /* 初始时全部为空 */
    sem_init(&full, 0);             /* 初始时没有满 */
    mutex_init(&mutex);
}

// 生产者
void producer(int item) {
    sem_wait(&empty);      /* 等待空槽位 */
    mutex_lock(&mutex);

    buffer[in] = item;
    in = (in + 1) % BUFFER_SIZE;

    mutex_unlock(&mutex);
    sem_post(&full);       /* 增加满槽位 */
}

// 消费者
int consumer(void) {
    sem_wait(&full);       /* 等待满槽位 */
    mutex_lock(&mutex);

    int item = buffer[out];
    out = (out + 1) % BUFFER_SIZE;

    mutex_unlock(&mutex);
    sem_post(&empty);      /* 增加空槽位 */

    return item;
}
```

## 二值信号量

二值信号量是信号量的特例，计数只能是 0 或 1，类似于互斥锁但语义不同：

```c
semaphore_t binary_sem;
sem_init(&binary_sem, 1);  /* 初始值为 1 */

// 线程 A
sem_wait(&binary_sem);
// 临界区
sem_post(&binary_sem);

// 线程 B
sem_wait(&binary_sem);
// 临界区
sem_post(&binary_sem);
```

## 信号量 vs 互斥锁

虽然两者都能实现互斥，但语义不同：

- 互斥锁：强调"所有权"，只有获取锁的线程才能释放锁
- 信号量：没有所有权概念，任何线程都可以 post

通常情况下，保护临界区用互斥锁；协调生产者-消费者用信号量。
