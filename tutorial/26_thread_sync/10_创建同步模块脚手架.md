# 创建同步模块脚手架 —— 构建系统配置

## 前言

在之前的文章中，我们实现了所有同步原语的接口和数据结构。现在需要把它们组织成一个完整的模块，配置到构建系统中。

这篇文章会创建 `kernel/sync/` 目录，编写 CMakeLists.txt，确保所有文件能正确编译和链接。

## 第一步——创建目录结构

```bash
cd /home/charliechen/CCOperatingSystemX64/kernel
mkdir -p sync
```

## 第二步——创建头文件

把所有头文件放到 `kernel/sync/` 目录：

- `atomic.h`
- `spinlock.h`
- `waitqueue.h`
- `mutex.h`
- `semaphore.h`
- `condvar.h`
- `rwlock.h`

## 第三步——创建源文件

把所有源文件放到 `kernel/sync/` 目录：

- `atomic.c`
- `spinlock.c`
- `waitqueue.c`
- `mutex.c`
- `semaphore.c`
- `condvar.c`
- `rwlock.c`

## 第四步——编写 CMakeLists.txt

```cmake
# Kernel Sync Module
add_library(sync STATIC
    atomic.c
    spinlock.c
    waitqueue.c
    mutex.c
    semaphore.c
    condvar.c
    rwlock.c
)

target_include_directories(sync PUBLIC
    ${CMAKE_CURRENT_SOURCE_DIR}
    ${CMAKE_SOURCE_DIR}/kernel
)

target_link_libraries(sync PUBLIC
    base
    process
)
```

## 第五步——更新主 CMakeLists.txt

在 `kernel/CMakeLists.txt` 中添加：

```cmake
add_subdirectory(sync)
```

## 第六步——验证编译

```bash
cd /home/charliechen/CCOperatingSystemX64
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

如果编译成功，说明同步模块已经正确集成到构建系统。
