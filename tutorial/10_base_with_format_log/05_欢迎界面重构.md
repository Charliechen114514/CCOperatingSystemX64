## 第一步：创建统一欢迎界面接口

首先我们创建一个统一的接口，让不同的欢迎界面（串口、VGA）都能被方便地调用。这样 `kernel_main` 只需要调用一个函数，所有的欢迎界面就会自动显示。

创建 `kernel/welcomes/welcome.h`：

```c
/**
 * @file welcome.h
 * @brief 统一欢迎界面接口
 * @date 2026-02-16
 */
#pragma once

/**
 * @brief 启动所有欢迎界面
 *
 * 这个函数会调用所有已实现的欢迎界面：
 * - 串口彩色欢迎界面
 * - VGA 文本模式欢迎界面
 */
void bootAllWelcomes(void);
```

创建 `kernel/welcomes/welcome.c`：

```c
/**
 * @file welcome.c
 * @brief 欢迎界面调度
 * @date 2026-02-16
 */
#include "welcome.h"

// 声明各个欢迎界面函数
void bootSerialWelcome(void);
void bootVGATextWelcome(void);

void bootAllWelcomes(void) {
    // 串口欢迎界面（带颜色）
    bootSerialWelcome();

    // VGA 欢迎界面
    bootVGATextWelcome();
}
```

这里用 `boot` 前缀是为了和之前的代码风格保持一致。你也可以用 `show`、`display` 等前缀，关键是要统一。我当时纠结了一下用哪个词，最后觉得 `boot` 最合适，因为这些欢迎界面是在系统启动时显示的。

## 第二步：实现串口彩色欢迎界面

现在我们用新的彩色日志系统来实现串口欢迎界面。这一次我们要做得漂亮一点，用 ANSI 转义序列实现一些酷炫的效果。

创建 `kernel/welcomes/serial_welcome.c`：

```c
/**
 * @file serial_welcome.c
 * @brief 串口彩色欢迎界面
 * @date 2026-02-16
 */
#include "ccos_config.h"
#include "driver/serial/serial.h"
#include "driver/serial/serial_color.h"

// ASCII Art Logo
static const char* CCOS_LOGO[] = {
    "  _____  _____ _____    ___    ",
    " /  _  \\/  ___//  __ \\  /   |   ",
    " | | | |\\ `--.| /  \\/ / /| |   ",
    " | | | | `--. \\ |    / /_| |   ",
    " | |_| |/\\__/ / \\__/\\____  |   ",
    "  \\___/ \\____/ \\____/    |_|   "
};

static const char* CCOS_NAME = "CCOperating System X64";

// 辅助函数：输出带颜色的文本
static void sync_serial_puts_color(const char* str, serial_color_t color) {
    sync_serial_puts(serial_color_ansi(color));
    sync_serial_puts(str);
    sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RESET));
}

// 输出分隔线
static void print_separator(int width, serial_color_t color) {
    sync_serial_puts(serial_color_ansi(color));
    for (int i = 0; i < width; i++) {
        sync_serial_puts("=");
    }
    sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RESET));
    sync_serial_puts("\r\n");
}

// 主欢迎界面
void bootSerialWelcome(void) {
    int box_width = 60;

    // 清屏（ANSI）
    sync_serial_puts("\033[2J\033[H");

    // 顶部装饰线
    print_separator(box_width, SERIAL_COLOR_BRIGHT_CYAN);
    sync_serial_puts("\r\n");

    // Logo 部分
    for (int i = 0; i < 6; i++) {
        int logo_padding = (box_width - 30) / 2;
        for (int j = 0; j < logo_padding; j++)
            sync_serial_puts(" ");
        sync_serial_puts(CCOS_LOGO[i]);
        sync_serial_puts("\r\n");
    }

    sync_serial_puts("\r\n");

    // 系统名称（加粗黄色）
    int name_padding = (box_width - 24) / 2;
    for (int i = 0; i < name_padding; i++)
        sync_serial_puts(" ");
    sync_serial_puts("\033[1;33m");  // 加粗黄色
    sync_serial_puts(CCOS_NAME);
    sync_serial_puts("\033[0m\r\n");

    sync_serial_puts("\r\n");

    // 版本信息
    int ver_padding = (box_width - 20) / 2;
    for (int i = 0; i < ver_padding; i++)
        sync_serial_puts(" ");
    sync_serial_puts_color("Version: ", SERIAL_COLOR_BRIGHT_GREEN);
    sync_serial_puts_color(CCOS_VERSION, SERIAL_COLOR_BRIGHT_GREEN);
    sync_serial_puts_color(" [Alpha]", SERIAL_COLOR_YELLOW);
    sync_serial_puts("\r\n");

    // 构建类型
    sync_serial_puts("\r\n");
    int build_padding = (box_width - 18) / 2;
    for (int i = 0; i < build_padding; i++)
        serial_puts(" ");
    sync_serial_puts("Build: ");
    sync_serial_puts_color(CCOS_BUILD_TYPE, SERIAL_COLOR_BRIGHT_WHITE);
    sync_serial_puts("\r\n");

    sync_serial_puts("\r\n");
    print_separator(box_width, SERIAL_COLOR_BRIGHT_CYAN);
    sync_serial_puts("\r\n");

    // 系统信息
    sync_serial_puts_color("  Architecture: ", SERIAL_COLOR_CYAN);
    sync_serial_puts("x86_64\r\n");
    sync_serial_puts_color("  Mode: ", SERIAL_COLOR_CYAN);
    sync_serial_puts("Long Mode (64-bit)\r\n");
    sync_serial_puts_color("  Page Size: ", SERIAL_COLOR_CYAN);
    sync_serial_puts("4096 bytes\r\n");

    sync_serial_puts("\r\n");
    print_separator(box_width, SERIAL_COLOR_BRIGHT_CYAN);
    sync_serial_puts("\r\n");

    // 完成信息
    sync_serial_puts_color("  >> Serial Console Ready <<", SERIAL_COLOR_BRIGHT_GREEN);
    sync_serial_puts("\r\n");

    // 最终重置
    sync_serial_puts(serial_color_ansi(SERIAL_COLOR_RESET));
}
```

这个欢迎界面做了几件事：清屏、显示 ASCII Art Logo、显示版本和构建信息、显示系统信息、显示完成提示。每个部分都用了不同的颜色，整体效果非常醒目。

这里我们用了一些 ANSI 转义序列的进阶功能。`\033[2J` 是清屏，`\033[H` 是把光标移到左上角。`[1m` 是加粗，`[1;33m` 是加粗黄色。这些组合可以产生更丰富的效果。

## 第三步：理解 ANSI 控制序列

在继续之前，让我们深入理解一下 ANSI 控制序列。上面的代码中用到了几个，我来解释一下。

**清屏和光标定位：**

| 序列 | 功能 |
|------|------|
| `\033[2J` | 清屏 |
| `\033[H` | 光标移到左上角（-home） |
| `\033[row;colH` | 光标移到指定位置 |

**文本样式：**

| 序列 | 功能 |
|------|------|
| `\033[0m` | 重置所有属性 |
| `\033[1m` | 加粗 |
| `\033[2m` | 变暗 |
| `\033[3m` | 斜体 |
| `\033[4m` | 下划线 |

**颜色设置：**

| 序列 | 功能 |
|------|------|
| `\033[30m`-`\033[37m` | 前景色（黑到白） |
| `\033[40m`-`\033[47m` | 背景色（黑到白） |
| `\033[90m`-`\033[97m` | 亮前景色 |
| `\033[100m`-`\033[107m` | 亮背景色 |

这些序列可以组合使用，比如 `\033[1;33m` 表示加粗黄色。分号分隔多个属性，顺序不重要。

## 第四步：保持 VGA 欢迎界面兼容

我们之前可能已经有 VGA 欢迎界面了。现在我们把它整合进来，保持兼容。VGA 和串口是两种不同的输出设备，串口支持 ANSI 转义序列，但 VGA 需要直接操作视频内存，用不同的颜色编码。

创建 `kernel/welcomes/vga_welcomes.c`：

```c
/**
 * @file vga_welcomes.c
 * @brief VGA 欢迎界面
 * @date 2026-02-16
 */
#include "driver/vga/vga.h"
#include "driver/vga/vga_helpers.h"

void bootVGATextWelcome(void) {
    // 清屏
    vga_clear_screen();

    // 设置颜色：蓝底白字
    vga_set_color(VGA_COLOR_BLUE, VGA_COLOR_WHITE);

    // 打印标题
    int row = 2;
    vga_printf_at(row++, 30, "CCOS Kernel v0.1.0");
    vga_printf_at(row++, 32, "Built: %s", __DATE__);

    row++;
    vga_printf_at(row++, 25, "Welcome to CharlieChen's Operating System!");
    vga_printf_at(row++, 28, "This is a learning project for OS dev.");

    row++;
    vga_printf_at(row++, 30, "System Information:");
    vga_printf_at(row++, 32, "- Architecture: x86_64");
    vga_printf_at(row++, 32, "- Mode: Long Mode (64-bit)");
    vga_printf_at(row++, 32, "- Page Size: 4096 bytes");

    row++;
    vga_set_color(VGA_COLOR_GREEN, VGA_COLOR_BLACK);
    vga_printf_at(row++, 30, "Kernel initialized successfully!");
}
```

这里我们用的是 VGA 专用的 API，比如 `vga_clear_screen`、`vga_set_color`、`vga_printf_at`。这些函数直接操作 VGA 文本模式的视频内存，不需要通过 ANSI 转义序列。

## 第六步：在 kernel_main 中整合

现在我们在 `kernel_main.c` 中整合所有东西。这是系统启动的第一步，初始化顺序非常重要。

```c
/**
 * @file kernel_main.c
 * @brief 内核主函数
 * @date 2026-02-16
 */
#include "welcomes/welcome.h"
#include "klogs/kprintf.h"
#include "klogs/backends/serial_backends.h"
#include "driver/vga/vga.h"

void kernel_main(void) {
    // ===== 第一步：初始化日志系统 =====
    klog_init(KLOG_BACKEND_SERIAL);
    klog_set_level(KLOG_LEVEL_INFO);

    // ===== 第二步：初始化 VGA =====
    vga_init();

    // ===== 第三步：显示欢迎界面 =====
    bootAllWelcomes();

    // ===== 第四步：内核主循环 =====
    klog_info("Entering kernel main loop...");

    while (1) {
        // CPU 空闲
        __asm__ volatile("hlt");
    }
}
```

初始化顺序很重要。日志系统要优先，这样后续的调试信息才能输出。VGA 初始化之后才能显示欢迎界面。欢迎界面显示完毕后，进入内核主循环。

## 第八步：调试技巧

如果输出有问题，这里有一些调试技巧。

**问题 1：串口没有颜色**

检查串口工具是否支持 ANSI 颜色。picocom 和 minicom 都支持，但有些老式工具不支持。试试换一个串口工具。

**问题 2：VGA 没有输出**

检查 VGA 初始化顺序。`vga_init()` 必须在 `vga_printf_at()` 之前调用。如果还是不行，用 GDB 调试一下，看看是不是 VGA 驱动的问题。

**问题 3：欢迎界面只显示一半**

检查缓冲区大小。串口输出是流式的，但 VGA 需要足够的缓冲区来存储文本。确保 VGA 缓冲区至少有 1KB。
