# 欢迎界面重构 —— Stage 10 整合实战指南

## 前言

写到这里，我们已经实现了一个完整的日志系统。但还有一个问题：我们之前写的欢迎界面代码还在用旧的输出方式。

你想想，现在我们有了这么漂亮的彩色日志系统，欢迎界面也应该升级一下。更重要的是，我们之前可能有多个欢迎界面（串口的、VGA 的），代码分散在各处，不好管理。

1. 创建统一的欢迎界面接口

4. 把所有东西整合到 `kernel_main` 里

这是 Stage 10 的最后一部分，做完这个，我们就大功告成了！

## 第一步：创建统一欢迎界面接口

首先，我们创建一个统一的接口，让不同的欢迎界面（串口、VGA）都能被方便地调用。

创建 `kernel/welcomes/welcome.h`：

```c
/**
 * @file welcome.h
 * @brief 统一欢迎界面接口
 * @date 2026-02-16
 */

#pragma once

/**
 * @brief 启动所有欢迎界面
 *
 * 这个函数会调用所有已实现的欢迎界面：
 * - 串口彩色欢迎界面
 * - VGA 文本模式欢迎界面
 * - VGA 图形模式欢迎界面（如果有）
 */
void bootAllWelcomes(void);
```

创建 `kernel/welcomes/welcome.c`：

```c
/**
 * @file welcome.c
 * @brief 欢迎界面调度
 * @date 2026-02-16
 */

#include "welcome.h"

// 声明各个欢迎界面函数
void bootSerialWelcome(void);
void bootVGATextWelcome(void);

void bootAllWelcomes(void) {
    // 串口欢迎界面（带颜色）
    bootSerialWelcome();

    // VGA 欢迎界面
    bootVGATextWelcome();
}
```

**为什么用 `boot` 前缀？**

这是为了和之前的代码风格保持一致。你也可以用 `show`、`display` 等前缀，关键是要统一。

## 第二步：实现串口彩色欢迎界面

现在我们用新的彩色日志系统来实现串口欢迎界面。

创建 `kernel/welcomes/serial_welcome.c`：

```c
/**
 * @file serial_welcome.c
 * @brief 串口彩色欢迎界面
 * @date 2026-02-16
 */

#include "klogs/kprintf.h"
#include "klogs/backends/serial_backends.h"
#include "driver/serial/serial_color.h"

/**
 * @brief 输出彩色分隔线
 */
static void print_separator(void) {
    kprintf(KLOG_BACKEND_SERIAL,
        "\033[36m========================================================\033[0m\n");
}

/**
 * @brief 输出带颜色的标题
 */
static void print_title(const char* title) {
    // 青色 + 加粗效果
    kprintf(KLOG_BACKEND_SERIAL, "\033[1;36m%s\033[0m\n", title);
}

void bootSerialWelcome(void) {
    // 确保串口后端已初始化
    const KLogBackendOps* ops = klog_get_backend_ops(KLOG_BACKEND_SERIAL);
    if (ops == NULL || !ops->is_ready()) {
        return;  // 串口未就绪，跳过
    }

    // 清屏效果（输出多个换行）
    for (int i = 0; i < 3; i++) {
        kprintf(KLOG_BACKEND_SERIAL, "\n");
    }

    print_separator();
    kprintf(KLOG_BACKEND_SERIAL, "\n");

    print_title("  ___  __      __               _       ");
    kprintf(KLOG_BACKEND_SERIAL, " / _ \\ \\ \\    / /__ _ __ _ __(_) ___  ___ ");
    kprintf(KLOG_BACKEND_SERIAL, "| | | |\\ \\/\\/ / _ \\ '__| '__| |/ _ \\/ __|");
    kprintf(KLOG_BACKEND_SERIAL, "| |_| | >  <  __/ |  | |  | |  __/\\__ \\");
    kprintf(KLOG_BACKEND_SERIAL, " \\___/ /_/\\_/\\___|_|  |_|  |_|\\___||___/");
    kprintf(KLOG_BACKEND_SERIAL, "\n");

    print_separator();
    kprintf(KLOG_BACKEND_SERIAL, "\n");

    // 使用分级日志输出信息
    klog_info("CCOS Kernel v0.1.0");
    klog_info("Built: %s %s", __DATE__, __TIME__);
    klog_info("Compiler: GCC %d.%d.%d",
        __GNUC__, __GNUC_MINOR__, __GNUC_PATCHLEVEL__);

    kprintf(KLOG_BACKEND_SERIAL, "\n");
    print_separator();
    kprintf(KLOG_BACKEND_SERIAL, "\n");

    // 系统信息
    klog_info("System Information:");
    klog_info("  Architecture: x86_64");
    klog_info("  Mode: Long Mode (64-bit)");
    klog_info("  Page Size: 4096 bytes");

    kprintf(KLOG_BACKEND_SERIAL, "\n");

    // 调试信息
    klog_debug("Debug Information:");
    klog_debug("  Kernel Start: 0x100000");
    klog_debug("  Kernel End: 0x200000");

    kprintf(KLOG_BACKEND_SERIAL, "\n");
    print_separator();

    klog_info("Kernel initialization complete. Welcome to CCOS!");
    klog_info("Type 'help' for available commands.");

    kprintf(KLOG_BACKEND_SERIAL, "\n");
}
```

**注意这里的设计**

1. **使用 `\033[...]m` 直接控制颜色**：而不是依赖 `klog_*` 宏，这样我们可以实现更复杂的颜色效果
2. **使用分级日志输出信息**：`INFO` 级别用绿色，`DEBUG` 级别用紫色
3. **ASCII Art Logo**：用字符画出一个 "CCOS" 的标志
4. **检查串口就绪状态**：避免在未初始化时输出

## 第三步：保持 VGA 欢迎界面兼容

我们之前可能已经有 VGA 欢迎界面了。现在我们把它整合进来，保持兼容。

创建 `kernel/welcomes/vga_welcomes.c`：

```c
/**
 * @file vga_welcomes.c
 * @brief VGA 欢迎界面
 * @date 2026-02-16
 */

#include "driver/vga/vga.h"
#include "driver/vga/vga_helpers.h"

void bootVGATextWelcome(void) {
    // 清屏
    vga_clear_screen();

    // 设置颜色：蓝底白字
    vga_set_color(VGA_COLOR_BLUE, VGA_COLOR_WHITE);

    // 打印标题
    int row = 2;
    vga_printf_at(row++, 30, "CCOS Kernel v0.1.0");
    vga_printf_at(row++, 32, "Built: %s", __DATE__);

    row++;
    vga_printf_at(row++, 25, "Welcome to CharlieChen's Operating System!");
    vga_printf_at(row++, 28, "This is a learning project for OS dev.");

    row++;
    vga_printf_at(row++, 30, "System Information:");
    vga_printf_at(row++, 32, "- Architecture: x86_64");
    vga_printf_at(row++, 32, "- Mode: Long Mode (64-bit)");
    vga_printf_at(row++, 32, "- Page Size: 4096 bytes");

    row++;
    vga_set_color(VGA_COLOR_GREEN, VGA_COLOR_BLACK);
    vga_printf_at(row++, 30, "Kernel initialized successfully!");
}
```

**为什么 VGA 不用颜色日志系统？**

VGA 和串口是两种不同的输出设备：
- 串口支持 ANSI 转义序列，可以用 `\033[...]m` 控制颜色
- VGA 需要直接操作视频内存，用不同的颜色编码

所以 VGA 需要自己的一套 API（`vga_set_color`、`vga_printf_at` 等）。

## 第五步：在 kernel_main 中整合

现在我们在 `kernel_main.c` 中整合所有东西。

更新 `kernel/kernel_main.c`：

```c
/**
 * @file kernel_main.c
 * @brief 内核主函数
 * @date 2026-02-16
 */

#include "welcomes/welcome.h"
#include "klogs/kprintf.h"
#include "klogs/backends/serial_backends.h"
#include "driver/vga/vga.h"

void kernel_main(void) {
    // ===== 第一步：初始化日志系统 =====
    klog_serial_backend_init();
    klog_register_backend(KLOG_BACKEND_SERIAL, klog_serial_backend_get_ops());
    klog_set_default_backend(KLOG_BACKEND_SERIAL);

    // 设置日志级别
    klog_set_level(KLOG_LEVEL_INFO);

    // ===== 第二步：初始化 VGA =====
    vga_init();

    // ===== 第三步：显示欢迎界面 =====
    bootAllWelcomes();

    // ===== 第四步：内核主循环 =====
    klog_info("Entering kernel main loop...");

    while (1) {
        // CPU 空闲
        __asm__ volatile("hlt");
    }
}
```

**初始化顺序很重要**

1. **日志系统优先**：先初始化日志，这样后续的调试信息才能输出
2. **VGA 初始化**：VGA 驱动初始化，准备好显示设备
3. **欢迎界面**：在一切就绪后显示欢迎信息
4. **主循环**：进入内核主循环

## 第七步：调试技巧

如果输出有问题，这里有一些调试技巧：

### 问题 1：串口没有颜色

检查串口工具是否支持 ANSI 颜色：
```bash
# picocom 支持
picocom -b 115200 /dev/ttyS0

# minicom 支持
minicom -D /dev/ttyS0 -b 115200
```

### 问题 2：VGA 没有输出

检查 VGA 初始化顺序：
```c
vga_init();  // 必须在 vga_printf_at 之前调用
```

### 问题 3：欢迎界面只显示一半

检查缓冲区大小和字符串长度：
```c
// 确保 VGA 缓冲区足够
static char vga_buffer[1024];

// 确保日志缓冲区足够
#define KPRINTF_BUFFER_SIZE 512
```
