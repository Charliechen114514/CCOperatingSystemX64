# 从字符串工具库开始 —— Stage 10 基础库实战指南

## 前言

说实话，写到 Stage 10 的时候，我意识到一个问题：我们一直在用各种字符串处理，但从来没有好好思考过这些函数到底是怎么实现的。

`atoi` 怎么把 `"123"` 变成整数 123？`strtol` 怎么处理十六进制的 `0x1a`？为什么内核里不能用标准库的 `string.h`？

这些问题如果不想清楚，以后写内核的时候会非常痛苦。你想调试一个函数，结果发现连 `printf` 的底层实现都不理解，这种感觉我太熟了。

所以，这一篇我们会一起手把手实现一套完整的字符串工具库。别担心，我们不会跳过任何步骤。每写一个函数，我们都会解释清楚它是怎么工作的，为什么要这么写。

准备好了吗？我们开始。

## 环境说明

在开始之前，先确认一下你的开发环境。这篇文章假设你已经完成了 Stage 09，串口输出已经能正常工作了。

```
操作系统: Ubuntu 22.04 LTS / WSL2 / Arch WSL
编译器:   GCC x86_64-elf-gcc 或类似交叉编译器
构建工具: CMake 3.25 或更高版本
模拟器:   QEMU 7.0 或更高版本
```

**为什么不能直接用标准库？**

好问题。内核环境和用户态程序有几个关键区别：

1. **没有标准库支持**：内核是最底层的，它没法依赖任何外部库
2. **需要自己实现所有东西**：`printf`、`strcpy`、`atoi` 这些都要自己写
3. **要考虑多进制**：调试的时候经常需要输出十六进制、二进制
4. **错误处理要简单**：内核里不能抛异常，出错了就要自己处理

所以，我们得自己造轮子。但这其实是好事，因为你会真正理解这些函数是怎么工作的。

## 第二步：实现字符分类函数

我们先从最简单的开始。字符分类函数是很多字符串操作的基础。

创建 `kernel/base/strhelpers.h`：

```c
/**
 * @file strhelpers.h
 * @brief 字符串辅助函数声明
 * @date 2026-02-16
 */

#pragma once
#include "defines/types.h"

/**
 * @brief 判断字符是否为空白字符
 *
 * 空白字符包括：空格、制表符、换行符、垂直制表符、换页符、回车符
 *
 * @param ch 要检查的字符
 * @return true 是空白字符
 * @return false 不是空白字符
 */
bool isspace(char ch);

/**
 * @brief 判断字符是否为数字
 *
 * @param ch 要检查的字符
 * @return true 是数字字符 ('0'-'9')
 * @return false 不是数字字符
 */
bool isdigit(char ch);
```

现在实现这些函数。创建 `kernel/base/strhelpers.c`：

```c
#include "strhelpers.h"
#include "string.h"

bool isspace(char ch) {
    if (ch == '\0')
        return false;
    // 空白字符：空格、制表符、换行符、垂直制表符、换页符、回车符
    return strchr(" \t\n\v\f\r", ch) != NULL;
}

bool isdigit(char ch) {
    // 数字字符的 ASCII 码是连续的：'0'=48, '9'=57
    return '0' <= ch && ch <= '9';
}
```

**等等，`strchr` 是哪里来的？**

好问题！`strchr` 是我们在 Stage 08 中实现的字符串函数。如果你还没实现，可以参考一下 `kernel/base/string.c`。或者，我们也可以简化一下，直接用比较：

```c
bool isspace(char ch) {
    if (ch == '\0')
        return false;
    return ch == ' ' || ch == '\t' || ch == '\n' ||
           ch == '\v' || ch == '\f' || ch == '\r';
}
```

两种方式都可以，看你的偏好。

## 第三步：实现字符串反转函数

接下来我们要实现 `reverse_str`，它会在 `itoa` 中用到。

在 `strhelpers.h` 中添加声明：

```c
/**
 * @brief 反转字符串（原地操作）
 *
 * @param str 要反转的字符串
 * @param len 字符串长度
 */
void reverse_str(char* str, int len);
```

在 `strhelpers.c` 中添加实现：

```c
void reverse_str(char* str, int len) {
    int i = 0, j = len - 1;
    while (i < j) {
        // 交换首尾字符
        char tmp = str[i];
        str[i] = str[j];
        str[j] = tmp;
        i++;
        j--;
    }
}
```

**为什么需要这个函数？**

你可能会问。这是因为我们把数字转换成字符串的时候，是从低位到高位生成的。比如 123，先生成 "321"，然后反转得到 "123"。这个技巧非常经典。

## 第四步：实现 strtol —— 字符串转整数（完整版）

现在我们来实现一个完整的字符串转整数函数。这个函数会处理很多边界情况，是理解字符串处理的好例子。

在 `strhelpers.h` 中添加声明：

```c
/**
 * @brief 将字符串转换为长整数
 *
 * 支持功能：
 * - 跳过前导空白字符
 * - 处理正负号
 * - 自动检测进制（0x 前缀表示十六进制，0 前缀表示八进制）
 * - 支持 2-36 任意进制
 *
 * @param nptr 要转换的字符串
 * @param endptr 指向第一个未转换字符的指针（可为 NULL）
 * @param base 进制（2-36，或 0 表示自动检测）
 * @return 转换后的长整数
 */
long strtol(const char* nptr, char** endptr, int base);
```

在 `strhelpers.c` 中添加实现：

```c
long strtol(const char* nptr, char** endptr, int base) {
    const char* s = nptr;
    long result = 0;
    bool neg = false;

    // 第一步：跳过前导空白字符
    while (isspace((unsigned char)*s))
        s++;

    // 第二步：处理正负号
    if (*s == '-') {
        neg = true;
        s++;
    } else if (*s == '+') {
        s++;
    }

    // 第三步：检测进制
    if (base == 0) {
        // 自动检测进制
        if (*s == '0') {
            if (*(s + 1) == 'x' || *(s + 1) == 'X') {
                base = 16;
                s += 2;
            } else {
                base = 8;
                s++;
            }
        } else {
            base = 10;
        }
    } else if (base == 16) {
        // 十六进制允许 0x 前缀
        if (*s == '0' && (*(s + 1) == 'x' || *(s + 1) == 'X'))
            s += 2;
    }

    // 第四步：转换数字
    const char* start = s;
    while (*s) {
        int digit;

        if (*s >= '0' && *s <= '9')
            digit = *s - '0';
        else if (*s >= 'a' && *s <= 'z')
            digit = *s - 'a' + 10;
        else if (*s >= 'A' && *s <= 'Z')
            digit = *s - 'A' + 10;
        else
            break;  // 遇到非法字符，停止转换

        if (digit >= base)
            break;  // 数字超出进制范围

        result = result * base + digit;
        s++;
    }

    // 第五步：设置 endptr
    if (endptr)
        *endptr = (s != start) ? (char*)s : (char*)nptr;

    return neg ? -result : result;
}
```

**这个函数做了什么？**

让我一步步解释：

1. **跳过空白**：`"  123"` → `"123"`
2. **处理符号**：`"-123"` → 负数标志 + `"123"`
3. **检测进制**：
   - `"0x1a"` → 十六进制
   - `"0123"` → 八进制
   - `"123"` → 十进制
4. **逐字符转换**：`"123"` → 1×10² + 2×10 + 3 = 123
5. **设置 endptr**：告诉调用者转换到哪里结束了

⚠️ **注意**

我们用 `(unsigned char)` 来转换，这是为了处理扩展 ASCII 字符。直接用 `char` 可能会有符号问题，导致意外行为。

## 第五步：实现 atoi 和 strtoul

有了 `strtol`，其他函数就简单多了。

在 `strhelpers.h` 中添加声明：

```c
/**
 * @brief 将字符串转换为整数（简化版）
 *
 * 相当于 strtol(nptr, NULL, 10)
 *
 * @param nptr 要转换的字符串
 * @return 转换后的整数
 */
int atoi(const char* nptr);

/**
 * @brief 将字符串转换为无符号长整数
 *
 * 与 strtol 类似，但不处理负号
 *
 * @param nptr 要转换的字符串
 * @param endptr 指向第一个未转换字符的指针（可为 NULL）
 * @param base 进制（2-36，或 0 表示自动检测）
 * @return 转换后的无符号长整数
 */
unsigned long strtoul(const char* nptr, char** endptr, int base);
```

在 `strhelpers.c` 中添加实现：

```c
int atoi(const char* nptr) {
    // 简化版：固定十进制，不检查错误
    return (int)strtol(nptr, NULL, 10);
}

unsigned long strtoul(const char* nptr, char** endptr, int base) {
    const char* s = nptr;
    unsigned long result = 0;

    // 跳过前导空白
    while (isspace((unsigned char)*s))
        s++;

    // 跳过可选的 '+' 号
    if (*s == '+')
        s++;

    // 检测进制
    if (base == 0) {
        if (*s == '0') {
            if (*(s + 1) == 'x' || *(s + 1) == 'X') {
                base = 16;
                s += 2;
            } else {
                base = 8;
                s++;
            }
        } else {
            base = 10;
        }
    } else if (base == 16) {
        if (*s == '0' && (*(s + 1) == 'x' || *(s + 1) == 'X'))
            s += 2;
    }

    // 转换数字
    const char* start = s;
    while (*s) {
        int digit;

        if (*s >= '0' && *s <= '9')
            digit = *s - '0';
        else if (*s >= 'a' && *s <= 'z')
            digit = *s - 'a' + 10;
        else if (*s >= 'A' && *s <= 'Z')
            digit = *s - 'A' + 10;
        else
            break;

        if (digit >= base)
            break;

        result = result * base + digit;
        s++;
    }

    if (endptr)
        *endptr = (s != start) ? (char*)s : (char*)nptr;

    return result;
}
```

## 第六步：实现 itoa 和 uitoa —— 整数转字符串

现在我们来做反向操作：把数字转换成字符串。这比 `strtol` 稍微复杂一点，因为我们需要处理负数和进制。

在 `strhelpers.h` 中添加声明：

```c
/**
 * @brief 将整数转换为字符串
 *
 * @param value 要转换的整数
 * @param str 存储结果的缓冲区（必须足够大）
 * @param base 进制（2-36）
 * @return 指向结果字符串的指针
 */
char* itoa(int value, char* str, int base);

/**
 * @brief 将无符号整数转换为字符串
 *
 * @param value 要转换的无符号整数
 * @param str 存储结果的缓冲区（必须足够大）
 * @param base 进制（2-36）
 * @return 指向结果字符串的指针
 */
char* uitoa(unsigned int value, char* str, int base);
```

在 `strhelpers.c` 中添加实现：

```c
char* itoa(int value, char* str, int base) {
    // 检查进制范围
    if (base < 2 || base > 36) {
        str[0] = '\0';
        return str;
    }

    int i = 0;
    int neg = 0;
    unsigned int uval;

    // 处理负数（仅十进制）
    if (value < 0 && base == 10) {
        neg = 1;
        uval = (unsigned int)(-value);
    } else {
        uval = (unsigned int)value;
    }

    // 从低位到高位生成数字
    do {
        int digit = uval % base;
        // 0-9 用 '0'-'9'，10-35 用 'a'-'z'
        str[i++] = (digit < 10) ? ('0' + digit) : ('a' + digit - 10);
        uval /= base;
    } while (uval != 0);

    // 添加负号
    if (neg)
        str[i++] = '-';

    str[i] = '\0';

    // 反转字符串
    reverse_str(str, i);

    return str;
}

char* uitoa(unsigned int value, char* str, int base) {
    // 检查进制范围
    if (base < 2 || base > 36) {
        str[0] = '\0';
        return str;
    }

    int i = 0;
    unsigned int uval = value;

    // 从低位到高位生成数字
    do {
        int digit = uval % base;
        str[i++] = (digit < 10) ? ('0' + digit) : ('a' + digit - 10);
        uval /= base;
    } while (uval != 0);

    str[i] = '\0';

    // 反转字符串
    reverse_str(str, i);

    return str;
}
```

**为什么用 `do-while` 而不是 `while`？**

好问题！如果 value 是 0，`while` 循环根本不会执行，结果就是空字符串。用 `do-while` 保证至少执行一次，0 会被正确转换为 `"0"`。

## 踩坑预警

在实现这些函数的过程中，有几个常见的陷阱：

### 坑 1：字符的符号问题

```c
// 错误写法
while (isspace(*s))  // 如果 *s 是负数，会有问题

// 正确写法
while (isspace((unsigned char)*s))
```

### 坑 2：缓冲区溢出

```c
char buf[4];
itoa(12345, buf, 10);  // 溢出！12345 有 5 位数字
```

**解决方案**：确保缓冲区足够大。对于 32 位整数，16 字节足够了（包括符号和结尾的 `\0`）。

### 坑 3：0 的特殊处理

```c
// 错误写法
while (uval != 0) {  // 如果 uval 是 0，循环不执行
    // ...
}

// 正确写法
do {
    // ...
} while (uval != 0);
```

### 坑 4：进制范围检查

```c
// 错误写法
char* itoa(int value, char* str, int base) {
    // 直接开始转换
}

// 正确写法
char* itoa(int value, char* str, int base) {
    if (base < 2 || base > 36) {
        str[0] = '\0';
        return str;
    }
    // ...
}
```
