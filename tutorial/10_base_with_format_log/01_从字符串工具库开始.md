# 从字符串工具库开始 —— Stage 10 基础库实战指南

## 前言

写到 Stage 10 的时候，我意识到一个被忽略很久的问题：我们一直在用各种字符串处理，但从来没有认真思考过这些函数到底是怎么实现的。

`atoi` 怎么把 `"123"` 变成整数 123？`strtol` 怎么处理十六进制的 `0x1a`？为什么内核里不能用标准库的 `string.h`？这些问题如果不想清楚，以后写内核调试的时候会非常痛苦。每次想打印一个变量，都不知道该怎么正确地格式化输出，这种感觉我太熟了。

所以这一篇我们会一起手把手实现一套完整的字符串工具库。别担心，我们不会跳过任何步骤，每写一个函数都会解释清楚它是怎么工作的，为什么要这么写，有哪些坑需要避开。准备好了吗？我们开始。

---

## 环境说明

在开始之前，先确认一下你的开发环境。这篇文章假设你已经完成了 Stage 09，串口输出已经能正常工作了。

```
操作系统: Ubuntu 22.04 LTS / WSL2 / Arch WSL
编译器:   GCC x86_64-elf-gcc 或类似交叉编译器
构建工具: CMake 3.25 或更高版本
模拟器:   QEMU 7.0 或更高版本
```

可能有人会问，为什么不能直接用标准库？这个问题问得好。内核环境和用户态程序有本质区别：内核是最底层的代码，它没法依赖任何外部库，`printf`、`strcpy`、`atoi` 这些我们习以为常的函数都要自己写。更麻烦的是，调试内核时经常需要输出十六进制、二进制等不同进制的数据，标准库的格式化功能不一定能满足需求。而且内核里不能抛异常，出错了就要自己处理，错误处理逻辑必须简单可靠。

听起来是要自己造轮子，但这其实是好事。因为你会真正理解这些函数是怎么工作的，出了问题知道怎么排查，而不是对着黑盒干瞪眼。

## 第二步：实现字符分类函数

我们先从最简单的开始。字符分类函数是很多字符串操作的基础，判断一个字符是数字、空白还是其他，这在解析字符串时经常用到。

创建 `kernel/base/strhelpers.h`：

```c
/**
 * @file strhelpers.h
 * @brief 字符串辅助函数声明
 * @date 2026-02-16
 */
#pragma once
#include "defines/types.h"

bool isspace(char ch);
bool isdigit(char ch);
```

现在实现这些函数。创建 `kernel/base/strhelpers.c`：

```c
#include "strhelpers.h"
#include "string.h"

bool isspace(char ch) {
    if (ch == '\0')
        return false;
    // 空白字符包括空格、制表符、换行符等
    return strchr(" \t\n\v\f\r", ch) != NULL;
}

bool isdigit(char ch) {
    // 数字字符的 ASCII 码是连续的
    return '0' <= ch && ch <= '9';
}
```

等等，`strchr` 是哪里来的？好问题。`strchr` 是我们在 Stage 08 中实现的字符串函数。如果你还没有实现，或者不想依赖它，这里有个更直接的写法：

```c
bool isspace(char ch) {
    if (ch == '\0')
        return false;
    // 直接比较，简单粗暴但有效
    return ch == ' ' || ch == '\t' || ch == '\n' ||
           ch == '\v' || ch == '\f' || ch == '\r';
}
```

两种方式都可以，看你的偏好。第一种方式代码更简洁，但依赖 `strchr` 的实现；第二种方式完全独立，但代码稍微长一点。我当时纠结了一下，最后选择了第一种，因为 `strchr` 已经有了，为什么不复用呢？不过如果你遇到奇怪的 bug，换成第二种方式试试说不定能解决问题。

## 第三步：实现字符串反转函数

接下来我们要实现 `reverse_str`，它会在后面的 `itoa` 中用到。这个函数的作用是原地反转一个字符串，比如把 `"321"` 变成 `"123"`。

你可能会问，为什么需要反转？这是因为我们把数字转换成字符串的时候，是从低位到高位生成的。比如 123，我们先得到个位的 3，然后是十位的 2，最后是百位的 1，生成的是 `"321"`，需要反转才能得到正确的 `"123"`。这个技巧非常经典，几乎所有整数转字符串的实现都会用到。

在 `strhelpers.h` 中添加声明：

```c
void reverse_str(char* str, int len);
```

在 `strhelpers.c` 中添加实现：

```c
void reverse_str(char* str, int len) {
    int i = 0, j = len - 1;
    while (i < j) {
        // 交换首尾字符，然后向中间移动
        char tmp = str[i];
        str[i] = str[j];
        str[j] = tmp;
        i++;
        j--;
    }
}
```

这个算法的时间复杂度是 O(n/2)，也就是 O(n)，空间复杂度是 O(1)，因为我们是原地操作。没啥特别的坑，只要注意边界条件就行。不过我当时写的时候差点忘了处理长度为 0 或 1 的情况，好在 while 循环的条件 `i < j` 自动处理了这种情况。

## 第四步：实现 strtol —— 字符串转整数（完整版）

现在我们来实现一个完整的字符串转整数函数。这个函数会处理很多边界情况，是理解字符串处理的好例子。`strtol` 是标准库函数，我们的实现会尽量兼容它的行为。

在 `strhelpers.h` 中添加声明：

```c
long strtol(const char* nptr, char** endptr, int base);
```

在 `strhelpers.c` 中添加实现。这个函数稍微复杂一点，我们分步骤来看：

```c
long strtol(const char* nptr, char** endptr, int base) {
    const char* s = nptr;
    long result = 0;
    bool neg = false;

    // 第一步：跳过前导空白字符
    while (isspace((unsigned char)*s))
        s++;

    // 第二步：处理正负号
    if (*s == '-') {
        neg = true;
        s++;
    } else if (*s == '+') {
        s++;
    }

    // 第三步：检测进制
    if (base == 0) {
        // 自动检测进制
        if (*s == '0') {
            if (*(s + 1) == 'x' || *(s + 1) == 'X') {
                base = 16;
                s += 2;
            } else {
                base = 8;
                s++;
            }
        } else {
            base = 10;
        }
    } else if (base == 16) {
        // 十六进制允许 0x 前缀
        if (*s == '0' && (*(s + 1) == 'x' || *(s + 1) == 'X'))
            s += 2;
    }

    // 第四步：逐字符转换
    const char* start = s;
    while (*s) {
        int digit;

        if (*s >= '0' && *s <= '9')
            digit = *s - '0';
        else if (*s >= 'a' && *s <= 'z')
            digit = *s - 'a' + 10;
        else if (*s >= 'A' && *s <= 'Z')
            digit = *s - 'A' + 10;
        else
            break;  // 遇到非法字符，停止转换

        if (digit >= base)
            break;  // 数字超出进制范围

        result = result * base + digit;
        s++;
    }

    // 第五步：设置 endptr
    if (endptr)
        *endptr = (s != start) ? (char*)s : (char*)nptr;

    return neg ? -result : result;
}
```

让我解释一下这个函数做了什么。第一步是跳过前导空白，`"  123"` 和 `"123"` 应该得到相同的结果。第二步是处理正负号，`"-123"` 应该返回负数。第三步是检测进制，`"0x1a"` 是十六进制，`"0123"` 是八进制，`"123"` 是十进制。第四步是逐字符转换，这是核心算法，用 `result = result * base + digit` 这个公式来累加。最后一步是设置 `endptr`，告诉调用者转换到哪里结束了，这个功能在解析复杂字符串时很有用。

这里有个坑要注意：我们用 `(unsigned char)` 来转换字符，这是为了处理扩展 ASCII 字符。如果 `char` 是有符号的，直接传给 `isspace` 可能会有问题。我当时在这个地方卡了半天，最后查了标准库的实现才发现问题所在。

## 第五步：实现 strtoll 和 atoi

有了 `strtol`，其他函数就简单多了。我们先补充 `strtoll`，它和 `strtol` 基本一样，只是返回类型是 `long long`：

在 `strhelpers.h` 中添加：

```c
long long strtoll(const char* nptr, char** endptr, int base);
```

在 `strhelpers.c` 中实现：

```c
long long strtoll(const char* nptr, char** endptr, int base) {
    // 直接复用 strtol 的实现，只是类型转换一下
    return (long long)strtol(nptr, endptr, base);
}
```

你可能觉得这个实现有点偷懒，但说实话，对于我们的内核环境，`long` 和 `long long` 的大小是一样的，都是 64 位。如果你需要完整支持 128 位整数，那就得重新实现一遍了。不过目前这样够用了。

接下来是 `atoi`，这是 `strtol` 的简化版本，固定十进制，不检查错误：

```c
int atoi(const char* nptr) {
    return (int)strtol(nptr, NULL, 10);
}
```

就这么简单。`atoi` 的行为在标准中其实是未定义的，如果输入不是有效数字会怎样？不同实现有不同的处理方式。我们的选择是直接返回 0，这在大多数情况下是合理的。

## 第六步：实现 itoa 和 uitoa —— 整数转字符串

现在我们来做反向操作：把数字转换成字符串。这比 `strtol` 稍微复杂一点，因为我们需要处理负数和不同进制。

在 `strhelpers.h` 中添加声明：

```c
char* itoa(int value, char* str, int base);
char* uitoa(unsigned int value, char* str, int base);
```

在 `strhelpers.c` 中添加实现：

```c
char* itoa(int value, char* str, int base) {
    // 检查进制范围
    if (base < 2 || base > 36) {
        str[0] = '\0';
        return str;
    }

    int i = 0;
    int neg = 0;
    unsigned int uval;

    // 处理负数（仅十进制）
    if (value < 0 && base == 10) {
        neg = 1;
        uval = (unsigned int)(-value);
    } else {
        uval = (unsigned int)value;
    }

    // 从低位到高位生成数字
    do {
        int digit = uval % base;
        // 0-9 用 '0'-'9'，10-35 用 'a'-'z'
        str[i++] = (digit < 10) ? ('0' + digit) : ('a' + digit - 10);
        uval /= base;
    } while (uval != 0);

    // 添加负号
    if (neg)
        str[i++] = '-';

    str[i] = '\0';

    // 反转字符串
    reverse_str(str, i);

    return str;
}
```

注意这里我们用的是 `do-while` 而不是 `while`。为什么？因为如果 value 是 0，`while` 循环根本不会执行，结果就是空字符串。用 `do-while` 保证至少执行一次，0 会被正确转换为 `"0"`。这个坑我踩过，写测试的时候发现输出是空的，排查了好久。

`uitoa` 是无符号版本，逻辑差不多，只是不需要处理负数：

```c
char* uitoa(unsigned int value, char* str, int base) {
    if (base < 2 || base > 36) {
        str[0] = '\0';
        return str;
    }

    int i = 0;
    unsigned int uval = value;

    do {
        int digit = uval % base;
        str[i++] = (digit < 10) ? ('0' + digit) : ('a' + digit - 10);
        uval /= base;
    } while (uval != 0);

    str[i] = '\0';
    reverse_str(str, i);

    return str;
}
```

## 第八步：编写测试验证功能

现在我们来测试一下这些函数是否正确工作。测试驱动开发是个好习惯，尤其是写底层库的时候。不写测试，你怎么知道代码是不是真的能跑？

创建一个测试程序，在 `kernel_main.c` 中添加测试代码：

```c
#include "kernel/base/strhelpers.h"
#include "driver/serial/serial.h"

void test_strhelpers(void) {
    char buffer[64];

    // 测试 isspace 和 isdigit
    serial_printf("=== String Helpers Test ===\n");
    serial_printf("isspace(' ') = %d\n", isspace(' '));
    serial_printf("isspace('a') = %d\n", isspace('a'));
    serial_printf("isdigit('5') = %d\n", isdigit('5'));
    serial_printf("isdigit('a') = %d\n", isdigit('a'));

    // 测试 atoi
    serial_printf("\nTesting atoi:\n");
    serial_printf("atoi(\"123\") = %d\n", atoi("123"));
    serial_printf("atoi(\"-456\") = %d\n", atoi("-456"));
    serial_printf("atoi(\"  789\") = %d\n", atoi("  789"));

    // 测试 strtol
    serial_printf("\nTesting strtol:\n");
    serial_printf("strtol(\"123\", NULL, 10) = %ld\n", strtol("123", NULL, 10));
    serial_printf("strtol(\"0xFF\", NULL, 0) = %ld\n", strtol("0xFF", NULL, 0));
    serial_printf("strtol(\"077\", NULL, 0) = %ld\n", strtol("077", NULL, 0));
    serial_printf("strtol(\"-42\", NULL, 10) = %ld\n", strtol("-42", NULL, 10));

    // 测试 itoa
    serial_printf("\nTesting itoa:\n");
    itoa(123, buffer, 10);
    serial_printf("itoa(123, 10) = \"%s\"\n", buffer);
    itoa(-456, buffer, 10);
    serial_printf("itoa(-456, 10) = \"%s\"\n", buffer);
    itoa(255, buffer, 16);
    serial_printf("itoa(255, 16) = \"%s\"\n", buffer);
    itoa(0, buffer, 10);
    serial_printf("itoa(0, 10) = \"%s\"\n", buffer);

    serial_printf("\nAll tests completed!\n");
}
```

在 `kernel_main.c` 中调用这个测试：

```c
void kernel_main(void) {
    // ... 其他初始化代码 ...

    test_strhelpers();

    // ... 其他代码 ...
}
```

## 到这里我们完成了什么

让我们回顾一下这篇文章的内容。我们实现了完整的字符串工具库，包括：

- `isspace` / `isdigit` — 字符分类函数，判断字符类型
- `reverse_str` — 字符串反转，`itoa` 的辅助函数
- `strtol` / `strtoll` / `strtoul` — 字符串转整数，支持多进制
- `atoi` — 简化版字符串转整数
- `itoa` / `uitoa` — 整数转字符串，支持多进制

这些函数是格式化输出的基础，下一篇我们会用它们来实现自己的 `printf` 函数。说实话，等到你完整实现了 `printf`，再看这些工具函数，会发现它们的价值远超想象。每一个细节都经过精心设计，每一个边界条件都有其存在的理由。
