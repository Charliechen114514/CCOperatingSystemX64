## 第一步 —— 编译验证

首先确保代码能编译通过：

```bash
# 进入项目根目录
cd /path/to/CCOperatingSystemX64

# 清理并重新构建
rm -rf build/
cmake -DCMAKE_BUILD_TYPE=Debug -B build
cmake --build build
```

你应该看到类似这样的输出：

```
-- Configuring done...
-- Generating done...
-- Build files have been written to: .../build

[ 10%] Building C object kernel/driver/vga/CMakeFiles/vga.dir/vga_helpers.c.o
[ 15%] Building C object kernel/driver/vga/gui_helper/CMakeFiles/gui_helper.dir/gui_helper.c.o

[ 80%] Linking C static library libgui_helper.a
[100%] Built target kernel.elf
```

⚠️ **常见编译错误**

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `undefined reference to vga_put_char_at` | 未链接 vga_helpers.c | 检查 CMakeLists.txt |
| `vga/vga_helpers.h: No such file` | 头文件路径错误 | 添加 `kernel/driver/vga` 到 include 路径 |
| `implicit declaration of function` | 函数未声明 | 检查头文件是否正确 include |

### 检查生成的文件

```bash
# 查看生成的文件
ls -lh build/kernel.elf build/kernel.bin build/boot.img

# 查看 kernel.elf 信息
file build/kernel.elf
# 应该显示: ELF 64-bit LSB executable, x86-64...

# 检查符号信息
nm build/kernel.elf | grep vga_put_char_at
# 应该看到符号地址
```

```bash
vncviewer localhost:5900
```

你应该能看到：
- 黑屏
- 如果欢迎界面已集成，会看到星空、Logo、动画边框

### VGA 辅助函数测试

如果不确定欢迎界面是否工作，可以写个简单测试：

```c
// 在 kernel_main.c 中临时添加测试代码
#include "driver/vga/vga.h"
#include "driver/vga/vga_helpers.h"

void kernel_main(void) {
    CCOS_VGA* vga = vga_instance();
    vga_clear(vga, VGA_COLOR_BLACK);

    // 测试 vga_put_char_at
    vga_put_char_at(vga, 0, 0, 'A', VGA_COLOR_WHITE, VGA_COLOR_BLACK);
    vga_put_char_at(vga, 1, 0, 'B', VGA_COLOR_YELLOW, VGA_COLOR_BLACK);
    vga_put_char_at(vga, 2, 0, 'C', VGA_COLOR_RED, VGA_COLOR_BLACK);

    // 测试颜色
    for (int i = 0; i < 16; i++) {
        vga_put_char_at(vga, i, 2, '0' + i, (vga_color_t)i, VGA_COLOR_BLACK);
    }

    // 延迟以便观察
    vga_delay(100000000);  // 约 2 秒

    while (1) {
        __asm__ volatile("hlt");
    }
}
```

重新构建并运行，你应该能看到：
```
ABC
0123456789:;<=>?@  (不同颜色)
```

## 第三步 —— GUI 库测试

测试 GUI 绘图函数：

```c
#include "driver/vga/gui_helper/gui_helper.h"

void test_gui(void) {
    CCOS_VGA* vga = vga_instance();
    vga_clear(vga, VGA_COLOR_BLACK);

    // 测试 1: 矩形
    vga_draw_rect(vga, 5, 5, 30, 10, VGA_COLOR_BRIGHT_CYAN);

    // 测试 2: 填充矩形
    vga_draw_fill_rect(vga, 40, 5, 20, 5, '#', VGA_COLOR_BRIGHT_GREEN, VGA_COLOR_BLACK);

    // 测试 3: 面板
    vga_panel_t panel = {
        .x = 10, .y = 18,
        .width = 40, .height = 5,
        .border_color = VGA_COLOR_YELLOW,
        .bg_color = VGA_COLOR_BLACK,
        .text_color = VGA_COLOR_WHITE,
        .title = "Test Panel"
    };
    vga_draw_panel(vga, &panel);

    // 测试 4: 居中文本
    vga_draw_text_centered(vga, 10, 20, 40, "Centered",
                          VGA_COLOR_BRIGHT_MAGENTA, VGA_COLOR_BLACK);

    // 测试 5: 进度条
    vga_draw_bar(vga, 10, 23, 40, 30, '=', VGA_COLOR_BRIGHT_GREEN, VGA_COLOR_DARK_GREY);

    vga_delay(100000000);
}
```

你应该能看到一个包含各种图形元素的测试画面。

## 第四步 —— 欢迎界面测试

### 完整欢迎界面

确保 `vga_display_welcome()` 被调用：

```c
// 在 kernel_init() 或 kernel_main() 中
#include "welcomes/vga_welcomes.h"

void kernel_init(void) {
    // 显示欢迎界面
    vga_display_welcome();

    // 延迟让用户看到动画
    vga_delay(50000000);  // 约 1-2 秒

    // 清屏准备进入主界面
    CCOS_VGA* vga = vga_instance();
    vga_clear(vga, VGA_COLOR_BLACK);
}
```

### 预期效果

1. **星空背景** —— 100 个随机分布的星点
2. **彩色边框** —— 颜色从青蓝流动到绿色
3. **Logo** —— CCOS ASCII Art
4. **系统名称** —— "CCOperating System X64"
5. **版本信息** —— "Version 0.1.0 [Alpha]"

### 动画问题排查

如果动画不流畅：

```c
// 增加延迟
for (int i = 0; i < num_colors; i++) {
    // ... 绘制代码
    vga_delay(1000000);  // 每帧后延迟
}
```

或者减少循环次数：

```c
for (int cycle = 0; cycle < 3; cycle++)  // 改为 1
```

## 常见问题排查

### 问题 1：VGA 屏幕全黑

**诊断**：

```bash
# 检查 VGA 是否初始化
# 在 VSCode 中设置断点在 vga_display_welcome
# 单步执行，看是否到达

# 检查显存地址
(gdb) print/x vga_instance()->base_addr
# 应该是 0xb8000
```

**解决方案**：
- 确保 `system_vga_init()` 被调用
- 确保 `vga_display_welcome()` 被调用

### 问题 2：动画无效果

**原因**：延迟太短或代码被优化

**解决方案**：
```c
// 使用 volatile 防止优化
volatile uint32_t delay = 10000000;
while (delay--) {
    __asm__ volatile("nop");
}
```

### 问题 3：VSCode 无法连接

**诊断**：

```bash
# 检查端口
lsof -i:1234

# 检查 QEMU 状态
./scripts/launch_qemu_for_vscode_debug.sh --status
```

**解决方案**：
- 确保 QEMU 正在运行
- 确保 `launch.json` 配置正确
- 检查防火墙设置

### 问题 4：QEMU 没有自动停止

**原因**：监控进程意外终止

**解决方案**：

```bash
# 手动停止
./scripts/launch_qemu_for_vscode_debug.sh --stop

# 或强制杀死
killall qemu-system-x86_64
```
