## 第二步 —— 设计 ASCII Art Logo

ASCII Art 是用字符组成的图形。我们来设计一个 CCOS 的 Logo：

```
  _____  _____ _____    ___
 /  _  \/  ___//  __ \  /   |
 | | | |\ `--.| /  \/ / /| |
 | | | | `--. \ |    / /_| |
 | |_| |/\__/ / \__/\____  |
  \___/ \____/ \____/    |_|
```

这个设计技巧是：
- 使用 `/` `\` `|` `_` `(` `)` 等字符构建线条
- 保持等宽对齐
- 总宽度 30 字符，可以在 80 字符屏幕上居中

### 定义 Logo 数组

```bash
cat > kernel/welcomes/vga_welcomes.c << 'EOF_PART1'
/**
 * @file vga_welcomes.c
 * @author Charliechen114514
 * @brief Boot Welcome with VGA graphics
 * @version 0.1
 * @date 2026-02-16
 */
#include "ccos_config.h"
#include "driver/vga/vga.h"
#include "driver/vga/vga_helpers.h"

// ==================== ASCII Art Logo ====================

static const char* CCOS_LOGO[] = {
    "  _____  _____ _____    ___    ",
    " /  _  \\/  ___//  __ \\  /   |   ",
    " | | | |\\ `--.| /  \\/ / /| |   ",
    " | | | | `--. \\ |    / /_| |   ",
    " | |_| |/\\__/ / \\__/\\____  |   ",
    "  \\___/ \\____/ \\____/    |_|   "
};

static const char* CCOS_NAME = "CCOperating System X64";
EOF_PART1
```

注意字符串中的转义：`\\` 表示一个反斜杠字符。

## 第三步 —— 实现星空背景

星空背景是在指定区域内随机画一些星点（`*` `.` `+` `'` `^` 等字符）。

```bash
cat >> kernel/welcomes/vga_welcomes.c << 'EOF_PART2'

// ==================== Starfield Background ====================

static void draw_starfield(CCOS_VGA* vga, vga_sz_t start_x, vga_sz_t start_y,
                           vga_sz_t width, vga_sz_t height) {
    const char stars[] = {'*', '.', '+', '\'', '^'};

    for (int i = 0; i < 100; i++) {
        // Use pseudo-random positions based on index
        vga_sz_t x = start_x + (vga_sz_t)(i * 73) % width;
        vga_sz_t y = start_y + (vga_sz_t)(i * 137) % height;
        char star = stars[(i / 20) % 5];
        vga_color_t color = (vga_color_t)(VGA_COLOR_WHITE - (i % 4));
        vga_put_char_at(vga, x, y, star, color, VGA_COLOR_BLACK);
    }
}
EOF_PART2
```

这里的"随机"其实是伪随机：
- `i * 73 % width` —— 水平位置
- `i * 137 % height` —— 垂直位置
- 73 和 137 是质数，能让分布更均匀

⚠️ **关于颜色**
`VGA_COLOR_WHITE - (i % 4)` 会让星星有不同亮度（白、亮白、灰、暗灰）。

## 第四步 —— 实现彩色动画边框

这是最精彩的部分 —— 边框颜色会循环流动！

```bash
cat >> kernel/welcomes/vga_welcomes.c << 'EOF_PART3'

// ==================== Animated Border ====================

static void draw_animated_border(CCOS_VGA* vga) {
    // Color cycle: Cyan -> Blue -> Magenta -> Red -> Yellow -> Green
    vga_color_t colors[] = {
        VGA_COLOR_BRIGHT_CYAN, VGA_COLOR_BRIGHT_BLUE, VGA_COLOR_BRIGHT_MAGENTA,
        VGA_COLOR_BRIGHT_RED, VGA_COLOR_YELLOW, VGA_COLOR_BRIGHT_GREEN
    };
    int num_colors = 6;

    vga_sz_t x = 5, y = 3;
    vga_sz_t width = 70, height = 19;

    // Animate the border colors cycling
    for (int cycle = 0; cycle < 3; cycle++) {           // 3 complete cycles
        for (int i = 0; i < num_colors; i++) {           // Color rotation
            // Draw top and bottom borders
            for (vga_sz_t col = 0; col < width; col++) {
                vga_color_t color = colors[(i + col / 5) % num_colors];

                // Top border
                vga_put_char_at(vga, x + col, y, '=', color, VGA_COLOR_BLACK);
                // Bottom border
                vga_put_char_at(vga, x + col, y + height - 1, '=',
                               color, VGA_COLOR_BLACK);
            }

            // Draw left and right borders
            for (vga_sz_t row = 0; row < height; row++) {
                vga_color_t color = colors[(i + row / 2) % num_colors];

                // Left border
                vga_put_char_at(vga, x, y + row, '|', color, VGA_COLOR_BLACK);
                // Right border
                vga_put_char_at(vga, x + width - 1, y + row, '|',
                               color, VGA_COLOR_BLACK);
            }

            // Draw corners
            vga_put_char_at(vga, x, y, '+', VGA_COLOR_WHITE, VGA_COLOR_BLACK);
            vga_put_char_at(vga, x + width - 1, y, '+', VGA_COLOR_WHITE,
                           VGA_COLOR_BLACK);
            vga_put_char_at(vga, x, y + height - 1, '+', VGA_COLOR_WHITE,
                           VGA_COLOR_BLACK);
            vga_put_char_at(vga, x + width - 1, y + height - 1, '+',
                           VGA_COLOR_WHITE, VGA_COLOR_BLACK);
        }
    }
}
EOF_PART3
```

### 动画原理解析

颜色流动效果是通过偏移量实现的：

```c
vga_color_t color = colors[(i + col / 5) % num_colors];
```

- `i` 是当前颜色循环索引（0-5）
- `col / 5` 是位置偏移（每 5 个字符换一个颜色）
- `% num_colors` 确保索引在数组范围内

效果：颜色从左到右"流动"过去。

## 第五步 —— 实现打字机文本效果

打字机效果是逐字符显示文本，看起来像有人在打字。

```bash
cat >> kernel/welcomes/vga_welcomes.c << 'EOF_PART4'

// ==================== Typewriter Effect ====================

static void typewriter_print(CCOS_VGA* vga, vga_sz_t x, vga_sz_t y,
                             const char* text, vga_color_t color) {
    set_vga_property(vga, &color, CURSOR_FONT_COLOR);

    for (int i = 0; text[i] != '\0'; i++) {
        vga_put_char_at(vga, x + i, y, text[i], color, VGA_COLOR_BLACK);
        // Optional: Add delay for each character
        // vga_delay(100000);
    }
}
EOF_PART4
```

如果想要更慢的打字效果，取消注释 `vga_delay(100000)`。

## 第六步 —— 组装完整欢迎界面

现在把所有效果组合起来：

```bash
cat >> kernel/welcomes/vga_welcomes.c << 'EOF_PART5'

// ==================== Main Welcome Screen ====================

void vga_display_welcome(void) {
    CCOS_VGA* vga_ins = vga_instance();

    // Start with black screen
    vga_clear(vga_ins, VGA_COLOR_BLACK);

    // Draw starfield background
    draw_starfield(vga_ins, 5, 3, 70, 19);

    // Draw animated border
    draw_animated_border(vga_ins);

    // Draw CCOS Logo
    vga_sz_t logo_start_x = (80 - 30) / 2;  // Center horizontally
    vga_sz_t logo_start_y = 6;
    vga_color_t logo_color = VGA_COLOR_BRIGHT_CYAN;
    set_vga_property(vga_ins, &logo_color, CURSOR_FONT_COLOR);

    for (int i = 0; i < 6; i++) {
        vga_set_cursor(vga_ins, logo_start_x, logo_start_y + i);
        vga_print_string(vga_ins, CCOS_LOGO[i]);
    }

    // Draw system name with typewriter effect
    vga_sz_t name_x = (80 - 24) / 2;  // Center "CCOperating System X64"
    typewriter_print(vga_ins, name_x, 13, CCOS_NAME, VGA_COLOR_YELLOW);

    // Draw version info
    vga_sz_t ver_x = (80 - 20) / 2;
    vga_set_cursor(vga_ins, ver_x, 15);
    vga_color_t ver_color = VGA_COLOR_BRIGHT_GREEN;
    set_vga_property(vga_ins, &ver_color, CURSOR_FONT_COLOR);
    vga_print_string(vga_ins, "Version " CCOS_VERSION " [Alpha]");
}
EOF_PART5
```

找到你的内核初始化代码（可能是 `kernel_main.c` 或 `kernel_init.c`），添加欢迎界面调用：

```c

void kernel_init(void) {
    CCOS_VGA* vga = vga_instance();

    // 显示欢迎界面
    vga_display_welcome();

    // 延迟一会儿让用户看到动画
```

## 常见问题

### 问题 1：动画太快看不清

**解决**：增加延迟

```c
// 在 draw_animated_border 中添加
for (int i = 0; i < num_colors; i++) {
    // ... 绘制代码
    vga_delay(1000000);  // 每个颜色循环后延迟
}
```

### 问题 2：Logo 显示错位

**原因**：字符串中包含转义字符

**检查**：
```c
// 错误
"  _____  _____ _____    ___    "

// 正确（注意反斜杠转义）
"  _____  _____ _____    ___    "
```

### 问题 3：星空不显示

**原因**：星空被边框覆盖

**解决**：先画星空，后画边框（顺序很重要）

```c
// 正确顺序
draw_starfield(...);   // 先画背景
draw_animated_border(...);  // 后画边框
```

## 动画性能优化

如果动画太慢，可以：

1. **减少循环次数**：
```c
for (int cycle = 0; cycle < 3; cycle++)  // 改为 1
```

2. **减少星星数量**：
```c
for (int i = 0; i < 100; i++)  // 改为 50
```

3. **减少颜色变化**：
```c
vga_color_t color = colors[(i + col / 10) % num_colors];  // 改为 /10
```
