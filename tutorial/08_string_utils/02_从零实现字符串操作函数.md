# 从零实现字符串操作函数

好了，废话不多说，让我们开始写代码。

今天我们要实现的是字符串操作中最基础的四个函数：
- `strlen` - 计算字符串长度
- `strnlen` - 有长度限制的字符串长度计算
- `strcpy` - 字符串复制
- `strncpy` - 有长度限制的字符串复制

这些函数虽然看起来简单，但它们是所有字符串操作的基础。

---

## 第一步：创建目录和头文件

首先，我们需要一个地方来放字符串函数。按照项目的组织结构，我们把它们放在 `kernel/base/` 目录下。

```bash
# 创建 base 目录
mkdir -p kernel/base

# 创建头文件和源文件
touch kernel/base/string.h
touch kernel/base/string.c
```

让我们先写头文件 `kernel/base/string.h`：

```c
/**
 * @file string.h
 * @brief Basic C-style string utility function declarations.
 *
 * This header provides common string manipulation functions for a
 * freestanding kernel environment.
 *
 * @note This is NOT the standard <string.h> - we implement everything
 *       ourselves because we're in a freestanding environment.
 */
#pragma once

#include "defines/types.h"

/* ================= Basic string operations ================= */

/**
 * @brief Compute the length of a null-terminated string.
 *
 * Counts the number of characters in the string before the first
 * null terminator.
 *
 * @param s Pointer to the input string.
 * @return Length of the string (excluding the null terminator).
 */
size_t strlen(const char* s);

/**
 * @brief Compute the length of a string with a maximum bound.
 *
 * Counts at most @p maxlen characters and stops early if a null
 * terminator is encountered.
 *
 * @param s Pointer to the input string.
 * @param maxlen Maximum number of characters to examine.
 * @return Length of the string up to @p maxlen.
 */
size_t strnlen(const char* s, size_t maxlen);

/**
 * @brief Copy a null-terminated string.
 *
 * Copies the string pointed to by @p src (including the null
 * terminator) into @p dest.
 *
 * @warning The destination buffer must be large enough!
 *
 * @param dest Destination buffer.
 * @param src Source string.
 * @return Pointer to @p dest.
 */
char* strcpy(char* dest, const char* src);

/**
 * @brief Copy a string with length limit.
 *
 * Copies at most @p n characters from @p src into @p dest.
 * If @p src is shorter than @p n, the remainder of @p dest
 * is padded with null bytes.
 *
 * @warning If @p src length >= @p n, the result is NOT null-terminated!
 *
 * @param dest Destination buffer.
 * @param src Source string.
 * @param n Maximum number of characters to copy.
 * @return Pointer to @p dest.
 */
char* strncpy(char* dest, const char* src, size_t n);
```

⚠️ **注意**

头文件里我们用了 `#pragma once` 而不是传统的 include guard。这两种方式功能相同，但 `#pragma once` 更简洁。不过要注意，不是所有编译器都支持（GCC 和 Clang 都支持）。

## 第二步：实现 strlen

`strlen` 是最简单的字符串函数 —— 它就是数数，数到第一个 `'\0'` 为止。

```c
/* 在 kernel/base/string.c 中 */

#include "string.h"

size_t strlen(const char* s)
{
    size_t len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}
```

就这么简单。但等等，我们还能优化一下：

```c
size_t strlen(const char* s)
{
    const char* p = s;
    while (*p != '\0') {
        p++;
    }
    return p - s;
}
```

这个版本用指针运算代替了索引，可能稍微快一点（因为避免了索引计算）。不过现代编译器通常会把这两种形式优化成相同的汇编代码。

**让我们验证一下逻辑**：

```
字符串: "hello\0"
         ^
         s = p

第一步: *p = 'h' != '\0' -> p++
       "hello\0"
            ^
            s        p

第二步: *p = 'e' != '\0' -> p++
       "hello\0"
             ^
            s         p

... 依此类推 ...

第五步: *p = 'o' != '\0' -> p++
       "hello\0"
               ^
            s          p

第六步: *p = '\0' -> 退出循环

返回: p - s = 5
```

完美！

## 第三步：实现 strnlen

`strnlen` 是 `strlen` 的安全版本 —— 它不会读取超过 `maxlen` 个字符。

```c
size_t strnlen(const char* s, size_t maxlen)
{
    size_t len = 0;
    while (len < maxlen && s[len] != '\0') {
        len++;
    }
    return len;
}
```

⚠️ **为什么要用 strnlen？**

想象一下这个场景：

```c
// 危险！如果字符串不是以 '\0' 结尾会怎样？
size_t len = strlen(some_unknown_string);

// 安全！最多只检查 100 个字符
size_t safe_len = strnlen(some_unknown_string, 100);
```

在处理不可信的输入时，`strnlen` 是你的好朋友。

## 第四步：实现 strcpy

`strcpy` 把一个字符串复制到另一个位置：

```c
char* strcpy(char* dest, const char* src)
{
    char* orig_dest = dest;
    while ((*dest++ = *src++) != '\0') {
        // 空循环体 - 所有工作都在条件里完成
    }
    return orig_dest;
}
```

这个实现用了 C 语言的几个技巧，让我们拆解一下：

**1. 条件赋值表达式**

```c
while ((*dest++ = *src++) != '\0')
```

这行代码做了三件事：
1. 把 `*src` 复制到 `*dest`
2. 递增 `dest` 指针
3. 递增 `src` 指针
4. 检查复制的字符是否是 `'\0'`

**2. 返回原始指针**

```c
char* orig_dest = dest;
// ... 复制操作 ...
return orig_dest;
```

这是 C 标准库的惯例 —— 返回目标指针，方便链式调用：

```c
char buf[100];
strcpy(buf, "Hello ");
strcpy(buf, "World");  // buf 现在是 "World"
```

⚠️ **注意缓冲区溢出！**

`strcpy` 是一个危险的函数，因为它不检查目标缓冲区的大小：

```c
char small[5];
strcpy(small, "Hello, World!");  // 💥 缓冲区溢出！
```

在后续阶段，我们可能会实现更安全的 `strlcpy` 函数。

## 第五步：实现 strncpy

`strncpy` 是 `strcpy` 的带长度限制版本：

```c
char* strncpy(char* dest, const char* src, size_t n)
{
    char* orig_dest = dest;
    size_t i;

    // 复制字符，直到遇到 '\0' 或复制了 n 个字符
    for (i = 0; i < n && src[i] != '\0'; i++) {
        dest[i] = src[i];
    }

    // 如果还没复制够 n 个字符，用 '\0' 填充剩余空间
    for (; i < n; i++) {
        dest[i] = '\0';
    }

    return orig_dest;
}
```

⚠️ **strncpy 的陷阱**

`strncpy` 有一个非常危险的特性：

```c
char buf[5];
strncpy(buf, "Hello, World!", 5);

// buf 现在是: "Hello" （没有 '\0' 结尾！）
```

如果源字符串长度 >= `n`，结果**不会**以 `'\0'` 结尾！这会导致后续的字符串操作出错。

**正确用法**：

```c
char buf[5];
strncpy(buf, "Hello, World!", sizeof(buf) - 1);
buf[sizeof(buf) - 1] = '\0';  // 手动添加结尾
```

这就是为什么很多现代代码库推荐使用 `strlcpy`（可惜它不是标准 C 函数）。

## 完整的 string.c 文件

把所有代码放在一起：

```c
/**
 * @file string.c
 * @brief Basic C-style string utility function implementations.
 */

#include "string.h"

size_t strlen(const char* s)
{
    const char* p = s;
    while (*p != '\0') {
        p++;
    }
    return p - s;
}

size_t strnlen(const char* s, size_t maxlen)
{
    size_t len = 0;
    while (len < maxlen && s[len] != '\0') {
        len++;
    }
    return len;
}

char* strcpy(char* dest, const char* src)
{
    char* orig_dest = dest;
    while ((*dest++ = *src++) != '\0') {
        // 空循环体
    }
    return orig_dest;
}

char* strncpy(char* dest, const char* src, size_t n)
{
    char* orig_dest = dest;
    size_t i;

    for (i = 0; i < n && src[i] != '\0'; i++) {
        dest[i] = src[i];
    }

    for (; i < n; i++) {
        dest[i] = '\0';
    }

    return orig_dest;
}
```

## 验证

现在我们想验证这些函数是否正确工作。但在内核环境里调试不太方便，所以我们先在主机环境测试。

创建一个简单的测试程序：

```c
/* 在项目根目录创建 test_strlen.c */

#include <stdio.h>
#include <stddef.h>

// 我们的函数实现
size_t strlen(const char* s)
{
    const char* p = s;
    while (*p != '\0') {
        p++;
    }
    return p - s;
}

size_t strnlen(const char* s, size_t maxlen)
{
    size_t len = 0;
    while (len < maxlen && s[len] != '\0') {
        len++;
    }
    return len;
}

char* strcpy(char* dest, const char* src)
{
    char* orig_dest = dest;
    while ((*dest++ = *src++) != '\0') {}
    return orig_dest;
}

char* strncpy(char* dest, const char* src, size_t n)
{
    char* orig_dest = dest;
    size_t i;

    for (i = 0; i < n && src[i] != '\0'; i++) {
        dest[i] = src[i];
    }

    for (; i < n; i++) {
        dest[i] = '\0';
    }

    return orig_dest;
}

// 测试代码
int main(void)
{
    printf("=== Testing strlen ===\n");
    printf("strlen(\"\") = %zu (expected: 0)\n", strlen(""));
    printf("strlen(\"hello\") = %zu (expected: 5)\n", strlen("hello"));
    printf("strlen(\"hello world\") = %zu (expected: 11)\n", strlen("hello world"));

    printf("\n=== Testing strnlen ===\n");
    printf("strnlen(\"hello\", 10) = %zu (expected: 5)\n", strnlen("hello", 10));
    printf("strnlen(\"hello\", 3) = %zu (expected: 3)\n", strnlen("hello", 3));

    printf("\n=== Testing strcpy ===\n");
    char buf1[20];
    strcpy(buf1, "test");
    printf("strcpy result: \"%s\" (expected: \"test\")\n", buf1);

    printf("\n=== Testing strncpy ===\n");
    char buf2[20];
    strncpy(buf2, "hello", sizeof(buf2));
    buf2[19] = '\0';  // 确保结尾
    printf("strncpy result: \"%s\" (expected: \"hello\")\n", buf2);

    return 0;
}
```

编译运行：

```bash
gcc -o test_strlen test_strlen.c
./test_strlen
```

预期输出：

```
=== Testing strlen ===
strlen("") = 0 (expected: 0)
strlen("hello") = 5 (expected: 5)
strlen("hello world") = 11 (expected: 11)

=== Testing strnlen ===
strnlen("hello", 10) = 5 (expected: 5)
strnlen("hello", 3) = 3 (expected: 3)

=== Testing strcpy ===
strcpy result: "test" (expected: "test")

=== Testing strncpy ===
strncpy result: "hello" (expected: "hello")
```

如果所有测试都通过了，恭喜你！基础的字符串操作函数已经完成了。
