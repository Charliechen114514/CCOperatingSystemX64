# 实现字符串比较函数 —— strcmp、strncmp、strcasecmp、strncasecmp

上一篇我们实现了基础的字符串操作函数，现在该轮到比较功能了。字符串比较看似简单，但有几个细节需要注意：大小写敏感 vs 忽略大小写、比较长度的限制、返回值的含义。而且我们还会实现一个巧妙的 `tolower` 函数，用位运算来处理大小写转换。

## 第一步：理解字符串比较的语义

C 标准库的字符串比较函数有一个特殊的约定，这个约定很多人容易搞错。`strcmp` 返回的不是简单的 0 或 1，而是一个有符号整数：负数表示第一个字符串小于第二个，0 表示相等，正数表示第一个字符串大于第二个。

具体来说，返回值通常是第一个不匹配字符的差值。比如 `strcmp("abc", "abd")` 会返回 `-1`（因为 `'c' - 'd' = -1`），而 `strcmp("abd", "abc")` 会返回 `1`。这个设计很巧妙，因为它不仅告诉你两个字符串是否相等，还告诉你它们"差多少"。

## 第二步：实现 strcmp

`strcmp` 的实现很直观 —— 逐个字符比较，直到找到不同的字符或遇到字符串结尾。

```c
int strcmp(const char* s1, const char* s2) {
    CCOS_DEBUG_ASSERT(s1 && s2);

    while (*s1 && (*s1 == *s2)) {
        s1++;
        s2++;
    }

    return (unsigned char)*s1 - (unsigned char)*s2;
}
```

让我们走一遍这个算法。假设比较 `"abc"` 和 `"abd"`：第一次循环 `'a' == 'a'`，继续；第二次循环 `'b' == 'b'`，继续；第三次循环 `'c' != 'd'`，退出；返回 `'c' - 'd' = -1`。完美。

这里有个重要的细节：返回值用的是 `unsigned char` 转换。这是因为在某些平台上 `char` 是有符号的，如果直接用 `char` 相减，负数结果可能不正确。用 `unsigned char` 确保了结果是正确的。

## 第三步：实现 strncmp

`strncmp` 是 `strcmp` 的带长度限制版本。它的逻辑和 `strcmp` 类似，但只比较前 `n` 个字符。

```c
int strncmp(const char* s1, const char* s2, size_t n) {
    CCOS_DEBUG_ASSERT(s1 && s2);

    for (; n && *s1 && (*s1 == *s2); --n, ++s1, ++s2)
        ;

    if (n == 0)
        return 0;

    return (unsigned char)*s1 - (unsigned char)*s2;
}
```

这个实现用一个 for 循环来处理计数。注意循环体是空的，所有的逻辑都在循环条件里。如果你不习惯这种写法，也可以改成 while 循环，但 for 循环更简洁。

这里的 `n` 是剩余的比较次数。每次循环都减一，当 `n` 变成 0 时，说明已经比较了 `n` 个字符，不管字符串是否相等都返回 0。

## 第四步：实现 tolower

为了实现忽略大小写的比较，我们需要先实现大小写转换。最直观的写法是这样：

```c
char tolower(char c) {
    if (c >= 'A' && c <= 'Z') {
        return c + ('a' - 'A');
    }
    return c;
}
```

这个实现没问题，但我们可以用一种更巧妙的方式。在 ASCII 码中，大写字母和小写字母的二进制表示只有一个位不同：第 5 位（从 0 开始计数）。具体来说，大写字母的 ASCII 码是 `01000001` ('A') 到 `01011010` ('Z')，小写字母是 `01100001` ('a') 到 `01111010` ('z')。它们的区别就是第 5 位。

所以我们可以用位运算来转换：

```c
char tolower(char c) {
    if ((unsigned)(c - 'A') <= ('Z' - 'A'))
        c |= 0x20;
    return c;
}
```

这个实现用了一个技巧：`(unsigned)(c - 'A') <= ('Z' - 'A')` 等价于 `c >= 'A' && c <= 'Z'`，但只需要一次比较。`c |= 0x20` 则是把第 5 位设置为 1，从而把大写字母变成小写字母。

这种写法虽然看起来有点"花哨"，但它在编译后通常会比条件判断更快。而且，一旦你理解了这个技巧，代码反而更简洁。

## 第五步：实现 strcasecmp

`strcasecmp` 是忽略大小写的字符串比较。它的逻辑和 `strcmp` 类似，但比较前先把字符转换成小写。

```c
int strcasecmp(const char* s1, const char* s2) {
    CCOS_DEBUG_ASSERT(s1 && s2);

    while (*s1 && *s2) {
        char c1 = tolower(*s1);
        char c2 = tolower(*s2);

        if (c1 != c2)
            return (unsigned char)c1 - (unsigned char)c2;

        ++s1;
        ++s2;
    }

    return (unsigned char)tolower(*s1) - (unsigned char)tolower(*s2);
}
```

这里我们每次比较都调用 `tolower`，这看起来有点浪费。但问题是，我们不能直接比较 `*s1` 和 `*s2`，因为它们的字母可能大小写不同。而且，我们不能预先把整个字符串转换成小写，因为那需要额外的内存。

实际使用中，这个函数的性能通常不是问题。如果你发现它成为了性能瓶颈，可以考虑优化：比如先检查两个字符是否相等，如果相等就不用转换了。

## 第六步：实现 strncasecmp

带长度限制的忽略大小写比较。它的逻辑和 `strcasecmp` 类似，但只比较前 `n` 个字符。

```c
int strncasecmp(const char* s1, const char* s2, size_t n) {
    CCOS_DEBUG_ASSERT(s1 && s2);

    for (; n; --n, ++s1, ++s2) {
        char c1 = tolower(*s1);
        char c2 = tolower(*s2);

        if (c1 != c2)
            return (unsigned char)c1 - (unsigned char)c2;

        if (c1 == '\0')
            return 0;
    }

    return 0;
}
```

这个实现和 `strcasecmp` 类似，但多了一个计数器 `n`。每次循环都减一，当 `n` 变成 0 时返回 0。

注意这里有个额外的检查：`if (c1 == '\0') return 0`。这是因为当我们已经比较到字符串末尾时，即使还有剩余的比较次数，也应该提前结束。否则可能会访问到不属于我们的内存。

## 验证和使用

创建一个测试程序验证这些函数：

```c
int main(void) {
    printf("Testing strcmp...\n");
    printf("strcmp(\"abc\", \"abc\") = %d (expected: 0)\n", strcmp("abc", "abc"));
    printf("strcmp(\"abc\", \"abd\") = %d (expected: negative)\n", strcmp("abc", "abd"));

    printf("\nTesting strcasecmp...\n");
    printf("strcasecmp(\"abc\", \"ABC\") = %d (expected: 0)\n", strcasecmp("abc", "ABC"));
    printf("strcasecmp(\"Hello\", \"HELLO\") = %d (expected: 0)\n", strcasecmp("Hello", "HELLO"));

    return 0;
}
```

编译运行，如果所有测试都通过了，说明我们的实现是正确的。

这些字符串比较函数在内核开发中非常有用。比如你可以用它们来比较命令名称、匹配设备名、处理配置项等等。而且，因为我们实现的版本和标准 C 库兼容，所以你也可以直接把很多现成的代码拿过来用。
