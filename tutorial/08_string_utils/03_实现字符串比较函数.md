# 实现字符串比较函数

上一篇我们实现了基础的字符串操作函数，现在该轮到比较功能了。

字符串比较看似简单，但有几个细节需要注意：
- 大小写敏感 vs 忽略大小写
- 比较长度的限制
- 返回值的含义

让我们一个一个来实现。

---

## 第一步：理解字符串比较的语义

C 标准库的字符串比较函数有一个特殊的约定：

```c
int strcmp(const char* s1, const char* s2);
```

返回值的含义：
- **负数**：`s1` < `s2`（按字典序）
- **0**：`s1` == `s2`
- **正数**：`s1` > `s2`

具体来说，返回值通常是第一个不匹配字符的差值：

```c
strcmp("abc", "abd")  // 返回 -1 (因为 'c' - 'd' = -1)
strcmp("abd", "abc")  // 返回 1  (因为 'd' - 'c' = 1)
strcmp("abc", "abc")  // 返回 0
```

## 第二步：更新头文件

首先，在 `kernel/base/string.h` 中添加函数声明：

```c
/* ================= String comparison ================= */

/**
 * @brief Compare two strings lexicographically.
 *
 * @param s1 First string.
 * @param s2 Second string.
 * @return An integer less than, equal to, or greater than zero
 *         if @p s1 is found, respectively, to be less than,
 *         to match, or be greater than @p s2.
 */
int strcmp(const char* s1, const char* s2);

/**
 * @brief Compare two strings up to a maximum length.
 *
 * @param s1 First string.
 * @param s2 Second string.
 * @param n Maximum number of characters to compare.
 * @return Comparison result as in strcmp.
 */
int strncmp(const char* s1, const char* s2, size_t n);

/**
 * @brief Compare two strings ignoring case.
 *
 * @param s1 First string.
 * @param s2 Second string.
 * @return Comparison result ignoring character case.
 */
int strcasecmp(const char* s1, const char* s2);

/**
 * @brief Compare two strings ignoring case with length limit.
 *
 * @param s1 First string.
 * @param s2 Second string.
 * @param n Maximum number of characters to compare.
 * @return Comparison result ignoring case up to @p n characters.
 */
int strncasecmp(const char* s1, const char* s2, size_t n);

/**
 * @brief Convert a character to lowercase.
 *
 * @param c Character to convert.
 * @return Lowercase version of @p c, or original if not uppercase.
 */
char tolower(char c);
```

## 第三步：实现 strcmp

`strcmp` 的实现很直观 —— 逐个字符比较，直到找到不同的字符或遇到字符串结尾：

```c
/* 在 kernel/base/string.c 中添加 */

int strcmp(const char* s1, const char* s2)
{
    while (*s1 && (*s1 == *s2)) {
        s1++;
        s2++;
    }
    return *(unsigned char*)s1 - *(unsigned char*)s2;
}
```

**让我们理解一下这个实现**：

```c
// 假设比较 "abc" 和 "abd"
//
// 初始状态: s1 = "abc", s2 = "abd"
//
// 第一次循环:
//   *s1 = 'a' (非 '\0')
//   *s1 == *s2? 'a' == 'a'? 是
//   s1++, s2++
//
// 第二次循环:
//   *s1 = 'b', *s2 = 'b'
//   相等，继续
//
// 第三次循环:
//   *s1 = 'c', *s2 = 'd'
//   *s1 == *s2? 'c' == 'd'? 否
//   退出循环
//
// 返回: 'c' - 'd' = -1
```

⚠️ **为什么要用 (unsigned char*)？**

这是一个重要的细节。C 标准规定 `strcmp` 的返回值必须是 `unsigned char` 的差值。如果直接用 `char`，在某些平台上 `char` 是有符号的，会导致负数结果不正确。

## 第四步：实现 strncmp

`strncmp` 是 `strcmp` 的带长度限制版本：

```c
int strncmp(const char* s1, const char* s2, size_t n)
{
    while (n > 0 && *s1 && (*s1 == *s2)) {
        s1++;
        s2++;
        n--;
    }
    if (n == 0) {
        return 0;  // 比较了 n 个字符都相等
    }
    return *(unsigned char*)s1 - *(unsigned char*)s2;
}
```

**边界情况检查**：

```c
strncmp("abc", "abc", 5)    // 返回 0 (字符串相等)
strncmp("abc", "abc", 3)    // 返回 0 (前 3 个字符相等)
strncmp("abc", "abd", 2)    // 返回 0 (前 2 个字符相等)
strncmp("abc", "abd", 3)    // 返回 -1 (第 3 个字符不等)
```

## 第五步：实现 tolower

为了实现忽略大小写的比较，我们需要先实现大小写转换：

```c
char tolower(char c)
{
    if (c >= 'A' && c <= 'Z') {
        return c + ('a' - 'A');
    }
    return c;
}
```

**ASCII 码分析**：

```
'A' = 65 (0x41)
'a' = 97 (0x61)

差值: 97 - 65 = 32 (0x20)

所以：
'A' + 32 = 'a'
'B' + 32 = 'b'
...
'Z' + 32 = 'z'
```

⚠️ **注意**

这个实现只适用于 ASCII 字符。对于完整的 Unicode 支持，需要更复杂的实现。但在内核开发阶段，ASCII 已经足够了。

## 第六步：实现 strcasecmp

`strcasecmp` 是忽略大小写的字符串比较：

```c
int strcasecmp(const char* s1, const char* s2)
{
    while (*s1 && (tolower(*s1) == tolower(*s2))) {
        s1++;
        s2++;
    }
    return tolower((unsigned char)*s1) - tolower((unsigned char)*s2);
}
```

**测试用例**：

```c
strcasecmp("abc", "ABC")     // 返回 0
strcasecmp("abc", "abd")     // 返回 -1
strcasecmp("Hello", "HELLO") // 返回 0
strcasecmp("abc", "ABCd")    // 返回 -1
```

## 性能分析

这些字符串比较函数的时间复杂度：

| 函数 | 时间复杂度 | 说明 |
|------|-----------|------|
| `strcmp` | O(n) | n 是较短字符串的长度 |
| `strncmp` | O(min(n, len)) | n 是限制长度 |
| `strcasecmp` | O(n) | 需要转换字符 |
| `strncasecmp` | O(min(n, len)) | 同上 |

**提前退出优化**：

注意到我们的实现会在发现不匹配时立即返回：

```c
while (*s1 && (*s1 == *s2)) {
    s1++;
    s2++;
}
// 第一个不匹配的字符就退出
return *(unsigned char*)s1 - *(unsigned char*)s2;
```

这意味着对于大部分不同的字符串，比较会很快结束。
