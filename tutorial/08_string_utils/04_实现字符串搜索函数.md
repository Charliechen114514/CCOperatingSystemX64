# 实现字符串搜索函数 —— strchr、strrchr、strstr、strpbrk、strspn、strcspn

之前我们实现了字符串的基本操作和比较功能，现在该玩点更高级的了 —— 字符串搜索。搜索功能在内核开发中非常常用：查找配置项、解析命令、匹配设备名等等。这一篇我们会实现查找字符、查找子串、字符集匹配、前缀长度计算等函数。

## 第一步：实现字符查找

`strchr` 和 `strrchr` 是最简单的搜索函数，它们在字符串中查找指定字符。`strchr` 从左到右找第一个，`strrchr` 从右到左找最后一个。

```c
char* strchr(const char* s, int c) {
    CCOS_DEBUG_ASSERT(s);

    unsigned char ch = (unsigned char)c;

    for (; *s; ++s) {
        if ((unsigned char)*s == ch)
            return (char*)s;
    }

    if (ch == '\0')
        return (char*)s;

    return NULL;
}
```

这个实现有个有趣的特性：它可以找到字符串末尾的 `'\0'`。比如 `strchr("hello", '\0')` 会返回指向字符串结尾的指针。这在某些场景下很有用，比如你想计算字符串长度但不想遍历整个字符串。

`strrchr` 的逻辑类似，但需要遍历整个字符串来记录最后一次出现的位置：

```c
char* strrchr(const char* s, int c) {
    CCOS_DEBUG_ASSERT(s);

    unsigned char ch = (unsigned char)c;
    const char* last = NULL;

    do {
        if ((unsigned char)*s == ch)
            last = s;
    } while (*s++);

    return (char*)last;
}
```

这里用 `do...while` 而不是 `while` 是因为我们要检查每个字符，包括末尾的 `'\0'`。如果查找的字符就是 `'\0'`，这会返回指向字符串末尾的指针。

## 第二步：实现子串查找

`strstr` 在一个字符串中查找另一个字符串（子串）。这个函数的时间复杂度是 O(n×m)，其中 n 是被查找字符串的长度，m 是子串的长度。对于我们的内核来说，这个简单实现已经足够了。

```c
char* strstr(const char* haystack, const char* needle) {
    CCOS_DEBUG_ASSERT(haystack && needle);

    if (*needle == '\0')
        return (char*)haystack;

    for (; *haystack; ++haystack) {
        const char* h = haystack;
        const char* n = needle;

        while (*h && *n && (*h == *n)) {
            ++h;
            ++n;
        }

        if (*n == '\0')
            return (char*)haystack;
    }

    return NULL;
}
```

这个算法的思路很简单：对于 `haystack` 的每个位置，尝试从这里开始匹配 `needle`。如果匹配到了 `needle` 的末尾，说明找到了子串。

但这个实现有个性能问题：如果 `haystack` 是 "aaa...aaa"（1000 个 'a'），`needle` 是 "aaa...aab"（999 个 'a' 加一个 'b'），那么每次都要比较 999 个字符，最后才发现不匹配。生产环境中通常会使用更高效的算法（如 Boyer-Moore 或 KMP），但对于我们的内核来说，这种情况不太常见，简单实现就够了。

## 第三步：实现字符集匹配

`strpbrk` 在字符串中查找任何一个指定集合中的字符。这个函数在解析命令和配置时特别有用，比如查找字符串中的第一个空格或标点。

```c
char* strpbrk(const char* s, const char* accept) {
    CCOS_DEBUG_ASSERT(s && accept);

    for (; *s; ++s) {
        for (const char* a = accept; *a; ++a) {
            if (*s == *a)
                return (char*)s;
        }
    }

    return NULL;
}
```

使用场景很多。比如你想查找字符串中的第一个空格或标点：`strpbrk(s, " ,.!?;:")`。或者查找字符串中的第一个数字：`strpbrk(s, "0123456789")`。

## 第四步：实现前缀长度计算

`strspn` 和 `strcspn` 是一对互补的函数。`strspn` 计算字符串开头有多少个字符都属于指定集合，`strcspn` 计算字符串开头有多少个字符都不属于指定集合。

```c
size_t strspn(const char* s, const char* accept) {
    CCOS_DEBUG_ASSERT(s && accept);

    size_t count = 0;

    for (; *s; ++s) {
        int ok = 0;
        for (const char* a = accept; *a; ++a) {
            if (*s == *a) {
                ok = 1;
                break;
            }
        }
        if (!ok)
            break;
        ++count;
    }

    return count;
}

size_t strcspn(const char* s, const char* reject) {
    CCOS_DEBUG_ASSERT(s && reject);

    size_t count = 0;

    for (; *s; ++s) {
        for (const char* r = reject; *r; ++r) {
            if (*s == *r)
                return count;
        }
        ++count;
    }

    return count;
}
```

这两个函数的实际应用场景很多。比如你想跳过前导空格：`size_t spaces = strspn(s, " "); char* start = s + spaces;`。或者你想检查字符串是否全是数字：`size_t len = strspn(s, "0123456789"); if (s[len] == '\0') { /* 全是数字 */ }`。

## 性能考虑

这些搜索函数的性能很大程度上取决于输入。在最坏情况下，`strstr` 的时间复杂度是 O(n×m)，但在实际使用中，大部分情况下都能很快找到匹配或不匹配。

如果这些函数成为了性能瓶颈，可以考虑几种优化：使用更高效的字符串搜索算法（如 Boyer-Moore），或者针对特定场景优化（比如固定长度的子串可以用特殊的比较指令）。但对于我们的内核来说，这些优化通常是过早优化，除非你真的遇到了性能问题。

## 验证

创建测试程序验证这些函数：

```c
int main(void) {
    printf("Testing strchr...\n");
    char* p = strchr("hello world", 'o');
    printf("strchr result: \"%s\"\n", p);

    printf("\nTesting strrchr...\n");
    p = strrchr("hello world", 'o');
    printf("strrchr result: \"%s\"\n", p);

    printf("\nTesting strstr...\n");
    p = strstr("hello world", "world");
    printf("strstr result: \"%s\"\n", p);

    printf("\nTesting strpbrk...\n");
    p = strpbrk("hello world", "aeiou");
    printf("strpbrk result: \"%s\"\n", p);

    printf("\nTesting strspn...\n");
    size_t n = strspn("123abc", "0123456789");
    printf("strspn result: %zu\n", n);

    return 0;
}
```

编译运行，如果所有测试都通过了，说明我们的实现是正确的。
