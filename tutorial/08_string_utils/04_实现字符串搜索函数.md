# 实现字符串搜索函数

之前我们实现了字符串的基本操作和比较功能，现在该玩点更高级的了 —— 字符串搜索。

搜索功能在内核开发中非常常用：查找配置项、解析命令、匹配设备名等等。这一篇我们会实现：

- `strchr` / `strrchr` - 查找字符
- `strstr` - 查找子串
- `strpbrk` - 字符集匹配
- `strspn` / `strcspn` - 前缀长度计算

---

## 第一步：更新头文件

在 `kernel/base/string.h` 中添加搜索函数声明：

```c
/* ================= String search ================= */

/**
 * @brief Find first occurrence of a character in a string.
 *
 * @param s Input string.
 * @param c Character to search for (converted to char).
 * @return Pointer to the first occurrence in @p s,
 *         or NULL if not found.
 */
char* strchr(const char* s, int c);

/**
 * @brief Find last occurrence of a character in a string.
 *
 * @param s Input string.
 * @param c Character to search for.
 * @return Pointer to the last occurrence in @p s,
 *         or NULL if not found.
 */
char* strrchr(const char* s, int c);

/**
 * @brief Find a substring within a string.
 *
 * @param haystack String to search in.
 * @param needle Substring to search for.
 * @return Pointer to the first occurrence of @p needle
 *         in @p haystack, or NULL if not found.
 */
char* strstr(const char* haystack, const char* needle);

/**
 * @brief Search a string for any of a set of characters.
 *
 * @param s Input string.
 * @param accept Set of characters to match.
 * @return Pointer to the first matching character in @p s,
 *         or NULL if none found.
 */
char* strpbrk(const char* s, const char* accept);

/**
 * @brief Compute length of initial segment containing only accepted characters.
 *
 * @param s Input string.
 * @param accept Set of accepted characters.
 * @return Number of characters in the initial segment of @p s
 *         consisting only of characters from @p accept.
 */
size_t strspn(const char* s, const char* accept);

/**
 * @brief Compute length of initial segment containing no rejected characters.
 *
 * @param s Input string.
 * @param reject Set of rejected characters.
 * @return Number of characters in the initial segment of @p s
 *         containing none of the characters in @p reject.
 */
size_t strcspn(const char* s, const char* reject);
```

## 第二步：实现 strchr

`strchr` 从左到右查找字符，返回第一个匹配的位置：

```c
/* 在 kernel/base/string.c 中添加 */

char* strchr(const char* s, int c)
{
    while (*s != (char)c) {
        if (*s == '\0') {
            return NULL;
        }
        s++;
    }
    return (char*)s;
}
```

**使用示例**：

```c
char* s = "hello world";
char* p = strchr(s, 'o');
// p 指向 "hello world" 中的第二个 'o'
//           ^
```

⚠️ **注意：也可以查找 '\0'**

`strchr` 有一个有趣的特性：它可以找到字符串末尾的 `'\0'`：

```c
char* s = "hello";
char* p = strchr(s, '\0');
// p 指向 '\0' 的位置，即 s + strlen(s)
```

## 第三步：实现 strrchr

`strrchr` 从右到左查找字符，返回最后一个匹配的位置：

```c
char* strrchr(const char* s, int c)
{
    const char* last = NULL;
    do {
        if (*s == (char)c) {
            last = s;
        }
    } while (*s++ != '\0');
    return (char*)last;
}
```

**使用示例**：

```c
char* s = "hello world";
char* p = strrchr(s, 'o');
// p 指向 "hello world" 中的最后一个 'o'
//                    ^
```

**算法分析**：

这个实现需要遍历整个字符串，记录最后一次看到目标字符的位置：

```
字符串: "hello world"
目标: 'o'

遍历过程:
'h' -> 不匹配
'e' -> 不匹配
'l' -> 不匹配
'l' -> 不匹配
'o' -> 匹配! last = 指向这里
' ' -> 不匹配
'w' -> 不匹配
'o' -> 匹配! last = 指向这里 (覆盖之前的)
'r' -> 不匹配
'l' -> 不匹配
'd' -> 不匹配
'\0' -> 结束

返回: 最后一次匹配的位置
```

## 第四步：实现 strstr

`strstr` 在一个字符串中查找另一个字符串（子串）：

```c
char* strstr(const char* haystack, const char* needle)
{
    // 如果 needle 是空字符串，返回 haystack
    if (*needle == '\0') {
        return (char*)haystack;
    }

    // 遍历 haystack 的每个位置
    while (*haystack != '\0') {
        const char* h = haystack;
        const char* n = needle;

        // 尝试匹配 needle
        while (*n != '\0' && *h == *n) {
            h++;
            n++;
        }

        // 如果匹配到 needle 结尾，找到子串
        if (*n == '\0') {
            return (char*)haystack;
        }

        haystack++;
    }

    return NULL;
}
```

**使用示例**：

```c
strstr("hello world", "world")  // 返回指向 "world" 的指针
strstr("hello world", "xyz")    // 返回 NULL
strstr("hello world", "")       // 返回指向 "hello world" 的指针
```

⚠️ **性能警告**

`strstr` 的时间复杂度是 O(n×m)，其中 n 是 haystack 的长度，m 是 needle 的长度。对于长字符串，这可能比较慢。

生产环境中通常会使用更高效的算法（如 Boyer-Moore 或 KMP），但对于我们的内核来说，这个简单实现已经足够了。

## 第五步：实现 strpbrk

`strpbrk` 在字符串中查找**任何一个**指定集合中的字符：

```c
char* strpbrk(const char* s, const char* accept)
{
    while (*s != '\0') {
        const char* a = accept;
        while (*a != '\0') {
            if (*s == *a) {
                return (char*)s;
            }
            a++;
        }
        s++;
    }
    return NULL;
}
```

**使用示例**：

```c
char* s = "hello world";
char* p = strpbrk(s, "aeiou");
// p 指向第一个元音字母 'e'
//         ^
```

**实际应用场景**：

```c
// 查找字符串中的第一个空格或标点
char* p = strpbrk(s, " ,.!?;:");

// 查找字符串中的第一个数字
char* p = strpbrk(s, "0123456789");
```

## 第六步：实现 strspn

`strspn` 计算字符串开头有多少个字符**都属于**指定集合：

```c
size_t strspn(const char* s, const char* accept)
{
    size_t len = 0;
    while (s[len] != '\0') {
        const char* a = accept;
        bool found = false;
        while (*a != '\0') {
            if (s[len] == *a) {
                found = true;
                break;
            }
            a++;
        }
        if (!found) {
            break;
        }
        len++;
    }
    return len;
}
```

**使用示例**：

```c
strspn("123abc", "0123456789")  // 返回 3（"123"）
strspn("abc123", "0123456789")  // 返回 0（第一个字符就不是数字）
strspn("hello", "abcdefghijk")  // 返回 5（全部匹配）
```

**实际应用场景**：

```c
// 跳过前导空格
char* s = "   hello world";
size_t spaces = strspn(s, " ");
char* start = s + spaces;  // start 指向 "hello"

// 检查字符串是否全是数字
size_t len = strspn(s, "0123456789");
if (s[len] == '\0') {
    // 字符串全是数字
}
```

## 第七步：实现 strcspn

`strcspn` 与 `strspn` 相反 —— 计算字符串开头有多少个字符**都不属于**指定集合：

```c
size_t strcspn(const char* s, const char* reject)
{
    size_t len = 0;
    while (s[len] != '\0') {
        const char* r = reject;
        bool found = false;
        while (*r != '\0') {
            if (s[len] == *r) {
                found = true;
                break;
            }
            r++;
        }
        if (found) {
            break;
        }
        len++;
    }
    return len;
}
```

**使用示例**：

```c
strcspn("hello world", " ")  // 返回 5（"hello"，到第一个空格为止）
strcspn("123.456", ".")      // 返回 3（"123"，到第一个小数点为止）
```

## 完整的搜索函数代码

```c
/* ========== String search ========== */

char* strchr(const char* s, int c)
{
    while (*s != (char)c) {
        if (*s == '\0') {
            return NULL;
        }
        s++;
    }
    return (char*)s;
}

char* strrchr(const char* s, int c)
{
    const char* last = NULL;
    do {
        if (*s == (char)c) {
            last = s;
        }
    } while (*s++ != '\0');
    return (char*)last;
}

char* strstr(const char* haystack, const char* needle)
{
    if (*needle == '\0') {
        return (char*)haystack;
    }

    while (*haystack != '\0') {
        const char* h = haystack;
        const char* n = needle;

        while (*n != '\0' && *h == *n) {
            h++;
            n++;
        }

        if (*n == '\0') {
            return (char*)haystack;
        }

        haystack++;
    }

    return NULL;
}

char* strpbrk(const char* s, const char* accept)
{
    while (*s != '\0') {
        const char* a = accept;
        while (*a != '\0') {
            if (*s == *a) {
                return (char*)s;
            }
            a++;
        }
        s++;
    }
    return NULL;
}

size_t strspn(const char* s, const char* accept)
{
    size_t len = 0;
    while (s[len] != '\0') {
        const char* a = accept;
        bool found = false;
        while (*a != '\0') {
            if (s[len] == *a) {
                found = true;
                break;
            }
            a++;
        }
        if (!found) {
            break;
        }
        len++;
    }
    return len;
}

size_t strcspn(const char* s, const char* reject)
{
    size_t len = 0;
    while (s[len] != '\0') {
        const char* r = reject;
        bool found = false;
        while (*r != '\0') {
            if (s[len] == *r) {
                found = true;
                break;
            }
            r++;
        }
        if (found) {
            break;
        }
        len++;
    }
    return len;
}
```

⚠️ **需要添加 bool 类型**

注意上面的代码用了 `bool` 类型。我们需要在 `kernel/defines/types.h` 中添加：

```c
/* 在 kernel/defines/types.h 中添加 */

typedef enum {
    false = 0,
    true  = 1
} bool;
```
