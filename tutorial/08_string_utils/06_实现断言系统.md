# 实现断言系统

字符串工具库搞定了，现在该来做一件更重要的事情 —— 断言系统。

说实话，写内核代码的时候最怕的就是那种"看起来没问题"的 Bug。你一遍遍地看代码，一遍遍地调试，最后发现是一个空指针被忘了检查。如果有断言系统，这种问题就能在第一时间被发现。

---

## 什么是断言？

断言（Assertion）是一种在代码中声明"某个条件必须为真"的机制。如果条件不满足，程序就会停止运行并报告错误。

**基本思想**：

```c
// 我断言这个指针不会是 NULL
CCOS_ASSERT(ptr != NULL);

// 我断言这个数组下标是合法的
CCOS_ASSERT(index < array_size);

// 我断言这个状态是合理的
CCOS_ASSERT(state == STATE_READY || state == STATE_BUSY);
```

如果断言失败，程序会：
1. 打印错误信息（文件、行号、表达式）
2. 停止运行（或触发调试器）

这样我们就能在问题发生时立刻知道"哪里出了问题"，而不是"什么时候会崩溃"。

---

## 我们需要什么样的断言系统？

在我们的内核中，我们需要两种断言：

### 1. `CCOS_ASSERT` - 始终启用的断言

用于关键检查，比如：
- 空指针检查
- 数组边界检查
- 状态不变式验证

无论 Debug 还是 Release 构建，这个断言都会生效。

### 2. `CCOS_DEBUG_ASSERT` - 仅 Debug 模式启用

用于调试辅助，比如：
- 函数参数验证
- 内部状态检查
- 性能相关的断言

在 Release 构建中，这些断言会被完全移除，不影响性能。

## 第二步：实现断言头文件

首先，我们来实现 `kernel/assert/assert.h`：

```c
/**
 * @file assert.h
 * @brief Kernel assertion macros and function declarations.
 *
 * This module provides assertion facilities for the CCOS kernel.
 * Assertions are used to catch programming errors early by
 * verifying that critical conditions are true.
 *
 * @note This is NOT the standard <assert.h> - we implement our own
 *       to work in a freestanding environment and provide custom
 *       error reporting.
 */
#pragma once

#include "defines/types.h"

/* Forward declaration */
struct ccos_assert_context;

/**
 * @brief Assert that a condition is true (always enabled).
 *
 * If the condition is false, the assertion handler will be called
 * with detailed information about the failure.
 *
 * This macro is active in both Debug and Release builds.
 *
 * @param EXPECTED_EXPR The expression to verify.
 */
#define CCOS_ASSERT(EXPECTED_EXPR) \
    ccos_assert_impl((EXPECTED_EXPR) != 0, #EXPECTED_EXPR, __FILE__, __LINE__, __func__)

/**
 * @brief Assert that a condition is true (Debug only).
 *
 * If the condition is false, the assertion handler will be called.
 * This macro is only active in Debug builds (when NDEBUG is not defined).
 * In Release builds, it compiles to nothing.
 *
 * @param EXPECTED_EXPR The expression to verify.
 */
#ifdef NDEBUG
#    define CCOS_DEBUG_ASSERT(EXPECTED_EXPR) ((void)0)
#else
#    define CCOS_DEBUG_ASSERT(EXPECTED_EXPR) \
        ccos_assert_impl((EXPECTED_EXPR) != 0, #EXPECTED_EXPR, __FILE__, __LINE__, __func__)
#endif

/**
 * @brief Internal assertion implementation function.
 *
 * This function is called by the assertion macros when a condition
 * fails. It collects the error context and calls the backend to
 * display the error and halt the system.
 *
 * @param condition The result of the condition check (0 = failed).
 * @param expr_str The stringified expression.
 * @param file The source file where the assertion failed.
 * @param line The line number where the assertion failed.
 * @param func The function name where the assertion failed.
 */
void ccos_assert_impl(bool condition, const char* expr_str,
                      const char* file, int line, const char* func);
```

⚠️ **理解宏的魔法**

让我们拆解一下 `CCOS_ASSERT` 宏：

```c
#define CCOS_ASSERT(EXPECTED_EXPR) \
    ccos_assert_impl((EXPECTED_EXPR) != 0, #EXPECTED_EXPR, __FILE__, __LINE__, __func__)
```

**1. `(EXPECTED_EXPR) != 0`**

把表达式转换成布尔值。在 C 语言中，任何非零值都是"真"。

**2. `#EXPECTED_EXPR`**

这是"字符串化"操作符。它把宏参数转换成字符串字面量：

```c
CCOS_ASSERT(x > 5);
// 展开成：
ccos_assert_impl((x > 5) != 0, "x > 5", "main.c", 42, "main");
```

这样我们就能在错误信息中看到原始的表达式！

**3. `__FILE__`, `__LINE__`, `__func__`**

这些都是编译器内置的宏，分别代表：
- `__FILE__` - 当前源文件名
- `__LINE__` - 当前行号
- `__func__` - 当前函数名

## 第三步：实现断言主体

现在实现 `kernel/assert/assert.c`：

```c
/**
 * @file assert.c
 * @brief Kernel assertion implementation.
 */

#include "assert.h"
#include "assert_action_backend.h"

/**
 * @brief Internal assertion implementation.
 *
 * This function is called when an assertion fails. It collects
 * information about the failure and delegates to the backend
 * for error reporting and system halt.
 */
void ccos_assert_impl(bool condition, const char* expr_str,
                      const char* file, int line, const char* func)
{
    if (condition) {
        return;  // 断言成功，什么都不做
    }

    // 断言失败！准备错误信息
    struct ccos_assert_context ctx = {
        .expr = expr_str,
        .file = file,
        .line = line,
        .func = func
    };

    // 调用后端处理
    assert_failed_action(&ctx);
}
```

## 第四步：定义后端接口

创建 `kernel/assert/assert_action_backend.h`：

```c
/**
 * @file assert_action_backend.h
 * @brief Assertion failure action backend interface.
 *
 * This module defines the interface for handling assertion failures.
 * The backend is responsible for displaying error information and
 * halting the system.
 */
#pragma once

#include <stdbool.h>

/**
 * @brief Context information for a failed assertion.
 */
struct ccos_assert_context {
    const char* expr;   /**< The failed expression as a string */
    const char* file;   /**< Source file where assertion failed */
    int line;           /**< Line number where assertion failed */
    const char* func;   /**< Function name where assertion failed */
};

/**
 * @brief Action taken when an assertion fails.
 *
 * This function is called by ccos_assert_impl() when an assertion
 * condition evaluates to false.
 *
 * Typical actions:
 * - Display error information on VGA
 * - Trigger breakpoint for debugger (Debug builds)
 * - Halt the system
 *
 * @param ctx Context information about the assertion failure.
 */
void assert_failed_action(const struct ccos_assert_context* ctx);
```

## 第五步：实现后端

创建 `kernel/assert/assert_action_backend.c`：

```c
/**
 * @file assert_action_backend.c
 * @brief Assertion failure action backend implementation.
 *
 * This module handles the display of assertion failure information
 * and system halt.
 */

#include "assert_action_backend.h"
#include "../driver/vga/vga.h"
#include <stdint.h>

/**
 * @brief Convert an integer to a string.
 *
 * Simple utility function to convert numbers to strings for display.
 * This is needed because we don't have sprintf() yet.
 *
 * @param value The integer value to convert.
 * @param buffer Buffer to store the resulting string.
 * @return Pointer to the buffer.
 */
static char* int_to_str(int value, char* buffer)
{
    if (value == 0) {
        buffer[0] = '0';
        buffer[1] = '\0';
        return buffer;
    }

    // Handle negative numbers
    bool is_negative = false;
    if (value < 0) {
        is_negative = true;
        value = -value;
    }

    // Convert digits (in reverse order)
    int i = 0;
    while (value > 0) {
        buffer[i++] = '0' + (value % 10);
        value /= 10;
    }

    // Add negative sign if needed
    if (is_negative) {
        buffer[i++] = '-';
    }

    buffer[i] = '\0';

    // Reverse the string
    int len = i;
    for (i = 0; i < len / 2; i++) {
        char tmp = buffer[i];
        buffer[i] = buffer[len - 1 - i];
        buffer[len - 1 - i] = tmp;
    }

    return buffer;
}

    // 显示表达式

}

/**
 * @brief Notify the debugger and halt the system.
 *
 * In Debug builds, this triggers a software breakpoint (int3).
 * In all builds, this halts the CPU.
 */
static void assert_failed_halt(void)
{
#ifdef NDEBUG
    // Release build: just halt
    __asm__ volatile ("cli; hlt");
    while (1) {
        __asm__ volatile ("hlt");
    }
#else
    // Debug build: trigger breakpoint first
    __asm__ volatile ("int3");
    __asm__ volatile ("cli; hlt");
    while (1) {
        __asm__ volatile ("hlt");
    }
#endif
}

/**
 * @brief Assertion failure action implementation.
 */
void assert_failed_action(const struct ccos_assert_context* ctx)
{
    // 1. 显示错误信息
    assert_failed_display(ctx);

    // 2. 停止系统
    assert_failed_halt();

    // Never returns
}
```

## 使用示例

现在我们可以在代码中使用断言了：

```c
#include "assert/assert.h"

void example_function(int* ptr, int index)
{
    // 关键检查 - 始终启用
    CCOS_ASSERT(ptr != NULL);

    // 调试检查 - 仅 Debug 模式
    CCOS_DEBUG_ASSERT(index >= 0);

    // 如果 ptr 是 NULL，程序会立即停止并报告错误
    // 如果 index < 0 且是 Debug 构建，程序也会停止
}
```

## 断言 vs 错误处理

重要的是理解断言和错误处理的区别：

| 特性 | 断言 (`CCOS_ASSERT`) | 错误处理 |
|------|---------------------|----------|
| 用途 | 检测编程错误 | 处理预期情况 |
| 触发条件 | 不应该发生的事情 | 可能发生的事情 |
| 行为 | 停止程序 | 恢复/清理 |
| 示例 | 指针不应该为 NULL | 文件可能不存在 |

```c
// ❌ 错误：用断言处理用户输入
CCOS_ASSERT(user_input >= 0 && user_input <= 100);  // 不要这样做！

// ✅ 正确：用错误处理
if (user_input < 0 || user_input > 100) {
    print_error("Invalid input range");
    return;
}

// ✅ 正确：用断言检测内部错误
CCOS_ASSERT(internal_state != NULL);  // 这应该永远是真的
```
