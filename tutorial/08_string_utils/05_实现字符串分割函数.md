# 实现字符串分割函数 —— strtok 和 strtok_r

我们来到字符串工具库的最后一部分 —— 字符串分割函数。`strtok` 是 C 标准库中最"臭名昭著"的函数之一。它非常强大，但也有不少陷阱。不过只要理解了它的工作原理，你就能在解析命令、配置文件等场景下得心应手。

## 第一步：理解 strtok 的行为

`strtok` 的作用是按照指定的分隔符把字符串分割成多个 token（标记）。第一次调用时传入要分割的字符串，后续调用传入 NULL。这个设计可能有点奇怪，但它是为了保持内部状态而做的妥协。

基本用法是这样的：

```c
char str[] = "hello world from CCOS";
char* token;

token = strtok(str, " ");  // "hello"
token = strtok(NULL, " "); // "world"
token = strtok(NULL, " "); // "from"
token = strtok(NULL, " "); // "CCOS"
token = strtok(NULL, " "); // NULL，表示分割完毕
```

第一次调用时，`strtok` 会记住传入的字符串位置，然后开始处理。后续调用传入 NULL，`strtok` 会从上次停止的地方继续。

## 第二步：理解陷阱

`strtok` 有两个重要的陷阱，很多人第一次用时都会踩到。

第一个陷阱是原字符串会被修改。`strtok` 会原地修改输入字符串，把分隔符替换成 `'\0'`。这是因为 `strtok` 不分配新内存，它只是把原字符串"切"成多个部分。

```c
char str[] = "hello world";
strtok(str, " ");
// str 现在是 "hello\0world"
//               ^
//               第一个空格被替换成 '\0'
```

第二个陷阱是非线程安全。`strtok` 使用静态变量来记住分割进度，所以多个线程同时使用会出问题。这就是为什么有 `strtok_r` 这个可重入版本。

## 第三步：实现 strtok

`strtok` 的核心思想是：记住当前扫描的位置，跳过前导分隔符，找到下一个分隔符并将其替换为 `'\0'`，返回当前 token 的起始位置。

```c
char* strtok(char* str, const char* delim) {
    static char* save = NULL;
    return strtok_r(str, delim, &save);
}
```

等等，我们的 `strtok` 怎么这么简单？因为我们直接调用了 `strtok_r`！这是现代实现中常见的方法，避免了代码重复。`strtok` 只有一个静态变量，然后把所有工作都委托给 `strtok_r`。

## 第四步：实现 strtok_r

`strtok_r` 是 `strtok` 的可重入版本，它使用调用者提供的指针来记住状态。实际的实现可以复用我们已经实现的 `strspn` 和 `strcspn` 函数。

```c
char* strtok_r(char* str, const char* delim, char** saveptr) {
    CCOS_DEBUG_ASSERT(delim && saveptr);

    char* s = str ? str : *saveptr;
    if (!s)
        return NULL;

    /* skip leading delimiters */
    s += strspn(s, delim);
    if (*s == '\0') {
        *saveptr = NULL;
        return NULL;
    }

    char* token = s;

    /* find end */
    s += strcspn(s, delim);
    if (*s) {
        *s = '\0';
        *saveptr = s + 1;
    } else {
        *saveptr = NULL;
    }

    return token;
}
```

这个实现比教科书上的要简洁得多，因为它复用了 `strspn` 和 `strcspn`。`strspn` 用来跳过前导分隔符，`strcspn` 用来找到下一个分隔符。这种写法更容易理解，而且更不容易出错。

让我们走一遍这个算法。假设输入是 `"  hello   world  "`，分隔符是 `" "`：

第一步，`strspn(s, " ")` 返回 2，跳过了两个前导空格。第二步，`token` 指向 `"hello"` 的开头。第三步，`strcspn(s, " ")` 返回 5，找到了 5 个非空格字符。第四步，把这 5 个字符后面的空格替换成 `'\0'`，`saveptr` 指向下一个位置。第五步，返回指向 `"hello"` 的指针。

完美！

## 第五步：实际应用

字符串分割在内核开发中有很多应用场景。

### 解析命令行

```c
void parse_command(char* cmd) {
    char* saveptr;
    char* token;

    token = strtok_r(cmd, " ", &saveptr);
    if (!token) return;  // 空命令

    if (strcmp(token, "echo") == 0) {
        char* arg = strtok_r(NULL, " ", &saveptr);
        if (arg) {
            // 打印参数
        }
    } else if (strcmp(token, "help") == 0) {
        // 显示帮助
    }
}
```

### 解析配置文件行

```c
void parse_config_line(char* line) {
    char* saveptr;
    char* key = strtok_r(line, "=", &saveptr);
    if (!key) return;

    char* value = strtok_r(NULL, "", &saveptr);
    if (!value) return;

    // 去除 key 的前后空格
    // （可以用之前实现的 strspn 和 strcspn）
}
```

### 解析路径

```c
void parse_path(const char* path) {
    char buf[256];
    strcpy(buf, path);

    char* saveptr;
    char* token = strtok_r(buf, "/", &saveptr);

    while (token) {
        // 处理路径组件
        token = strtok_r(NULL, "/", &saveptr);
    }
}
```
