# 更新构建系统

代码写完了，现在让我们把构建系统也整理一下。

---

## 之前的构建系统

重构之前，我们需要分别编译两个文件：

```makefile
BOOT_ASM = boot.asm
BOOT2_ASM = boot2.asm

BOOT_BIN = build/boot.bin
BOOT2_BIN = build/boot2.bin

all: $(BOOT_IMG)

$(BOOT_BIN): $(BOOT_ASM)
	$(AS) $(ASFLAGS) $< -o $@

$(BOOT2_BIN): $(BOOT2_ASM)
	$(AS) $(ASFLAGS) $< -o $@

$(BOOT_IMG): $(BOOT_BIN) $(BOOT2_BIN) $(KERNEL_BIN)
	dd if=$(BOOT_BIN) of=$@ bs=512 count=1
	dd if=$(BOOT2_BIN) of=$@ bs=512 seek=1
	dd if=$(KERNEL_BIN) of=$@ bs=512 seek=3
```

这很繁琐，而且容易出错。

---

## 重构后的构建系统

现在我们只有一个 `bootloader.asm` 文件：

```makefile
BOOTLOADER_ASM = boot/bootloader.asm

BOOTLOADER_BIN = build/bootloader.bin

all: $(BOOT_IMG)

$(BOOTLOADER_BIN): $(BOOTLOADER_ASM)
	nasm -f bin $< -o $@

$(BOOT_IMG): $(BOOTLOADER_BIN) $(KERNEL_BIN)
	dd if=$(BOOTLOADER_BIN) of=$@ bs=512 count=4
	dd if=$(KERNEL_BIN) of=$@ bs=512 seek=4
```

**等等！** 这里有个重要的变化：**扇区布局变了**。

---

## 扇区布局的变化

### 重构之前

```
扇区 1:     boot.bin     (Stage 1, 512 bytes)
扇区 2-3:   boot2.bin    (Stage 2, ~824 bytes)
扇区 4+:     kernel.bin   (内核)
```

### 重构之后

```
扇区 1-4:   bootloader.bin  (Stage 1+2, ~2KB)
扇区 5+:     kernel.bin      (内核)
```

⚠️ **注意**：内核起始扇区从 4 变成了 5！

这是因为：
- `bootloader.asm` 里的 `.mbr` 段是 512 字节（正好 1 扇区）
- `.stage2` 段大约 1500 字节（大约 3 扇区）
- 总共需要 4 扇区

所以内核要从扇区 5 开始。

## 自动生成配置文件

我们还引入了 CMake 自动生成的 `boot_config.inc`：

```asm
; boot_config.inc - AUTO-GENERATED by CMake
%define KERNEL_LBA_START          5
%define KERNEL_SECTOR_COUNT       31
%define KERNEL_LOAD_SEGMENT       0x1000
%define KERNEL_LOAD_OFFSET        0x0000
%define BOOTLOADER_SECTORS        4
%define SECTORS_PER_TRACK         63
%define HEADS                     16
```

这样做的好处是：
- **自动计算**内核大小和扇区数
- **避免硬编码**魔法数字
- **减少人为错误**

### CMake 配置

在 CMakeLists.txt 中添加：

```cmake
# Get kernel size
get_filename_component(KERNEL_BIN ${KERNEL_BIN} ABSOLUTE)

# Calculate kernel sector count
execute_process(
    COMMAND ${CMAKE_COMMAND} -E copy_if_different ${KERNEL_BIN} ${KERNEL_BIN}.tmp
    COMMAND ${CMAKE_COMMAND} -E env WC_CMD="wc -c < ${KERNEL_BIN}.tmp"
    COMMAND bash -c "echo $(( $($(wc -c < ${KERNEL_BIN}.tmp) + 511) / 512 ))"
    OUTPUT_VARIABLE KERNEL_SECTOR_COUNT
    OUTPUT_STRIP_TRAILING_WHITESPACE
)

# Calculate bootloader sector count
execute_process(
    COMMAND bash -c "echo $(( $($(wc -c < ${BOOTLOADER_BIN}) + 511) / 512 ))"
    OUTPUT_VARIABLE BOOTLOADER_SECTORS
    OUTPUT_STRIP_TRAILING_WHITESPACE
)

# Generate boot_config.inc
configure_file(
    ${CMAKE_SOURCE_DIR}/boot/boot_config.inc.in
    ${CMAKE_SOURCE_DIR}/boot/boot_config.inc
    @ONLY
)
```

`boot_config.inc.in` 模板：

```asm
; ==============================================================================
; CCOS Bootloader Configuration
; ==============================================================================
; This file is AUTO-GENERATED by CMake during build
; Generated from: @KERNEL_BIN@ (@KERNEL_SECTOR_COUNT@ sectors)
;              : @BOOTLOADER_BIN@ (@BOOTLOADER_SECTORS@ sectors)
; DO NOT EDIT MANUALLY - Changes will be overwritten
; ==============================================================================

%define KERNEL_LBA_START          @BOOTLOADER_SECTORS@
%define KERNEL_SECTOR_COUNT       @KERNEL_SECTOR_COUNT@
%define KERNEL_LOAD_SEGMENT       0x1000
%define KERNEL_LOAD_OFFSET        0x0000
%define BOOTLOADER_SECTORS        @BOOTLOADER_SECTORS@
%define SECTORS_PER_TRACK         63
%define HEADS                     16
```

## 完整的 Makefile

这里是一个完整的 Makefile 示例：

```makefile
# ==============================================================================
# CCOS Build System
# ==============================================================================

AS = nasm
ASFLAGS = -f bin

BUILD_DIR = build
BOOT_DIR = boot
KERNEL_DIR = kernel

BOOTLOADER_ASM = $(BOOT_DIR)/bootloader.asm
BOOTLOADER_BIN = $(BUILD_DIR)/bootloader.bin

KERNEL_ASM = $(KERNEL_DIR)/kernel.asm
KERNEL_BIN = $(BUILD_DIR)/kernel.bin

BOOT_IMG = $(BUILD_DIR)/boot.img

.PHONY: all clean run debug

all: $(BOOT_IMG)

$(BOOTLOADER_BIN): $(BOOTLOADER_ASM)
	@echo "==> Building bootloader..."
	@mkdir -p $(BUILD_DIR)
	$(AS) $(ASFLAGS) $< -o $@
	@echo "==> Bootloader size: $$(wc -c < $@) bytes"

$(KERNEL_BIN): $(KERNEL_ASM)
	@echo "==> Building kernel..."
	@mkdir -p $(BUILD_DIR)
	$(AS) $(ASFLAGS) $< -o $@
	@echo "==> Kernel size: $$(wc -c < $@) bytes"

$(BOOT_IMG): $(BOOTLOADER_BIN) $(KERNEL_BIN)
	@echo "==> Generating boot image..."
	@# Get bootloader size in sectors
	@BOOTLOADER_SECTORS=$$(($($(wc -c < $(BOOTLOADER_BIN)) + 511) / 512)); \
	echo "Bootloader: $$BOOTLOADER_SECTORS sectors"; \
	# Write bootloader
	dd if=$(BOOTLOADER_BIN) of=$@ bs=512 count=$$BOOTLOADER_SECTORS 2>/dev/null; \
	# Write kernel
	dd if=$(KERNEL_BIN) of=$@ bs=512 seek=$$BOOTLOADER_SECTORS 2>/dev/null; \
	echo "==> Boot image generated: $@"

clean:
	@echo "==> Cleaning..."
	rm -rf $(BUILD_DIR)

run: $(BOOT_IMG)
	@echo "==> Running QEMU..."
	qemu-system-x86_64 -drive format=raw,file=$(BOOT_IMG) -serial stdio

debug: $(BOOT_IMG)
	@echo "==> Starting QEMU with GDB server..."
	qemu-system-x86_64 -drive format=raw,file=$(BOOT_IMG) -s -S

gdb:
	@echo "==> Starting GDB..."
	gdb $(BOOTLOADER_BIN) -ex "target remote :1234"
```

## 常见问题

### 问题 1：内核加载失败

检查：
1. `boot_config.inc` 中的 `KERNEL_LBA_START` 是否正确
2. Makefile 中 `dd` 命令的 `seek` 参数是否正确
3. 内核实际扇区数是否和配置一致

### 问题 2：bootloader 大小超过预期

检查：
1. 是否有不必要的代码或数据
2. `times 510-($-$$) db 0` 填充是否在正确的 section
3. 用 `ls -lh` 查看实际大小

### 问题 3：CMake 配置不生效

检查：
1. `boot_config.inc` 是否被正确生成
2. CMake 是否正确设置了变量
3. `@BOOTLOADER_SECTORS@` 是否被替换成实际值
