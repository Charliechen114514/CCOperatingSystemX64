# 加上串口输出

相信我，加上串口输出后，你的调试效率会提升十倍。

---

## 为什么要加串口？

VGA 调试虽然直观，但有几个大问题：

1. **需要图形界面** - 在无头服务器上没法用
2. **信息量有限** - VGA 文本模式只有 80×25 个字符
3. **不易保存** - 截图和复制都很麻烦
4. **不支持重定向** - 不能直接保存到日志文件

串口就没这些限制：
- 纯文本输出，可以保存到文件
- QEMU 可以用 `-serial stdio` 直接输出到终端
- 也可以用 `-serial file:serial.log` 保存到文件
- 支持远程调试（通过串口线连接另一台机器）

---

## 串口硬件基础

PC 的串口（COM1）使用的是 16550 UART 芯片，I/O 端口是 `0x3F8-0x3FF`。

主要寄存器：

| 寄存器名     | 端口 | 说明                           |
| ------------ | ---- | ------------------------------ |
| THR          | 0x3F8 | 发送保持寄存器（写）           |
| RBR          | 0x3F8 | 接收缓冲寄存器（读）           |
| IER          | 0x3F9 | 中断使能寄存器                 |
| FCR          | 0x3FA | FIFO 控制寄存器（写）          |
| LCR          | 0x3FB | 线路控制寄存器                 |
| MCR          | 0x3FC | 调制解调器控制寄存器           |
| LSR          | 0x3FD | 线路状态寄存器                 |
| DLL          | 0x3F8 | 除数锁存器低字节（DLAB=1）    |
| DLM          | 0x3F9 | 除数锁存器高字节（DLAB=1）    |

**我们主要关心这几个**：
- THR - 发送数据
- LSR - 检查发送缓冲区是否为空
- LCR - 设置波特率和数据格式
- DLL/DLM - 设置波特率除数

---

## 波特率计算

串口的时钟频率是 **1.8432 MHz**。

波特率除数 = 1843200 / (波特率 × 16)

常用的除数：

| 波特率 | 除数 | DLL | DLM |
| ------ | ---- | --- | --- |
| 9600   | 12   | 12  | 0   |
| 115200 | 1    | 1   | 0   |

我们使用 **115200 波特率**，所以除数是 1。

## 第一步：定义串口常量

在 `bootloader.asm` 的开头加上串口相关常量：

```asm
; ==============================================================================
; Serial Port Constants (COM1)
; ==============================================================================
SERIAL_PORT        equ 0x3F8
SERIAL_THR         equ 0x03F8  ; Transmit Holding Register (write)
SERIAL_RBR         equ 0x03F8  ; Receive Buffer Register (read)
SERIAL_IER         equ 0x03F9  ; Interrupt Enable Register
SERIAL_IIR         equ 0x03FA  ; Interrupt Identification Register
SERIAL_FCR         equ 0x03FA  ; FIFO Control Register (write)
SERIAL_LCR         equ 0x03FB  ; Line Control Register
SERIAL_MCR         equ 0x03FC  ; Modem Control Register
SERIAL_LSR         equ 0x03FD  ; Line Status Register
SERIAL_MSR         equ 0x03FE  ; Modem Status Register
SERIAL_DLL         equ 0x03F8  ; Divisor Latch Low (when DLAB=1)
SERIAL_DLM         equ 0x03F9  ; Divisor Latch High (when DLAB=1)

; Line Control bits
LCR_DLAB           equ 0x80    ; Divisor Latch Access Bit
LCR_8BIT           equ 0x03    ; 8 bits per character
LCR_NO_PARITY      equ 0x00    ; No parity
LCR_ONE_STOP       equ 0x00    ; 1 stop bit

; Line Status bits
LSR_THRE           equ 0x20    ; Transmit Holding Register Empty
LSR_TEMT           equ 0x40    ; Transmitter Empty
```

8N1 格式就是：8 位数据、无校验、1 位停止位。

## 第二步：实现串口初始化（16 位）

我们在 Stage 1 的 16 位实模式下初始化串口：

```asm
; serial_init - Initialize COM1 for 115200 8N1
; Input: none
; Output: none
; Clobbers: AX, DX
serial_init:
    push dx

    ; Disable interrupts during setup
    mov dx, SERIAL_IER
    xor al, al
    out dx, al

    ; Enable DLAB to set divisor
    mov dx, SERIAL_LCR
    mov al, LCR_DLAB | LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Set divisor low byte (115200 baud)
    mov dx, SERIAL_DLL
    mov al, 0x01    ; Divisor = 1 (115200 baud)
    out dx, al

    ; Set divisor high byte
    mov dx, SERIAL_DLM
    mov al, 0x00
    out dx, al

    ; Clear DLAB and set 8N1 format
    mov dx, SERIAL_LCR
    mov al, LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Enable FIFO, clear buffers, 14-byte threshold
    mov dx, SERIAL_FCR
    mov al, 0x07    ; Enable FIFO, clear RX/TX
    out dx, al

    ; Set modem control (RTS+DTR on)
    mov dx, SERIAL_MCR
    mov al, 0x03    ; RTS + DTR
    out dx, al

    pop dx
    ret
```

**流程解释**：
1. 禁用中断（避免干扰）
2. 设置 DLAB 位（允许访问 DLL/DLM）
3. 设置除数（115200 波特率）
4. 清除 DLAB 位（恢复正常操作）
5. 启用 FIFO（提高性能）
6. 设置调制解调器控制

## 第三步：实现串口输出函数（16 位）

```asm
; serial_write_char_blocking - Write a character to serial port (blocking)
; Input: AL = character to write
; Output: none
; Clobbers: AX, DX
serial_write_char_blocking:
    push dx
    push ax                         ; Save the character to write
.write_loop:
    ; Wait until THR is empty
    mov dx, SERIAL_LSR
    in al, dx
    test al, LSR_THRE
    jz .write_loop

    ; Restore character and write to THR
    pop ax                          ; Restore character
    mov dx, SERIAL_THR
    out dx, al

    pop dx
    ret


; serial_write_string - Write null-terminated string to serial port
; Input: SI = pointer to string
; Output: none
; Clobbers: AX, SI
serial_write_string:
    pusha
.loop:
    lodsb
    test al, al
    jz .done
    call serial_write_char_blocking
    jmp .loop
.done:
    popa
    ret
```

**阻塞模式**意味着函数会等待直到发送缓冲区为空。这样最简单，也最可靠。

## 第四步：在 Stage 1 使用串口

现在我们在 Stage 1 初始化串口，并输出一些消息：

```asm
start:
    cli
    xor ax, ax
    mov ds, ax
    mov es, ax
    mov ss, ax
    mov sp, 0x7c00
    sti

    ; ===== 新增：初始化串口 =====
    call serial_init

    ; clear screen
    mov ah, 0x00
    mov al, 0x03
    int 0x10

    ; print header to VGA
    mov si, header_msg
    call print_string

    ; ===== 新增：也输出到串口 =====
    mov si, header_msg
    call serial_write_string

    ; print welcome to VGA
    mov si, welcome_msg
    call print_string

    ; ===== 新增：也输出到串口 =====
    mov si, welcome_msg
    call serial_write_string

    ; ... 继续后面的代码 ...
```

现在每个重要消息都会同时输出到 VGA 和串口。

## 第五步：实现 32 位和 64 位版本的串口函数

当切换到保护模式和长模式后，16 位函数就不好用了。我们需要 32 位和 64 位版本：

### 32 位版本

```asm
; serial_init_32 - Initialize COM1 for 115200 8N1 (32-bit version)
; Input: none
; Output: none
; Clobbers: EAX, EDX
bits 32
serial_init_32:
    push edx

    ; Disable interrupts during setup
    mov dx, SERIAL_IER
    xor al, al
    out dx, al

    ; Enable DLAB to set divisor
    mov dx, SERIAL_LCR
    mov al, LCR_DLAB | LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Set divisor low byte (115200 baud)
    mov dx, SERIAL_DLL
    mov al, 0x01
    out dx, al

    ; Set divisor high byte
    mov dx, SERIAL_DLM
    mov al, 0x00
    out dx, al

    ; Clear DLAB and set 8N1 format
    mov dx, SERIAL_LCR
    mov al, LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Enable FIFO, clear buffers
    mov dx, SERIAL_FCR
    mov al, 0x07
    out dx, al

    ; Set modem control
    mov dx, SERIAL_MCR
    mov al, 0x03
    out dx, al

    pop edx
    ret
```

### 64 位版本

```asm
; serial_init_64 - Initialize COM1 for 115200 8N1 (64-bit version)
; Input: none
; Output: none
; Clobbers: RAX, RDX
bits 64
serial_init_64:
    push rdx

    ; Disable interrupts during setup
    mov dx, SERIAL_IER
    xor al, al
    out dx, al

    ; Enable DLAB to set divisor
    mov dx, SERIAL_LCR
    mov al, LCR_DLAB | LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Set divisor low byte (115200 baud)
    mov dx, SERIAL_DLL
    mov al, 0x01
    out dx, al

    ; Set divisor high byte
    mov dx, SERIAL_DLM
    mov al, 0x00
    out dx, al

    ; Clear DLAB and set 8N1 format
    mov dx, SERIAL_LCR
    mov al, LCR_8BIT | LCR_NO_PARITY | LCR_ONE_STOP
    out dx, al

    ; Enable FIFO, clear buffers
    mov dx, SERIAL_FCR
    mov al, 0x07
    out dx, al

    ; Set modem control
    mov dx, SERIAL_MCR
    mov al, 0x03
    out dx, al

    pop rdx
    ret


; serial_write_string_64 - Write null-terminated string to serial port (64-bit)
; Input: RSI = pointer to string
; Output: none
; Clobbers: RAX, RSI
bits 64
serial_write_string_64:
    push rax
    push rdx
    push rdi
.loop:
    lodsb
    test al, al
    jz .done
    call serial_write_char_64
    jmp .loop
.done:
    pop rdi
    pop rdx
    pop rax
    ret
```

注意：64 位模式下用 `RSI/RDI` 而不是 `ESI/EDI`，但串口 I/O 端口还是用 `DX`。

## 第六步：验证串口输出

编译并运行：

```bash
nasm -f bin bootloader.asm -o bootloader.bin
qemu-system-x86_64 -drive format=raw,file=boot.img -serial stdio
```

你应该能在终端看到串口输出：

```
=== BootLoader Stage Start ===
READY TO BOOT CCOS
[1] Stage 1: Loading second stage...
[2] Stage 2: Loading kernel...
READY TO BOOT KERNEL
=== BootLoader Stage End ===
```

如果你想保存到文件：

```bash
qemu-system-x86_64 -drive format=raw,file=boot.img -serial file:serial.log
cat serial.log
```

## 常见问题

### 问题 1：串口没有输出

检查：
1. 是否调用了 `serial_init`
2. QEMU 是否加了 `-serial stdio` 参数
3. 端口地址是否正确（COM1 是 0x3F8）

### 问题 2：输出乱码

检查：
1. 波特率是否匹配（我们用 115200）
2. 数据格式是否正确（8N1）
3. 终端程序是否设置为相同波特率

### 问题 3：保护模式后串口不工作

检查：
1. 是否调用了 `serial_init_32` 或 `serial_init_64`
2. 串口函数的 bits 模式是否正确
