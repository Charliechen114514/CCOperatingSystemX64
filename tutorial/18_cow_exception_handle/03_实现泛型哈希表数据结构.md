# 03 - 实现泛型哈希表数据结构

说实话，在选择 COW 页跟踪的数据结构时，我纠结了好一阵子。

---

## 为什么 COW 需要哈希表

在实现 COW 之前，我们需要解决一个基础问题：如何高效地管理 COW 页的元数据？

### COW 需要什么操作

让我们先看看 COW 模块需要对数据结构做什么：

1. **添加 COW 页**：当 fork() 时，需要把所有共享页添加到跟踪结构
2. **查找 COW 页**：页错误时，需要快速找到对应的 COW 块
3. **删除 COW 页**：引用计数为 0 时，需要从跟踪结构中移除
4. **更新引用计数**：增加或减少引用计数

这些操作的频率很高——每次页错误都需要查找，每次 fork() 需要批量添加。

### 数据结构选择

我考虑了几种数据结构：

| 数据结构 | 查找 | 插入 | 删除 | 内存开销 | 实现复杂度 |
|---------|------|------|------|---------|-----------|
| 链表 | O(n) | O(1) | O(n) | 低 | 简单 |
| 数组 | O(n) | O(1) | O(n) | 中等 | 简单 |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | 中等 | 复杂 |
| 红黑树 | O(log n) | O(log n) | O(log n) | 高 | 非常复杂 |
| 哈希表 | O(1) | O(1) | O(1) | 中等 | 中等 |

对于 COW 这种查找密集型的场景，哈希表是最合适的选择。

### 为什么不用红黑树

红黑树的查找效率是 O(log n)，虽然也不错，但哈希表的 O(1) 更好。而且红黑树的实现复杂度很高，容易出错。

哈希表实现简单，调试容易，性能也更好——这就是我们选择它的原因。

## 哈希表设计决策

在实现之前，我们需要做一些设计决策。

### 开放定址 vs 链式法

哈希表处理冲突有两种主要方法：

**开放定址法**：冲突时在表中寻找下一个空位

```c
// 优点：内存连续，缓存友好
// 缺点：删除复杂，表满时需要扩容
```

**链式法**：每个桶是一个链表

```c
// 优点：实现简单，删除容易
// 缺点：指针开销，缓存不友好
```

我们选择链式法，原因是：

1. 实现简单，不容易出错
2. 删除操作非常直观
3. COW 页数量不会特别多，链式法的开销可以接受

### 桶数量选择

我们使用 64 个桶：

```c
#define COW_HASH_SIZE  64
```

为什么是 64？这是一个经验值：

- 太小：冲突多，链表长，性能差
- 太大：浪费内存
- 64 = 2^6：2 的幂次，可以用位运算优化取模

### 哈希函数选择

对于物理地址这样的指针类型，最简单的哈希函数就是直接使用指针值：

```c
size_t hash_ptr(const void* key) {
    return (size_t)key;
}
```

对于 64 位整数：

```c
size_t hash_uint64(const void* key) {
    uint64_t val = *(const uint64_t*)key;
    return (size_t)val;
}
```

简单直接，效果好。

```c
/* ==============================================================================
 * CCOS - Generic Hash Map Implementation
 * ==============================================================================
 * This module provides a generic hash map data structure that can be reused
 * across different kernel components. Uses chaining for collision resolution.
 * ==============================================================================
 */

#pragma once

#include "defines/types.h"
```

### 函数指针类型

为了实现泛型哈希表，我们需要函数指针：

```c
/* ============================================================================
 * Hash Map Types
 * ============================================================================ */

/**
 * @brief Hash function type
 * @param key Pointer to the key
 * @return Hash value (should be size_t)
 */
typedef size_t (*hash_fn_t)(const void* key);

/**
 * @brief Key equality function type
 * @param a First key
 * @param b Second key
 * @return true if keys are equal, false otherwise
 */
typedef bool (*hash_eq_fn_t)(const void* a, const void* b);
```

### 数据结构定义

```c
/**
 * @brief Hash map entry (internal)
 */
typedef struct hash_entry {
    const void* key;           /* Pointer to key (not owned by hashmap) */
    void* value;               /* Pointer to value (not owned by hashmap) */
    struct hash_entry* next;   /* Next entry in chain */
} hash_entry_t;

/**
 * @brief Hash map structure
 */
typedef struct {
    hash_entry_t** buckets;    /* Array of bucket heads */
    size_t num_buckets;        /* Number of buckets (power of 2 recommended) */
    size_t size;               /* Number of entries currently stored */
    hash_fn_t hash_func;       /* Hash function */
    hash_eq_fn_t eq_func;      /* Equality function */
} hashmap_t;
```

⚠️ 注意：`hash_entry_t` 中的 `key` 和 `value` 指针不被哈希表拥有——这意味着哈希表不会释放它们。这给了调用者完全的控制权。

### API 声明

```c
/* ============================================================================
 * Hash Map API
 * ============================================================================ */

hashmap_t* hashmap_create(size_t num_buckets, hash_fn_t hash_fn, hash_eq_fn_t eq_fn);
void hashmap_destroy(hashmap_t* map);
int hashmap_put(hashmap_t* map, const void* key, void* value);
void* hashmap_get(hashmap_t* map, const void* key);
void* hashmap_remove(hashmap_t* map, const void* key);
size_t hashmap_size(hashmap_t* map);
bool hashmap_contains(hashmap_t* map, const void* key);
void hashmap_clear(hashmap_t* map);

/* ============================================================================
 * Common Hash Functions
 * ============================================================================ */

size_t hash_uint64(const void* key);
size_t hash_ptr(const void* key);
bool eq_uint64(const void* a, const void* b);
bool eq_ptr(const void* a, const void* b);

/* ============================================================================
 * Iteration Support
 * ============================================================================ */

typedef bool (*hashmap_iterator_fn)(const void* key, void* value, void* context);
size_t hashmap_foreach(hashmap_t* map, hashmap_iterator_fn iter_fn, void* context);
```

### 内部辅助函数

首先实现一些内部辅助函数：

```c
/* ==============================================================================
 * CCOS - Generic Hash Map Implementation
 * ==============================================================================
 */

#include "hashmap.h"
#include "memory.h"
#include "mm/heap/heap.h"

/* ============================================================================
 * Internal Helpers
 * ============================================================================ */

/**
 * @brief Get bucket index for a key
 */
static inline size_t bucket_index(hashmap_t* map, const void* key) {
    size_t hash = map->hash_func(key);
    return hash & (map->num_buckets - 1); /* Works for power-of-2 sizes */
}

/**
 * @brief Create a new hash entry
 */
static hash_entry_t* entry_create(const void* key, void* value) {
    hash_entry_t* entry = (hash_entry_t*)kmalloc(sizeof(hash_entry_t));
    if (entry == NULL) {
        return NULL;
    }
    entry->key = key;
    entry->value = value;
    entry->next = NULL;
    return entry;
}
```

`bucket_index` 使用位运算而不是取模，这要求桶数量是 2 的幂次。我们在 `hashmap_create` 中会保证这一点。

### 创建哈希表

```c
hashmap_t* hashmap_create(size_t num_buckets, hash_fn_t hash_fn, hash_eq_fn_t eq_fn) {
    if (num_buckets == 0 || hash_fn == NULL || eq_fn == NULL) {
        return NULL;
    }

    /* Round up to power of 2 if not already */
    size_t buckets = num_buckets;
    if (buckets & (buckets - 1)) {
        /* Find next power of 2 */
        buckets--;
        buckets |= buckets >> 1;
        buckets |= buckets >> 2;
        buckets |= buckets >> 4;
        buckets |= buckets >> 8;
        buckets |= buckets >> 16;
        buckets++;
    }

    /* Allocate hash map structure */
    hashmap_t* map = (hashmap_t*)kmalloc(sizeof(hashmap_t));
    if (map == NULL) {
        return NULL;
    }

    /* Allocate bucket array */
    map->buckets = (hash_entry_t**)kmalloc(sizeof(hash_entry_t*) * buckets);
    if (map->buckets == NULL) {
        kfree(map);
        return NULL;
    }

    /* Initialize buckets to NULL */
    for (size_t i = 0; i < buckets; i++) {
        map->buckets[i] = NULL;
    }

    map->num_buckets = buckets;
    map->size = 0;
    map->hash_func = hash_fn;
    map->eq_func = eq_fn;

    return map;
}
```

这个函数使用一个巧妙的技巧把数字向上取整到 2 的幂次。如果你不熟悉这个技巧，可以花点时间理解一下——它是一位一位地填充 1。

### 插入和查找

```c
int hashmap_put(hashmap_t* map, const void* key, void* value) {
    if (map == NULL || key == NULL) {
        return -1;
    }

    size_t idx = bucket_index(map, key);
    hash_entry_t* entry = map->buckets[idx];

    /* Check if key already exists */
    while (entry != NULL) {
        if (map->eq_func(entry->key, key)) {
            /* Update existing entry */
            entry->value = value;
            return 0;
        }
        entry = entry->next;
    }

    /* Create new entry */
    hash_entry_t* new_entry = entry_create(key, value);
    if (new_entry == NULL) {
        return -2; /* OOM */
    }

    /* Insert at head of bucket */
    new_entry->next = map->buckets[idx];
    map->buckets[idx] = new_entry;
    map->size++;

    return 0;
}

void* hashmap_get(hashmap_t* map, const void* key) {
    if (map == NULL || key == NULL) {
        return NULL;
    }

    size_t idx = bucket_index(map, key);
    hash_entry_t* entry = map->buckets[idx];

    while (entry != NULL) {
        if (map->eq_func(entry->key, key)) {
            return entry->value;
        }
        entry = entry->next;
    }

    return NULL;
}
```

⚠️ 注意：我们使用头插法（插入到链表头部），这样代码最简单。如果你想稍微优化性能，可以改用尾插法。

### 常用哈希函数

```c
/* ============================================================================
 * Common Hash Functions
 * ============================================================================ */

size_t hash_uint64(const void* key) {
    return (size_t)*(const uint64_t*)key;
}

size_t hash_ptr(const void* key) {
    return (size_t)key;
}

bool eq_uint64(const void* a, const void* b) {
    return *(const uint64_t*)a == *(const uint64_t*)b;
}

bool eq_ptr(const void* a, const void* b) {
    return a == b;
}
```

简单直接，对于大多数场景足够好了。

## 使用示例

现在让我们看看如何使用这个哈希表：

### 示例一：基本使用

```c
#include "base/hashmap.h"

void example_basic(void) {
    /* 创建哈希表 */
    hashmap_t* map = hashmap_create(64, hash_uint64, eq_uint64);

    if (map) {
        /* 插入键值对 */
        uint64_t key = 0x1000;
        uint64_t value = 0xDEADBEEF;
        hashmap_put(map, &key, &value);

        /* 查找值 */
        void* result = hashmap_get(map, &key);
        if (result) {
            uint64_t found = *(uint64_t*)result;
            // found = 0xDEADBEEF
        }

        /* 获取大小 */
        size_t size = hashmap_size(map);
        // size = 1

        /* 销毁哈希表 */
        hashmap_destroy(map);
    }
}
```

### 示例二：迭代所有条目

```c
bool iter_callback(const void* key, void* value, void* context) {
    uint64_t k = *(const uint64_t*)key;
    uint64_t v = *(uint64_t*)value;
    klog_info("Key: 0x%llX, Value: 0x%llX\n", k, v);
    return true;  /* 继续迭代 */
}

void example_iterate(hashmap_t* map) {
    hashmap_foreach(map, iter_callback, NULL);
}
```
