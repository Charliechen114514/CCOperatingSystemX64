# LBA48 扩展支持 —— Stage 24 ATA 驱动实战指南

## 前言

上一篇文章我们实现了基于 LBA28 的 PIO 读写，对于小容量磁盘（< 128GB）来说完全够用。但现在的磁盘动辄几百 GB 甚至几 TB，LBA28 的 137GB 限制显然不够用。

LBA48 扩展使用 48 位地址，最大支持 128PB 的磁盘容量。说实话，对于我们的操作系统开发项目来说，LBA48 可能用不上，但作为一个完整的驱动实现，支持它是很有必要的。而且 LBA48 的实现也不复杂，主要是寄存器写入顺序的变化。

这篇文章我们会详细讲解 LBA48 的原理和实现。准备好了吗？我们开始。

---

## LBA28 的容量限制

让我们先看看 LBA28 为什么不够用。

### 计算容量

```
LBA28 最大地址 = 2^28 - 1 = 268,435,455 扇区
最大容量 = 268,435,456 × 512 字节 = 137,438,953,472 字节
         ≈ 128 GB
```

对于 1994 年的硬盘来说，128GB 是天文数字。但在今天：

```
QEMU 默认镜像:    128 MB → 用 LBA28 浪费
现代 SSD:        256 GB → 超过 LBA28 限制
服务器硬盘:      4 TB → 远超 LBA28 限制
```

### 实际影响

虽然我们在这个项目中可能用不到大容量磁盘，但：
1. 完整性 - 一个完整的驱动应该支持所有标准功能
2. 学习价值 - 理解 LBA48 有助于深入理解 ATA 协议
3. 未来扩展 - 以后可能需要支持更大的磁盘

---

## LBA48 命令格式

LBA48 使用"扩展"命令，与 LBA28 命令的主要区别是寄存器写入顺序。

### 扩展命令列表

```c
#define ATA_CMD_READ_SECTORS_EXT  0x24    // LBA48 读
#define ATA_CMD_WRITE_SECTORS_EXT 0x34    // LBA48 写
#define ATA_CMD_FLUSH_CACHE_EXT   0xEA    // LBA48 缓存刷新
```

### 寄存器写入差异

LBA28 写入顺序（每个寄存器写一次）：
```
LBA_LO  ← bits 7:0
LBA_MID ← bits 15:8
LBA_HI  ← bits 23:16
DEVICE  ← bits 27:24 + 设备选择
```

LBA48 写入顺序（每个寄存器写两次）：
```
LBA_LO  ← bits 7:0
LBA_MID ← bits 15:8
LBA_HI  ← bits 23:16

LBA_LO  ← bits 31:24    (再次写入！)
LBA_MID ← bits 39:32
LBA_HI  ← bits 47:40
```

同样，扇区计数寄存器也需要写两次：
```
SECCOUNT ← sectors_low
SECCOUNT ← sectors_high
```

### 为什么这样设计

LBA48 是在 LBA28 基础上的向后兼容扩展：
1. 保持原有寄存器布局
2. 通过"写入两次"来传递更多数据
3. 设备根据命令码判断是 LBA28 还是 LBA48

## LBA48 地址分解

现在我们需要把 64 位 LBA 地址分解到这些寄存器中。

### 地址分解算法

```c
void setup_lba48(uint16_t io_base, uint64_t lba, ata_device_t device,
                 uint16_t sectors) {
    // 第一次写入：低 32 位
    outb(io_base + ATA_REG_SECCOUNT, sectors & 0xFF);        // 扇区数低字节
    outb(io_base + ATA_REG_LBA_LO, lba & 0xFF);             // LBA 7:0
    outb(io_base + ATA_REG_LBA_MID, (lba >> 8) & 0xFF);     // LBA 15:8
    outb(io_base + ATA_REG_LBA_HI, (lba >> 16) & 0xFF);     // LBA 23:16

    // 第二次写入：高 32 位
    outb(io_base + ATA_REG_SECCOUNT, (sectors >> 8) & 0xFF); // 扇区数高字节
    outb(io_base + ATA_REG_LBA_LO, (lba >> 24) & 0xFF);     // LBA 31:24
    outb(io_base + ATA_REG_LBA_MID, (lba >> 32) & 0xFF);     // LBA 39:32
    outb(io_base + ATA_REG_LBA_HI, (lba >> 40) & 0xFF);     // LBA 47:40

    // Device 寄存器保持不变（LBA48 不使用它的高位）
    uint8_t dev_byte = ATA_DEV_LBA;
    if (device == ATA_DEVICE_SLAVE) {
        dev_byte |= ATA_DEV_SLAVE;
    }
    outb(io_base + ATA_REG_DEVICE, dev_byte);
}
```

### 扇区数的处理

LBA48 支持 16 位扇区数（最大 65536），而 LBA28 只支持 8 位（最大 256）：

```c
// LBA28: sectors = 256 编码为 0
uint8_t sec_count = (sectors == 256) ? 0 : sectors;

// LBA48: sectors = 65536 编码为 0x0000
uint16_t sec_count = sectors;  // 0 表示 65536
```

## LBA48 读取实现

现在我们来实现 LBA48 的读取功能。

### ata_read_pio_lba48() 函数

```c
ata_result_t ata_read_pio_lba48(ata_controller_t* ctrl, ata_device_t device,
                                uint64_t lba, void* buffer, uint16_t sectors) {
    // 第一步：选择设备
    uint8_t dev_byte = ATA_DEV_LBA;
    if (device == ATA_DEVICE_SLAVE) {
        dev_byte |= ATA_DEV_SLAVE;
    }
    outb(ctrl->io_base + ATA_REG_DEVICE, dev_byte);

    ata_delay();

    // 第二步：等待 BSY 清除
    ata_result_t result = ata_wait_bsy(ctrl->io_base);
    if (result != ATA_OK) return result;

    // 第三步：设置 LBA48 地址
    // 第一次写入
    outb(ctrl->io_base + ATA_REG_SECCOUNT, sectors & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_LO, lba & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_MID, (lba >> 8) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_HI, (lba >> 16) & 0xFF);

    // 第二次写入
    outb(ctrl->io_base + ATA_REG_SECCOUNT, (sectors >> 8) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_LO, (lba >> 24) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_MID, (lba >> 32) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_HI, (lba >> 40) & 0xFF);

    // 第四步：发送 LBA48 读命令
    outb(ctrl->io_base + ATA_REG_COMMAND, ATA_CMD_READ_SECTORS_EXT);

    // 第五步：读取数据
    uint16_t* buf16 = (uint16_t*)buffer;

    for (uint16_t sec = 0; sec < sectors; sec++) {
        // 等待 BSY 清除
        result = ata_wait_bsy(ctrl->io_base);
        if (result != ATA_OK) return result;

        // 等待 DRQ 置位
        result = ata_wait_drq(ctrl->io_base);
        if (result != ATA_OK) return result;

        // 读取 256 字
        for (int i = 0; i < 256; i++) {
            buf16[sec * 256 + i] = inw(ctrl->io_base + ATA_REG_DATA);
        }
    }

    return ATA_OK;
}
```

### 与 LBA28 读取的差异

1. **命令不同** - 使用 `ATA_CMD_READ_SECTORS_EXT`
2. **寄存器写入两次** - 传递 48 位地址
3. **扇区数 16 位** - 支持更多扇区

## LBA48 写入实现

写入实现与读取类似，但需要注意数据方向和缓存刷新。

### ata_write_pio_lba48() 函数

```c
ata_result_t ata_write_pio_lba48(ata_controller_t* ctrl, ata_device_t device,
                                 uint64_t lba, const void* buffer, uint16_t sectors) {
    // 第一步：选择设备
    uint8_t dev_byte = ATA_DEV_LBA;
    if (device == ATA_DEVICE_SLAVE) {
        dev_byte |= ATA_DEV_SLAVE;
    }
    outb(ctrl->io_base + ATA_REG_DEVICE, dev_byte);

    ata_delay();

    // 第二步：等待 BSY 清除
    ata_result_t result = ata_wait_bsy(ctrl->io_base);
    if (result != ATA_OK) return result;

    // 第三步：设置 LBA48 地址
    // 第一次写入
    outb(ctrl->io_base + ATA_REG_SECCOUNT, sectors & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_LO, lba & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_MID, (lba >> 8) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_HI, (lba >> 16) & 0xFF);

    // 第二次写入
    outb(ctrl->io_base + ATA_REG_SECCOUNT, (sectors >> 8) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_LO, (lba >> 24) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_MID, (lba >> 32) & 0xFF);
    outb(ctrl->io_base + ATA_REG_LBA_HI, (lba >> 40) & 0xFF);

    // 第四步：发送 LBA48 写命令
    outb(ctrl->io_base + ATA_REG_COMMAND, ATA_CMD_WRITE_SECTORS_EXT);

    // 第五步：写入数据
    const uint16_t* buf16 = (const uint16_t*)buffer;

    for (uint16_t sec = 0; sec < sectors; sec++) {
        // 等待 DRQ 置位
        result = ata_wait_drq(ctrl->io_base);
        if (result != ATA_OK) return result;

        // 写入 256 字
        for (int i = 0; i < 256; i++) {
            outw(ctrl->io_base + ATA_REG_DATA, buf16[sec * 256 + i]);
        }
    }

    // 第六步：刷新缓存
    ata_flush_cache_ext(ctrl);

    return ATA_OK;
}
```

### LBA48 缓存刷新

```c
ata_result_t ata_flush_cache_ext(ata_controller_t* ctrl) {
    // 发送 LBA48 刷新命令
    outb(ctrl->io_base + ATA_REG_COMMAND, ATA_CMD_FLUSH_CACHE_EXT);

    // 等待完成
    return ata_wait_bsy(ctrl->io_base);
}
```

## 自动选择 LBA 模式

现在我们需要修改公共 API，让它能够自动选择使用 LBA28 还是 LBA48。

### 修改后的 ata_read()

```c
ata_result_t ata_read(int device, uint64_t lba,
                      void* buffer, uint16_t sectors) {
    // ... 参数验证和控制器获取 ...

    // 检查设备是否支持 LBA48
    ata_device_info_t info;
    ata_result_t info_result = ata_get_info(device, &info);

    bool use_lba48 = false;
    if (info_result == ATA_OK && info.lba48_supported) {
        // 如果 LBA 地址超过 LBA28 范围，必须使用 LBA48
        if (lba >= 0x0FFFFFFF) {  // 2^28 - 1
            use_lba48 = true;
        }
    }

    // 调用对应的读取函数
    ata_result_t result;
    if (use_lba48) {
        result = ata_read_pio_lba48(ctrl, drive, lba, buffer, sectors);
    } else {
        result = ata_read_pio(ctrl, drive, (uint32_t)lba, buffer, sectors);
    }

    // 更新统计
    if (result == ATA_OK) {
        ctrl->read_count++;
    } else {
        ctrl->error_count++;
    }

    return result;
}
```

### 修改后的 ata_write()

```c
ata_result_t ata_write(int device, uint64_t lba,
                       const void* buffer, uint16_t sectors) {
    // ... 参数验证和控制器获取 ...

    // 检查设备是否支持 LBA48
    ata_device_info_t info;
    ata_result_t info_result = ata_get_info(device, &info);

    bool use_lba48 = false;
    if (info_result == ATA_OK && info.lba48_supported) {
        if (lba >= 0x0FFFFFFF) {
            use_lba48 = true;
        }
    }

    // 调用对应的写入函数
    ata_result_t result;
    if (use_lba48) {
        result = ata_write_pio_lba48(ctrl, drive, lba, buffer, sectors);
    } else {
        result = ata_write_pio(ctrl, drive, (uint32_t)lba, buffer, sectors);
    }

    // 更新统计
    if (result == ATA_OK) {
        ctrl->write_count++;
    } else {
        ctrl->error_count++;
    }

    return result;
}
```

## 存储设备信息

为了让 `ata_get_info()` 能够工作，我们需要在初始化时存储设备信息。

### 全局设备信息数组

```c
static ata_device_info_t g_device_info[4];  // 4 个设备的信息
```

### 在初始化时填充

```c
int ata_init(void) {
    // ... 控制器初始化 ...

    // 检测并识别设备
    for (int ctrl_idx = 0; ctrl_idx < 2; ctrl_idx++) {
        ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];

        for (int dev = 0; dev < 2; dev++) {
            ata_device_t device = (dev == 0) ? ATA_DEVICE_MASTER : ATA_DEVICE_SLAVE;
            int device_idx = ctrl_idx * 2 + dev;

            // 检测设备
            bool present = ata_device_present(ctrl, device);
            if (dev == 0) {
                ctrl->master_present = present;
            } else {
                ctrl->slave_present = present;
            }

            // 如果存在，读取信息
            if (present) {
                ata_result_t result = ata_identify_device(
                    ctrl, device, &g_device_info[device_idx]);

                if (result == ATA_OK) {
                    klog_info("[ATA] Device %d: %s\n", device_idx,
                              g_device_info[device_idx].model);
                    klog_info("[ATA]   Capacity: %llu sectors (%llu MB)\n",
                              g_device_info[device_idx].lba48_sectors ?
                              g_device_info[device_idx].lba48_sectors :
                              g_device_info[device_idx].lba_sectors,
                              (g_device_info[device_idx].lba48_sectors ?
                               g_device_info[device_idx].lba48_sectors :
                               g_device_info[device_idx].lba_sectors) / 2048);
                }
            }
        }
    }

    return 0;
}
```

### ata_get_info() 实现

```c
ata_result_t ata_get_info(int device, ata_device_info_t* info) {
    if (device < 0 || device > 3) {
        return ATA_ERR_INVALID_PARAM;
    }
    if (info == NULL) {
        return ATA_ERR_INVALID_PARAM;
    }

    int ctrl_idx = ATA_DEV_TO_CONTROLLER(device);
    ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];

    if (!ctrl->initialized) {
        return ATA_ERR_NOT_INIT;
    }

    // 复制存储的设备信息
    *info = g_device_info[device];
    return ATA_OK;
}
```

## 测试 LBA48 功能

### 测试大 LBA 地址

```c
void test_lba48_read(void) {
    // 假设我们有一个大容量磁盘
    ata_device_info_t info;
    ata_result_t result = ata_get_info(ATA_PRIMARY_MASTER, &info);

    if (result != ATA_OK) {
        klog_error("Failed to get device info\n");
        return;
    }

    if (!info.lba48_supported) {
        klog_info("Device does not support LBA48\n");
        return;
    }

    klog_info("Device supports LBA48\n");
    klog_info("  LBA28 sectors: %llu\n", info.lba_sectors);
    klog_info("  LBA48 sectors: %llu\n", info.lba48_sectors);

    // 读取接近 LBA28 边界的扇区
    if (info.lba48_sectors > 0x0FFFFFFF) {
        uint8_t buffer[512];
        uint64_t test_lba = 0x0FFFFFFF;  // LBA28 边界

        result = ata_read(ATA_PRIMARY_MASTER, test_lba, buffer, 1);

        if (result == ATA_OK) {
            klog_info("Successfully read LBA %llu (LBA48 range)\n", test_lba);
        } else {
            klog_error("Failed to read LBA %llu: %s\n",
                       test_lba, ata_error_string(result));
        }
    }
}
```

## 常见问题排查

### 问题 1：大 LBA 地址读取失败

**症状**：LBA 地址超过 2^28 时读取失败

**可能原因**：
1. 设备不支持 LBA48
2. 未正确使用 LBA48 命令
3. 寄存器写入顺序错误

**解决方案**：
```c
// 检查设备是否支持 LBA48
if (!info.lba48_supported) {
    klog_error("Device does not support LBA48\n");
    return ATA_ERR_UNSUPPORTED;
}
```

### 问题 2：LBA48 与 LBA28 混淆

**症状**：在小 LBA 地址上使用 LBA48 命令失败

**原因**：某些设备对 LBA48 命令支持不完善

**解决方案**：优先使用 LBA28，只在必要时使用 LBA48

```c
// 只在 LBA 地址超过 LBA28 范围时使用 LBA48
if (lba >= 0x0FFFFFFF && info.lba48_supported) {
    use_lba48 = true;
}
```
