# 异步 I/O 与中断驱动 —— Stage 24 ATA 驱动实战指南

## 前言

到目前为止，我们实现的 ATA 驱动都是基于同步轮询模式的。每次读写操作，CPU 都要傻傻地等待设备完成，期间什么都不能做。说实话，这种方式对于单任务系统来说还可以接受，但对于一个"真正"的操作系统来说，这简直是灾难。

想象一下，你的系统正在从磁盘读取一个大文件，CPU 被完全阻塞，连键盘输入都无法响应。用户体验极差。

异步 I/O 通过中断驱动模式解决了这个问题。CPU 发起读写请求后可以立即返回去做其他事情，当设备完成操作时会触发中断，然后处理程序来处理数据。这篇文章我们会实现完整的异步 I/O 系统。准备好了吗？我们开始。

---

## 同步模式的问题

让我们先看看同步模式的问题有多严重。

### CPU 时间浪费

```c
// 同步读取
ata_read(device, lba, buffer, sectors);
// CPU 在这里傻等，可能等待几毫秒甚至更久

// 这段时间 CPU 本可以做：
// - 处理用户输入
// - 运行其他进程
// - 响应网络请求
// - ...任何有用的事情
```

### 系统响应延迟

```
时间线：
0ms:   进程 A 调用 ata_read()
1ms:   CPU 等待 DRQ...
2ms:   CPU 等待 DRQ...
3ms:   用户按下键盘（无法处理）
4ms:   CPU 等待 DRQ...
5ms:   网络包到达（无法处理）
10ms:  ata_read() 返回
10ms+: 才能处理之前的事件
```

可以看到，整个系统在磁盘 I/O 期间基本是"冻结"的。

## 异步 I/O 设计

我们的异步 I/O 设计基于中断驱动模式。

### 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                   应用程序                               │
│  ata_read_async(..., callback, context)                 │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│              ATA 驱动异步层                              │
│  - 创建异步操作描述符                                     │
│  - 加入操作队列                                           │
│  - 启动第一个操作                                         │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│              硬件中断层                                   │
│  IRQ 14/15 触发                                          │
│  → ata_irq_handler()                                    │
│  - 传输数据                                              │
│  - 完成操作                                              │
│  - 调用回调                                              │
│  - 启动下一个操作                                         │
└─────────────────────────────────────────────────────────┘
```

### 异步操作结构

每个异步操作用一个描述符表示：

```c
typedef struct ata_async_operation {
    ata_async_op_type_t type;        // 读/写/刷新
    ata_async_status_t status;       // 当前状态

    int device;                      // 设备号
    ata_device_t drive;              // 主/从
    uint64_t lba;                    // 起始 LBA
    uint16_t sectors;                // 扇区数
    uint16_t sectors_done;           // 已完成
    void* buffer;                    // 数据缓冲区

    ata_async_callback_fn callback;  // 完成回调
    void* context;                   // 用户上下文

    bool use_lba48;                  // 使用 LBA48
    struct ata_async_operation* next; // 队列链接
} ata_async_operation_t;
```

### 操作队列

每个控制器有一个操作队列：

```c
typedef struct ata_async_queue {
    struct ata_async_operation* head;     // 队列头
    struct ata_async_operation* tail;     // 队列尾
    struct ata_async_operation* active;   // 当前执行的操作
    volatile bool irq_pending;             // IRQ 待处理标志
} ata_async_queue_t;
```

## 异步 I/O 初始化

在使用异步模式之前，需要先初始化。

### ata_init_async_mode() 函数

```c
ata_result_t ata_init_async_mode(void) {
    // 确保同步初始化已完成
    if (!g_ata_controllers[0].initialized &&
        !g_ata_controllers[1].initialized) {
        return ATA_ERR_NOT_INIT;
    }

    // 初始化两个控制器的异步 I/O
    ata_result_t result;

    result = ata_init_async_io(&g_ata_controllers[0]);
    if (result != ATA_OK) {
        klog_error("[ATA] Failed to init Primary async I/O: %s\n",
                   ata_error_string(result));
        return result;
    }

    result = ata_init_async_io(&g_ata_controllers[1]);
    if (result != ATA_OK) {
        klog_error("[ATA] Failed to init Secondary async I/O: %s\n",
                   ata_error_string(result));
        return result;
    }

    klog_info("[ATA] Async I/O mode enabled\n");
    return ATA_OK;
}
```

### ata_init_async_io() 实现

```c
ata_result_t ata_init_async_io(ata_controller_t* ctrl) {
    // 分配队列
    ctrl->queue = kmalloc(sizeof(ata_async_queue_t));
    if (ctrl->queue == NULL) {
        return ATA_ERR_IO_ERROR;
    }

    // 初始化队列
    ctrl->queue->head = NULL;
    ctrl->queue->tail = NULL;
    ctrl->queue->active = NULL;
    ctrl->queue->irq_pending = false;

    // 注册 IRQ 处理器
    int irq_vector = 32 + ctrl->irq;  // IRQ 14 = 向量 46, IRQ 15 = 向量 47

    idt_register_handler(irq_vector, ata_irq_handler, ctrl);

    // 保存 IRQ 描述符以便后续管理
    ctrl->irq_desc.vector = irq_vector;
    ctrl->irq_desc.handler = ata_irq_handler;
    ctrl->irq_desc.context = ctrl;

    // 启用 IRQ
    pic_enable_irq(ctrl->irq);

    // 启用控制器中断
    ata_enable_interrupts(ctrl);

    ctrl->use_async_mode = true;
    ctrl->interrupts_enabled = true;

    return ATA_OK;
}
```

## 启用中断

ATA 控制器默认中断是禁用的，需要手动启用。

### ata_enable_interrupts() 函数

```c
void ata_enable_interrupts(ata_controller_t* ctrl) {
    // 读取 Device Control 寄存器
    uint8_t ctl = inb(ctrl->ctrl_base + ATA_CTRL_DEVICE_CTL);

    // 清除 nIEN 位（位 1）来启用中断
    ctl &= ~ATA_CTL_nIEN;

    // 写回寄存器
    outb(ctrl->ctrl_base + ATA_CTRL_DEVICE_CTL, ctl);
}
```

### 禁用中断

```c
void ata_disable_interrupts(ata_controller_t* ctrl) {
    // 读取 Device Control 寄存器
    uint8_t ctl = inb(ctrl->ctrl_base + ATA_CTRL_DEVICE_CTL);

    // 设置 nIEN 位来禁用中断
    ctl |= ATA_CTL_nIEN;

    // 写回寄存器
    outb(ctrl->ctrl_base + ATA_CTRL_DEVICE_CTL, ctl);
}
```

## 异步读取实现

现在我们实现异步读取的公共 API。

### ata_read_async() 函数

```c
ata_result_t ata_read_async(int device, uint64_t lba, void* buffer,
                            uint16_t sectors, ata_read_callback_fn callback,
                            void* context) {
    // 参数验证
    if (device < 0 || device > 3) {
        return ATA_ERR_INVALID_PARAM;
    }
    if (buffer == NULL) {
        return ATA_ERR_INVALID_PARAM;
    }
    if (sectors == 0 || sectors > 65536) {
        return ATA_ERR_INVALID_PARAM;
    }

    // 获取控制器
    int ctrl_idx = ATA_DEV_TO_CONTROLLER(device);
    ata_device_t drive = ATA_DEV_TO_DRIVE(device);
    ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];

    if (!ctrl->initialized || !ctrl->use_async_mode) {
        return ATA_ERR_NOT_INIT;
    }

    // 检查设备存在
    bool present = (drive == ATA_DEVICE_MASTER) ?
                   ctrl->master_present : ctrl->slave_present;
    if (!present) {
        return ATA_ERR_NO_DEVICE;
    }

    // 分配异步操作描述符
    ata_async_operation_t* op = kmalloc(sizeof(ata_async_operation_t));
    if (op == NULL) {
        return ATA_ERR_IO_ERROR;
    }

    // 填充操作描述符
    op->type = ATA_ASYNC_OP_READ;
    op->status = ATA_ASYNC_PENDING;
    op->device = device;
    op->drive = drive;
    op->lba = lba;
    op->sectors = sectors;
    op->sectors_done = 0;
    op->buffer = buffer;
    op->callback = (ata_async_callback_fn)callback;
    op->context = context;

    // 判断是否使用 LBA48
    ata_device_info_t info;
    if (ata_get_info(device, &info) == ATA_OK && info.lba48_supported && lba >= 0x0FFFFFFF) {
        op->use_lba48 = true;
    } else {
        op->use_lba48 = false;
    }

    op->next = NULL;

    // 加入队列
    ata_async_queue_t* queue = ctrl->queue;

    if (queue->tail == NULL) {
        // 队列为空，设置为头和尾
        queue->head = op;
        queue->tail = op;
    } else {
        // 加入队尾
        queue->tail->next = op;
        queue->tail = op;
    }

    // 如果没有活跃操作，启动这个操作
    if (queue->active == NULL) {
        ata_start_next_async_op(ctrl);
    }

    return ATA_OK;
}
```

## 启动异步操作

当队列为空或有操作完成时，需要启动下一个操作。

### ata_start_next_async_op() 函数

```c
void ata_start_next_async_op(ata_controller_t* ctrl) {
    ata_async_queue_t* queue = ctrl->queue;

    if (queue == NULL) {
        return;
    }

    // 如果当前有活跃操作，不启动新的
    if (queue->active != NULL) {
        return;
    }

    // 获取队列头部的操作
    ata_async_operation_t* op = queue->head;
    if (op == NULL) {
        return;  // 队列为空
    }

    // 从队列移除
    queue->head = op->next;
    if (queue->head == NULL) {
        queue->tail = NULL;
    }

    // 设置为活跃操作
    queue->active = op;
    op->status = ATA_ASYNC_IN_PROGRESS;

    // 选择设备
    uint8_t dev_byte = ATA_DEV_LBA;
    if (op->drive == ATA_DEVICE_SLAVE) {
        dev_byte |= ATA_DEV_SLAVE;
    }
    outb(ctrl->io_base + ATA_REG_DEVICE, dev_byte);
    ata_delay();

    // 根据操作类型启动
    switch (op->type) {
        case ATA_ASYNC_OP_READ:
            ata_start_async_read(ctrl, op);
            break;
        case ATA_ASYNC_OP_WRITE:
            ata_start_async_write(ctrl, op);
            break;
        case ATA_ASYNC_OP_FLUSH:
            ata_start_async_flush(ctrl, op);
            break;
    }
}
```

### 启动异步读取

```c
void ata_start_async_read(ata_controller_t* ctrl, ata_async_operation_t* op) {
    uint16_t io_base = ctrl->io_base;
    uint64_t lba = op->lba;
    uint16_t sectors = op->sectors;

    if (op->use_lba48) {
        // LBA48 设置
        outb(io_base + ATA_REG_SECCOUNT, sectors & 0xFF);
        outb(io_base + ATA_REG_LBA_LO, lba & 0xFF);
        outb(io_base + ATA_REG_LBA_MID, (lba >> 8) & 0xFF);
        outb(io_base + ATA_REG_LBA_HI, (lba >> 16) & 0xFF);

        outb(io_base + ATA_REG_SECCOUNT, (sectors >> 8) & 0xFF);
        outb(io_base + ATA_REG_LBA_LO, (lba >> 24) & 0xFF);
        outb(io_base + ATA_REG_LBA_MID, (lba >> 32) & 0xFF);
        outb(io_base + ATA_REG_LBA_HI, (lba >> 40) & 0xFF);

        outb(io_base + ATA_REG_COMMAND, ATA_CMD_READ_SECTORS_EXT);
    } else {
        // LBA28 设置
        uint8_t sec_count = (sectors == 256) ? 0 : sectors;
        outb(io_base + ATA_REG_SECCOUNT, sec_count);
        outb(io_base + ATA_REG_LBA_LO, lba & 0xFF);
        outb(io_base + ATA_REG_LBA_MID, (lba >> 8) & 0xFF);
        outb(io_base + ATA_REG_LBA_HI, (lba >> 16) & 0xFF);

        uint8_t dev_byte = ATA_DEV_LBA;
        if (op->drive == ATA_DEVICE_SLAVE) {
            dev_byte |= ATA_DEV_SLAVE;
        }
        dev_byte |= (lba >> 24) & 0x0F;
        outb(io_base + ATA_REG_DEVICE, dev_byte);

        outb(io_base + ATA_REG_COMMAND, ATA_CMD_READ_SECTORS);
    }

    // 命令已发送，中断会触发后续处理
}
```

## IRQ 处理器

中断发生时，我们需要处理数据传输并完成操作。

### ata_irq_handler() 函数

```c
void ata_irq_handler(interrupt_frame_t* frame, void* context) {
    ata_controller_t* ctrl = (ata_controller_t*)context;
    ata_async_queue_t* queue = ctrl->queue;

    if (queue == NULL || queue->active == NULL) {
        // 没有活跃操作，可能是假中断
        pic_send_eoi(ctrl->irq);
        return;
    }

    ata_async_operation_t* op = queue->active;
    uint16_t io_base = ctrl->io_base;

    // 读取状态
    uint8_t status = inb(io_base + ATA_REG_STATUS);

    // 检查错误
    if (status & ATA_STATUS_ERR) {
        // 操作失败
        op->status = ATA_ASYNC_ERROR;
        ata_complete_async_op(op, ATA_ERR_IO_ERROR);
        pic_send_eoi(ctrl->irq);
        return;
    }

    // 检查是否有数据可传输
    if (status & ATA_STATUS_DRQ) {
        // 传输一个扇区
        uint16_t* buf16 = (uint16_t*)op->buffer;
        uint16_t offset = op->sectors_done * 256;

        if (op->type == ATA_ASYNC_OP_READ) {
            // 读取数据
            for (int i = 0; i < 256; i++) {
                buf16[offset + i] = inw(io_base + ATA_REG_DATA);
            }
        }

        op->sectors_done++;

        // 检查是否完成
        if (op->sectors_done >= op->sectors) {
            // 操作完成
            op->status = ATA_ASYNC_COMPLETED;
            ata_complete_async_op(op, ATA_OK);
        }
        // 如果没有完成，设备会再次触发中断
    }

    // 发送 EOI
    pic_send_eoi(ctrl->irq);
}
```

### 完成异步操作

```c
void ata_complete_async_op(ata_async_operation_t* op, ata_result_t result) {
    // 获取控制器
    int ctrl_idx = ATA_DEV_TO_CONTROLLER(op->device);
    ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];
    ata_async_queue_t* queue = ctrl->queue;

    // 清除活跃操作
    queue->active = NULL;

    // 调用回调（如果存在）
    if (op->callback != NULL) {
        op->callback(op->device, op->lba, op->sectors,
                    op->buffer, result, op->context);
    }

    // 释放操作描述符
    kfree(op);

    // 启动下一个操作
    ata_start_next_async_op(ctrl);
}
```

## 异步写入实现

异步写入的实现与读取类似，但数据传输方向相反。

### ata_write_async() 函数

```c
                             void* context) {

    if (device < 0 || device > 3) {
        return ATA_ERR_INVALID_PARAM;
    }
    if (buffer == NULL) {
        return ATA_ERR_INVALID_PARAM;
    }
    if (sectors == 0 || sectors > 65536) {
        return ATA_ERR_INVALID_PARAM;
    }

    // 获取控制器
    int ctrl_idx = ATA_DEV_TO_CONTROLLER(device);
    ata_device_t drive = ATA_DEV_TO_DRIVE(device);
    ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];

    if (!ctrl->initialized || !ctrl->use_async_mode) {
        return ATA_ERR_NOT_INIT;
    }

    // 检查设备存在
    bool present = (drive == ATA_DEVICE_MASTER) ?
                   ctrl->master_present : ctrl->slave_present;
    if (!present) {
        return ATA_ERR_NO_DEVICE;
    }

    // 分配异步操作描述符
    ata_async_operation_t* op = kmalloc(sizeof(ata_async_operation_t));
    if (op == NULL) {
        return ATA_ERR_IO_ERROR;
    }

    // 填充操作描述符
    op->type = ATA_ASYNC_OP_WRITE;
    op->status = ATA_ASYNC_PENDING;

    op->drive = drive;
    op->lba = lba;

    op->sectors_done = 0;
    op->buffer = (void*)buffer;  // 去掉 const，内部使用
    op->callback = (ata_async_callback_fn)callback;
    op->context = context;

    // 判断是否使用 LBA48
    ata_device_info_t info;
    if (ata_get_info(device, &info) == ATA_OK && info.lba48_supported && lba >= 0x0FFFFFFF) {
        op->use_lba48 = true;
    } else {
        op->use_lba48 = false;
    }

    op->next = NULL;

    // 加入队列
    ata_async_queue_t* queue = ctrl->queue;

    if (queue->tail == NULL) {
        queue->head = op;
        queue->tail = op;
    } else {
        queue->tail->next = op;
        queue->tail = op;
    }

    // 如果没有活跃操作，启动这个操作
    if (queue->active == NULL) {
        ata_start_next_async_op(ctrl);
    }

    return ATA_OK;
}
```

## 轮询完成状态

如果不使用回调，可以轮询操作是否完成。

### ata_async_is_idle() 函数

```c
bool ata_async_is_idle(int device) {
    if (device < 0 || device > 3) {
        return true;
    }

    int ctrl_idx = ATA_DEV_TO_CONTROLLER(device);
    ata_controller_t* ctrl = &g_ata_controllers[ctrl_idx];

    if (!ctrl->initialized || !ctrl->use_async_mode) {
        return true;
    }

    ata_async_queue_t* queue = ctrl->queue;
    if (queue == NULL) {
        return true;
    }

    // 检查是否有活跃或排队的操作
    return (queue->active == NULL && queue->head == NULL);
}
```

## 使用示例

现在我们来看看如何使用异步 API。

### 异步读取示例

```c
// 回调函数
void read_complete(int device, uint64_t lba, uint16_t sectors,
                   void* buffer, ata_result_t result, void* context) {
    if (result == ATA_OK) {
        klog_info("Async read completed: %u sectors from LBA %llu\n",
                  sectors, lba);
        // 处理数据...
    } else {
        klog_error("Async read failed: %s\n", ata_error_string(result));
    }
}

// 启动异步读取
void example_async_read(void) {
    static uint8_t buffer[4096];  // 必须是静态或全局的！

    ata_result_t result = ata_read_async(
        ATA_PRIMARY_MASTER,
        0,              // LBA 0
        buffer,
        8,              // 8 个扇区
        read_complete,
        NULL            // 不需要上下文
    );

    if (result != ATA_OK) {
        klog_error("Failed to start async read: %s\n",
                   ata_error_string(result));
    }

    // 可以做其他事情...
    klog_info("Async read started, doing other work...\n");
}
```

```c
void example_polling_async(void) {

    // 启动异步读取（不使用回调）
    ata_read_async(ATA_PRIMARY_MASTER, 0, buffer, 8, NULL, NULL);

    // 做其他事情
    do_other_work();

    // 等待完成
    while (!ata_async_is_idle(ATA_PRIMARY_MASTER)) {
        // 继续做其他事情
        do_more_work();
    }

    klog_info("Async read completed!\n");
}
```

## 常见问题排查

### 问题 1：中断从未触发

**症状**：异步操作启动后永远不完成

**可能原因**：
1. IRQ 未启用
2. IRQ 处理器未注册
3. nIEN 位被设置

**解决方案**：
```c
// 检查 IRQ 状态
pic_enable_irq(14);  // Primary
pic_enable_irq(15);  // Secondary

ata_enable_interrupts(ctrl);
```

### 问题 2：假中断

**症状**：没有异步操作时也触发中断

**原因**：ATA 控制器的硬件特性

**解决方案**：
```c
if (queue->active == NULL) {
    // 假中断，不发送 EOI
    return;
}
```

### 问题 3：回调函数中的数据损坏

**症状**：回调函数中读取的数据不正确

**原因**：buffer 在操作完成前被释放或重用

**解决方案**：确保 buffer 在异步操作期间保持有效
```c
// 错误
void bad_example(void) {
    uint8_t buffer[512];  // 栈上的缓冲区
    ata_read_async(..., buffer, ...);
}  // buffer 失效！

// 正确
static uint8_t g_buffer[512];  // 静态或全局缓冲区
void good_example(void) {
    ata_read_async(..., g_buffer, ...);
}
```
