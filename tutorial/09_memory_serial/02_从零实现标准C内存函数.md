# 02 - 从零实现标准 C 内存函数

说实话，实现内存函数听起来很简单，但里面有不少坑。

---

## 我们现在要做什么

我们需要实现四个标准 C 内存函数：`memset`、`memcpy`、`memmove`、`memcmp`。

但是这里有个问题：**怎么测试这些函数？**

如果每次都要重新编译内核、启动 QEMU 才能测试，那开发效率也太低了。所以我们先搭建一个**主机端测试环境**，让我们能在宿主机上直接测试这些函数。

---

## 第一步 —— 创建目录和头文件

我们先创建一个 `kernel/base/` 目录来存放基础库函数：

```bash
mkdir -p kernel/base
```

然后创建头文件 `kernel/base/memory.h`：

```c
/**
 * @file memory.h
 * @brief Standard C memory operation functions
 */
#pragma once

#include <stddef.h>

/**
 * @brief Fill memory block with a constant byte
 * @param s Pointer to memory block
 * @param c Byte value to fill
 * @param n Number of bytes to fill
 * @return Original pointer s
 */
void* memset(void* s, int c, size_t n);

/**
 * @brief Copy memory block (non-overlapping)
 * @param dest Destination pointer
 * @param src Source pointer
 * @param n Number of bytes to copy
 * @return Destination pointer dest
 * @warning Undefined behavior if source and destination overlap
 */
void* memcpy(void* dest, const void* src, size_t n);

/**
 * @brief Copy memory block (supports overlapping)
 * @param dest Destination pointer
 * @param src Source pointer
 * @param n Number of bytes to copy
 * @return Destination pointer dest
 */
void* memmove(void* dest, const void* src, size_t n);

/**
 * @brief Compare two memory blocks
 * @param s1 First memory block
 * @param s2 Second memory block
 * @param n Number of bytes to compare
 * @return Negative if s1 < s2, 0 if equal, Positive if s1 > s2
 */
int memcmp(const void* s1, const void* s2, size_t n);
```

**⚠️ 注意**：我们使用 `#pragma once` 而不是 include guard，这在现代编译器上是标准做法。

---

## 第二步 —— 实现 memset

`memset` 是最简单的一个，但有一个有趣的地方：我们从后向前填充。

创建文件 `kernel/base/memory.c`：

```c
#include "memory.h"

void* memset(void* s, int c, size_t n) {
    char* asByteWrite = (char*)s;
    while (n > 0) {
        asByteWrite[n - 1] = (char)c;
        n--;
    }
    return s;
}
```

**为什么从后向前？**

这是一种实现风格。从前向后、从后向前都可以，关键是：
1. 使用 `n - 1` 作为索引，避免额外的计数器变量
2. 参数 `c` 会被自动转换为 `unsigned char`（符合 C 标准）
3. 返回原始指针，支持链式调用

**⚠️ 常见错误**：

```c
// ❌ 错误：期望填充 0x1234，实际只填充 0x34
memset(ptr, 0x1234, 100);

// ✅ 正确：只填充单个字节
memset(ptr, 0x34, 100);
```

`memset` 只能填充单字节值，高位会被截断。

---

## 第三步 —— 实现 memcpy

`memcpy` 从低地址向高地址拷贝，**不支持重叠内存区域**：

```c
void* memcpy(void* dest, const void* src, size_t n) {
    char* asCharDest = (char*)dest;
    char* asCharSrc = (char*)src;

    while (n > 0) {
        *asCharDest = *asCharSrc;
        asCharDest++;
        asCharSrc++;
        n--;
    }

    return dest;
}
```

**为什么不能处理重叠？**

假设你要把 `[0,1,2,3,4]` 拷贝到偏移 1 的位置：

```
源：  [0, 1, 2, 3, 4, ...]
目标：    [?, ?, ?, ?, ...]
           ↑ 从这里开始拷贝
```

从前向后拷贝：
```
步骤 1: [0, 0, 2, 3, 4, ...]  # 第一个 0 被拷贝
步骤 2: [0, 0, 0, 3, 4, ...]  # 第二个 0 是刚拷贝的，不是原来的 1！
步骤 3: [0, 0, 0, 0, 4, ...]  # 崩溃了...
```

这就是为什么我们需要 `memmove`。

---

## 第四步 —— 实现 memmove

`memmove` 能正确处理重叠，关键是**根据重叠情况决定拷贝方向**：

```c
void* memmove(void* dest, const void* src, size_t n) {
    unsigned char* d = (unsigned char*)dest;
    const unsigned char* s = (const unsigned char*)src;

    if (d == s || n == 0) {
        return dest;
    }

    // 检测重叠：dest 在 src 范围内需要反向拷贝
    if (d > s && d < s + n) {
        // 从后向前拷贝
        d += n;
        s += n;
        while (n--) {
            *(--d) = *(--s);
        }
    } else {
        // 从前向后拷贝
        while (n--) {
            *d++ = *s++;
        }
    }

    return dest;
}
```

**重叠检测图解**：

```
情况 1: dest < src → 从前向后
src:    [0, 1, 2, 3, 4]
dest:  [?, ?, ?, ?]

情况 2: dest > src + n → 从前向后
src:  [0, 1, 2, 3]
dest:            [?, ?, ?, ?]

情况 3: src < dest < src + n → 从后向前
src:  [0, 1, 2, 3, 4]
dest:    [?, ?, ?, ?]
         ↑↑↑ 重叠区域
```

## 第五步 —— 实现 memcmp

`memcmp` 逐字节比较，返回第一个不同字节的差值：

```c
int memcmp(const void* s1, const void* s2, size_t n) {
    const unsigned char* _s1 = s1;
    const unsigned char* _s2 = s2;

    for (; n && *_s1 == *_s2; --n, ++_s1, ++_s2)
        ;

    if (n == 0)
        return 0;

    return *_s1 - *_s2;
}
```

**⚠️ 注意**：

1. 使用 `unsigned char` 比较，确保返回值符号正确
2. 返回值不是 -1/0/1，而是实际的差值
3. 正确用法：`if (memcmp(a, b, n) < 0) ...` 而不是 `if (memcmp(a, b, n) == -1)`

---

## 第六步 —— 更新 CMakeLists.txt

在 `kernel/base/CMakeLists.txt` 中添加我们的 memory.c：

```cmake
add_library(kernel_base INTERFACE
    # ... 现有文件 ...
    memory.c
)

target_include_directories(kernel_base INTERFACE
    ${CMAKE_CURRENT_SOURCE_DIR}
)
```

## 第七步 —— 搭建主机端测试环境

现在问题来了：**怎么在宿主机上测试这些函数？**

内核代码是 freestanding 的，不能直接在主机上运行。我们需要创建一个测试桩（stub）。

### 创建测试目录

```bash
mkdir -p test
```

### 创建断言桩 `test/assert_stub.c`：

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

void ccos_assert_impl(bool condition, const char* expr_str,
                      const char* file, int line, const char* func) {
    if (condition) return;

    fprintf(stderr, "*** ASSERTION FAILED ***\n");
    fprintf(stderr, "File: %s:%d\n", file, line);
    fprintf(stderr, "Function: %s\n", func);
    fprintf(stderr, "Expression: %s\n", expr_str);

    abort();
}
```

### 创建测试头文件 `test/host_support.h`：

```c
#pragma once

#include <stdio.h>
#include <stdbool.h>

// 测试统计变量
extern int g_test_passed;
extern int g_test_failed;

// 测试断言宏
#define TEST_ASSERT_EQ(a, b, msg) \
    do { \
        if ((a) != (b)) { \
            g_test_failed++; \
            printf("FAIL: %s (expected %d, got %d)\n", msg, (int)(b), (int)(a)); \
        } else { \
            g_test_passed++; \
        } \
    } while(0)

#define TEST_ASSERT_TRUE(cond, msg) \
    do { \
        if (!(cond)) { \
            g_test_failed++; \
            printf("FAIL: %s\n", msg); \
        } else { \
            g_test_passed++; \
        } \
    } while(0)

#define TEST_INFO(msg) printf("[TEST] %s\n", msg)

// 测试运行器宏
#define TEST_RUNNER_BEGIN(name) \
    int main(void) { \
        printf("=== %s ===\n", name); \
        g_test_passed = 0; \
        g_test_failed = 0;

#define TEST_RUNNER_END() \
        printf("\n=== Results ===\n"); \
        printf("Passed: %d\n", g_test_passed); \
        printf("Failed: %d\n", g_test_failed); \
        return g_test_failed > 0 ? 1 : 0; \
    }
```

### 创建测试文件 `test/test_memory.c`：

```c
#include <stdio.h>
#include <string.h>
#include "host_support.h"

// 声明我们要测试的函数
extern void* memset(void* s, int c, size_t n);
extern void* memcpy(void* dest, const void* src, size_t n);
extern void* memmove(void* dest, const void* src, size_t n);
extern int memcmp(const void* s1, const void* s2, size_t n);

int g_test_passed = 0;
int g_test_failed = 0;

// === memset 测试 ===
static void test_memset_basic(void) {
    TEST_INFO("Testing memset basic fill");

    char buffer[100];
    memset(buffer, 0x42, 100);

    for (int i = 0; i < 100; i++) {
        TEST_ASSERT_EQ(buffer[i], 0x42, "memset fill value");
    }
}

static void test_memset_zero_length(void) {
    TEST_INFO("Testing memset with zero length");

    char buffer[100] = {0};
    memset(buffer, 0xAA, 0);

    // 零长度不应该修改任何内容
    TEST_ASSERT_EQ(buffer[0], 0, "memset zero length no change");
}

static void test_memset_return_value(void) {
    TEST_INFO("Testing memset return value");

    char buffer[100];
    void* result = memset(buffer, 'X', 100);

    TEST_ASSERT_TRUE(result == buffer, "memset returns original pointer");
}

// === memcpy 测试 ===
static void test_memcpy_basic(void) {
    TEST_INFO("Testing memcpy basic");

    char src[] = "Hello, World!";
    char dest[100];

    memcpy(dest, src, sizeof(src));

    TEST_ASSERT_TRUE(strcmp(dest, src) == 0, "memcpy copy correct");
}

static void test_memcpy_return_value(void) {
    TEST_INFO("Testing memcpy return value");

    char src[] = "Test";
    char dest[100];

    void* result = memcpy(dest, src, sizeof(src));

    TEST_ASSERT_TRUE(result == dest, "memcpy returns dest pointer");
}

// === memmove 测试 ===
static void test_memmove_non_overlap(void) {
    TEST_INFO("Testing memmove non-overlapping");

    char src[] = "Hello";
    char dest[100];

    memmove(dest, src, sizeof(src));

    TEST_ASSERT_TRUE(strcmp(dest, src) == 0, "memmove non-overlap copy");
}

static void test_memmove_overlap_forward(void) {
    TEST_INFO("Testing memmove overlapping (dest > src)");

    char buffer[] = "0123456789";
    // 拷贝 "01234" 到 "23456" 位置
    memmove(buffer + 2, buffer, 5);

    // 应该是 "010123456789" 的前 10 个字符
    TEST_ASSERT_EQ(buffer[0], '0', "memmove overlap: byte 0");
    TEST_ASSERT_EQ(buffer[1], '1', "memmove overlap: byte 1");
    TEST_ASSERT_EQ(buffer[2], '0', "memmove overlap: byte 2");
    TEST_ASSERT_EQ(buffer[3], '1', "memmove overlap: byte 3");
    TEST_ASSERT_EQ(buffer[4], '2', "memmove overlap: byte 4");
}

// === memcmp 测试 ===
static void test_memcmp_equal(void) {
    TEST_INFO("Testing memcmp equal buffers");

    char a[] = "Same content";
    char b[] = "Same content";

    int result = memcmp(a, b, sizeof(a));

    TEST_ASSERT_EQ(result, 0, "memcmp equal returns 0");
}

static void test_memcmp_less(void) {
    TEST_INFO("Testing memcmp less than");

    char a[] = "AAA";
    char b[] = "BBB";

    int result = memcmp(a, b, 3);

    TEST_ASSERT_TRUE(result < 0, "memcmp a < b returns negative");
}

static void test_memcmp_greater(void) {
    TEST_INFO("Testing memcmp greater than");

    char a[] = "CCC";
    char b[] = "BBB";

    int result = memcmp(a, b, 3);

    TEST_ASSERT_TRUE(result > 0, "memcmp a > b returns positive");
}

// === 主测试运行器 ===
TEST_RUNNER_BEGIN("Memory Functions Test Suite")

    printf("\n--- memset Tests ---\n");
    test_memset_basic();
    test_memset_zero_length();
    test_memset_return_value();

    printf("\n--- memcpy Tests ---\n");
    test_memcpy_basic();
    test_memcpy_return_value();

    printf("\n--- memmove Tests ---\n");
    test_memmove_non_overlap();
    test_memmove_overlap_forward();

    printf("\n--- memcmp Tests ---\n");
    test_memcmp_equal();
    test_memcmp_less();
    test_memcmp_greater();

TEST_RUNNER_END()
```

### 创建测试 CMakeLists.txt

在 `test/CMakeLists.txt` 中：

```cmake
# 主机端可执行文件
add_executable(test_memory
    test_memory.c
    assert_stub.c
)

# 链接我们的 kernel_base（只链接 memory.o）
target_link_libraries(test_memory PRIVATE kernel_base)

# 主机端测试不需要 freestanding
target_compile_options(test_memory PRIVATE
    -fno-builtin
)
```

## 第八步 —— 运行测试

现在我们来验证一下实现是否正确：

```bash
# 配置构建
cmake -B build -DCMAKE_BUILD_TYPE=Debug

# 构建
cmake --build build

# 运行测试
./build/test/test_memory
```

**预期输出**：

```
=== Memory Functions Test Suite ===

--- memset Tests ---
[TEST] Testing memset basic fill
[TEST] Testing memset with zero length
[TEST] Testing memset return value

--- memcpy Tests ---
[TEST] Testing memcpy basic
[TEST] Testing memcpy return value

--- memmove Tests ---
[TEST] Testing memmove non-overlapping
[TEST] Testing memmove overlapping (dest > src)

--- memcmp Tests ---
[TEST] Testing memcmp equal buffers
[TEST] Testing memcmp less than
[TEST] Testing memcmp greater than

=== Results ===
Passed: 14
Failed: 0
```

如果看到 `Failed: 0`，恭喜你，所有测试都通过了！

**⚠️ 常见问题**：

1. **链接错误**：检查 CMakeLists.txt 是否正确链接了 `kernel_base`
2. **断言失败**：可能是循环边界问题，检查 `n - 1` 和 `n--` 的使用
3. **测试崩溃**：使用 `gdb` 运行测试查看具体哪里出错
