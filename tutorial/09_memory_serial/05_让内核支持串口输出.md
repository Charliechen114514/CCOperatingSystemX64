# 05 - 让内核支持串口输出

串口驱动已经实现了，现在要把它集成到内核里。

---

## 我们现在要做什么

我们需要修改内核代码，让串口驱动真正工作起来：

1. **在内核初始化时初始化串口**
2. **在主函数中使用串口输出**
3. **更新 CMakeLists.txt** 链接串口驱动
4. **编译验证** 确保一切正常

---

## 第一步 —— 修改内核初始化

打开 `kernel/kernel_init.c`，我们需要在系统初始化时初始化串口：

```c
#include "defines/types.h"
#include "driver/serial/serial.h"
#include "assert/assert.h"

void system_vga_init(void);
void system_vga_print_welcome(void);

void kernel_init(void) {
    // 先初始化 VGA
    system_vga_init();
    system_vga_print_welcome();

    // 初始化串口
    bool serial_ok = serial_init();
    CCOS_ASSERT(serial_ok);

    // 通过串口输出欢迎信息
    sync_serial_puts("\033[0;32m");  // 绿色
    sync_serial_puts("=== CCOS Kernel ===\n");
    sync_serial_puts("Serial port initialized at 115200 8N1\n");
    sync_serial_puts("\033[0m");  // 重置颜色
}
```

**⚠️ 注意**：

1. 我们先初始化 VGA，再初始化串口 —— 这样即使串口失败也能看到 VGA 输出
2. 使用 `CCOS_ASSERT` 确保串口初始化成功
3. 添加了 ANSI 颜色代码，让输出更友好

**ANSI 颜色代码**：

| 代码 | 效果 |
|------|------|
| `\033[0m` | 重置 |
| `\033[0;31m` | 红色 |
| `\033[0;32m` | 绿色 |
| `\033[0;33m` | 黄色 |
| `\033[1m` | 粗体 |

---

## 第二步 —— 修改内核主函数

打开 `kernel/kernel_main.c`，让主函数也使用串口输出：

```c
#include "defines/types.h"
#include "driver/vga/vga.h"
#include "driver/serial/serial.h"

extern kernel_vga_t* vga;

void kernel_main(void) {
    // VGA 输出
    vga_print_string(vga, "Hello from CCOS kernel!\n");
    vga_print_string(vga, "Kernel is running in 64-bit long mode.\n");

    // 串口输出
    sync_serial_puts("[KERNEL] Hello from CCOS kernel!\n");
    sync_serial_puts("[KERNEL] Kernel is running in 64-bit long mode.\n");
    sync_serial_puts("[KERNEL] VGA + Serial dual output is working!\n");

    // 使用颜色区分不同级别的消息
    sync_serial_puts("\033[0;32m[INFO]\033[0m System initialized successfully\n");
    sync_serial_puts("\033[1;33m[WARN]\033[0m This is a warning message\n");
    sync_serial_puts("\033[0;31m[ERROR]\033[0m This is an error message\n");

    // 死循环，防止内核退出
    while (1) {
        __asm__ volatile("hlt");
    }
}
```

---

## 第三步 —— 更新 CMakeLists.txt

我们需要确保串口驱动被正确链接。

检查 `kernel/CMakeLists.txt`，确保依赖关系正确：

```cmake
# 内核可执行文件
add_executable(kernel.elf
    # ... 现有文件 ...
    kernel_init.c
    kernel_main.c
)

# 链接串口驱动
target_link_libraries(kernel.elf PRIVATE
    kernel_base      # 内存函数
    driver_serial    # 串口驱动（会自动链接 driver_io）
    driver_vga       # VGA 驱动
    # ... 其他依赖 ...
)
```

**⚠️ 注意**：

- `driver_serial` 会自动链接 `driver_io`（因为我们在 serial 的 CMakeLists.txt 中声明了依赖）
- 如果链接顺序错误，可能会遇到 undefined reference 错误

---

## 第四步 —— 编译验证

```bash
# 清理旧的构建
rm -rf build

# 重新配置
cmake -B build -DCMAKE_BUILD_TYPE=Debug

# 构建
cmake --build build
```

**预期输出**：

```
[ 10%] Building C object kernel/CMakeFiles/kernel_base.dir/base/memory.c.o
[ 20%] Building C object kernel/CMakeFiles/driver_io.dir/io/io.c.o
[ 30%] Building C object kernel/CMakeFiles/driver_serial.dir/serial/serial.c.o
[ 40%] Building C object kernel/CMakeFiles/kernel.elf.dir/kernel_init.c.o
[ 50%] Building C object kernel/CMakeFiles/kernel.elf.dir/kernel_main.c.o
[ 60%] Linking C executable kernel.elf
[100%] Built target kernel.elf
```

**⚠️ 常见错误**：

1. **undefined reference to `inb`**
   - 检查 `driver_io` 是否正确链接
   - 确保 `io.h` 被正确包含

2. **undefined reference to `serial_init`**
   - 检查 `driver_serial` 是否正确链接
   - 确保 `serial.h` 被正确包含

3. **multiple definition**
   - 检查是否有重复的源文件被编译
   - 确保头文件有 `#pragma once` 或 include guard

## 第五步 —— 验证链接输出

让我们看看内核 ELF 文件是否包含了我们的新代码：

```bash
# 查看符号表
nm build/kernel/kernel.elf | grep -E "(serial|memory|inb|outb)"
```

**预期输出**：

``
0000000000001234 T serial_init
0000000000001280 T sync_serial_putc
00000000000012a0 T sync_serial_puts
0000000000001300 T memset
0000000000001320 T memcpy
0000000000001340 T memmove
0000000000001360 T memcmp
0000000000001380 T inb
0000000000001390 T outb
```

如果能看到这些符号，说明链接成功了。

---

## 第六步 —— 快速串口测试

在完整测试之前，我们先快速验证串口输出是否工作。

创建一个简单的测试脚本 `test_serial.sh`：

```bash
#!/bin/bash

# 启动 QEMU，串口重定向到 stdio
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial mon:stdio
```

运行脚本：

```bash
chmod +x test_serial.sh
./test_serial.sh
```

**预期输出**：

```
QEMU 7.0.0 monitor - type 'help' for commands
=== CCOS Bootloader v1.0 ===
[Serial] Bootloader initialized
[Serial] Loading kernel...
=== CCOS Kernel ===
Serial port initialized at 115200 8N1
[KERNEL] Hello from CCOS kernel!
[KERNEL] Kernel is running in 64-bit long mode.
[KERNEL] VGA + Serial dual output is working!
[INFO] System initialized successfully
[WARN] This is a warning message
[ERROR] This is an error message
```

如果你看到这些输出，恭喜！串口驱动已经成功集成了。

**⚠️ 如果没有串口输出**：

1. 检查 QEMU 是否使用了 `-serial mon:stdio`
2. 确认 `serial_init()` 被调用了
3. 使用 GDB 连接 QEMU，检查串口寄存器值
