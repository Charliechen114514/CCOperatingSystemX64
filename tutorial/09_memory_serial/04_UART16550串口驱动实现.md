# 04 - UART 16550 串口驱动实现

串口是裸机开发中最有用的调试工具，没有之一。

---

## 我们现在要做什么

我们需要实现一个完整的 UART 16550 串口驱动，包括：

1. **串口初始化** — 配置波特率、数据格式
2. **字符输出** — 阻塞式单字符发送
3. **字符串输出** — 批量发送字符串

最终我们能在串口上看到内核的调试输出，这比盯着 VGA 屏幕舒服太多了。

---

## 第一步 —— 理解 UART 16550

UART 16550 是 PC 标准的串口控制器，自 1980 年代以来就存在。它的特点：

| 特性 | 说明 |
|------|------|
| 兼容性 | 所有 PC 都支持 |
| 端口地址 | COM1 = 0x3F8, COM2 = 0x2F8 |
| 中断 | IRQ4（COM1） |
| FIFO | 16 字节发送/接收缓冲 |
| 速度 | 最高 115200 波特率 |

**为什么用串口调试？**

```
VGA 输出：
- 屏幕滚动后信息丢失
- 需要图形窗口
- 不方便保存日志

串口输出：
- 可以重定向到文件
- 支持远程调试
- 完整启动日志
- ANSI 颜色支持
```

---

## 第二步 —— 寄存器映射

UART 16550 有一组寄存器，通过端口 I/O 访问：

| 偏移 | DLAB=0 读 | DLAB=0 写 | DLAB=1 读 | DLAB=1 写 | 说明 |
|------|----------|----------|----------|----------|------|
| +0 | RBR | THR | DLL | DLL | 接收/发送/除数低 |
| +1 | IER | - | DLM | DLM | 中断使能/除数高 |
| +2 | IIR | FCR | - | - | 中断识别/FIFO 控制 |
| +3 | LCR | LCR | - | - | 线路控制 |
| +4 | MCR | MCR | - | - | 调制解调器控制 |
| +5 | LSR | - | - | - | 线路状态 |
| +6 | MSR | - | - | - | 调制解调器状态 |
| +7 | SCR | SCR | - | - | 暂存寄存器 |

**DLAB 是什么？**

DLAB（Divisor Latch Access Bit）是 LCR 寄存器的第 7 位。当 DLAB=1 时，访问波特率除数；DLAB=0 时，访问正常寄存器。

## 第四步 —— 创建寄存器定义

创建 `kernel/driver/serial/serial_config.h`：

```c
/**
 * @file serial_config.h
 * @brief UART 16550 register definitions
 */
#pragma once

#include "defines/types.h"

// COM1 基地址
#define SERIAL_COM1_BASE 0x3F8

// 寄存器偏移
#define SERIAL_DATA_REG(base)        ((base) + 0)  // RBR/THR/DLL
#define SERIAL_INT_ENABLE_REG(base)  ((base) + 1)  // IER/DLM
#define SERIAL_FIFO_CTRL_REG(base)   ((base) + 2)  // IIR/FCR
#define SERIAL_LINE_CTRL_REG(base)   ((base) + 3)  // LCR
#define SERIAL_MODEM_CTRL_REG(base)  ((base) + 4)  // MCR
#define SERIAL_LINE_STATUS_REG(base) ((base) + 5)  // LSR
#define SERIAL_MODEM_STATUS_REG(base)((base) + 6)  // MSR
#define SERIAL_SCRATCH_REG(base)     ((base) + 7)  // SCR

// LSR (Line Status Register) 位定义
#define SERIAL_LSR_DR         0x01  // Data Ready
#define SERIAL_LSR_OE         0x02  // Overrun Error
#define SERIAL_LSR_PE         0x04  // Parity Error
#define SERIAL_LSR_FE         0x04  // Frame Error
#define SERIAL_LSR_BI         0x10  // Break Interrupt
#define SERIAL_LSR_READY_TO_SEND 0x20  // THR Empty (可以发送)
#define SERIAL_LSR_TEMT       0x40  // Transmitter Empty

// LCR (Line Control Register) 位定义
#define SERIAL_LCR_DLAB       0x80  // Divisor Latch Access Bit
#define SERIAL_LCR_SBC        0x40  // Set Break Control
#define SERIAL_LCR_SP         0x20  // Stick Parity
#define SERIAL_LCR_EPS        0x10  // Even Parity Select
#define SERIAL_LCR_PEN        0x08  // Parity Enable
#define SERIAL_LCR_STB        0x04  // Stop Bits (0=1bit, 1=2bits)
#define SERIAL_LCR_WLS8       0x03  // 8 bits data
#define SERIAL_LCR_WLS7       0x02  // 7 bits data
#define SERIAL_LCR_WLS6       0x01  // 6 bits data
#define SERIAL_LCR_WLS5       0x00  // 5 bits data
```

## 第五步 —— 计算波特率除数

波特率由一个内部除数控制。UART 的基准时钟是 1.8432 MHz。

```
波特率 = 时钟 / (16 × 除数)
除数 = 时钟 / (16 × 波特率)
```

对于 115200 波特率：

```
除数 = 1843200 / (16 × 115200) = 1843200 / 1843200 = 1
```

常用波特率除数：

| 波特率 | 除数 | DLL | DLM |
|--------|------|-----|-----|
| 115200 | 1 | 0x01 | 0x00 |
| 57600 | 2 | 0x02 | 0x00 |
| 38400 | 3 | 0x03 | 0x00 |
| 19200 | 6 | 0x06 | 0x00 |
| 9600 | 12 | 0x0C | 0x00 |

## 第六步 —— 实现串口初始化

创建 `kernel/driver/serial/serial.h`：

```c
/**
 * @file serial.h
 * @brief UART 16550 serial driver
 */
#pragma once

#include "defines/types.h"
#include <stdbool.h>

/**
 * @brief Initialize COM1 serial port at 115200 8N1
 * @return true if successful
 */
bool serial_init(void);

/**
 * @brief Send a string to serial port (blocking)
 * @param str Null-terminated string
 */
void sync_serial_puts(const char* str);
```

创建 `kernel/driver/serial/serial.c`：

```c
#include "serial.h"
#include "serial_config.h"
#include "io/io.h"

// 波特率除数（115200 = 除数 1）
#define BAUD_DIVISOR_LOW  1
#define BAUD_DIVISOR_HIGH 0

/**
 * @brief Send single character (blocking)
 */
static void sync_serial_putc(char c) {
    const uint16_t base = SERIAL_COM1_BASE;

    // 等待发送保持寄存器为空
    while ((inb(SERIAL_LINE_STATUS_REG(base)) & SERIAL_LSR_READY_TO_SEND) == 0) {
        // 忙等待
    }

    // 发送字符
    outb(SERIAL_DATA_REG(base), (uint8_t)c);
}

bool serial_init(void) {
    const uint16_t base = SERIAL_COM1_BASE;

    // Step 1: 禁用中断
    outb(SERIAL_INT_ENABLE_REG(base), 0x00);

    // Step 2: 启用 DLAB（设置波特率需要）
    outb(SERIAL_LINE_CTRL_REG(base), SERIAL_LCR_DLAB);

    // Step 3: 设置波特率除数
    outb(SERIAL_DATA_REG(base), BAUD_DIVISOR_LOW);   // DLL
    outb(SERIAL_INT_ENABLE_REG(base), BAUD_DIVISOR_HIGH);  // DLM

    // Step 4: 配置 8N1 格式（8 位数据，无校验，1 停止位）
    outb(SERIAL_LINE_CTRL_REG(base), SERIAL_LCR_WLS8);

    // Step 5: 启用 FIFO，清空缓冲，设置 14 字节阈值
    outb(SERIAL_FIFO_CTRL_REG(base), 0xC7);

    // Step 6: 设置调制解调器控制（启用 RTS/DSR）
    outb(SERIAL_MODEM_CTRL_REG(base), 0x0B);

    return true;
}

void sync_serial_puts(const char* str) {
    if (str == NULL) {
        return;
    }

    while (*str != '\0') {
        sync_serial_putc(*str);
        str++;
    }
}
```

## 第七步 —— 理解初始化流程

让我们逐个步骤理解串口初始化：

```
┌─────────────────────────────────────────────────────────┐
│                  串口初始化六步骤                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 禁用中断 (IER = 0x00)                               │
│     │                                                   │
│     ▼                                                   │
│  2. 启用 DLAB (LCR = 0x80)                              │
│     │  → 现在可以访问波特率除数寄存器                   │
│     ▼                                                   │
│  3. 设置波特率 (DLL=1, DLM=0 → 115200)                  │
│     │                                                   │
│     ▼                                                   │
│  4. 配置格式 (LCR = 0x03 → 8N1)                         │
│     │  → 禁用 DLAB，恢复正常寄存器访问                  │
│     ▼                                                   │
│  5. 启用 FIFO (FCR = 0xC7)                              │
│     │  → 清空缓冲，启用 16 字节 FIFO                    │
│     ▼                                                   │
│  6. 设置调制解调器 (MCR = 0x0B)                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**每一步的作用**：

1. **禁用中断** — 我们使用轮询模式，不需要中断
2. **启用 DLAB** — 允许访问波特率除数
3. **设置波特率** — 除数为 1 = 115200
4. **配置格式** — 8 位数据，无校验，1 停止位（8N1）
5. **启用 FIFO** — 减少 CPU 轮询频率
6. **调制解调器控制** — 启用 RTS/DSR 信号

## 第八步 —— 发送字符流程

`sync_serial_putc` 的流程很简单：

```
┌─────────────────────────────────────────────────────────┐
│                  字符发送流程                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  while (LSR & 0x20 == 0)                                │
│     │                                                   │
│     ▼  ←───────┐                                       │
│  等待 THR 为空 │                                       │
│     │          │  (忙等待)                             │
│     └──────────┘                                       │
│     │                                                   │
│     ▼                                                   │
│  outb(DATA, char)                                       │
│     │                                                   │
│     ▼                                                   │
│  字符写入 THR，硬件自动发送                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**LSR 寄存器位 5 (THRE)**：

- 1 = 发送保持寄存器为空，可以写入新字符
- 0 = 发送保持寄存器忙，等待

## 第十步 —— 为什么使用阻塞式输出

你可能问：**为什么不用中断驱动的串口输出？**

| 方式 | 优点 | 缺点 |
|------|------|------|
| 阻塞式 | 实现简单，可靠性高 | CPU 占用高 |
| 中断驱动 | CPU 占用低 | 复杂，需要中断系统 |

**我们的选择**：

对于调试输出，阻塞式输出完全够用：
- 启动阶段调试输出不多
- 代码简单，没有竞争条件
- 输出立即可见，调试友好

等我们实现了中断系统后，可以再升级成中断驱动版本。
