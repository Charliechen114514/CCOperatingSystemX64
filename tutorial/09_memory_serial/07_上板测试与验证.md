## 第一步 —— QEMU 串口重定向配置

QEMU 提供多种串口重定向方式，每种都有适用场景。

### 方法 1：重定向到 stdio（推荐）

最常用的方式，串口和控制台混在一起：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial mon:stdio
```

| 参数 | 作用 |
|------|------|
| `-nographic` | 禁用 VGA 图形输出 |
| `-serial mon:stdio` | 监控器+串口都重定向到标准输入输出 |

**⚠️ 注意**：按 `Ctrl+A, X` 退出 QEMU。

### 方法 2：分离监控器和串口

监控器和串口分开：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -monitor stdio \
    -serial stdio
```

这样监控器在一个终端，串口在另一个（如果用 pty）。

### 方法 3：重定向到文件

保存所有串口输出到文件：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial file:serial.log
```

运行后查看日志：

```bash
cat serial.log
```

### 方法 4：VGA + 串口同时使用

同时显示 VGA 和串口：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -vga std -display vnc=:0 \
    -nographic \
    -serial mon:stdio
```

- VGA：通过 VNC 查看（`vncviewer localhost:5900`）
- 串口：在终端查看

## 第三步 —— 常见问题排查

### 问题 1：没有串口输出

**可能原因**：

| 原因 | 检查方法 | 解决方案 |
|------|----------|----------|
| QEMU 配置错误 | 检查是否加了 `-serial mon:stdio` | 添加串口重定向参数 |
| 串口未初始化 | 使用 GDB 检查 `serial_init` 是否被调用 | 确认初始化代码执行 |
| 端口地址错误 | 检查 COM1 = 0x3F8 | 确认宏定义正确 |

**调试方法**：

```bash
# 使用 GDB 连接
gdb build/kernel/kernel.elf
(gdb) target remote :1234
(gdb) break serial_init
(gdb) continue
```

### 问题 2：串口输出乱码

**可能原因**：

| 原因 | 检查方法 | 解决方案 |
|------|----------|----------|
| 波特率不匹配 | 检查 DLL/DLM 值 | 确认 DLL=1, DLM=0 |
| 数据格式错误 | 检查 LCR 值 | 确认 LCR=0x03（8N1） |
| 终端编码 | 检查终端设置 | 使用 UTF-8 终端 |

### 问题 3：内存测试失败

**调试方法**：

```bash
# 使用 GDB 运行测试
gdb ./build/test/test_memory
(gdb) run
# 如果崩溃
(gdb) backtrace
(gdb) print <变量名>
```

### 问题 4：编译链接错误

**undefined reference to `inb`**：

```cmake
# 确保链接顺序正确
target_link_libraries(kernel.elf PRIVATE
    driver_serial    # 串口驱动
    driver_io        # 必须在 serial 之后
    # ...
)
```

## 第四步 —— 保存和分析串口日志

### 自动保存日志

创建一个脚本 `run_with_log.sh`：

```bash
#!/bin/bash

# 日志文件名（带时间戳）
LOG_FILE="serial_$(date +%Y%m%d_%H%M%S).log"

echo "Saving serial output to: $LOG_FILE"

# 运行 QEMU，串口输出到文件
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial file:"$LOG_FILE"

echo "Log saved to: $LOG_FILE"
```

### 同时显示和保存

使用 `tee` 同时显示和保存：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial mon:stdio 2>&1 | tee serial.log
```

### 分析日志

```bash
# 查找错误
grep -i error serial.log

# 查找特定消息
grep "KERNEL" serial.log

# 统计行数
wc -l serial.log

# 查看启动时间
head -1 serial.log
tail -1 serial.log
```

## 第五步 —— 创建便捷启动脚本

创建 `scripts/launch_qemu.sh`：

```bash
#!/bin/bash

# CCOS QEMU 启动脚本

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(dirname "$SCRIPT_DIR")"
BUILD_DIR="$PROJECT_ROOT/build"
BOOT_IMG="$BUILD_DIR/boot.img"

# 检查构建是否存在
if [ ! -f "$BOOT_IMG" ]; then
    echo "Error: $BOOT_IMG not found. Run 'cmake --build build' first."
    exit 1
fi

# 默认参数
SERIAL_MODE="stdio"
VGA_MODE="none"

# 解析参数
while [[ $# -gt 0 ]]; do
    case $1 in
        --serial-file)
            SERIAL_MODE="file:serial.log"
            shift
            ;;
        --vga)
            VGA_MODE="std"
            shift
            ;;
        *)
            echo "Unknown option: $1"
            exit 1
            ;;
    esac
done

# 构建 QEMU 命令
QEMU_CMD="qemu-system-x86_64"
QEMU_CMD+=" -drive format=raw,file=$BOOT_IMG"

if [ "$VGA_MODE" = "std" ]; then
    QEMU_CMD+=" -vga std -display vnc=:0"
else
    QEMU_CMD+=" -nographic"
fi

QEMU_CMD+=" -serial mon:$SERIAL_MODE"

echo "Launching QEMU..."
echo "Press Ctrl+A, X to exit"
eval "$QEMU_CMD"
```

使用方式：

```bash
# 默认模式（串口到 stdio）
./scripts/launch_qemu.sh

# VGA + 串口
./scripts/launch_qemu.sh --vga

# 串口保存到文件
./scripts/launch_qemu.sh --serial-file
```

## 第六步 —— 调试技巧汇总

### GDB 远程调试

1. 启动 QEMU（带 GDB server）：

```bash
qemu-system-x86_64 \
    -drive format=raw,file=build/boot.img \
    -nographic \
    -serial mon:stdio \
    -s -S
```

- `-s` : 监听 GDB on 1234
- `-S` : 启动时暂停 CPU

2. 连接 GDB：

```bash
gdb build/kernel/kernel.elf
(gdb) target remote :1234
(gdb) break kernel_main
(gdb) continue
```

### QEMU Monitor 命令

在 QEMU 中按 `Ctrl+A, C` 进入监控模式：

```
(qemu) info serial      # 显示串口状态
(qemu) info registers   # 显示寄存器
(qemu) xp /20bx 0x3F8   # 查看端口内存
(qemu) x/10i 0x7C00     # 查看汇编代码
(qemu) quit             # 退出
```

### 常用 GDB 命令

```gdb
# 查看内存
(gdb) x/20bx 0x7C00     # 20 字节
(gdb) x/10hx 0x10000    # 10 个半字

# 查看寄存器
(gdb) info registers
(gdb) print $rax

# 查看汇编
(gdb) disassemble
(gdb) x/10i $pc

# 单步执行
(gdb) stepi             # 指令级单步
(gdb) nexti             # 指令级单步（跳过函数调用）
```
