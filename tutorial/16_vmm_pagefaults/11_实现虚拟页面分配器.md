# 11 - 实现虚拟页面分配器

说实话，实现虚拟页面分配器比我想象的要复杂。你不能像物理帧分配器那样维护一个空闲链表，因为虚拟地址空间是稀疏的。

---

## vmm_init 的实现

`vmm_init` 是 VMM 模块的入口点，它初始化内部状态并建立基本的映射。首先检查是否已经初始化，如果是则直接返回。然后从 page 模块获取内核 PML4 地址，初始化分配提示为内核堆基地址，并注册内核代码和数据区域。

```c
vmm_result_t vmm_init(void) {
    if (s_initialized) {
        return VMM_OK;
    }

    /* Get kernel PML4 from page module */
    s_kernel_pml4 = page_get_pml4();

    /* Initialize allocation hint */
    s_kernel_virt_hint = KERNEL_HEAP_BASE;

    /* Register kernel regions */
    vmm_add_region(KERNEL_TEXT_BASE, KERNEL_DATA_BASE, 0, 0, "kernel_text");
    vmm_add_region(KERNEL_DATA_BASE, KERNEL_HEAP_BASE, 0, 0, "kernel_data");

    s_initialized = true;
    return VMM_OK;
}
```

`vmm_init` 必须在 `page_init` 之后调用，因为它需要使用 `page_get_pml4` 来获取内核 PML4 地址。

## 虚拟地址分配策略

内核空间的虚拟地址分配使用简单的线性搜索策略。我们从 `KERNEL_HEAP_BASE` 开始，逐个检查每个候选地址。如果候选地址不与已有区域冲突，返回这个地址。如果到达 `KERNEL_HEAP_MAX`，返回错误。

首先我们根据请求的大小确定对齐要求：

```c
static vmm_result_t find_free_virt_range(uint64_t size, virtual_addr_t* out_vaddr) {
    virtual_addr_t hint = s_kernel_virt_hint;
    virtual_addr_t end = KERNEL_HEAP_MAX;

    /* Determine alignment based on size */
    uint64_t alignment = (size >= PAGE_SIZE_2MB) ? PAGE_SIZE_2MB : PAGE_SIZE;
    hint = (hint + alignment - 1) & ~(alignment - 1);
```

然后进行线性搜索，找到空闲区域：

```c
    /* Linear search for free region */
    while (hint + size <= end) {
        if (!check_region_collision(hint, hint + size)) {
            *out_vaddr = hint;
            s_kernel_virt_hint = hint + size;
            return VMM_OK;
        }
        hint += alignment;
    }

    return VMM_ERR_OOM;
}
```

这是一个非常简单的分配策略，有很多优化空间。比如，你可以使用红黑树来维护空闲区域，或者实现伙伴系统来减少碎片。但对于当前的内核来说，这个简单策略已经足够了。

## vmm_alloc_pages 的实现

`vmm_alloc_pages` 是 VMM 模块的核心函数，它分配指定数量的虚拟页面。函数首先检查是否已初始化，然后根据标志确定页面大小，计算总大小。

```c
virtual_addr_t vmm_alloc_pages(uint64_t page_count, uint64_t flags) {
    if (!s_initialized) {
        return 0;
    }

    /* Determine page size from flags */
    bool use_2mb = (flags & VMAP_FLAG_HUGE_2MB) != 0;
    bool use_1gb = (flags & VMAP_FLAG_HUGE_1GB) != 0;

    uint64_t page_size = PAGE_SIZE;
    if (use_1gb) {
        page_size = PAGE_SIZE_1GB;
    } else if (use_2mb) {
        page_size = PAGE_SIZE_2MB;
    }

    uint64_t total_size = page_count * page_size;
```

接下来我们查找空闲的虚拟地址：

```c
    /* Find free virtual address */
    virtual_addr_t vaddr;
    if (find_free_virt_range(total_size, &vaddr) != VMM_OK) {
        return 0;
    }
```

然后我们分配物理帧并建立映射。这里我们实现了回滚机制：如果在映射过程中某一步失败，我们会取消之前已映射的所有页面，释放已分配的物理帧，确保不会留下部分映射。

```c
    /* Allocate physical frames and map */
    for (uint64_t i = 0; i < page_count; i++) {
        physical_addr_t paddr;
        if (pframe_alloc(&paddr) != PFRAME_OK) {
            /* Rollback: unmap what we've mapped so far */
            for (uint64_t j = 0; j < i; j++) {
                virtual_addr_t va = vaddr + (j * page_size);
                page_unmap_page(s_kernel_pml4, va, false);
            }
            return 0;
        }

        virtual_addr_t va = vaddr + (i * page_size);
        if (page_map_page(s_kernel_pml4, va, paddr, flags, true) != PAGE_OK) {
            /* Rollback */
            pframe_free(paddr);
            for (uint64_t j = 0; j < i; j++) {
                virtual_addr_t va = vaddr + (j * page_size);
                page_unmap_page(s_kernel_pml4, va, false);
            }
            return 0;
        }
    }
```

最后我们更新统计信息并注册区域：

```c
    /* Update statistics */
    s_stats.total_pages += page_count;
    s_stats.mapped_pages += page_count;
    s_stats.kernel_pages += page_count;

    /* Register region */
    vmm_add_region(vaddr, vaddr + total_size, 0, flags, "allocated");

    return vaddr;
}
```

```c
            /* Free physical frame */
            pframe_free(result.phys_addr);
        }

        /* Unmap page */
        page_unmap_page(s_kernel_pml4, va, false);
    }
```

最后更新统计信息并移除区域：

```c
    /* Update statistics */
    s_stats.mapped_pages -= page_count;
    s_stats.kernel_pages -= page_count;

    /* Remove region */
    vmm_remove_region(vaddr);

    return VMM_OK;
}
```

当前实现假设所有页面都是 4KB 的。如果你分配了 2MB 或 1GB 巨大页，这个函数不会正确释放它们。这是一个已知的限制，未来版本会改进。

## 测试虚拟页面分配

我们可以写一个测试来验证虚拟页面分配是否正常工作：

```c
/* Test virtual page allocation */
void test_vmm_alloc(void) {
    /* Allocate 4 pages (16KB) */
    virtual_addr_t vaddr = vmm_alloc_pages(4, VMAP_FLAG_WRITE);

    if (vaddr != 0) {
        klog_info("[TEST] Allocated 4 pages at 0x%llX\n", vaddr);

        /* Write to the pages */
        volatile uint64_t* ptr = (volatile uint64_t*)vaddr;
        for (int i = 0; i < 4 * (PAGE_SIZE / 8); i++) {
            ptr[i] = i;
        }

        /* Read back */
        bool ok = true;
        for (int i = 0; i < 4 * (PAGE_SIZE / 8); i++) {
            if (ptr[i] != i) {
                ok = false;
                break;
            }
        }

        if (ok) {
            klog_info("[TEST] Memory test PASSED\n");
        }

        /* Free */
        vmm_free_pages(vaddr, 4);
        klog_info("[TEST] Pages freed\n");
    } else {
        klog_error("[TEST] Failed to allocate pages\n");
    }
}
```
