# 12 - 用户地址空间与临时映射

说实话，用户地址空间的概念一开始让我很困惑。每个进程都有自己的页表，内核怎么知道应该用哪个页表？

---

## 临时物理映射

临时物理映射是一个很实用的功能。它允许你把任意物理内存映射到内核虚拟地址空间，访问完成后解除映射。这个功能在很多场景下都很实用：访问设备寄存器（比如 VGA 显存在物理地址 0xB8000，你可以临时映射它来访问），访问其他进程的物理内存（在某些情况下，内核需要访问用户进程的物理内存），或者实现特殊的内存操作（比如 memcpy 任意物理内存）。

`vmm_map_physical` 函数实现临时映射。首先检查是否已初始化，然后查找一个空闲的虚拟地址：

```c
virtual_addr_t vmm_map_physical(physical_addr_t phys, uint64_t flags) {
    if (!s_initialized) {
        return 0;
    }

    /* Find a free virtual address in kernel space */
    virtual_addr_t vaddr;
    if (find_free_virt_range(PAGE_SIZE, &vaddr) != VMM_OK) {
        return 0;
    }
```

然后映射物理页并注册区域：

```c
    /* Map the physical page */
    if (page_map_page(s_kernel_pml4, vaddr, phys, flags, true) != PAGE_OK) {
        return 0;
    }

    /* Register region */
    vmm_add_region(vaddr, vaddr + PAGE_SIZE, phys, flags, "temp_physical");

    return vaddr;
}
```

这个实现非常简单，每次映射都分配一个新的虚拟地址。如果你需要频繁地映射和取消映射，这会浪费虚拟地址空间。更高效的实现是使用一个固定的"临时映射区域"。

取消临时映射也很简单：

```c
void vmm_unmap_physical(virtual_addr_t vaddr) {
    if (!s_initialized) {
        return;
    }

    /* Unmap the page */
    page_unmap_page(s_kernel_pml4, vaddr, false);

    /* Remove region */
    vmm_remove_region(vaddr);
}
```

## 用户地址空间的概念

每个用户进程都需要自己独立的地址空间，这样进程之间不会互相干扰。在 x86_64 上，这是通过给每个进程分配自己的 PML4 来实现的。

用户地址空间的布局通常是这样的：NULL 页（0x0000000000000000 - 0x000000000003FFFF）不映射，这样可以捕获空指针访问。用户程序从 0x400000（4MB）开始，延伸到 0x00007FFFFFFFFFFF（128TB 用户限制）。

虽然每个进程有自己的用户空间，但内核空间是共享的。这意味着所有进程的 PML4 的高半部分（内核空间）都是相同的。当创建新进程时，你需要复制内核空间的映射到新进程的 PML4，这样新进程才能访问内核代码和数据。

---

## vmm_create_user_space 的实现

`vmm_create_user_space` 创建一个新的用户地址空间。首先分配一个新的 PML4：

```c
vmm_result_t vmm_create_user_space(physical_addr_t* out_pml4) {
    if (!s_initialized) {
        return VMM_ERR_NOT_INIT;
    }

    /* Allocate a new PML4 */
    if (page_create_table(out_pml4) != PAGE_OK) {
        return VMM_ERR_OOM;
    }
```

然后从内核 PML4 复制内核空间的映射。我们只复制内核空间的映射（PML4 项 256-511），用户空间的映射（项 0-255）保持为零（未映射）。这样新进程的用户空间是完全空的，需要由加载器来设置。

```c
    /* Copy kernel space mappings from kernel PML4 */
    pml4_t* kernel_pml4 = (pml4_t*)phys_to_virt(s_kernel_pml4);
    pml4_t* user_pml4 = (pml4_t*)phys_to_virt(*out_pml4);

    /* Copy entries 256-511 (kernel space) */
    for (int i = 256; i < 512; i++) {
        if (kernel_pml4->entries[i].bits.present) {
            user_pml4->entries[i].value = kernel_pml4->entries[i].value;
        }
    }

    /* Entries 0-255 (user space) are zero (unmapped) */

    return VMM_OK;
}
```

## vmm_map_to_user 的实现

`vmm_map_to_user` 把一个物理页映射到用户地址空间。函数首先检查是否已初始化，然后确保设置了 USER 标志，这样用户程序才能访问这个映射。

```c
vmm_result_t vmm_map_to_user(physical_addr_t pml4_phys,
                            virtual_addr_t user_vaddr,
                            physical_addr_t paddr,
                            uint64_t page_count,
                            uint64_t flags) {
    if (!s_initialized) {
        return VMM_ERR_NOT_INIT;
    }

    /* Ensure USER flag is set */
    flags |= VMAP_FLAG_USER;
```

然后逐页映射，如果失败则回滚：

```c
    /* Map each page */
    for (uint64_t i = 0; i < page_count; i++) {
        virtual_addr_t va = user_vaddr + (i * PAGE_SIZE);
        physical_addr_t pa = paddr + (i * PAGE_SIZE);

        if (page_map_page(pml4_phys, va, pa, flags, true) != PAGE_OK) {
            /* Rollback */
            for (uint64_t j = 0; j < i; j++) {
                virtual_addr_t va = user_vaddr + (j * PAGE_SIZE);
                page_unmap_page(pml4_phys, va, false);
            }
            return VMM_ERR_OOM;
        }
    }

    return VMM_OK;
}
```

我们总是设置 `VMAP_FLAG_USER` 标志，确保用户程序可以访问这个映射。如果你忘记设置这个标志，用户程序访问这个页面会触发页错误。

## 测试用户地址空间

我们可以写一个测试来验证用户地址空间创建：

```c
/* Test user address space creation */
void test_user_space(void) {
    physical_addr_t user_pml4;

    if (vmm_create_user_space(&user_pml4) == VMM_OK) {
        klog_info("[TEST] User space created with PML4 at 0x%X\n", user_pml4);

        /* Allocate a physical page */
        physical_addr_t paddr;
        if (pframe_alloc(&paddr) == PFRAME_OK) {
            /* Map to user space */
            virtual_addr_t user_vaddr = 0x400000;
            if (vmm_map_to_user(user_pml4, user_vaddr, paddr, 1,
                               VMAP_FLAG_WRITE | VMAP_FLAG_USER) == VMM_OK) {
                klog_info("[TEST] Mapped physical page 0x%X to user address 0x%llX\n",
                          paddr, user_vaddr);
            }

            pframe_free(paddr);
        }

        /* Free the user PML4 */
        page_free_table(user_pml4);
    }
}
```
