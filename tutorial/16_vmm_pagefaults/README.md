## 技术要点

### x86_64 四级页表
```
虚拟地址: [PML4 9b][PDPT 9b][PD 9b][PT 9b][Offset 12b]
每个页表: 512 项 × 8 字节 = 4KB
```

### 页表项标志位
- 位 0: Present（页面存在）
- 位 1: Read/Write（读写权限）
- 位 2: User/Supervisor（用户/内核）
- 位 7: Page Size（巨大页）
- 位 63: No-Execute（禁止执行）

### 地址空间布局
```
直接映射:   0xFFFF800000000000 - 0xFFFF800001000000 (256MB)
内核代码:   0xFFFFFFFF80000000 - 0xFFFFFFFF80200000 (2MB)
内核数据:   0xFFFFFFFF80200000 - 0xFFFFFFFF80400000 (2MB)
内核堆:     0xFFFFFFFF81000000 - 0xFFFFFFFF89000000 (128MB)
用户空间:   0x0000000000400000 - 0x00007FFFFFFFFFFF (128TB)
```

## 常见问题

### Q: 为什么需要四级页表？

A: 四级页表是一个平衡点。既能支持巨大的地址空间（48 位虚拟地址），又保持每个页表 4KB 大小，便于内存管理。

### Q: 什么是规范地址？

A: x86_64 要求虚拟地址的位 63-48 必须是位 47 的符号扩展。满足这个条件的地址叫规范地址，访问非规范地址会触发 #GP。

### Q: 为什么要刷新 TLB？

A: TLB 缓存虚拟地址到物理地址的转换。修改页表后，TLB 中的旧缓存可能不再正确，必须刷新才能让 CPU 使用新的映射。

### Q: 什么是直接映射？

A: 直接映射是一种把物理地址空间映射到连续虚拟地址区域的方法。在我们的内核中，物理地址 `X` 映射到虚拟地址 `X + 0xFFFF800000000000`。
