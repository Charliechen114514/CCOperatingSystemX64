# 编写演示程序 —— Stage 22 调度类框架实战指南（八）

## 前言

前面七篇文章，我们搭好了框架，实现了 RR 和 Priority 调度类，完成了进程管理与调度器的集成。代码写完了，但怎么验证它确实能工作呢？这就需要演示程序了。

演示程序（demo）是内核开发中非常重要的一环。它不仅能验证代码的正确性，还能展示各个功能是如何工作的。对于调度器来说，我们需要验证：RR 调度确实轮流执行任务，Priority 调度确实优先执行高优先级任务，抢占机制确实能工作。

说实话，写演示程序往往比写实现代码还要费心。你需要设计各种测试用例，覆盖不同的场景，还要考虑如何清晰地展示测试结果。一个设计良好的演示程序，能让你在调试时事半功倍。

这篇文章我们会编写完整的调度器演示程序，包括单元测试、集成测试和可视化输出。

## 演示程序设计

### 测试框架

我们需要一个简单的测试框架来组织测试用例：

```c
/* ============================================================================
 * Test Result Tracking
 * ============================================================================ */

static int tests_passed = 0;
static int tests_failed = 0;

#define TEST_ASSERT(condition, message) \
    do { \
        if (!(condition)) { \
            klog_error("[SCHED_DEMO] FAILED: %s\n", message); \
            tests_failed++; \
            return false; \
        } \
    } while(0)

#define TEST_START(name) \
    klog_info("[SCHED_DEMO] Test: %s...\n", name)

#define TEST_PASS() \
    do { \
        klog_info("[SCHED_DEMO] PASSED\n"); \
        tests_passed++; \
        return true; \
    } while(0)
```

`TEST_ASSERT` 用于断言条件，如果条件为假就记录失败并返回。`TEST_START` 和 `TEST_PASS` 用于标记测试的开始和通过。

### 测试用例组织

我们把测试分为几类：

1. **RR 调度类测试**：验证 RR 调度的基本功能
2. **Priority 调度类测试**：验证 Priority 调度的基本功能
3. **抢占行为测试**：验证优先级抢占是否正确
4. **多策略共存测试**：验证 RR 和 Priority 能否同时工作

### 测试 3：RR 抢占逻辑

```c
/**
 * @brief Test 3: RR Should Preempt Logic
 */
static bool test_rr_should_preempt(void) {
    TEST_START("RR Should Preempt Logic");

    sched_class_t* rr_class = sched_rr_get_class();

    /* Create test tasks with minimal pcb_t structure */
    pcb_t task1, task2;
    memset(&task1, 0, sizeof(pcb_t));
    memset(&task2, 0, sizeof(pcb_t));

    INIT_LIST_HEAD(&task1.sched_entity.run_list);
    INIT_LIST_HEAD(&task2.sched_entity.run_list);

    task1.sched_entity.sched_class = rr_class;
    task1.sched_entity.policy = SCHED_NORMAL;
    task1.sched_entity.time_slice = 5;
    task1.sched_entity.time_slice_total = 10;

    task2.sched_entity.sched_class = rr_class;
    task2.sched_entity.policy = SCHED_NORMAL;
    task2.sched_entity.time_slice = 10;
    task2.sched_entity.time_slice_total = 10;

    /* Test 1: Task with time slice should not be preempted in RR */
    bool should_preempt = rr_class->should_preempt(&task2, &task1);
    TEST_ASSERT(!should_preempt,
               "Task with time slice should not be preempted in RR");

    /* Test 2: Task without time slice can be preempted */
    task1.sched_entity.time_slice = 0;
    should_preempt = rr_class->should_preempt(&task2, &task1);
    TEST_ASSERT(should_preempt,
               "Task without time slice should be preempted in RR");

    TEST_PASS();
}
```

这个测试验证 RR 的抢占逻辑：只有当前任务时间片用完时才允许"抢占"。

验证 RR 返回固定时间片，不管进程的优先级如何。

### 测试 7：Priority 抢占逻辑

```c
/**
 * @brief Test 7: Priority Should Preempt Logic
 */
static bool test_priority_should_preempt(void) {
    TEST_START("Priority Should Preempt Logic");

    sched_class_t* prio_class = sched_prio_get_class();

    /* Create test tasks */
    pcb_t high_task, low_task, same_prio_task;
    memset(&high_task, 0, sizeof(pcb_t));
    memset(&low_task, 0, sizeof(pcb_t));
    memset(&same_prio_task, 0, sizeof(pcb_t));

    INIT_LIST_HEAD(&high_task.sched_entity.run_list);
    INIT_LIST_HEAD(&low_task.sched_entity.run_list);
    INIT_LIST_HEAD(&same_prio_task.sched_entity.run_list);

    /* High priority task (priority = 10) */
    high_task.sched_entity.sched_class = prio_class;
    high_task.sched_entity.policy = SCHED_PRIORITY;
    high_task.sched_entity.priority = 10;
    high_task.sched_entity.time_slice = 10;
    high_task.sched_entity.time_slice_total = 10;

    /* Low priority task (priority = 50) */
    low_task.sched_entity.sched_class = prio_class;
    low_task.sched_entity.policy = SCHED_PRIORITY;
    low_task.sched_entity.priority = 50;
    low_task.sched_entity.time_slice = 10;
    low_task.sched_entity.time_slice_total = 10;

    /* Same priority task (priority = 50) */
    same_prio_task.sched_entity.sched_class = prio_class;
    same_prio_task.sched_entity.policy = SCHED_PRIORITY;
    same_prio_task.priority = 50;
    same_prio_task.time_slice = 10;
    same_prio_task.time_slice_total = 10;

    /* Test 1: Higher priority should preempt lower priority */
    bool should_preempt = prio_class->should_preempt(&high_task, &low_task);
    TEST_ASSERT(should_preempt,
               "Higher priority should preempt lower priority");

    /* Test 2: Lower priority should not preempt higher priority */
    should_preempt = prio_class->should_preempt(&low_task, &high_task);
    TEST_ASSERT(!should_preempt,
               "Lower priority should not preempt higher priority");

    /* Test 3: Same priority without time slice exhausted */
    should_preempt = prio_class->should_preempt(&same_prio_task, &low_task);
    TEST_ASSERT(!should_preempt,
               "Same priority should not preempt if current has time slice");

    /* Test 4: Same priority with time slice exhausted */
    low_task.sched_entity.time_slice = 0;
    should_preempt = prio_class->should_preempt(&same_prio_task, &low_task);
    TEST_ASSERT(should_preempt,
               "Same priority should preempt if current has no time slice");

    TEST_PASS();
}
```

这个测试验证 Priority 调度的抢占逻辑：高优先级任务总是能抢占低优先级任务，相同优先级只有在时间片用完时才切换。

## 抢占行为演示

### 创建测试任务

为了演示抢占行为，我们需要创建一些实际运行的测试任务。这些任务会运行一段时间，然后主动让出 CPU：

```c
/* ============================================================================
 * Demo Task Functions
 * ============================================================================ */

/**
 * @brief Simple counter task for RR demo
 */
static void rr_counter_task(void* arg) {
    int task_id = *(int*)arg;
    int iterations = 0;

    klog_info("[RR_DEMO] Task %d starting\n", task_id);

    /* Run for a fixed number of iterations */
    while (iterations < 100) {
        /* Do some work */
        volatile int dummy = 0;
        for (int i = 0; i < 10000; i++) {
            dummy += i;
        }

        iterations++;

        /* Print progress every 20 iterations */
        if (iterations % 20 == 0) {
            klog_info("[RR_DEMO] Task %d: iteration %d\n", task_id, iterations);
        }

        /* Occasionally yield to demonstrate scheduling */
        if (iterations % 30 == 0) {
            sys_yield();
        }
    }

    klog_info("[RR_DEMO] Task %d completed %d iterations\n", task_id, iterations);
}

/**
 * @brief Priority-based demo task
 */
static void prio_counter_task(void* arg) {
    int task_id = *(int*)arg;
    int priority = scheduler.current->sched_entity.priority;
    int iterations = 0;

    klog_info("[PRIO_DEMO] Task %d (priority %d) starting\n", task_id, priority);

    /* Run for a fixed number of iterations */
    while (iterations < 50) {
        /* Do some work */
        volatile int dummy = 0;
        for (int i = 0; i < 10000; i++) {
            dummy += i;
        }

        iterations++;

        /* Print progress less frequently for low priority tasks */
        if (iterations % 10 == 0) {
            klog_info("[PRIO_DEMO] Task %d (prio %d): iteration %d\n",
                     task_id, priority, iterations);
        }

        /* Occasionally yield */
        if (iterations % 20 == 0) {
            sys_yield();
        }
    }

    klog_info("[PRIO_DEMO] Task %d (prio %d) completed\n", task_id, priority);
}
```

### RR 调度演示

```c
/**
 * @brief Run the RR scheduling demo
 */
int sched_run_rr_demo(void) {
    klog_info("[SCHED_DEMO] ========== Round-Robin Scheduling Demo ==========\n");

    /* Reset test counters */
    tests_passed = 0;
    tests_failed = 0;

    /* Run unit tests */
    test_rr_class_init();
    test_rr_time_slice_constants();
    test_rr_should_preempt();
    test_rr_get_time_slice();

    klog_info("[SCHED_DEMO] Unit Tests: %d passed, %d failed\n",
              tests_passed, tests_failed);

    /* Create demo tasks */
    #define NUM_RR_TASKS 4
    int task_ids[NUM_RR_TASKS];
    pcb_t* tasks[NUM_RR_TASKS];

    for (int i = 0; i < NUM_RR_TASKS; i++) {
        task_ids[i] = i + 1;
        tasks[i] = proc_create_kernel_thread(rr_counter_task, &task_ids[i],
                                             "rr_task_%d", i + 1);

        if (tasks[i] == NULL) {
            klog_error("[SCHED_DEMO] Failed to create task %d\n", i + 1);
            return -1;
        }

        /* Set RR scheduling policy */
        sched_set_policy(tasks[i], SCHED_NORMAL, 0);
        sched_init_time_slice(tasks[i]);
        sched_enqueue_task(tasks[i], false);

        klog_info("[SCHED_DEMO] Created RR task %d (PID=%d)\n", i + 1, tasks[i]->pid);
    }

    klog_info("[SCHED_DEMO] All RR tasks created, starting scheduling...\n");

    return 0;
}
```

/**
 * @brief Run mixed scheduling demo (RR + Priority)
 */
int sched_run_mixed_demo(void) {
    klog_info("[SCHED_DEMO] ========== Mixed Scheduling Demo ==========\n");

    /* Create RR tasks */
    pcb_t* rr_task1 = proc_create_kernel_thread(rr_counter_task, &(int){1},
                                                  "mixed_rr_1");
    pcb_t* rr_task2 = proc_create_kernel_thread(rr_counter_task, &(int){2},
                                                  "mixed_rr_2");

    sched_set_policy(rr_task1, SCHED_NORMAL, 0);
    sched_set_policy(rr_task2, SCHED_NORMAL, 0);
    sched_init_time_slice(rr_task1);
    sched_init_time_slice(rr_task2);
    sched_enqueue_task(rr_task1, false);
    sched_enqueue_task(rr_task2, false);

    /* Create Priority tasks */
    pcb_t* prio_task1 = proc_create_kernel_thread(prio_counter_task, &(int){3},
                                                    "mixed_prio_1");
    pcb_t* prio_task2 = proc_create_kernel_thread(prio_counter_task, &(int){4},
                                                    "mixed_prio_2");

    sched_set_policy(prio_task1, SCHED_PRIORITY, 30);
    sched_set_policy(prio_task2, SCHED_PRIORITY, 60);
    sched_init_time_slice(prio_task1);
    sched_init_time_slice(prio_task2);
    sched_enqueue_task(prio_task1, false);
    sched_enqueue_task(prio_task2, false);

    klog_info("[SCHED_DEMO] Created 2 RR tasks and 2 Priority tasks\n");
    klog_info("[SCHED_DEMO] Priority tasks should preempt RR tasks\n");

    return 0;
}

## 常见问题

**问题：演示任务没有运行**

检查任务是否正确加入运行队列。可以在 `sched_enqueue_task()` 后添加日志验证。

**问题：单元测试全部失败**

检查调度类是否正确注册。确保 `sched_rr_init()` 和 `sched_prio_init()` 在演示运行前被调用。

**问题：测试任务创建了但没有输出**

可能是任务没有被调度。检查 `schedule()` 是否被正确调用，调度器锁是否正确释放。
