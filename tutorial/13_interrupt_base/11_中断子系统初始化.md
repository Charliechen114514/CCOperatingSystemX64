# 中断子系统初始化 —— Stage 13 中断基础实战指南

## 前言

前面几篇文章我们实现了中断系统的各个组件：PIC 驱动、IDT 管理、汇编 stub、C 分发器。现在到了最后一步 —— 把这些组件集成起来，实现完整的初始化流程。

---

## 第一步：实现 interrupt_init() 函数

这个函数负责按正确顺序初始化各个组件：

```c
/**
 * @file interrupt.c
 */

#include "interrupt.h"
#include "driver/pic/pic.h"
#include "idt.h"
#include "klogs/kprintf.h"

/* ============================================================================
 * 中断子系统初始化
 * ============================================================================ */

/**
 * @brief 启用所有 IRQ
 */
static void interrupt_enable_all_irqs(void) {
    for (int i = 0; i < 16; i++) {
        pic_enable_irq(i);
    }
    klog_trace("All IRQs enabled\n");
}

/**
 * @brief 初始化中断子系统
 */
void interrupt_init(void) {
    klog_trace("Initializing interrupt subsystem...\n");

    // 第一步：初始化并重映射 PIC
    pic_init(0x20, 0x28);  // IRQ 0-15 → 向量 32-47
    klog_trace("PIC initialized\n");

    // 第二步：禁用所有 IRQ（初始化期间）
    pic_disable_all();
    klog_trace("All IRQs disabled during init\n");

    // 第三步：初始化 IDT
    idt_init();
    klog_trace("IDT initialized\n");

    // 注意：此时中断还没有启用
    // 需要在所有设备初始化完成后调用 interrupt_finalize()
}
```

---

## 第二步：实现 interrupt_finalize() 函数

这个函数在所有设备初始化完成后调用，启用中断：

```c
/**
 * @brief 完成中断初始化并启用中断
 */
void interrupt_finalize(void) {
    klog_trace("Finalizing interrupt initialization...\n");

    // 启用所有 IRQ
    interrupt_enable_all_irqs();

    // 启用 CPU 中断（STI 指令）
    interrupt_enable();

    klog_info("Interrupts enabled\n");
}

/* 内联函数实现 */
static inline void interrupt_enable(void) {
    __asm__ volatile("sti");
}

static inline void interrupt_disable(void) {
    __asm__ volatile("cli");
}

static inline bool is_intr_enabled(void) {
    uint64_t rflags;
    __asm__ volatile("pushfq; popq %0" : "=r"(rflags));
    return (rflags & 0x200) != 0;
}
```

---

## 第三步：在内核中集成

修改 `kernel/kernel_init.c`：

```c
#include "interrupt/interrupt.h"

void kernel_init(void) {
    // ... 其他初始化 ...

    // 初始化中断子系统（在 klog_init 之后）
    interrupt_init();

    // ... 其他设备初始化 ...

    // 完成中断初始化并启用中断
    interrupt_finalize();

    klog_info("kernel init finished!\n");
}
```

---

## 第四步：在 kernel_main 中使用定时器

修改 `kernel/kernel_main.c`：

```c
#include "interrupt/interrupt.h"

void kernel_main(void) {
    kernel_init();

    klog_info("=== Kernel Stage Reach End ===\n");

    // 监控定时器滴答
    uint64_t last_ticks = 0;
    while (1) {
        uint64_t current_ticks = timer_get_ticks();

        // 每 ~100 滴答输出一次
        if (current_ticks > last_ticks + 99) {
            klog_info("[TIMER] Active! Total ticks: %lu\n", current_ticks);
            last_ticks = current_ticks;
        }

        __asm__ volatile("hlt");
    }
}
```

---

## 第五步：完整的初始化顺序

中断系统的初始化顺序非常重要：

```
1. klog_init()           // 初始化日志（最先）
2. serial_init()         // 初始化串口
3. vga_init()            // 初始化 VGA
4. interrupt_init()      // 初始化 PIC 和 IDT（禁用 IRQ）
5. [其他设备初始化]      // 初始化设备驱动
6. interrupt_finalize()  // 启用 IRQ 和 CPU 中断（最后）
```

如果在设备初始化之前就启用了中断，可能会导致中断发生时处理函数还没准备好，造成系统崩溃。
