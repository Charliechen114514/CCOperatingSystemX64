# C 语言中断分发器 —— Stage 13 中断基础实战指南

## 前言

前面几篇文章我们实现了汇编 stub，那是中断处理的第一站。现在到了 C 语言部分 —— 中断分发器。这个模块负责：
1. 根据中断向量决定调用哪个处理函数
2. 显示 CPU 异常信息
3. 处理定时器中断

这部分代码逻辑不复杂，但需要仔细设计。

---

## 第一步：实现异常显示函数

当 CPU 异常发生时，我们需要显示详细信息帮助调试：

```c
/**
 * @file interrupt.c
 * @brief 中断分发器实现
 */

#include "idt.h"
#include "idt_constants.h"
#include "klogs/kprintf.h"

/* ============================================================================
 * 异常信息显示
 * ============================================================================ */

static void dump_exception_info(uint64_t vector, uint64_t error_code,
                                 interrupt_frame_t* frame) {
    klog_error("=== EXCEPTION OCCURRED ===\n");
    klog_error("Vector: %d - %s\n", vector, idt_get_exception_name(vector));
    klog_error("Error Code: 0x%016lx\n", error_code);
    klog_error("RIP: 0x%016lx\n", frame->rip);
    klog_error("CS:  0x%016lx\n", frame->cs);
    klog_error("RFLAGS: 0x%016lx\n", frame->rflags);
    klog_error("RSP: 0x%016lx\n", frame->rsp);
    klog_error("SS:  0x%016lx\n", frame->ss);
}
```

## 第二步：实现定时器中断处理

定时器中断（IRQ 0）是最常用的中断，我们实现一个简单的滴答计数器：

```c
/* ============================================================================
 * 定时器支持
 * ============================================================================ */

static volatile uint64_t g_timer_ticks = 0;

uint64_t timer_get_ticks(void) {
    return g_timer_ticks;
}

static void timer_handler(interrupt_frame_t* frame) {
    (void)frame;
    g_timer_ticks++;

    // 每隔一定滴答数输出一次（避免刷屏）
    if (g_timer_ticks % 100 == 0) {
        klog_info("[TIMER] Ticks: %lu\n", g_timer_ticks);
    }

    // 发送 EOI
    pic_send_eoi(0);
}
```

## 第三步：实现默认 IRQ 处理器

对于没有专门处理函数的 IRQ，我们使用默认处理器：

```c
static void default_irq_handler(uint64_t irq) {
    klog_warn("Unhandled IRQ: %lu\n", irq);
    pic_send_eoi(irq);
}
```

## 第四步：实现中断分发器主函数

这是 `interrupt_common` 调用的 C 函数：

```c
/* ============================================================================
 * 中断分发器
 * ============================================================================ */

void interrupt_handler(uint64_t vector, uint64_t error_code,
                        interrupt_frame_t* frame) {
    if (vector < 32) {
        // CPU 异常
        dump_exception_info(vector, error_code, frame);

        // 调用栈回溯（如果可用）
        extern void dump_stack(int);
        dump_stack(16);

        // 停止系统
        while (1) {
            __asm__ volatile("hlt");
        }
    } else if (vector < 48) {
        // IRQ (32-47)
        uint64_t irq = vector - 32;

        switch (irq) {
            case 0:  // 定时器
                timer_handler(frame);
                break;
            // 未来会添加更多设备处理
            default:
                default_irq_handler(irq);
                break;
        }
    } else {
        // 用户定义的中断
        klog_warn("Unhandled interrupt: %lu\n", vector);
    }
}
```

## 第五步：导出接口

在 `interrupt.h` 中导出公共接口：

```c
/**
 * @file interrupt.h
 * @brief 中断子系统接口
 */

#pragma once

#include "idt.h"
#include "defines/types.h"

/**
 * @brief 获取定时器滴答数
 */
uint64_t timer_get_ticks(void);

/**
 * @brief 中断处理函数类型
 */
typedef void (*interrupt_handler_fn)(interrupt_frame_t* frame);

/**
 * @brief 注册中断处理函数
 */
void idt_register_handler(uint8_t vector, interrupt_handler_fn handler);
```
