## 常见问题排查

### 问题 1：没有任何输出

**可能原因**：
- 串口初始化失败
- 日志系统未初始化
- 系统在初始化前崩溃

**排查方法**：
1. 检查 `klog_init()` 是否在 `interrupt_init()` 之前调用
2. 使用 QEMU Monitor 查看系统状态
3. 在 `kernel_init` 开始处添加测试输出

---

### 问题 2：触发 Divide Error

**可能原因**：栈不对齐

**排查方法**：
1. 检查 `interrupt.asm` 中的对齐 dummy 是否存在
2. 计算栈偏移确保 16 字节对齐
3. 查看是否使用了正确的宏

---

### 问题 3：定时器只输出一次

**可能原因**：忘记发送 EOI

**排查方法**：
1. 检查 `timer_handler()` 是否调用了 `pic_send_eoi(0)`
2. 确认 EOI 在处理函数的最后调用

---

### 问题 4：系统完全卡死

**可能原因**：中断风暴

**排查方法**：
1. 检查是否有 IRQ 反复触发
2. 确认处理函数执行时间不要太长
3. 在初始化时禁用所有 IRQ，再逐个启用

## QEMU 调试技巧

### 使用 QEMU Monitor

```bash
# 启动 QEMU 时添加 monitor
qemu-system-x86_64 -drive format=raw,file=build/disk.img \
    -serial stdio -monitor telnet::4444,server,nowait

# 在另一个终端连接
telnet localhost 4444
```

在 QEMU Monitor 中：
```
(qemu) info registers    # 查看寄存器
(qemu) info pic          # 查看 PIC 状态
(qemu) x/16x 0x8000     # 查看内存
(qemu) xp/16x $rsp      # 查看栈
```

### 使用 GDB

```bash
# 启动 QEMU 时添加 GDB 支持
qemu-system-x86_64 -drive format=raw,file=build/disk.img \
    -serial stdio -s -S

# 在另一个终端启动 GDB
gdb build/kernel/kernel.elf
(gdb) target remote :1234
(gdb) break interrupt_handler
(gdb) continue
```
