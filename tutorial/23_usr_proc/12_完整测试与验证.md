# 完整测试与验证

## 前言

我们已经实现了用户态支持系统，包括用户内存管理、系统调用扩展、用户库、用户程序嵌入等。现在我们需要全面测试这个系统，确保它在各种情况下都能正常工作。

说实话，测试用户态代码比测试内核代码要困难得多。用户程序运行在不同的特权级，我们无法直接访问它的内存，调试也更加困难。但全面的测试是必不可少的，因为用户态是操作系统和用户程序之间的边界，任何错误都可能导致安全漏洞或系统崩溃。

这篇文章我们会设计一个完整的测试套件，涵盖：
1. 单元测试（各个模块）
2. 集成测试（模块间交互）
3. 压力测试（边界条件）
4. 错误处理测试（异常情况）

---

## 测试策略

### 测试金字塔

```
        ┌─────────────┐
        │  手动测试    │  少量、验证性
        ├─────────────┤
        │  集成测试    │  中等、关键路径
        ├─────────────┤
        │  单元测试    │  大量、全面覆盖
        └─────────────┘
```

### 测试分类

1. **单元测试**
   - 用户指针验证
   - brk/mmap 功能
   - 系统调用处理

2. **集成测试**
   - 用户程序加载
   - Ring 3 切换
   - 系统调用往返

3. **压力测试**
   - 多进程并发
   - 内存压力
   - 系统调用频率

4. **错误处理测试**
   - 无效指针
   - 权限违规
   - 资源耗尽

## 单元测试

### 用户指针验证测试

```c
/* ==============================================================================
 * User Pointer Validation Tests
 * ==============================================================================
 */

#include "user/user.h"
#include "klogs/kprintf.h"
#include "mm/vmm/vmm.h"

void test_user_pointer_validation(void) {
    klog_info("=== User Pointer Validation Tests ===\n");

    int passed = 0;
    int total = 0;

    /* Test 1: Valid user pointer */
    total++;
    char* valid_user_ptr = (char*)0x400000;
    if (user_validate_pointer(valid_user_ptr, 100, false)) {
        passed++;
        klog_info("[PASS] Test 1: Valid user pointer accepted\n");
    } else {
        klog_error("[FAIL] Test 1: Valid user pointer rejected\n");
    }

    /* Test 2: Kernel pointer should be rejected */
    total++;
    char* kernel_ptr = (char*)0xFFFF8000000000000ULL;
    if (!user_validate_pointer(kernel_ptr, 100, false)) {
        passed++;
        klog_info("[PASS] Test 2: Kernel pointer rejected\n");
    } else {
        klog_error("[FAIL] Test 2: Kernel pointer accepted (should be rejected)\n");
    }

    /* Test 3: NULL pointer should be rejected */
    total++;
    char* null_ptr = NULL;
    if (!user_validate_pointer(null_ptr, 10, false)) {
        passed++;
        klog_info("[PASS] Test 3: NULL pointer rejected\n");
    } else {
        klog_error("[FAIL] Test 3: NULL pointer accepted (should be rejected)\n");
    }

    /* Test 4: Overflow test */
    total++;
    virtual_addr_t overflow_addr = 0xFFFFFFFFFFFFFFF0ULL;
    if (!user_validate_pointer((void*)overflow_addr, 0x100, false)) {
        passed++;
        klog_info("[PASS] Test 4: Overflow detected\n");
    } else {
        klog_error("[FAIL] Test 4: Overflow not detected\n");
    }

    /* Test 5: Large valid size */
    total++;
    if (user_validate_pointer((void*)0x400000, 1024 * 1024, false)) {
        passed++;
        klog_info("[PASS] Test 5: Large valid size accepted\n");
    } else {
        klog_error("[FAIL] Test 5: Large valid size rejected\n");
    }

    klog_info("=== Tests Complete: %d/%d passed ===\n", passed, total);
}
```

### brk/mmap 测试

```c
/* ==============================================================================
 * Memory Management Tests
 * ==============================================================================
 */

#include "user/user.h"
#include "process/process.h"
#include "mm/vmm/vmm.h"
#include "klogs/kprintf.h"

void test_memory_management(void) {
    klog_info("=== Memory Management Tests ===\n");

    int passed = 0;
    int total = 0;

    /* Create a test process */
    pcb_t* pcb = proc_allocate_pcb();
    if (!pcb) {
        klog_error("Failed to allocate test PCB\n");
        return;
    }

    pcb->pid = 9999;
    pcb->state = PROC_READY;

    /* Create user address space */
    if (vmm_create_user_space(&pcb->mm.pml4_phys) != 0) {
        klog_error("Failed to create user address space\n");
        kfree(pcb);
        return;
    }

    /* Test 1: Query initial brk (should be 0) */
    total++;
    virtual_addr_t brk = user_brk(pcb, 0);
    if (brk == 0) {
        passed++;
        klog_info("[PASS] Test 1: Initial brk is 0\n");
    } else {
        klog_error("[FAIL] Test 1: Initial brk is 0x%llX (expected 0)\n", brk);
    }

    /* Test 2: Set new brk */
    total++;
    virtual_addr_t new_brk = USER_BASE + (16 * 1024 * 1024) + (4 * PAGE_SIZE);
    brk = user_brk(pcb, new_brk);
    if (brk == new_brk) {
        passed++;
        klog_info("[PASS] Test 2: brk set to 0x%llX\n", brk);
    } else {
        klog_error("[FAIL] Test 2: brk returned 0x%llX (expected 0x%llX)\n", brk, new_brk);
    }

    /* Test 3: Shrink brk */
    total++;
    virtual_addr_t shrink_brk = new_brk - (2 * PAGE_SIZE);
    brk = user_brk(pcb, shrink_brk);
    if (brk == shrink_brk) {
        passed++;
        klog_info("[PASS] Test 3: brk shrunk to 0x%llX\n", brk);
    } else {
        klog_error("[FAIL] Test 3: brk returned 0x%llX (expected 0x%llX)\n", brk, shrink_brk);
    }

    /* Test 4: Invalid brk (below USER_BASE) */
    total++;
    virtual_addr_t invalid_brk = USER_BASE - PAGE_SIZE;
    brk = user_brk(pcb, invalid_brk);
    if (brk == shrink_brk) {  /* Should return old brk unchanged */
        passed++;
        klog_info("[PASS] Test 4: Invalid brk rejected\n");
    } else {
        klog_error("[FAIL] Test 4: Invalid brk accepted\n");
    }

    /* Test 5: mmap allocation */
    total++;
    virtual_addr_t mmap_addr = user_mmap(pcb, 0, 8 * PAGE_SIZE,
                                         0x3, 0x22, 0, 0);
    if (mmap_addr != 0 && mmap_addr >= USER_BASE) {
        passed++;
        klog_info("[PASS] Test 5: mmap returned 0x%llX\n", mmap_addr);
    } else {
        klog_error("[FAIL] Test 5: mmap failed\n");
    }

    /* Test 6: munmap */
    total++;
    int result = user_munmap(pcb, mmap_addr, 8 * PAGE_SIZE);
    if (result == 0) {
        passed++;
        klog_info("[PASS] Test 6: munmap succeeded\n");
    } else {
        klog_error("[FAIL] Test 6: munmap failed\n");
    }

    /* Cleanup */
    vmm_destroy_user_space(pcb->mm.pml4_phys);
    kfree(pcb);

    klog_info("=== Tests Complete: %d/%d passed ===\n", passed, total);
}
```

## 压力测试

### 多进程测试

```c
/* ==============================================================================
 * Stress Tests
 * ==============================================================================
 */

#define TEST_PROCESS_COUNT 10

void test_multiple_user_processes(void) {
    klog_info("=== Multiple User Processes Test ===\n");

    pcb_t* processes[TEST_PROCESS_COUNT];
    int created = 0;

    /* Create multiple user processes */
    for (int i = 0; i < TEST_PROCESS_COUNT; i++) {
        pcb_t* pcb = proc_allocate_pcb();
        if (!pcb) {
            klog_error("Failed to allocate PCB for process %d\n", i);
            break;
        }

        pcb->pid = proc_allocate_pid();
        pcb->state = PROC_READY;

        if (vmm_create_user_space(&pcb->mm.pml4_phys) != 0) {
            klog_error("Failed to create address space for process %d\n", i);
            kfree(pcb);
            break;
        }

        processes[created++] = pcb;

        klog_info("Created process %d: pid=%d\n", i, pcb->pid);
    }

    klog_info("Created %d processes\n", created);

    /* Clean up */
    for (int i = 0; i < created; i++) {
        if (processes[i]->mm.pml4_phys != 0) {
            vmm_destroy_user_space(processes[i]->mm.pml4_phys);
        }
        kfree(processes[i]);
    }

    klog_info("=== Stress Test Complete ===\n");
}
```

### 内存压力测试

```c
void test_memory_pressure(void) {
    klog_info("=== Memory Pressure Test ===\n");

    pcb_t* pcb = proc_allocate_pcb();
    if (!pcb) {
        klog_error("Failed to allocate test PCB\n");
        return;
    }

    pcb->pid = 8888;
    pcb->state = PROC_READY;

    if (vmm_create_user_space(&pcb->mm.pml4_phys) != 0) {
        klog_error("Failed to create user address space\n");
        kfree(pcb);
        return;
    }

    /* Allocate large amounts of memory */
    size_t total_allocated = 0;
    size_t max_pages = 1024;  /* Try to allocate 4MB */

    for (size_t i = 0; i < max_pages; i++) {
        virtual_addr_t new_brk = USER_BASE + (16 * 1024 * 1024) + ((i + 1) * PAGE_SIZE);
        virtual_addr_t result = user_brk(pcb, new_brk);

        if (result == new_brk) {
            total_allocated += PAGE_SIZE;
        } else {
            klog_info("Memory allocation stopped at %zu pages\n", i);
            break;
        }
    }

    klog_info("Allocated %zu bytes in total\n", total_allocated);

    /* Clean up */
    vmm_destroy_user_space(pcb->mm.pml4_phys);
    kfree(pcb);

    klog_info("=== Memory Pressure Test Complete ===\n");
}
```

## 测试运行器

### 主测试函数

```c
/* ==============================================================================
 * Test Runner
 * ==============================================================================
 */

typedef struct test_case {
    const char* name;
    void (*test_func)(void);
    bool enabled;
} test_case_t;

static const test_case_t s_test_cases[] = {
    /* Unit Tests */
    { "User Pointer Validation", test_user_pointer_validation, true },
    { "Memory Management", test_memory_management, true },

    /* Integration Tests */
    { "User Program Loading", test_user_program_loading, true },
    { "Ring 3 Transition", test_ring3_transition, true },

    /* Stress Tests */
    { "Multiple User Processes", test_multiple_user_processes, true },
    { "Memory Pressure", test_memory_pressure, true },
};

static const size_t s_num_test_cases = sizeof(s_test_cases) / sizeof(s_test_cases[0]);

/**
 * @brief Run all enabled tests
 */
void run_all_tests(void) {
    klog_info("\n");
    klog_info("========================================\n");
    klog_info("  CCOS User Mode Test Suite\n");
    klog_info("========================================\n");
    klog_info("\n");

    int total_run = 0;
    int total_passed = 0;

    for (size_t i = 0; i < s_num_test_cases; i++) {
        const test_case_t* test = &s_test_cases[i];

        if (!test->enabled) {
            continue;
        }

        total_run++;

        klog_info("\n--- Running: %s ---\n", test->name);
        test->test_func();
        klog_info("--- Completed: %s ---\n\n", test->name);
    }

    klog_info("========================================\n");
    klog_info("  Test Summary\n");
    klog_info("========================================\n");
    klog_info("Tests run: %d\n", total_run);
    klog_info("Tests passed: %d\n", total_passed);
    klog_info("Tests failed: %d\n", total_run - total_passed);
    klog_info("========================================\n");
}
```

### 在内核初始化时运行测试

在 `kernel/main.c` 中：

```c
void kernel_main(void) {
    /* ... existing initialization ... */

#ifdef RUN_TESTS
    /* Run test suite */
    run_all_tests();
#endif

    /* Continue normal boot */
    kernel_main_continue();
}
```

## 性能基准测试

虽然我们还不关注性能，但一些基本的基准测试是有用的：

```c
void benchmark_syscall_overhead(void) {
    klog_info("=== System Call Overhead Benchmark ===\n");

    const int iterations = 1000;

    /* Benchmark getpid() */
    uint64_t start = rdtsc();
    for (int i = 0; i < iterations; i++) {
        getpid();
    }
    uint64_t end = rdtsc();

    uint64_t cycles = end - start;
    uint64_t cycles_per_call = cycles / iterations;

    klog_info("getpid() overhead: %llu cycles per call\n", cycles_per_call);
}
```

## 常见测试问题

### 问题 1：测试导致系统崩溃

**症状**：某个测试运行后系统崩溃

**原因**：测试没有正确清理资源

**解决**：确保每个测试都有对应的清理代码

```c
void test_something(void) {
    /* Allocate resources */
    pcb_t* pcb = allocate_pcb();

    /* Run test */
    /* ... */

    /* Always clean up */
cleanup:
    if (pcb) kfree(pcb);
}
```

### 问题 2：测试之间相互影响

**症状**：单独运行测试通过，一起运行失败

**原因**：测试共享了全局状态

**解决**：每个测试使用独立的状态，或重置全局状态

### 问题 3：假阳性

**症状**：测试通过了，但功能实际上不工作

**原因**：测试不够全面

**解决**：增加边界条件和异常情况的测试
