## 演示程序概述

我们的演示程序会做以下事情：

1. **内核初始化**：在内核启动后初始化用户态子系统
2. **加载用户程序**：将嵌入的 `uname_test` 加载到用户空间
3. **创建用户进程**：设置 PCB、用户栈、页表
4. **切换到用户态**：使用 `iretq` 切换到 Ring 3
5. **用户程序执行**：在 Ring 3 中运行 `uname_test`
6. **系统调用**：用户程序通过 `syscall` 调用内核服务
7. **退出处理**：用户程序调用 `exit()` 退出

## 内核初始化

### 在内核启动时初始化用户态

打开 `kernel/main.c`（或你的内核入口文件），在初始化序列中添加用户态初始化：

```c
/* ==============================================================================
 * Kernel Main Entry Point
 * ==============================================================================
 */

#include "user/user.h"
#include "syscall/syscall.h"
#include "mm/vmm/vmm.h"
#include "mm/pframe/pframe.h"
#include "process/process.h"
#include "klogs/kprintf.h"

void kernel_main(void) {
    /* ... existing initialization ... */

    klog_info("=== Initializing User Mode Subsystem ===\n");

    /* Initialize user mode support */
    if (user_init() != 0) {
        klog_error("Failed to initialize user mode subsystem\n");
        return;
    }

    /* Register system calls */
    syscall_register_all();

    /* Start demo */
    kernel_main_continue();
}
```

### 延迟启动用户程序

用户程序的执行需要调度器支持，所以我们不能在 `kernel_main()` 中直接执行。我们需要在调度器启动后再执行：

```c
/* ==============================================================================
 * User Demo - Run after scheduler is ready
 * ==============================================================================
 */

extern int execute_uname_test(void);

void kernel_main_continue(void) {
    /* This is called after the scheduler has started */

    klog_info("=== Starting User Mode Demo ===\n");

    /* Execute the uname_test user program */
    if (execute_uname_test() != 0) {
        klog_error("Failed to execute uname_test\n");
        return;
    }

    klog_info("=== User Mode Demo Complete ===\n");
}
```

## 用户程序加载器

让我们实现完整的用户程序加载器。

### user_loader.c

```c
/* ==============================================================================
 * CCOS - User Process Loader
 * ==============================================================================
 *
 * This module handles loading embedded user programs into user space
 * and creating processes to execute them.
 *
 * ==============================================================================
 */

#include "user/user.h"
#include "mm/vmm/vmm.h"
#include "mm/pframe/pframe.h"
#include "mm/vmm/page.h"
#include "process/process.h"
#include "process/process_defines.h"
#include "klogs/kprintf.h"
#include "base/memory.h"
#include "base/string.h"

/* ==============================================================================
 * External Symbols - Embedded User Programs
 * ==============================================================================
 */

extern const uint8_t _binary_user_programs_demo_uname_test_start[];
extern const uint8_t _binary_user_programs_demo_uname_test_end[];
extern const uint64_t _binary_user_programs_demo_uname_test_size;

/* ==============================================================================
 * User Program Loading
 * ==============================================================================
 */

/**
 * @brief Load embedded user program into user space
 *
 * @param name Program name (e.g., "uname_test")
 * @param pcb PCB to initialize
 * @return 0 on success, negative on error
 */
int load_user_program(const char* name, pcb_t* pcb) {
    const uint8_t* program_data;
    size_t program_size;
    virtual_addr_t entry_point;

    klog_info("[USER LOADER] Loading program: %s\n", name);

    /* Find the program */
    if (strcmp(name, "uname_test") == 0) {
        program_data = _binary_user_programs_demo_uname_test_start;
        program_size = (size_t)_binary_user_programs_demo_uname_test_size;
        entry_point = USER_BASE;  /* Load at 4MB */
    } else {
        klog_error("[USER LOADER] Unknown program: %s\n", name);
        return -1;
    }

    klog_info("[USER LOADER] Program size: %zu bytes\n", program_size);

    /* Create user address space */
    klog_debug("[USER LOADER] Creating user address space...\n");
    if (vmm_create_user_space(&pcb->mm.pml4_phys) != 0) {
        klog_error("[USER LOADER] Failed to create user address space\n");
        return -1;
    }

    /* Calculate how many pages we need */
    size_t num_pages = (program_size + PAGE_SIZE - 1) / PAGE_SIZE;
    klog_debug("[USER LOADER] Need %zu pages for program\n", num_pages);

    /* Map program pages into user space */
    for (size_t i = 0; i < num_pages; i++) {
        physical_addr_t paddr;

        /* Allocate a physical page */
        if (pframe_alloc(&paddr) != PFRAME_OK) {
            klog_error("[USER LOADER] Failed to allocate program page %zu\n", i);
            vmm_destroy_user_space(pcb->mm.pml4_phys);
            return -1;
        }

        /* Map to user space */
        virtual_addr_t vaddr = entry_point + (i * PAGE_SIZE);
        vmm_result_t result = vmm_map_to_user(pcb->mm.pml4_phys, vaddr,
                                               paddr, 1,
                                               VMAP_FLAG_USER);
        if (result != VMM_OK) {
            klog_error("[USER LOADER] Failed to map program page at 0x%llX\n", vaddr);
            pframe_free(paddr);
            vmm_destroy_user_space(pcb->mm.pml4_phys);
            return -1;
        }

        /* Copy program data to the page */
        size_t copy_size = PAGE_SIZE;
        size_t offset = i * PAGE_SIZE;
        if (offset + copy_size > program_size) {
            copy_size = program_size - offset;
        }

        void* dest = (void*)phys_to_virt_offset(paddr);
        memcpy(dest, program_data + offset, copy_size);

        /* Zero the rest of the page */
        if (copy_size < PAGE_SIZE) {
            memset((char*)dest + copy_size, 0, PAGE_SIZE - copy_size);
        }

        klog_trace("[USER LOADER] Mapped page %zu: 0x%llX -> 0x%X\n",
                   i, vaddr, paddr);
    }

    /* Create user process (sets up stack) */
    klog_debug("[USER LOADER] Creating user process...\n");
    if (user_create_process(entry_point, pcb) != 0) {
        klog_error("[USER LOADER] Failed to create user process\n");
        vmm_destroy_user_space(pcb->mm.pml4_phys);
        return -1;
    }

    klog_info("[USER LOADER] Program loaded: entry=0x%llX, pid=%d\n",
              entry_point, pcb->pid);

    return 0;
}

/* ==============================================================================
 * User Process Execution
 * ==============================================================================
 */

/**
 * @brief Execute the uname_test user program
 *
 * This function creates a new process and loads the uname_test program
 * into user space.
 *
 * @return 0 on success, negative on error
 */
int execute_uname_test(void) {
    /* Allocate a PCB */
    pcb_t* pcb = proc_allocate_pcb();
    if (!pcb) {
        klog_error("[USER] Failed to allocate PCB\n");
        return -1;
    }

    /* Initialize basic PCB fields */
    pcb->pid = proc_allocate_pid();
    pcb->state = PROC_READY;
    pcb->priority = PROC_PRIORITY_NORMAL;
    pcb->sched_class = SCHED_CLASS_NORMAL;

    klog_info("[USER] Creating process for uname_test: pid=%d\n", pcb->pid);

    /* Load the program */
    if (load_user_program("uname_test", pcb) != 0) {
        kfree(pcb);
        return -1;
    }

    /* Set up user context for Ring 3 transition */
    user_context_t user_ctx = {
        .entry = USER_BASE,  /* Entry point */
        .stack_top = pcb->user_stack + pcb->user_stack_size,
        .cs = USER_CS,       /* 0x1B */
        .ss = USER_SS,       /* 0x23 */
        .rflags = 0x202      /* IF = 1 */
    };

    /* Save the user context in PCB */
    pcb->user_context = user_ctx;

    /* Add to ready queue */
    proc_add_to_ready_queue(pcb);

    klog_info("[USER] uname_test process ready: pid=%d\n", pcb->pid);

    return 0;
}
```

## 用户态切换

当调度器选择用户进程运行时，我们需要切换到用户态。

### 在进程调度器中

打开 `kernel/process/scheduler.c`（或你的调度器实现），找到进程切换的代码：

```c
/* ==============================================================================
 * Process Switch - User Mode Support
 * ==============================================================================
 */

/**
 * @brief Switch to a user mode process
 *
 * This function is called by the scheduler when a user process is selected
 * to run. It performs the transition from Ring 0 to Ring 3.
 */
void proc_switch_to_user(pcb_t* pcb) {
    klog_debug("[SCHED] Switching to user process: pid=%d\n", pcb->pid);

    /* Set the current process */
    proc_set_current(pcb);

    /* Load the user address space */
    vmm_load_pml4(pcb->mm.pml4_phys);

    /* Switch to user mode */
    /* This function does not return */
    user_switch_to_usermode(&pcb->user_context);
}

/**
 * @brief Main scheduler entry point
 *
 * This is called from the timer interrupt or when a process yields.
 */
void schedule(void) {
    pcb_t* next = proc_get_next_to_run();

    if (!next) {
        /* No process to run, stay in idle */
        return;
    }

    if (next->is_user_mode) {
        /* Switch to user mode process */
        proc_switch_to_user(next);
    } else {
        /* Switch to kernel mode process */
        proc_switch_to_kernel(next);
    }
}
```

⚠️ **注意：上下文切换顺序**

切换到用户态进程时：
1. 先设置当前进程
2. 再加载页表（这样 user_context 的地址是正确的）
3. 最后调用 `user_switch_to_usermode()`

## 从系统调用返回

当用户程序调用系统调用后，内核需要返回到用户态。

### 系统调用返回处理

```c
/* ==============================================================================
 * System Call Return - User Mode
 * ==============================================================================
 */

/**
 * @brief Return from system call to user mode
 *
 * This is called after a system call handler completes.
 * It restores the user context and returns to Ring 3.
 */
void syscall_return_to_user(syscall_frame_t* frame, pcb_t* pcb) {
    /* Update registers if needed */
    /* frame->rax contains the return value */

    /* Set up iretq frame */
    /* This is typically done in assembly */

    /* The assembly stub will execute iretq to return to user mode */
    __asm__ volatile(
        "mov %0, %%rsp\n"     /* Load kernel stack pointer */
        "jmp syscall_return_user_common\n"
        :
        : "r"((uint64_t)&pcb->kernel_stack_top)
        : "memory"
    );
}
```

### 汇编返回桩

在 `kernel/syscall/syscall_entry.asm` 中：

```assembly
; ==============================================================================
; System Call Return to User Mode
; ==============================================================================

global syscall_return_user_common
syscall_return_user_common:
    ; RSP points to the syscall frame

    ; Pop general-purpose registers
    pop r15
    pop r14
    pop r13
    pop r12
    pop r11
    pop r10
    pop r9
    pop r8
    pop rbp
    pop rdi
    pop rsi
    pop rdx
    pop rcx
    pop rbx
    pop rax

    ; Check if returning to user mode
    ; RCX contains the user RIP (saved by syscall)
    ; R11 contains the user RFLAGS

    ; Restore RCX and R11
    mov rcx, [rsp + SYSCALL_FRAME_RCX]
    mov r11, [rsp + SYSCALL_FRAME_R11]

    ; Execute sysret to return to user mode
    sysretq
```

## 常见问题

### 问题 1：立即崩溃

**症状**：切换到用户态后立即崩溃

**原因**：可能是栈未正确设置或用户栈地址错误

**解决**：
1. 检查 `pcb->user_stack` 是否正确
2. 检查 `user_context.stack_top` 是否正确
3. 验证用户栈页已正确映射

### 问题 2：页错误

**症状**：用户程序触发页错误

**原因**：程序代码页未正确映射

**解决**：
1. 检查 `vmm_map_to_user()` 调用
2. 使用 `vmm_dump_page_table()` 查看页表
3. 确认程序数据已正确复制

### 问题 3：系统调用不工作

**症状**：用户程序调用系统调用后无响应

**原因**：系统调用入口或返回有问题

**解决**：
1. 检查 MSR 设置（`IA32_STAR`）
2. 验证系统调用号
3. 检查 `sysretq` 返回代码

### 问题 4：输出混乱

**症状**：用户程序输出与内核输出混合

**原因**：并发访问串口

**解决**：添加锁保护串口输出
