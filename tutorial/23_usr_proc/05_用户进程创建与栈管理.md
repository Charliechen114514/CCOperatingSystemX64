# 用户进程创建与栈管理

## 前言

在上一篇文章中，我们实现了 Ring 3 切换的汇编代码。那是一个关键的里程碑，但只是第一步。现在我们需要把各个部分串联起来 —— 创建一个完整的用户进程。

创建用户进程涉及很多事情：分配用户栈、映射内存、设置 PCB 标志、准备用户上下文。每一步都不能出错，否则切换到用户态后程序会崩溃。

这篇文章我们会实现 `user_create_process()` 和 `user_destroy_process()` 函数，并扩展 PCB 结构来支持用户态。

---

## 扩展 PCB 结构

首先，我们需要在 PCB 中添加用户态相关的字段。

打开 `kernel/process/process.h`，找到 PCB 结构的定义。我们已经有了这些字段：

```c
/* ===== User Mode Specific ===== */
bool               is_user_mode;   /* true = user process, false = kernel process */
virtual_addr_t     user_stack;     /* User stack top */
size_t             user_stack_size;/* User stack size */
```

如果你看到这些字段，说明 PCB 已经被扩展过了。如果没有，你需要添加它们。

### 字段说明

**`is_user_mode`**

这是一个布尔标志，表示这个进程是用户进程还是内核进程。
- `true` = 用户进程，运行在 Ring 3
- `false` = 内核进程，运行在 Ring 0

**`user_stack`**

用户栈的虚拟地址。注意这是栈的**底部**地址（较小的地址），因为栈向下增长。栈顶是 `user_stack + user_stack_size`。

**`user_stack_size`**

用户栈的大小，我们定义为 1MB (`USER_STACK_SIZE`)。

---

## 用户栈的位置和大小

在设计用户栈之前，我们需要确定几个问题：
- 栈放在用户空间的什么位置？
- 栈应该多大？
- 栈应该怎么增长？

### 栈的位置

我们把用户栈放在用户空间的顶部：

```
┌─────────────────────────────────────────────────────────┐
│                    内核空间                             │
│                  0xFFFF800000000000                     │
└─────────────────────────────────────────────────────────┘
                    USER_END
                         │
                    ↓ 栈向下增长
                         │
┌─────────────────────────────────────────────────────────┐
│                    用户栈 (1MB)                         │
│                  user_stack ... USER_END                │
└─────────────────────────────────────────────────────────┘
```

栈的起始地址是：
```c
pcb->user_stack = (USER_END - USER_STACK_SIZE) & ~(PAGE_SIZE - 1);
```

注意页对齐！`& ~(PAGE_SIZE - 1)` 确保栈地址是 4KB 对齐的。

### 栈的大小

我们选择 1MB 作为默认栈大小。这个选择是基于：
- **够用**：对于大多数用户程序来说，1MB 足够了
- **不太大**：每个进程 1MB 的物理内存是可接受的
- **可扩展**：后续可以添加栈扩展机制

如果程序递归太深或分配太多局部变量，会触发栈溢出（#PF 异常），我们可以捕获并扩展栈。

## 实现用户进程创建

现在来实现 `user_create_process()` 函数：

```c
int user_create_process(virtual_addr_t entry, pcb_t* pcb) {
    if (!pcb) {
        return -1;
    }

    (void)entry;  /* TODO: Use entry point when implementing exec */

    klog_info("[USER] Creating user process\n");

    /* Calculate user stack parameters */
    size_t stack_pages = USER_STACK_SIZE / PAGE_SIZE;
    pcb->user_stack_size = USER_STACK_SIZE;

    /* Align user stack to page boundary */
    pcb->user_stack = (USER_END - USER_STACK_SIZE) & ~(PAGE_SIZE - 1);

    klog_debug("[USER] Allocating user stack: %lu pages @ 0x%llX\n",
              stack_pages, pcb->user_stack);
```

### 分配和映射用户栈

现在我们需要分配物理页并映射到用户空间：

```c
    /* Map user stack pages */
    for (size_t i = 0; i < stack_pages; i++) {
        physical_addr_t paddr;

        /* Allocate a physical frame */
        if (pframe_alloc(&paddr) != PFRAME_OK) {
            klog_error("[USER] Failed to allocate user stack page %zu\n", i);

            /* Cleanup already allocated pages */
            for (size_t j = 0; j < i; j++) {
                virtual_addr_t vaddr = pcb->user_stack + (j * PAGE_SIZE);
                physical_addr_t phys;
                if (page_virt_to_phys(pcb->mm.pml4_phys, vaddr, &phys) == PAGE_OK) {
                    pframe_free(phys);
                }
                page_unmap_page(pcb->mm.pml4_phys, vaddr, false);
            }
            pcb->user_stack = 0;
            pcb->user_stack_size = 0;
            return -1;
        }

        /* Map to user space */
        virtual_addr_t vaddr = pcb->user_stack + (i * PAGE_SIZE);
        vmm_result_t result = vmm_map_to_user(pcb->mm.pml4_phys, vaddr, paddr, 1,
                                               VMAP_FLAG_WRITE | VMAP_FLAG_USER);
        if (result != VMM_OK) {
            klog_error("[USER] Failed to map user stack page at 0x%llX\n", vaddr);
            pframe_free(paddr);

            /* Cleanup */
            for (size_t j = 0; j < i; j++) {
                virtual_addr_t vaddr2 = pcb->user_stack + (j * PAGE_SIZE);
                physical_addr_t phys;
                if (page_virt_to_phys(pcb->mm.pml4_phys, vaddr2, &phys) == PAGE_OK) {
                    pframe_free(phys);
                }
                page_unmap_page(pcb->mm.pml4_phys, vaddr2, false);
            }
            pcb->user_stack = 0;
            pcb->user_stack_size = 0;
            return -1;
        }

        /* Clear the stack page (security) */
        memset((void*)phys_to_virt_offset(paddr), 0, PAGE_SIZE);
    }
```

### 代码解释

**物理页分配**

我们使用 `pframe_alloc()` 从物理帧分配器分配一页物理内存。如果分配失败，我们需要清理已经分配的页。

**页映射**

`vmm_map_to_user()` 将物理页映射到用户空间的虚拟地址。参数说明：
- `pcb->mm.pml4_phys`：进程的页表物理地址
- `vaddr`：要映射的虚拟地址
- `paddr`：物理页地址
- `1`：映射 1 页
- `VMAP_FLAG_WRITE | VMAP_FLAG_USER`：可写 + 用户空间

**清零栈页**

我们将栈页清零，这是一个安全措施。如果不清零，用户程序可能会读取到之前数据的残留。

### 设置用户模式标志

最后，设置用户模式标志：

```c
    pcb->is_user_mode = true;

    klog_info("[USER] User process created: stack=0x%llX, stack_size=%lu\n",
              pcb->user_stack, (unsigned long)pcb->user_stack_size);

    return 0;
}
```

## 实现用户进程销毁

当用户进程退出时，我们需要释放它的所有资源：

```c
void user_destroy_process(pcb_t* pcb) {
    if (!pcb || !pcb->is_user_mode) {
        return;
    }

    klog_info("[USER] Destroying user process\n");

    /* Free user stack pages */
    if (pcb->user_stack != 0 && pcb->user_stack_size != 0) {
        size_t stack_pages = pcb->user_stack_size / PAGE_SIZE;

        for (size_t i = 0; i < stack_pages; i++) {
            virtual_addr_t vaddr = pcb->user_stack + (i * PAGE_SIZE);
            physical_addr_t phys;

            /* Get physical address and free it */
            if (page_virt_to_phys(pcb->mm.pml4_phys, vaddr, &phys) == PAGE_OK) {
                pframe_free(phys);
            }

            /* Unmap from page table */
            page_unmap_page(pcb->mm.pml4_phys, vaddr, false);
        }
    }

    /* Destroy the user address space */
    if (pcb->mm.pml4_phys != 0) {
        vmm_destroy_user_space(pcb->mm.pml4_phys);
    }

    klog_info("[USER] User process destroyed\n");
}
```

### 清理顺序

清理资源的顺序很重要：
1. 先释放物理页（`pframe_free`）
2. 再取消页表映射（`page_unmap_page`）
3. 最后销毁地址空间（`vmm_destroy_user_space`）

如果顺序错了，可能会有问题。比如如果先销毁地址空间，页表就不存在了，后面的操作会失败。

## 用户栈设置（进阶）

对于完整的程序启动，我们还需要在用户栈上设置 `argv` 和 `envp`。这是 POSIX 的标准要求。

```c
int user_setup_user_stack(pcb_t* pcb, const char** argv, const char** envp) {
    if (!pcb || !pcb->is_user_mode) {
        return -1;
    }

    /* TODO: Implement proper argv/envp setup on user stack
     * For now, we just set up a minimal stack */
    (void)argv;
    (void)envp;

    return 0;
}
```

这个函数是一个占位符。完整的实现需要：
1. 计算 argv 和 envp 的大小
2. 在用户栈上分配空间
3. 复制字符串到用户栈
4. 设置指针数组
5. 设置栈指针指向正确的位置

这是一个比较复杂的过程，我们可以在后续完善。现在先保持简单。

⚠️ **常见编译错误**

**错误 1：`pframe_alloc` 未定义**

确保 `mm/pframe/pframe.h` 被包含。这个函数应该在物理帧管理模块中实现。

**错误 2：`vmm_map_to_user` 未定义**

确保 `mm/vmm/vmm.h` 被包含，并且 VMM 模块已实现用户空间映射功能。

**错误 3：`page_virt_to_phys` 未定义**

确保 `mm/page/page.h` 被包含。

void test_user_process_creation(void) {
    klog_info("=== User Process Creation Test ===\n");

        kfree(pcb);
        return;
    }

    /* Create user process (allocates and maps stack) */
    if (user_create_process(0, pcb) != 0) {
        klog_error("Failed to create user process\n");
        vmm_destroy_user_space(pcb->mm.pml4_phys);
        kfree(pcb);
        return;
    }

    /* Verify the PCB */
    klog_info("PCB state:\n");
    klog_info("  is_user_mode: %s\n", pcb->is_user_mode ? "true" : "false");
    klog_info("  user_stack: 0x%llX\n", pcb->user_stack);
    klog_info("  user_stack_size: %lu\n", pcb->user_stack_size);

    /* Verify stack is mapped */
    for (size_t i = 0; i < 256; i++) {  /* Check first 1MB */
        virtual_addr_t vaddr = pcb->user_stack + (i * PAGE_SIZE);
        physical_addr_t phys;
        if (page_virt_to_phys(pcb->mm.pml4_phys, vaddr, &phys) == PAGE_OK) {

                klog_info("  Stack page 0 mapped: 0x%llX -> 0x%X\n", vaddr, phys);

        } else {
            klog_error("  Stack page %zu not mapped!\n", i);
            break;
        }
    }

    /* Cleanup */
    user_destroy_process(pcb);
    kfree(pcb);

    klog_info("=== Test Complete ===\n");
}

## 常见问题

### 问题 1：用户栈未对齐

**症状**：页错误或映射失败

**原因**：栈地址未页对齐

**解决**：确保使用 `& ~(PAGE_SIZE - 1)` 对齐

```c
/* 错误 */
pcb->user_stack = USER_END - USER_STACK_SIZE;

/* 正确 */
pcb->user_stack = (USER_END - USER_STACK_SIZE) & ~(PAGE_SIZE - 1);
```

### 问题 2：物理页分配失败

**症状**：`Failed to allocate user stack page`

**原因**：物理内存不足或页帧分配器有问题

**解决**：
1. 检查物理内存总量
2. 检查页帧分配器是否正确初始化
3. 减少 `USER_STACK_SIZE` 试试

### 问题 3：映射后访问失败

**症状**：栈映射成功，但访问时触发页错误

**原因**：可能页表权限不对，或者映射到了错误的地址空间

**解决**：
1. 检查 `VMAP_FLAG_WRITE | VMAP_FLAG_USER` 是否正确
2. 检查 `pcb->mm.pml4_phys` 是否正确
3. 使用 `vmm_dump_page_table()` 查看页表内容
