# 系统调用扩展 —— uname、brk、mmap

## 前言

在之前的阶段，我们已经实现了一些基础的系统调用，比如 `write()`、`exit()`、`fork()` 等。但用户程序需要的远不止这些。

用户程序需要能够：
- 获取系统信息（`uname()`）
- 管理内存（`brk()`, `mmap()`, `munmap()`）
- 可能还需要一些其他的系统调用

说实话，添加新的系统调用看起来很简单 —— 就是在系统调用表中加一项，实现一个函数。但有一些细节需要注意，特别是用户指针验证。

这篇文章我们会添加几个重要的用户态系统调用，并确保它们是安全的。

---

## 系统调用号定义

首先，我们需要在系统调用头文件中定义新的系统调用号。

打开 `kernel/syscall/syscall.h`（或你的系统调用定义文件），添加以下定义：

```c
/* Memory management */
#define SYS_BRK      20
#define SYS_MMAP     21
#define SYS_MUNMAP   22

/* System information */
#define SYS_UNAME    30
```

⚠️ **注意：系统调用号分配**

系统调用号是稳定的 ABI，一旦分配就不应该改变。选择一个新的系统调用号时：
1. 避免使用已占用的号
2. 为将来预留一些空间
3. 按功能分组（比如 20-29 是内存管理，30-39 是系统信息）

## uname 系统调用

`uname()` 是一个经典的 POSIX 系统调用，用于获取系统信息。

### utsname 结构

首先定义 `utsname` 结构：

```c
/**
 * @brief uname system call structure
 *
 * This structure is defined by POSIX and contains system information.
 */
struct utsname {
    char sysname[65];    /* Operating system name */
    char nodename[65];   /* Network node hostname */
    char release[65];    /* OS release version */
    char version[65];    /* OS version string */
    char machine[65];    /* Hardware identifier */
    char domainname[65]; /* NIS/YP domain name */
};
```

### 实现 uname

```c
/**
 * @brief Get system information (uname)
 */
static int64_t sys_uname(syscall_frame_t* frame) {
    struct utsname* buf = (struct utsname*)frame->arg0;

    /* Validate user pointer */
    pcb_t* current = proc_current();
    if (!current || !user_validate_pointer(buf, sizeof(struct utsname), true)) {
        return SYS_ERR_INVAL;
    }

    /* Create kernel info structure */
    struct utsname kernel_info = {
        .sysname = "CCOS",
        .nodename = "localhost",
        .release = CCOS_VERSION,
        .version = "CCOS x86_64 v" CCOS_VERSION,
        .machine = "x86_64",
        .domainname = "(none current)",
    };

    /* Copy to user space */
    int64_t result = user_copy_to_user(buf, &kernel_info, sizeof(struct utsname));
    if (result < 0) {
        return SYS_ERR_IO;
    }

    return SYS_OK;
}
```

### 代码解释

**用户指针验证**

```c
if (!user_validate_pointer(buf, sizeof(struct utsname), true)) {
    return SYS_ERR_INVAL;
}
```

这是最重要的安全检查。我们确保：
1. `buf` 在用户空间范围内
2. 有足够的空间容纳整个结构
3. 用户有写权限

**填充内核结构**

```c
struct utsname kernel_info = {
    .sysname = "CCOS",
    .nodename = "localhost",
    .release = CCOS_VERSION,
    .version = "CCOS x86_64 v" CCOS_VERSION,
    .machine = "x86_64",
    .domainname = "(none current)",
};
```

我们在内核栈上创建一个临时结构，填充系统信息。注意我们使用 `CCOS_VERSION` 宏来保持版本一致性。

**复制到用户空间**

```c
int64_t result = user_copy_to_user(buf, &kernel_info, sizeof(struct utsname));
```

使用我们之前实现的 `user_copy_to_user()` 来安全地复制数据到用户空间。

### 注册系统调用

```c
void syscall_register_all(void) {
    /* ... other syscalls ... */

    /* System information */
    syscall_register_handler(SYS_UNAME, sys_uname, "uname");
}
```

## brk 系统调用

`brk()` 系统调用已经在上一篇文章中实现了 `user_brk()` 函数，现在我们只需要包装它。

### 实现 brk

```c
/**
 * @brief Change data segment size (brk)
 */
static int64_t sys_brk(syscall_frame_t* frame) {
    void* new_brk = (void*)frame->arg0;
    pcb_t* current = proc_current();

    if (!current) {
        return SYS_ERR_INVAL;
    }

    /* NULL argument queries current break */
    if (new_brk == NULL) {
        return (int64_t)current->mm.brk;
    }

    /* Call user_brk to handle the actual break change */
    virtual_addr_t result = user_brk(current, (virtual_addr_t)new_brk);
    return (int64_t)result;
}
```

### 代码解释

**查询当前断点**

```c
if (new_brk == NULL) {
    return (int64_t)current->mm.brk;
}
```

按照 POSIX 规范，当 `new_brk` 为 NULL 时，应该返回当前断点。

**调用底层函数**

```c
virtual_addr_t result = user_brk(current, (virtual_addr_t)new_brk);
```

我们调用 `user_brk()` 来实际处理断点变更。这样分离关注点，系统调用只负责参数传递和返回值处理。

## mmap 系统调用

`mmap()` 是一个复杂的系统调用，支持多种映射类型。

### POSIX mmap 参数

```c
void* mmap(void* addr, size_t length, int prot, int flags,
           int fd, size_t offset);
```

参数说明：
- `addr`：建议地址（0 表示任意）
- `length`：映射长度
- `prot`：保护标志（PROT_READ, PROT_WRITE, PROT_EXEC）
- `flags`：映射类型（MAP_SHARED, MAP_PRIVATE, MAP_ANONYMOUS, MAP_FIXED）
- `fd`：文件描述符（匿名映射时为 -1）
- `offset`：文件偏移

### 保护标志定义

```c
/* mmap protection flags */
#define PROT_READ      0x1    /* Page is readable */
#define PROT_WRITE     0x2    /* Page is writable */
#define PROT_EXEC      0x4    /* Page is executable */
```

### 映射标志定义

```c
/* mmap mapping flags */
#define MAP_SHARED     0x01   /* Share changes */
#define MAP_PRIVATE    0x02   /* Private copy-on-write */
#define MAP_FIXED      0x10   /* Fixed address */
#define MAP_ANONYMOUS  0x20   /* Anonymous mapping */
```

### 实现 mmap

```c
/**
 * @brief mmap - Map files or devices into memory
 */
static int64_t sys_mmap(syscall_frame_t* frame) {
    virtual_addr_t addr = (virtual_addr_t)frame->arg0;
    size_t length = (size_t)frame->arg1;
    int prot = (int)frame->arg2;
    int flags = (int)frame->arg3;
    int fd = (int)frame->arg4;
    size_t offset = (size_t)frame->arg5;

    (void)fd;     /* No filesystem yet */
    (void)offset; /* No filesystem yet */

    pcb_t* current = proc_current();
    if (!current) {
        return SYS_ERR_INVAL;
    }

    /* Validate flags - only support anonymous private mappings for now */
    if (!(flags & MAP_ANONYMOUS)) {
        return SYS_ERR_NOTIMPL; /* Only anonymous mappings */
    }

    /* Call user_mmap to handle the actual mapping */
    virtual_addr_t result = user_mmap(current, addr, length, prot, flags, fd, offset);
    return (int64_t)result;
}
```

### 代码解释

**当前限制**

```c
if (!(flags & MAP_ANONYMOUS)) {
    return SYS_ERR_NOTIMPL;
}
```

我们当前只支持匿名映射，因为我们还没有文件系统。文件映射（`mmap()` 一个文件）需要文件系统支持。

## munmap 系统调用

`munmap()` 用于取消内存映射。

### 实现 munmap

```c
/**
 * @brief munmap - Unmap memory
 */
static int64_t sys_munmap(syscall_frame_t* frame) {
    virtual_addr_t addr = (virtual_addr_t)frame->arg0;
    size_t length = (size_t)frame->arg1;

    pcb_t* current = proc_current();
    if (!current) {
        return SYS_ERR_INVAL;
    }

    /* Call user_munmap to handle the actual unmapping */
    int result = user_munmap(current, addr, length);
    return (int64_t)result;
}
```

## 用户空间包装

现在用户程序需要能够调用这些系统调用。我们可以在用户库中添加包装函数。

### unistd.h 扩展

打开 `user/include/unistd.h`，添加：

```c
/* System information */
struct utsname {
    char sysname[65];
    char nodename[65];
    char release[65];
    char version[65];
    char machine[65];
    char domainname[65];
};

int uname(struct utsname* buf);

/* Memory management */
void* sbrk(intptr_t incr);

void* mmap(void* addr, size_t length, int prot, int flags,
          int fd, size_t offset);

int munmap(void* addr, size_t length);
```

### unistd.c 实现

在 `user/src/unistd.c` 中添加：

```c
/* ============================================================================
 * System Information
 * ============================================================================ */

int uname(struct utsname* buf) {
    return (int)_syscall1(SYS_UNAME, (long)buf);
}

/* ============================================================================
 * Memory Management
 * ============================================================================ */

void* sbrk(intptr_t incr) {
    return (void*)_syscall1(SYS_BRK, incr);
}

void* mmap(void* addr, size_t length, int prot, int flags, int fd, size_t offset) {
    return (void*)_syscall6(SYS_MMAP, (long)addr, (long)length, (long)prot,
                           (long)flags, (long)fd, (long)offset);
}

int munmap(void* addr, size_t length) {
    return (int)_syscall2(SYS_MUNMAP, (long)addr, (long)length);
}
```

⚠️ **注意：_syscall6 宏**

如果你还没有实现 `_syscall6` 宏（6 参数系统调用），你需要添加它：

```c
/* syscall/x86_64/syscall.c */

static inline long _syscall6(long num, long arg1, long arg2, long arg3,
                             long arg4, long arg5, long arg6) {
    long ret;
    __asm__ volatile(
        "syscall"
        : "=a"(ret)
        : "a"(num), "D"(arg1), "S"(arg2), "d"(arg3),
          "r"(r8), "r"(r9)
        : "rcx", "r11", "memory"
    );
    return ret;
}
```

注意 `mmap()` 的 6 个参数分别放在 `RDI, RSI, RDX, R10, R8, R9` 寄存器中（System V AMD64 ABI）。

⚠️ **常见编译错误**

**错误 1：`_syscall6` 未定义**

```
undefined reference to `_syscall6'
```

**解决**：在 `user/syscall/x86_64/syscall.c` 中添加 `_syscall6` 实现。

**错误 2：`struct utsname` 重定义**

```
error: redefinition of 'struct utsname'
```

**解决**：确保只在头文件中定义一次，使用 `#pragma once` 或 `#ifndef` 保护。

## 验证测试

让我们写一个用户程序来测试新的系统调用：

```c
/* test_uname.c - Test uname syscall */

#define SYS_UNAME    30
#define SYS_WRITE    13
#define SYS_EXIT     0

#define STDOUT_FILENO   1

struct utsname {
    char sysname[65];
    char nodename[65];
    char release[65];
    char version[65];
    char machine[65];
    char domainname[65];
};

static inline long syscall1(long num, long arg1) {
    long ret;
    __asm__ volatile("syscall" : "=a"(ret) : "a"(num), "D"(arg1)
                      : "rcx", "r11", "memory");
    return ret;
}

static inline long syscall3(long num, long arg1, long arg2, long arg3) {
    long ret;
    __asm__ volatile("syscall" : "=a"(ret) : "a"(num), "D"(arg1), "S"(arg2), "d"(arg3)
                      : "rcx", "r11", "memory");
    return ret;
}

static void exit(int status) {
    syscall1(SYS_EXIT, status);
    __builtin_unreachable();
}

static long write(int fd, const void* buf, long count) {
    return syscall3(SYS_WRITE, fd, (long)buf, count);
}

static long str_len(const char* s) {
    long len = 0;
    while (s[len]) len++;
    return len;
}

void _start(void) {
    struct utsname uts;
    char newline = '\n';

    /* Call uname */
    long ret = syscall1(SYS_UNAME, (long)&uts);
    if (ret != 0) {
        const char* err = "uname() failed!\n";
        write(STDOUT_FILENO, err, 16);
        exit(1);
    }

    /* Print results */
    const char* labels[] = {
        "sysname: ",
        "nodename: ",
        "release: ",
        "version: ",
        "machine: ",
        "domainname: "
    };

    char* fields[] = {
        uts.sysname,
        uts.nodename,
        uts.release,
        uts.version,
        uts.machine,
        uts.domainname
    };

    int label_lens[] = { 9, 10, 9, 9, 9, 13 };

    for (int i = 0; i < 6; i++) {
        write(STDOUT_FILENO, labels[i], label_lens[i]);
        long len = str_len(fields[i]);
        write(STDOUT_FILENO, fields[i], len);
        write(STDOUT_FILENO, &newline, 1);
    }

    exit(0);
}
```

运行后应该看到：

```
sysname: CCOS
nodename: localhost
release: 0.1.0
version: CCOS x86_64 v0.1.0
machine: x86_64
domainname: (none current)
```

## 系统调用调试技巧

### 打印系统调用

在开发过程中，你可能想看到每个系统调用的详细信息。可以在系统调用入口添加日志：

```c
/* In syscall_entry() */
void syscall_entry(syscall_frame_t* frame) {
    /* ... */

    klog_trace("[SYSCALL] %s(%llX, %llX, %llX, ...)\n",
              get_syscall_name(frame->number),
              frame->arg0, frame->arg1, frame->arg2);

    /* Call handler */
    /* ... */
}
```

### 统计系统调用

你可以维护一个统计表：

```c
typedef struct syscall_stats {
    uint64_t count;
    uint64_t total_time;
} syscall_stats_t;

static syscall_stats_t s_stats[256];

void syscall_record(uint64_t num, uint64_t time) {
    if (num < 256) {
        s_stats[num].count++;
        s_stats[num].total_time += time;
    }
}
```

### 验证用户指针

在调试时，你可能想看到哪些用户指针验证失败了：

```c
if (!user_validate_pointer(buf, sizeof(struct utsname), true)) {
    klog_warn("[SYSCALL] uname: invalid user pointer 0x%llX\n", buf);
    return SYS_ERR_INVAL;
}
```

## 常见问题

### 问题 1：uname 返回垃圾数据

**症状**：`uname()` 返回成功，但结构中是随机数据

**原因**：用户指针在验证后没有被正确复制

**解决**：确保使用 `user_copy_to_user()` 而不是 `memcpy()`。

### 问题 2：mmap 总是返回 -1

**症状**：`mmap()` 总是失败

**原因**：可能是 flags 检查失败

**解决**：
1. 确保传递 `MAP_ANONYMOUS` (0x20)
2. 检查系统调用号是否正确
3. 检查参数传递顺序

### 问题 3：sbrk 不工作

**症状**：`sbrk()` 返回的地址不正确

**原因**：可能混淆了 `sbrk()` 和 `brk()`

**解决**：
- `brk(addr)` 设置绝对地址
- `sbrk(incr)` 增加相对增量，返回旧地址
