# 用户态支持模块从零实现

## 前言

在上一篇文章中，我们理解了 x86_64 特权级机制的基础知识。现在终于可以开始写代码了。

说实话，写用户态支持模块就像是在给我们的操作系统装"安全门"。我们要确保用户程序不能乱跑，不能访问不该访问的内存，不能破坏内核的数据结构。这需要谨慎的设计和严谨的实现。

这篇文章我们会创建 `kernel/user/` 目录，实现用户指针验证和安全内存复制。这些代码虽然不如 Ring 3 切换那么激动人心，但它们是整个用户态安全性的基础。如果我们在这里偷工减料，后面一定会出问题。

---

现在我们来创建用户态支持模块的目录结构。

## 定义用户空间常量

首先，我们需要定义用户空间的地址范围和栈配置。

打开 `kernel/user/user.h`，我们先来定义基础常量：

```c
/* ==============================================================================
 * CCOS - User Mode Support
 * ==============================================================================
 */

#pragma once

#include "defines/types.h"
#include "mm/vmm/vmm_config.h"
#include "mm/page_config.h"

/* ==============================================================================
 * User Mode Constants
 * ============================================================================== */

/* User space address range */
#define USER_BASE       0x0000000000400000ULL  /* 4MB - NULL protection */
#define USER_END        0xFFFF800000000000ULL  /* Kernel space boundary */

/* User stack configuration */
#define USER_STACK_SIZE    (1 * 1024 * 1024)   /* 1MB user stack */
#define USER_STACK_TOP     (USER_END - 8)       /* Stack top */

/* User mode segment selectors with RPL=3 */
#define USER_CS    (0x18 | 3)   /* GDT_USER_CODE with RPL=3 = 0x1B */
#define USER_SS    (0x20 | 3)   /* GDT_USER_DATA with RPL=3 = 0x23 */
```

### 为什么是这些值？

**USER_BASE = 4MB**

我们保留了最低 4MB 作为 NULL 页保护。这样如果用户程序尝试解引用 NULL 指针，会立即触发页错误。这是一种安全措施。

**USER_END = 0xFFFF800000000000**

这是 x86_64 的 canonical 地址边界。高于这个地址的是内核空间，低于这个的是用户空间。

**USER_STACK_SIZE = 1MB**

1MB 的栈空间对于大多数用户程序来说足够了。如果程序需要更多，我们可以以后实现栈扩展机制。

## 用户上下文结构

我们需要一个结构来保存从 Ring 0 切换到 Ring 3 所需的信息。

```c
/* ==============================================================================
 * User Context Structure
 * ============================================================================== */

/**
 * @brief User context for Ring 3 transition
 *
 * This structure contains the information needed to switch from
 * kernel mode (Ring 0) to user mode (Ring 3) via iretq.
 */
typedef struct user_context {
    virtual_addr_t entry;      /* Entry point (user RIP) */
    virtual_addr_t stack_top;  /* Top of user stack (user RSP) */
    uint64_t cs;               /* User CS selector (must have RPL=3) */
    uint64_t ss;               /* User SS selector (must have RPL=3) */
    uint64_t rflags;           /* User RFLAGS (IF bit usually set) */
} user_context_t;
```

这个结构对应 iretq 栈帧的五个字段。后面我们会看到如何使用它。

## 用户指针验证

现在来实现最关键的安全功能：用户指针验证。

### 为什么需要验证？

当用户程序通过系统调用传递指针给内核时，我们必须验证这些指针：
1. 指针必须指向用户空间，不能指向内核空间
2. 指针 + 访问长度不能溢出
3. 指针不能在 NULL 页保护区域

如果我们不验证，恶意程序可能会传递一个内核地址给我们，然后我们就把数据复制到了内核空间，这是非常危险的。

### 实现验证函数

在 `kernel/user/user.c` 中实现 `user_validate_pointer`：

```c
/* ==============================================================================
 * Safe User Memory Access
 * ============================================================================== */

bool user_validate_pointer(const void* ptr, size_t size, bool write) {
    (void)write;  /* TODO: Use write flag to check page permissions */

    virtual_addr_t addr = (virtual_addr_t)ptr;

    /* Check if address is in user space range */
    if (!vmm_is_user_addr(addr)) {
        return false;
    }

    /* Check for overflow: addr + size must not wrap around */
    if (addr + size < addr) {
        return false;
    }

    /* Check if the entire range fits in user space */
    if (addr + size > USER_END) {
        return false;
    }

    /* Check for NULL page access (first 4MB is protected) */
    if (addr < USER_BASE) {
        return false;
    }

    return true;
}
```

### 每个检查的含义

**`vmm_is_user_addr(addr)` 检查**

这个函数由 VMM 模块提供，检查地址是否在用户空间范围内。这是第一道防线。

**溢出检查 `addr + size < addr`**

这是一个常见的整数溢出漏洞。如果 `addr` 是一个非常大的值，加上 `size` 可能会溢出回小值。比如：

```c
// 假设 addr = 0xFFFFFFFFFFFFFFF0, size = 0x100
// addr + size = 0x100 (溢出了！)
// 如果我们不检查，这个范围看起来是合法的
```

**USER_END 检查**

确保整个访问范围都在用户空间内。

**USER_BASE 检查**

拒绝访问 NULL 页。这可以快速捕获空指针解引用。

⚠️ **注意**

我们当前的实现是简化版。完整的实现应该还要：
1. 遍历页表，检查每页是否已映射
2. 根据 `write` 参数检查页的读写权限
3. 处理按需分页 (demand paging)

这些功能可以后续添加。现在先确保基础安全。

## 安全的内存复制

有了验证函数，我们就可以实现安全的内存复制了。

### 从用户空间复制

```c
int64_t user_copy_from_user(void* dst, const void* src, size_t count) {
    if (count == 0) {
        return 0;
    }

    /* Validate source pointer is in user space */
    if (!user_validate_pointer(src, count, false)) {
        klog_warn("[USER] Invalid user pointer in copy_from_user: 0x%llX\n",
                  (virtual_addr_t)src);
        return -1;
    }

    /* For now, just do a direct copy. A full implementation would
     * use page fault fixup to handle unmapped pages gracefully. */
    memcpy(dst, src, count);
    return (int64_t)count;
}
```

**解释**：
1. 首先验证源指针在用户空间
2. 如果验证失败，记录警告并返回错误
3. 验证通过后，执行复制
4. 返回复制的字节数

### 到用户空间复制

```c
int64_t user_copy_to_user(void* dst, const void* src, size_t count) {
    if (count == 0) {
        return 0;
    }

    /* Validate destination pointer is in user space */
    if (!user_validate_pointer(dst, count, true)) {
        klog_warn("[USER] Invalid user pointer in copy_to_user: 0x%llX\n",
                  (virtual_addr_t)dst);
        return -1;
    }

    memcpy(dst, src, count);
    return (int64_t)count;
}
```

### 字符串复制

对于字符串，我们需要特殊处理，因为不知道长度：

```c
int64_t user_strncpy_from_user(char* dst, const char* src, size_t max_len) {
    if (max_len == 0) {
        return 0;
    }

    /* Validate source pointer is in user space */
    if (!user_validate_pointer(src, max_len, false)) {
        klog_warn("[USER] Invalid user string pointer: 0x%llX\n",
                  (virtual_addr_t)src);
        return -1;
    }

    /* Copy string, ensuring we don't read past max_len */
    size_t i;
    for (i = 0; i < max_len; i++) {
        dst[i] = src[i];
        if (src[i] == '\0') {
            return (int64_t)i;  /* Return length excluding null */
        }
    }

    /* String wasn't null-terminated within max_len */
    dst[max_len - 1] = '\0';
    return (int64_t)max_len;
}
```

**注意**：这个函数确保不会读取超过 `max_len` 的字节，即使字符串没有 null 终止符。

### 字符串验证

有时候我们只需要验证字符串是否合法，不需要复制：

```c
bool user_validate_string(const char* str, size_t max_len) {
    if (!user_validate_pointer(str, max_len, false)) {
        return false;
    }

    /* Check if string is null-terminated within max_len */
    for (size_t i = 0; i < max_len; i++) {
        if (str[i] == '\0') {
            return true;
        }
    }

    return false;
}
```

## 用户内存区域类型

为了方便管理用户空间的内存区域，我们定义一个类型枚举：

```c
/* ==============================================================================
 * User Memory Region Types
 * ============================================================================== */

typedef enum user_region_type {
    USER_REGION_TEXT,      /* Executable code */
    USER_REGION_DATA,      /* Read-write data */
    USER_REGION_RODATA,    /* Read-only data */
    USER_REGION_HEAP,      /* Heap (grows upward) */
    USER_REGION_STACK,     /* Stack (grows downward) */
    USER_REGION_MMAP,      /* Memory-mapped region */
} user_region_type_t;

/* ==============================================================================
 * User Memory Region Descriptor
 * ============================================================================== */

/**
 * @brief User memory region descriptor
 *
 * This structure describes a region of user memory.
 * It can be used for debugging and memory management.
 */
typedef struct user_region {
    virtual_addr_t start;           /* Region start */
    virtual_addr_t end;             /* Region end */
    physical_addr_t phys_start;     /* Physical address (0 if anonymous) */
    uint64_t flags;                 /* Protection flags */
    user_region_type_t type;        /* Region type */
    char name[32];                  /* Region name for debugging */
} user_region_t;
```

## 完整的头文件

现在让我们把头文件的其他部分补充完整：

```c
/* ==============================================================================
 * User Mode Process Creation API
 * ============================================================================== */

/**
 * @brief Create a new user mode process
 * @param entry Entry point address
 * @param pcb Pointer to PCB to initialize
 * @return 0 on success, negative on error
 */
int user_create_process(virtual_addr_t entry, pcb_t* pcb);

/**
 * @brief Destroy a user mode process and free its resources
 * @param pcb Process PCB to destroy
 */
void user_destroy_process(pcb_t* pcb);

/* ==============================================================================
 * Safe User Memory Access API
 * ============================================================================== */

bool user_validate_pointer(const void* ptr, size_t size, bool write);
int64_t user_copy_from_user(void* dst, const void* src, size_t count);
int64_t user_copy_to_user(void* dst, const void* src, size_t count);
int64_t user_strncpy_from_user(char* dst, const char* src, size_t max_len);
bool user_validate_string(const char* str, size_t max_len);

/* ==============================================================================
 * User Memory Region Management
 * ============================================================================== */

/**
 * @brief Map a memory region into user space
 * @param pcb Process PCB
 * @param vaddr Virtual address (0 for auto-allocate)
 * @param size Size of region (must be page-aligned)
 * @param flags Protection flags (VMAP_FLAG_*)
 * @param type Region type
 * @param name Region name for debugging
 * @return Mapped virtual address, or 0 on error
 */
virtual_addr_t user_map_region(pcb_t* pcb, virtual_addr_t vaddr, size_t size,
                               uint64_t flags, user_region_type_t type,
                               const char* name);

/**
 * @brief Unmap a memory region from user space
 * @param pcb Process PCB
 * @param vaddr Virtual address to unmap
 * @param size Size of region
 * @return 0 on success, negative on error
 */
int user_unmap_region(pcb_t* pcb, virtual_addr_t vaddr, size_t size);

/* ==============================================================================
 * Heap Management API
 * ============================================================================== */

/**
 * @brief Set program break (traditional brk syscall)
 * @param pcb Process PCB
 * @param new_brk New program break
 * @return New program break, or 0 on error
 */
virtual_addr_t user_brk(pcb_t* pcb, virtual_addr_t new_brk);

/**
 * @brief Map memory into user space (mmap syscall)
 * @param pcb Process PCB
 * @param addr Suggested address (0 for any)
 * @param length Length of mapping
 * @param prot Protection flags
 * @param flags Mapping flags
 * @param fd File descriptor (0 for anonymous)
 * @param offset File offset
 * @return Mapped address, or 0 on error
 */
virtual_addr_t user_mmap(pcb_t* pcb, virtual_addr_t addr, size_t length,
                        int prot, int flags, int fd, size_t offset);

/**
 * @brief Unmap memory from user space
 * @param pcb Process PCB
 * @param addr Address to unmap
 * @param length Length of region
 * @return 0 on success, negative on error
 */
int user_munmap(pcb_t* pcb, virtual_addr_t addr, size_t length);

/* ==============================================================================
 * Ring 3 Transition
 * ============================================================================== */

/**
 * @brief Execute transition from Ring 0 to Ring 3
 *
 * This function does NOT return. It loads the user context and
 * executes an iretq to switch to user mode.
 *
 * @param ctx User context to load
 */
void user_switch_to_usermode(user_context_t* ctx) __attribute__((noreturn));

/* ==============================================================================
 * Initialization
 * ============================================================================== */

int user_init(void);
```

## CMakeLists.txt 配置

现在我们需要配置构建系统。

创建 `kernel/user/CMakeLists.txt`：

```cmake
# ==============================================================================
# CCOS - User Mode Support Module
# ==============================================================================

set(USER_SOURCES
    user.c
)

set(USER_ASM_SOURCES
    user_enter.asm
)

add_library(user_obj OBJECT ${USER_SOURCES})

target_compile_options(user_obj PRIVATE
    ${CCOS_KERNEL_COMPILE_FLAGS}
)

target_include_directories(user_obj PRIVATE
    ${CMAKE_SOURCE_DIR}
    ${CMAKE_SOURCE_DIR}/kernel
)

# Add user mode support to the kernel
list(APPEND KERNEL_SOURCES
    $<TARGET_OBJECTS:user_obj>
)

# Assembly source
add_library(user_asm OBJECT ${USER_ASM_SOURCES})

target_include_directories(user_asm PRIVATE
    ${CMAKE_SOURCE_DIR}
    ${CMAKE_SOURCE_DIR}/kernel
)

list(APPEND KERNEL_ASM_OBJECTS
    $<TARGET_OBJECTS:user_asm>
)
```

然后在父目录的 `CMakeLists.txt` 中添加这个子目录。

⚠️ **常见编译错误**

**错误 1：`vmm_is_user_addr` 未定义**

确保 `mm/vmm/vmm.h` 被正确包含。这个函数应该已经在 VMM 模块中实现。

**错误 2：`PAGE_SIZE` 未定义**

确保 `mm/page_config.h` 被包含。

**错误 3：链接错误**

检查 `CMakeLists.txt` 中的对象文件是否正确添加到内核链接列表。

## 验证测试

让我们写一个简单的测试来验证用户指针验证是否工作。

在内核初始化代码中添加：

```c
void test_user_pointer_validation(void) {
    klog_info("=== User Pointer Validation Test ===\n");

    /* Test 1: Valid user pointer */
    char* user_ptr = (char*)0x400000;
    bool valid = user_validate_pointer(user_ptr, 100, false);
    klog_info("Test 1 - Valid user pointer: %s\n", valid ? "PASS" : "FAIL");

    /* Test 2: Kernel pointer should be rejected */
    char* kernel_ptr = (char*)0xFFFF8000000000000ULL;
    valid = user_validate_pointer(kernel_ptr, 100, false);
    klog_info("Test 2 - Kernel pointer rejected: %s\n", !valid ? "PASS" : "FAIL");

    /* Test 3: NULL pointer should be rejected */
    char* null_ptr = NULL;
    valid = user_validate_pointer(null_ptr, 10, false);
    klog_info("Test 3 - NULL pointer rejected: %s\n", !valid ? "PASS" : "FAIL");

    /* Test 4: Overflow test */
    virtual_addr_t overflow_addr = 0xFFFFFFFFFFFFFFF0ULL;
    valid = user_validate_pointer((void*)overflow_addr, 0x100, false);
    klog_info("Test 4 - Overflow detected: %s\n", !valid ? "PASS" : "FAIL");

    klog_info("=== Tests Complete ===\n");
}
```

在 `user_init()` 之后调用这个测试函数，你应该看到所有测试都通过：

```
=== User Pointer Validation Test ===
Test 1 - Valid user pointer: PASS
Test 2 - Kernel pointer rejected: PASS
Test 3 - NULL pointer rejected: PASS
Test 4 - Overflow detected: PASS
=== Tests Complete ===
```
