# 实现线程管理

## 前言

进程是资源分配的单位，线程是调度的单位。一个进程可以包含多个线程，这些线程共享进程的地址空间、文件描述符等资源，但每个线程有独立的栈和寄存器状态。

线程的优势在于轻量级。创建线程比创建进程快得多，线程切换也比进程切换快，因为不需要切换地址空间。这使得线程非常适合处理并行任务，比如服务器同时处理多个客户端连接。

但线程也有代价。由于共享地址空间，线程间可以直接访问彼此的内存，这虽然方便通信，但也容易引入竞争条件。多个线程同时访问共享数据时，必须用锁或其他同步机制来保护，否则会出现数据不一致。

## 线程与进程的区别

在设计线程管理之前，让我们明确一下线程和进程的区别：

**地址空间** - 进程有独立的地址空间，线程共享进程的地址空间。这意味着线程可以直接访问进程的全局变量和堆内存，但不能访问其他线程的栈。

**资源** - 进程有独立的文件描述符表、信号处理等，线程共享这些资源。关闭文件会影响同一进程的所有线程。

**创建开销** - 创建进程需要复制页表、分配新的内存，创建线程只需要分配新的栈。线程创建通常比进程创建快 10-100 倍。

**切换开销** - 进程切换需要切换 CR3（页表），线程切换不需要。线程切换通常比进程切换快 5-10 倍。

**通信** - 进程间通信需要 IPC（管道、共享内存、消息队列等），线程间可以直接访问共享内存，但需要同步机制。

## PCB 中的线程相关字段

我们在 PCB 中预留了一些线程相关的字段：

```c
typedef struct pcb {
    /* ... other fields ... */

    /* Thread Identification */
    int32_t            tgid;           /* Thread Group ID */
    bool               is_thread;      /* Is this a thread, not a process */
    list_head          thread_list;    /* Threads in this thread group */
    list_head          thread_group;   /* Node in leader's thread_list */

    /* Address Space Reference Counting */
    atomic_t           mm_refcount;    /* Reference count for shared mm */

    /* Thread Join Support */
    void*              join_waiters;   /* Opaque pointer to wait_queue_head_t */
    bool               detached;       /* Thread cannot be joined */
    void*              return_value;   /* Thread return value */

    /* Thread Entry Point */
    virtual_addr_t     thread_entry;   /* User space function pointer */
    virtual_addr_t     thread_arg;     /* Argument to thread function */
} pcb_t;
```

`tgid` 是线程组 ID，等于主线程的 PID。同一进程的所有线程有相同的 `tgid`，但有不同的 `pid`（在 Linux 中，线程也叫"轻量级进程"，有自己的 PID）。

`is_thread` 标志这个 PCB 是线程还是进程。如果是线程，它共享父进程的地址空间；如果是进程，它有独立的地址空间。

`thread_list` 是线程组的所有线程链表，由主线程（线程组组长）维护。

`mm_refcount` 是地址空间的引用计数。进程退出时，只有当引用计数归零才真正销毁地址空间。这确保了只要还有一个线程存活，地址空间就不会被释放。

`join_waiters` 是等待这个线程结束的其他线程的等待队列。`detached` 标志线程是否可以被 join。如果 detached，线程结束时不会通知等待者，返回值也会被丢弃。

`return_value` 存储线程的返回值，join 时可以获取。

`thread_entry` 和 `thread_arg` 是线程的入口函数和参数。

## 创建内核线程

内核线程是只在内核态运行的线程，没有用户地址空间。它们常用于后台任务，如内核守护进程、定时器处理等。

```c
pcb_t* proc_create_kernel_thread(thread_fn_t fn, void* arg, const char* name) {
    /* Allocate PCB */
    pcb_t* thread = proc_alloc_pcb();
    if (!thread) {
        return NULL;
    }

    /* Allocate PID */
    thread->pid = pid_alloc();
    if (thread->pid < 0) {
        proc_free_pcb(thread);
        return NULL;
    }

    /* Set up thread info */
    thread->ppid = proc_current() ? proc_current()->pid : 0;
    thread->state = PROC_READY;
    thread->is_thread = true;
    thread->is_user_mode = false;

    /* Copy name */
    if (name) {
        for (int i = 0; i < 15; i++) {
            thread->comm[i] = name[i];
            if (name[i] == '\0') break;
        }
        thread->comm[15] = '\0';
    }

    /* Share address space with current process */
    pcb_t* current = proc_current();
    if (current) {
        thread->mm = current->mm;
        thread->tgid = current->tgid;
        thread->parent = current;
        atomic_inc(&current->mm_refcount);

        /* Add to thread group */
        list_add_tail(&thread->thread_group, &current->thread_list);
    }

    /* Set up CPU context to start at thread function */
    thread->cpu_ctx->rip = (uint64_t)fn;
    thread->cpu_ctx->rsp = thread->kernel_stack;

    /* Pass arg through RDI (first argument register) */
    /* We'll need to modify switch_to_first or create a wrapper */
    /* For now, store arg in pcb and let the thread function retrieve it */
    thread->thread_arg = (virtual_addr_t)arg;

    /* Initialize scheduling entity */
    sched_set_policy(thread, SCHED_NORMAL, 0);

    /* Add to run queue */
    sched_enqueue_task(thread, false);

    klog_info("[PROC] Created kernel thread: PID=%d, name=%s\n",
              thread->pid, thread->comm ? thread->comm : "(null)");

    return thread;
}
```

内核线程共享当前进程的地址空间（增加引用计数），设置入口函数为指定的线程函数。注意这里有一个简化：我们通过 `thread_arg` 传递参数，线程函数需要从 PCB 中读取。

## 创建用户线程

用户线程是运行在用户态的线程，有用户栈，可以执行用户代码。创建用户线程更复杂，因为需要设置用户栈和陷阱帧。

```c
int32_t proc_create_user_thread(pcb_t* parent, virtual_addr_t entry,
                                virtual_addr_t arg,
                                virtual_addr_t stack_addr,
                                size_t stack_size) {
    if (!parent) {
        return -1;
    }

    /* Allocate PCB */
    pcb_t* thread = proc_alloc_pcb();
    if (!thread) {
        return -1;
    }

    /* Allocate PID */
    thread->pid = pid_alloc();
    if (thread->pid < 0) {
        proc_free_pcb(thread);
        return -1;
    }

    /* Set up thread info */
    thread->ppid = parent->pid;
    thread->state = PROC_READY;
    thread->is_thread = true;
    thread->is_user_mode = true;
    thread->tgid = parent->tgid;
    thread->parent = parent;

    /* Share address space with parent */
    thread->mm = parent->mm;
    atomic_inc(&parent->mm_refcount);
    list_add_tail(&thread->thread_group, &parent->thread_list);

    /* Set up user stack */
    if (stack_addr == 0) {
        /* Allocate new stack */
        size_t stack_pages = (stack_size + PAGE_SIZE - 1) / PAGE_SIZE;
        for (size_t i = 0; i < stack_pages; i++) {
            virtual_addr_t vaddr = USER_STACK - (i + 1) * PAGE_SIZE;
            physical_addr_t paddr = pframe_alloc();
            if (paddr == 0) {
                /* Cleanup and fail */
                proc_free_pcb(thread);
                return -1;
            }
            page_map_page(thread->mm.pml4_phys, vaddr, paddr,
                          PAGE_FLAG_WRITE | PAGE_FLAG_USER);
        }
        thread->user_stack = USER_STACK - stack_pages * PAGE_SIZE;
        thread->user_stack_size = stack_pages * PAGE_SIZE;
    } else {
        /* Use provided stack */
        thread->user_stack = stack_addr;
        thread->user_stack_size = stack_size;
    }

    /* Set up trap frame */
    thread->trap_frame = (trap_frame_t*)kmalloc(sizeof(trap_frame_t));
    if (!thread->trap_frame) {
        proc_free_pcb(thread);
        return -1;
    }
    memset(thread->trap_frame, 0, sizeof(trap_frame_t));

    /* Set up entry point and argument */
    thread->trap_frame->rip = entry;
    thread->trap_frame->rdi = arg;  /* First argument */
    thread->trap_frame->rsp = thread->user_stack + thread->user_stack_size;
    thread->trap_frame->cs = 0x23;  /* User code segment (3 + ring) */
    thread->trap_frame->ss = 0x1B;  /* User data segment (3 + ring) */
    thread->trap_frame->rflags = 0x202;  /* Interrupts enabled */

    thread->has_saved_trap_frame = true;

    /* Initialize scheduling entity */
    sched_set_policy(thread, SCHED_NORMAL, 0);

    /* Add to run queue */
    sched_enqueue_task(thread, false);

    klog_info("[PROC] Created user thread: TID=%d, entry=%p\n",
              thread->pid, (void*)entry);

    return thread->pid;
}
```

用户线程需要分配用户栈（如果没有提供），设置陷阱帧以便通过 `iretq` 进入用户态。入口函数和参数分别设置到 `rip` 和 `rdi`。

## 线程退出

线程退出比进程退出简单一些，因为不需要处理子进程：

```c
void proc_thread_exit(void* retval) {
    pcb_t* current = proc_current();
    if (!current) {
        /* No current thread, just halt */
        while (1) {
            __asm__ volatile("hlt");
        }
    }

    klog_info("[PROC] Thread %d exiting\n", current->pid);

    /* Save return value for join */
    current->return_value = retval;

    /* If detached, free immediately */
    if (current->detached) {
        if (atomic_dec_and_test(&current->mm_refcount)) {
            vmm_destroy_user_space(current->mm.pml4_phys);
        }
        proc_free_pcb(current);
        schedule();
        __builtin_unreachable();
    }

    /* Otherwise, become zombie and wake joiners */
    current->state = PROC_ZOMBIE;
    list_del(&current->run_list);

    /* TODO: Wake up joiners */
    /* wakeup(&current->join_waiters); */

    schedule();
    __builtin_unreachable();
}
```

如果线程是 detached 的，退出时立即释放资源。否则变成僵尸，等待其他线程 join。

## 线程 Join

join 让一个线程等待另一个线程结束，并获取返回值：

```c
int32_t proc_thread_join(int32_t tid, void** retval) {
    pcb_t* current = proc_current();
    if (!current) {
        return -1;
    }

    /* Find target thread */
    pcb_t* target = proc_find_by_tid(tid);
    if (!target) {
        return -1; /* No such thread */
    }

    /* Check if detached */
    if (target->detached) {
        return -1; /* Cannot join detached thread */
    }

    /* TODO: Implement blocking wait */
    /* For now, just check if target is zombie */
    if (target->state != PROC_ZOMBIE) {
        return -1; /* Not exited yet */
    }

    /* Get return value */
    if (retval) {
        *retval = target->return_value;
    }

    /* Free target */
    if (atomic_dec_and_test(&target->mm_refcount)) {
        vmm_destroy_user_space(target->mm.pml4_phys);
    }
    proc_free_pcb(target);

    return 0;
}
```

当前实现是简化的：只能 join 已经退出的线程。完整的实现应该支持阻塞等待，使用等待队列机制。

## 线程 Detach

detach 让线程变成"不可 join"的状态：

```c
int32_t proc_thread_detach(int32_t tid) {
    pcb_t* target = proc_find_by_tid(tid);
    if (!target) {
        return -1;
    }

    target->detached = true;

    /* If already zombie, free immediately */
    if (target->state == PROC_ZOMBIE) {
        if (atomic_dec_and_test(&target->mm_refcount)) {
            vmm_destroy_user_space(target->mm.pml4_phys);
        }
        proc_free_pcb(target);
    }

    return 0;
}
```

## 测试线程管理

让我们写一个简单的测试来验证线程管理：

```c
bool test_thread_creation(void) {
    klog_info("[PROC_DEMO] Test: Thread Creation...\n");

    /* Create a parent process */
    pcb_t* parent = proc_alloc_pcb();
    if (!parent) {
        return false;
    }

    parent->pid = 1;
    parent->tgid = 1;
    parent->ppid = 0;
    parent->state = PROC_RUNNING;
    parent->mm_refcount.data = 1;
    INIT_LIST_HEAD(&parent->thread_list);
    scheduler.current = parent;

    /* Create a kernel thread */
    static volatile bool thread_ran = false;
    void test_thread_fn(void* arg) {
        (void)arg;
        thread_ran = true;
        proc_thread_exit(NULL);
    }

    pcb_t* thread = proc_create_kernel_thread(test_thread_fn, NULL, "test");
    if (!thread) {
        klog_error("[PROC_DEMO] Failed to create thread\n");
        return false;
    }

    /* Verify thread was created */
    if (thread->pid <= 0) {
        klog_error("[PROC_DEMO] Thread has invalid PID\n");
        return false;
    }

    if (!thread->is_thread) {
        klog_error("[PROC_DEMO] Thread is not marked as thread\n");
        return false;
    }

    klog_info("[PROC_DEMO] Thread Creation test PASSED\n");
    return true;
}
```
